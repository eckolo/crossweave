# AZ追比較：時刻114で4回復を一度早く使う

2026-09-12。[自然な6設置の観測](検討結果.md)を保全したうえで、そこで初めて正の回復が合法になる時刻114から、回復草を一度だけ早く使った。以後は元のAV `leave_support` に戻し、元の12手終点までに残っていた**9P手**と同じ予算で止めた。

**設置は4回から1回、攻撃は3回から6回になったが、終点余力は変わらず、V0へのHP進展は1少なく、内部時間は4長くなった。** 設置連続が切れたことだけを改善とは数えない。早回復を採用する根拠にはしていない。

## 期限1の札は消滅せず、別の経路で循環した

追比較では回復草を時刻114に使うと、A札が実際に手札から失効し、`reason: expiry`で共有の回収山へ戻った。この個体は破壊されていない。基準では同じ札を設置して手札期限による失効を避けていた。

| 同一個体 `V1_initial_0025` | 基準 | 早回復 |
|---|---|---|
| 時刻114 | PがA素材として設置 | Pの未使用手札から期限失効、回収山へ |
| 時刻120 | V0の防御材料として回収後、V1へ再配分 | V0へ再配分 |
| 後続の設置 | V1が150に設置 | V0が170に設置 |
| Pによる再利用 | 150に攻撃材料、V0へHP6・探査90 | 174に防御材料 |

失効が早まったために同個体がどの主体へ戻り、何の材料になるかも変わった。これは実現した循環の追跡であり、時刻114でプレイヤーに先の配分を見せて判断させたものではない。

早回復枝では全9手で失効が**6回、5個体**あった。内訳は114の上記A札、124・134の踏み込みB各1個体、144・194の同じV0由来B札、174のV0由来D札。複数回循環した同個体の失効を別の札の数へ読み替えない。回復後に元方策へ戻って攻撃を選び続ける間にも、他の手札が失効して補充が進んだ。

基準で詳細な失効・補充イベントが残っているのは、今回の開始から先頭4P手、次の操作可能時刻150までである。この同じ4P手予算では**基準0回、早回復4回**（早回復側の次操作可能時刻154）と照合できる。基準の残り5手はAVの要約行動列に失効欄がなく、元9手全体の失効総数は未保存のまま不明とした。これを0と見なしたり、数字を埋めるために基準を再走したりはしていない。

## 判断に使える範囲

4回復を早める選択には、期限1の非回復札を今の手札から失い、場素材と回収・補充の経路が変わるという具体的な機会費用があった。一方、その札は循環から永久に消えるわけでもない。元方策の温存は「回復が合法でない」ためではなく、このような状況で全量回復または期限1まで待つ閾値によるものと整理できる。

今回、早回復後は設置が減り攻撃が増えたが、同じP手数の終点で余力・保護成果の上積みはなく、V0のHP進展と時間も優位ではなかった。これで早回復一般が劣るとも、元方策が最適とも言わない。単一の既存局面に対する1回だけの変更から、設置回数の少なさを改善代理指標にできないことが確認できた。

追加枝はこの1本で終了した。最終クリアまでの延長、別閾値・別局面・新seed、数値の正式採用、人の退屈や面白さの判断は行っていない。基礎仕様0.53／D53は維持している。

# AU1 — 成長段階・取得札の構築と共有循環

2026-09-12。基点 `b4594629cd721ab9b288f7b57daf4e66fda4639e`。基本設計0.53・D53を維持する設計検討と処理検証。正式な数値採用、画面実装、人の試遊ではない。

## 今回の判断

取得札を出発札組へ入れ、探索・共有循環・帰還・保存へ接続した。取得品は序盤だけでなく、自分が捨て場から山札を補充した後にも使われ、他主体も同じ性能を利用した。持込構築が混入後に無意味になる、という結果ではない。

一方、取得札の自動投入を強化の保証にはできない。同じ所持・装備・乱数から48対を比較すると、初期札では敗北した条件が取得札でクリアへ変わったのは6対、逆は4対。両方クリアの36対では取得札側が平均2.36行動長く、差は24行動短縮〜35行動延長だった。用途と場への供給を含めて組み替える理由を示す準備表示を優先する。

Cの霧先行では取得札を使った初期4条件が全敗したが、同じ取得札で目的先行は4条件ともクリア。これだけで札や隠蔽の値を一律に弱めず、対象選択と共有の場の扱いを切り分ける。次に詰める数値は、判断を変えた後も負担だけが続く区間を特定してから選ぶ。

## 1. 成長段階の仮置き

段階は全習得率や周回数だけで区切らず、「使える準備」と「判断が変わる理由」で置く。以下は全編の量・終点・解放条件の新たな採用ではない。

| 段階 | 用意したい手段 | 主な判断 | 現行試作との対応 |
|---|---|---|---|
| 最初の探索 | 初期通常札だけで複数の配分。取得品や購入は不要 | 道へ進展を出す／任意対象を狙う、場へ置く／一致で使う、保護後に戻る | 初期0pt・取得品なし。A/Bから選択する既存仮案 |
| 最初の持帰り後 | 習得点による基礎の選択、実際に得た札・心得一個からの変更 | 今回の失敗や目標に対して一枠を何へ替えるか。反対側の成果も必要か | A/Bの片方クリアでCが開く仮案。今回は4経過とも一探索目に初クリアし、二探索目に基礎一種と取得札一枚でCへ |
| 複数の役割を組み合わせる段階 | 基礎を広く習得し、容量内で同種・混合・修飾を選ぶ。手放す品にも用途 | 単純な上位品選びに加え、対象、札の由来、場作用、行動時間に合わせて構成を変える | 全4基礎を学んだ出発は全4経過で四探索目。C初クリアはその前。全習得を次の攻略の必須条件にしない |
| 一通りの攻略後を含む継続収集 | 基礎全習得を許し、複数修飾・得意不得意のある個体・目的別の再訪を続ける | 同じ場所を楽に通る／別の成果を狙う／異なる条件を攻略する | 八帰還時は全4基礎・所持12〜19個。これは小さなA/B/C試作の到達状態であり、製品全編の終点ではない。以後の内容・物語の節目は別途接続 |

全習得を遅らせることを調整の目的にしない。早めに基礎が揃っても組合せの選択が続けばよい。逆に、取得個体が増えても同じ操作・同じ目的しか残らないなら、取得数を増やすだけでは解決しない。

## 2. 接続した範囲と具体案

- 持込12枚・基礎単位2枚までを継承する試行。修飾名を変えて上限を回避しない。帰還後のAPIで任意の合法な札組へ変更できる。
- 初期十種の通常札は無料の選択肢。取得札は所持個体一個につき持込一枚を認める仮案。同じ個体の二重指定は拒否し、別個体なら基礎上限内で二枚を使える。
- 旧AHの「解放済み基礎なら通常札を自由に作る」入口は、AUでは所持確認の後だけ使う。記録に解放が残っていても、最後の所持品を変換すれば初期無料札以外を持ち込めない。解放・知識と所持を区別するAP案の接続であり、新たな正式採用ではない。
- 選択中の品は変換対象から保護。外して売る場合も、他の札や心得を勝手に変更しない。探索用の現物、借り札、補充札から売却可能な在庫を作らない。
- 修飾・出現元・札の寿命・捨てる時の消滅を探索中の現物へ保持。他主体に渡っても同じ札性能を用い、その主体の効果だけを別途適用する。
- 消費型札を探索で使い切っても、持帰り済みの所持個体は失わない。次回の準備に補充料を加えない。取得札は進行中の山札へ自動追加しない。

自由編集の入口を実装したことと、人が自由に構築して評価したことは別。今回の比較方策は事前に決めた一〜数枚の交換で、全組合せ探索やUIの完成ではない。

## 4. 共有循環の前後で何が残ったか

以下は96比較の集計。「補充前後」は**Pが初めて捨て場から山札を補充した前後**。他主体はそれ以前にも補充するため、共有が完全に始まっていない期間とは呼ばない。

| 指標 | Pの初回補充前 | Pの初回補充後 |
|---|---:|---:|
| Pの行動 | 715 | 2,513 |
| Pが自分の初期札を使用 | 715 | 1,205 |
| Pが借り札を使用 | 0 | 1,308 |
| Pが持込取得札を使用 | 65 | 114 |
| Pが場の持込取得札を材料に使用 | 0 | 40 |

他主体による持込取得札の使用は105回、場の材料としての利用は66回。例えば「堅い・踏ん張り」を敵が身構に使い、また場へ置く経過があった。札を強くすることには、自分で使う利点と他主体に利用される変化の両方がある。環境も利用者に含むため、105回をそのまま敵の強化回数や被害増加へ読み替えない。

### Cだけの追加確認：公開順を見た設置

上記のCでの差を受け、[追確認条件](followup-conditions.json)を固定した。最初の4帰還を同じ条件で再現し、新方策でCの8枝だけを追加。元のCの16結果はAU1を読み、再調整していない。

目的先行を基本に、今の一手で終えられる支援対象を優先候補とし、設置時には公開された敵の次行動時刻と場の補正を使って同じ期限の札を比較した。敵の非公開手札・未来の札順は参照しない。場補正の総合点は候補選択の仮の目安で、将来被害の確定予測ではない。

[結果](followup-results.json)は初期札・取得札とも4/4クリア。取得札では平均49.00→41.75行動、帰還HP17.25→23.50。個別の行動数は63→37、34→34、58→45、41→51で、短縮2・同数1・延長1だった。変更した設置は全8枝で11手。支援対象を今すぐ終える条件は**一度も成立せず**、その選択規則の有効性は未確認。

この範囲では、公開順と場の材料を見直すだけでも経過が変わる。ただし一律に有利な設置方策は得ておらず、霧の除去・残置の適切な切替条件も未解決。結果を見た後の追確認であり、独立した未使用seedでの再現ではない。

## 5. 緩急・帰還と、次に調整する箇所

96探索のP行動3,228手中、攻撃対象を複数選べたのは1,408手。そのうち二つの固定方策で対象が変わる局面は919手あった。選択の余地は存在するが、何を選べばよいか人が読めることの証明ではない。

同じイベント中の「同じ行動種・同じ対象」は最長11手連続。該当するC後半の例では12手中11手が攻撃で、その11手中7手はHP進展なしだった。隠蔽を削る進展、場・手札・機転の変化は別に起きるため、これを無駄な11手とは扱わない。試遊で確認すべき反復候補として場面を特定した。

保護が生じた自然局面からの即帰還を8箇所で分岐し、保護成果の持帰りと過去所持の維持を確認。帰還側だけを検査した例であり、余力や残る有限回復による続行との優劣はまだ評価していない。死亡で今回の保護分も失う規則は維持する。

次の調整順は以下とする。

1. **Cの支援対象を残す／除く判断。** 自分への攪乱支援、敵への支援、他主体への攻撃、供給される札、退場による消滅を同じ局面で比較する。手元の借り札あり／なし、敵登場前／後を分ける。今回は即時除去の切替が発生せず、最優先として残る。
2. **保護直後の続行／帰還。** 同じ保護成果から、実際の余力・有限回復・手札・既知情報で後半の得失を比較する。今回確認した帰還処理を使い、低余力だから機械的に帰る方策を先に正解にしない。
3. **判断後の長さの調整。** 上記で反復が残る区間について、まず対象の残量を単独で変える。区間数や主体数は供給・保護地点も変えるため、同時に削って原因を混ぜない。道の隠蔽1と初回1倍を維持し、進行を不安定に戻さない。
4. **準備表示と人の試遊への接続。** 変更札の突破・探査・身構・場作用・行動時間、失う役割、所持／使用中／変換可能を示す。単一の強さ点や「取得品なので自動更新」を第一案にしない。総コスト方式・価格4ptは試行のまま、その後の集中・混合、基礎習得より個体を優先する比較へ戻る。

# 文字の限定比較と本編条件

取得titleの上端3px補正は確認。IDcropの明るい字面は原本[14,52,38,19]／現在[14,52,38,18]で、幅/上端は揃い、高さ1pxが残ります。同title領域を限定AA差の候補として特定しますが、AAのみと断定/許容採用はしません。

詳細の最初の行y123→119、見出しy248→242、次の見出しy382→365、content高446→377とscrollbar消失はmetric/余白の差です。table header/初行も約10/12pxの差があります。役割別のline box/margin/wrapを先に修正してください。

比較は既存暗色ID領域を使用し、生成・拡大補間はしません。[実測](実測.json)と[証拠受領](証拠受領.json)に各path/blob/sha256を記録。fontはYu Gothic UI400/実600 face、Georgia400とfallbackの提出hash/同Windows/FHDを維持します。CSS500と実選択face600を区別し、face記録だけで全字形を合格にしません。

A案は同metricを合わせた後、残る当該AA領域だけ個別許容候補にすること。B案はその領域の差も許容しないこと。いずれも全UI/全engine差の免除、新font/規則/保存変更の採用ではありません。今の人作業は全UI AA許容ではなく、修正版から成立した特定比較だけです。

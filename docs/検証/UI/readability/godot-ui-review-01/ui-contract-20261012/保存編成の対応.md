# 保存編成の種類と使用中・解除の原本対応

回答は原本と公開fieldの対応で、named presetの追加採用・API実装・実入力の成立ではありません。旧返却「保存preset」の出所はUI ab1bのmissing_statesで、独立した保存名/ID/保存先の採用根拠はその項目に付いていません。

| 分類 | 原本の意図・節 | 公開fieldと対応 | 未解決 |
| --- | --- | --- | --- |
| 旧返却の「保存preset」 | 過去返却の不足状態名。named presetの仕様・API・保存先を指定した採用根拠ではない。／missing_states「保存presetで使用中」 | ／この語だけをnamed preset要件にしない。原本の保存済み案／確定編成とは別に、元の表記意図を照会する。 | 独立したnamed presetを要求するなら、既存採用commit/path/blob・節・名称/ID・保存/適用/解除先が必要。 |
| 保存済みの編成案（saved draft） | 確定編成を変えず単一の編集案を保存する。現行二段階UIの通常画面内編集にはsave_draft不要。旧/互換の「選択を保存」はsave_draft。／ui-handoff「公開情報」「確認と一括確定」／runtime-connection「戻す」／draftPane・controls／execute save_draft | JS display_data.draft.plan/dirty/valid/errors；C# view.draft.plan/dirty/valid/errors；home.owned[].references: saved_draft_deck/saved_draft_equipment／複数の名前付き編成保存とは同義にしない。保存済み案だけの参照もitem_in_useへ対応。 | 対応特定（実入力/描画は別） |
| 確定編成 | 取得・支払・編成を一括確定し、次の出発で使う現在の編成。／current home・commit_preparation／references・Usage／GameApplication.Execute commit_preparation | JS display_data.home.deck/equipment；C# view.home.deck.composition/equipment.entries；home.owned[].selected/location；references: confirmed_deck/equipment／「確認→確定する」はcommit_preparation。成功時に現在編成を更新しdraftもその編成へ戻す。local previewを確定へ読み替えない。 | 対応特定（実入力/描画は別） |
| named preset | 名前/IDを持つ複数の保存編成等の別概念。今回の既存公開契約の単一draft・確定編成では提供を確認できない。／preparation2のplan／全Execute分岐／Usageの参照種別／返却語 | ／現在の共有契約だけでnamed preset APIを新設しない。全UI・全過去採用での不存在は断定しない。 | 別のUI専用機構なら、保存原本・採用節・公開field・使用中/解除の対応を既存UI/とりまとめへ返す。 |

原本の現行二段階取得では、通常画面内編集にsave_draftは不要です。保存済み案を破棄する場合の「戻す」はdiscard_draft。「確認→確定」はcommit_preparation。旧/互換画面の「選択を保存」からsave_draftへの対応は実在しますが、現行画面に旧ボタンを再導入する指示ではありません。

## ST-P08の使用中・ロックと参照解除

| 状態 | 公開field・根拠 | 解除条件／本編へ渡す条件 |
| --- | --- | --- |
| 確定編成で使用 | selected=true、location=composition、referencesにconfirmed_deck/equipment | 確定編成から対象を外した合法planをcommit_preparation。成功時にdraftも新確定編成へ戻り、全参照から対象が消えることを確認。 |
| 保存済み案だけで使用 | selected=falseでもsaved_draft_deck/equipmentがreferencesにある。conversion_reasonsにitem_in_use | 確定編成に対象がなければdiscard_draftでその参照を解除、または対象を含まない別の合法案をsave_draft。selectedだけで変換可能としない。 |
| 確定編成＋保存済み案の両方 | confirmed_deck/equipmentとsaved_draft_*が共存 | discard_draftだけでは確定編成の対象参照が残る。対象を含まない編成の確定が必要。 |
| lock／複合不能理由 | locked=true、conversion_reasonsのitem_lockedとitem_in_useは独立。初期札はinitial_grant_not_convertibleもあり得る | set_item_lock(false)はlockだけ解除。refs解除・初期配布制約・phase制約を消さない。conversion_availableと全reasonsを読む。 |
| 画面内の未保存編集／preview／pending | 未確定plan・pending=true/read_onlyの予測個体。正式ownedとは別 | local edit/PreviewPreparationは保存済み参照を書き換えない。予測中の表示を正式所持のlock/変換・参照解除成功に使わない。 |
| 失敗・stale・busy・非home | capabilities／revision/view_token、refusal、原本の未確定案 | 成功した正式command後のfresh Inspectで判断。保存失敗では旧確定/参照を保持し、return未ackや探索中の拒否を正常変換へ扱わない。 |

CoreのUsageはconfirmed_deck／equipment／saved_draft_deck／saved_draft_equipmentを別に返します。選択済みselectedは確定編成だけで、保存済み案だけの使用でもselected=falseのままitem_in_useです。初期grant・lock・使用中は独立理由で、conversion_availableとreasons全体を読みます。7211の説明文は「編成中、または保存済みの案で使っているため変換できません。」。画面内編集のDraftDirtyは別の操作ゲートです。

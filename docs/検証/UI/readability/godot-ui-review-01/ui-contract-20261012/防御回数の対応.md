# R04：カード・個別効果・集計・効果なしの原本対応

**guard.uses=nullを単独で「制限なし」にしません。guard自体nullは効果なしです。** カード付与回数、現在の個別効果の残り回数、集計表示は別の値です。

## 既存本編7211の静的対応と限界

ActorFacts.Durationは公開effectを身構/攪乱ごとに分け、uses欠落→未公開、全null→∞、全同じ有限→×n、それ以外→混在。leaf行はkey欠落と明示nullを区別します。既存のこの表示adapterを照合しましたが、ビルド・描画・合法caseの実証は今回実施していません。C#にはJSのduration shapeがなくても公開leafがあり、別の値へ置換する理由にはなりません。

カード欠落時の既定2はCore Playの既存規則です。C#のCardView/home詳細の補完は表示用コピーで、private card・通常保存を変更しません。knowledgeはWithOptionalで欠落を省略するため、全領域へ同じ2を推測付与しません。元JSの行省略とC#の「未公開」/説明用2との表示差は、今回の原本対応回答からUI適合へ読み替えません。

無制限leafは攻撃消費で減りませんが、受け手の一致/退出・張り直しで終わるため永久とは表示しません。基準D55/D56/D57の既採用条件は再承認を求めません。

# UI-R-001 情報設計

未採用の画面案。採用済み仕様は設計集約の基本設計0.41、今回の操作比較は0.39対応のPT-Z-001固定版。新しい情報開示・永続知識はこの画面へ追加しない。

## 課題と整理

F03の文字量への所感と、F01の混入後の判断負担を受領。既存画面には主体の数値、手札の主効果と場効果、予測全文、初期状態で開いた山札全種類の効果説明が並ぶ。DOM実行では選択・対象切替・実行の動作を確認した。実ブラウザー表示はURLポリシーで拒否され、視線・スクロール量・読み取り時間は測定していない。

案1は、今の一手の関係を同じ領域で追える配置と、詳細の段階的表示を組み合わせる。常設ターゲット・共有枠・手札の選択を維持し、追加の毎回確認操作は増やさない。選択後の実行は元版同様1回。色の暗記を前提とせず、属性文字、枠、選択ラベルと配置を併用する。

|---|---|---|

「用途別」は札の主効果の種類による枚数集計であり、すぐその効果を使える枚数ではない。一致するかは共有枠で確認する。持込にない種類を自動で有利な強化と評価しない。

表示上の補正は1点。元の詳細予測は退場由来札・補填札の期限切れも単に「回収」と表示していたため、公開済みの消滅フラグに従い「回収時に消滅」へ明確化した。短い予測と詳細の食い違いを避ける補正であり、消滅規則や演算の変更ではない。元の行動ログ全文は過去版の表示として維持し、新しい変化要約には実際の消滅を併記する。

## 探索全体への接続

出発前は構成と狙い、探索中は現在の対象・場・一手、区間を進む場面は主体の参加退場と成果保護、終了時は持帰りと喪失、次の出発は構成と得た知識を軸にする。今回、出発と終了は固定版が持つ範囲を整理した。自由構築、具体報酬価値、帰還後の強化、知識開示画面の新規実装は行っていない。

画面を大岩の専用攻略パネルにはしない。主体一覧・共有枠・手札・変化要約は後続の環境／敵にも同じ構造で適用する。存在効果や退場理由の名称は既存固定版の内容を表示している。並行イベントの新設・数値変更は設計Workの別試験が必要。

## 限界と次の判断

折りたたみを増やすことで全体量は減る一方、複数札の場効果を横断して比較するときに開閉の負担が生じ得る。まず1案を操作して、常時残すべき追加情報があるかを観察する。結果要約は自分の行動から次の自分の手番までの差分であり、すべてを自分の一撃の結果と読ませないよう時間帯と直前の順序を併記した。

読みやすさが改善しても、混入後の予測負担やゲームの面白さが改善したとは直結しない。F01〜F03は受領済みの前提であり、このUIへの肯定・否定として数えない。

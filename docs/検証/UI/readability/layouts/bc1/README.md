# UI-L-003：BC1・可変枠の配置図

2026-09-10。使用版0.1。ゲーム未接続の画面構成検討。

BC1の「場を挟んで相対する」構図を、上＝相手・環境、中央＝共有の場、下＝自分・手札として表示する。[前提](../bc/BC1_可変枠方針.md)と[全UIの表示時機](../bc/検討.md)を引き継ぐ。

## 表示と操作

組立済みの`preview.html`を取得してブラウザーで開く。GitHubのコード表示では操作できない。再生成はリポジトリルートから以下を実行する。

```sh
node docs/検証/UI/readability/layouts/bc1/build.cjs crossweave-bc1-preview.html --standalone
```

- 「3枠／5枠／8枠」で同じ配置の密度を比較する。広い画面は5列、700px以下は3列の表示例。枠の増加時には既存の位置を保ち、収まらない分を次の段へ置く。減少はこの図では末尾から行う。
- 「選択時の表示」で手札のすぐ上に予測・消費・重要な損失の置き場を表示する。
- 山札・回収山・履歴は参照ボタンから開閉する。最新の変化の要点は場と手札の間に残す。

枠数3・5・8、画面幅による列数、手札3枚、対象2個は描画例であり仕様・上限ではない。枠の番号は表示上の識別子であり属性ではない。必要な枠集合の全体を表示し、枠増減のゲームルールは追加していない。参照欄は情報の置き場の模式表示であり、札・数値・計算の実データを含まない。山札残数の常時表示の有無は引き続き比較候補。

今回の図は位置安定性を見せるため、少数時も同じ列幅で先頭から配置する。少数時に中央へ寄せる別案、実際の枠削除時の選択解除、ゲーム状態からの表示連動、端末別の画面比調整は未実装。札を縮小して全枠を一段へ押し込む方式ではなく、段数に応じて場の高さが増える。

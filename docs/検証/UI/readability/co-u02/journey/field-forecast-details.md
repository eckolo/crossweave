# 予測の場札から詳細を開く

2026-09-26（日本時間）／UI0.14.8。

手札を選び、場に置く予測が表示されているとき、その予測札をクリックして詳細を確認できるようにした。表示専用だった予測札を通常の場札と同じbutton・詳細表示の経路へ接続。公開済みの元札の詳細を使い、仮の実所持札やゲーム状態は作らない。

- 手札の選択・行動対象・予測を保ち、クリックでは詳細だけを開く。同じ予測札の再クリックで閉じる。
- 札面の「＋ 予測」と破線を保持し、窓の見出しも「予測 · 札名」にする。「場に置くと」の値・効果など、既存の札詳細を確認できる。
- 窓は予測札が見えている場の位置を基準に反対側の端へ置く。0.14.7の寸法・縦位置を継承。
- 別の手札へ切り替えて予測札が消えたときは、その古い詳細も閉じる。自動で詳細を開く設定がOFFでも、予測札を明示的にクリックすれば確認できる。
- 実行は従来の「場に置く」または手札のドラッグ経路。予測札をクリック・ホールドしても出札しない。

ユーザーは詳細窓の位置を概ね了承。場の詳細の縦位置には微調整余地があるが、仮UI段階では今回の変更対象にしない。正式画面の仕上げ時に必要なら再評価する。

## 寸法と素材の範囲

ゲーム枠1920×1080、札248×208、相手320×224、窓520×480を維持。背景画像の派生寸法は1920×1280。水路は中央より少し上の `50% 40%`、拠点は `50% 50%` で切り取り、縦横に引き伸ばさない。通常の背景上の可読性用レイヤーを維持する。

背景原本は1536×1024で、1.25倍の派生画像を使用している。1920幅のネイティブな細部を追加した素材ではない。今回は仮接続として採用し、正式な高解像度素材の納品・差替後には描画品質を確認する。敵原本は1586×992・透過PNG。派生640×400を、相手枠上部320×108の絵の領域へ縦横比を保って収める。名称・能力値の領域と分離する。手番の小さな肖像は顔寄りに切り取る。

[素材と出典の記録](../art-assets/README.md)、[寸法・原本と派生物のSHA256](../art-assets/manifest.json)、[生成指示全文](../art-assets/diver-prompt.txt)。ビジュアル枝 `25e7ce99bffc551e2370568b74704865c3de13e0` を読取参照し、背景原本のハッシュ一致を確認した。別Workの枝や原本を変更していない。

場面の対応は `SCN-001` の公開対象に限定する。相手の `knowledge_key` と公開 `knowledge_views` の一致から対象IDを取得し、`SCN-001-ACT-02` に潜水服、`ACT-01`・`ACT-04` に水路を割り当てる。固定入力は再訪 `ACT-04` のため、再訪への同じ水路画像の使用は**今回だけの仮接続**として明示する。正式な解決後・再訪差分を採用した意味にはしない。門・通路・未知対象・別caseへ名前や敵種別から流用しない。

## ホールドの共通挙動

`hold-cue.js`／`hold-cue.css` が表示だけを担当し、既存のジェスチャー側が成立時間と動作を保持する。

- 相手は350msで詳細を開く。手札と取得編成の札・心得は初期220msで移動可能になる。手札の既存設定値を尊重する。
- 操作が有効な間だけ、実際の成立時間に合わせて円が一周する。通信の読み込みやループアニメーションではない。
- 成立時は円を消して詳細またはドラッグへ移る。早いリリース、保持前の送り操作、取消、capture喪失、非アクティブ化、複数ポインター、場面・倍率変更では円と保留操作を消す。
- 円は32 CSS px、操作名は12 CSS px。ゲームの縮尺を逆補正し、縮小表示でも見える大きさを保つ。画面下端では操作名の高さも含めて位置を補正する。表示自体は入力を奪わない。
- 通常のボタンや余白パンに、成立しないホールド表示を出さない。操作名の追加で取得・編成・出札・支払いを先行させない。

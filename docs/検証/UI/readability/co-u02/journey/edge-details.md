# 隣の札を続けて選べる端配置

2026-09-26（日本時間）／UI0.14.7。

「左端の札を確認してから右隣を確認しようとすると詳細窓が邪魔になる」という指摘に対応。0.14.6の選択元のすぐ脇への配置を、反対側の画面端への配置へ変更した。

## 規則

- 手札・場・予測・敵・地形・行動順で、選択元の中心が左半分なら右端、中央以右なら左端へ開く。画面端の余白は16px。元との距離によらず、同じ側の札なら同じ横位置になる。
- 左右の決定と端寄せを `placeEdgeWindow` へ共通化。敵だけにあった空き領域への横補正も不要となり、端へ揃える。
- 手札・場・予測は520×480px、相手は416×384pxを維持。縦位置は前版を継承し、札の詳細と予測は同じ位置、相手は共通上端16px。画面中央にある札は倍率計算の微小誤差で左右が入れ替わらないよう扱う。
- 同じ札の再クリックで閉じる操作、別の札への切替、場への出札・予測・対象選択は継承。メニュー・親子窓は従来配置。

選択元とその左右の隣枠を見ながら順番に確認できることを優先する。反対端に多数の要素が集まる場面で全要素が同時に見える保証ではない。

# 探索先を複数候補から選ぶ画面（UI0.14.9）

2026-09-26。Work `20260910-ui-readability`／`ui/readability-20260910`。

ユーザーの「後続タスクがあるなら続けて」「探索先選択は複数選択想定の画面パターンも出して欲しい」に対応。文脈上の「複数選択」は複数候補から一つの行き先を選ぶ意味とし、同時に複数へ出発する仕様は追加しない。

## 提示した画面と操作

- 1920×1080の既存出発前画面を拡張する一案。拠点背景・上下の操作帯・編成導線を継承し、左に候補一覧、右に選択中の名前・踏破状態・大まかな攻略傾向・目的を配置する。
- 候補4件はすべて520×152px、間隔20px。選択しても寸法は変えない。左側の印・選択色・チェックと右側の概要で選択を示す。4件をスクロールなしで並べる寸法設計であり、実フォントでの収まりは未確認。
- 右側は幅880pxの共通領域。詳細は既存の窓へ接続し、右下の出発操作の近くにも選択先名を置く。数値報酬・入場費・難度・解放条件・地図は追加しない。

| 操作 | 結果 |
|---|---|
| 候補の枠をクリック | 一件だけを選択し、概要と出発先名を更新。ゲーム状態・着想・編成は変更しない |
| 詳細 | 選択先の目的・攻略の手掛かりと現在の編成を既存窓に表示 |
| 別の候補をクリック | 選択を切り替え、以前の候補の詳細窓を閉じる |
| 札組／心得へ移動し、戻る | 選択した探索先を保持 |
| 出発 | 実装済みの夜潮の排水路のみ、既存の実Campaignへ接続 |

## 仮候補と本編の境界

[確認用カタログ](../review/destinations.json)の「蔦に覆われた旧道」「灯りの消えた停車場」「風の抜ける見張り台」と、それらの目的・状態・傾向は配置と切替を確認する仮データ。正式なシナリオ・探索先の解放・踏破履歴ではない。夜潮の排水路の名前・目的・状態は既存の公開情報を優先し、短い傾向ラベルは確認用の表現とする。

仮候補でも概要・詳細・編成との往復は確認できる。出発ボタンは無効とし、呼出し側のガードでも決済・出発を行わない。仮候補を選んだまま夜潮の排水路へ出発することはない。この制限は試作の提供範囲であり、ゲーム内の未解放状態を表すものではない。

本体の探索先は引き続き `SCN-001` の一件。`mountJourney` の確認用オプション `destinationPreview` にカタログを渡した入口だけで一覧を表示し、通常入口は従来の一件表示を維持する。共通runtime・経済・保存スキーマ・固定セーブを変更せず、別のゲーム処理や架空のAPIを作らない。

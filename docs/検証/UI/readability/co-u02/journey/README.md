# 全画面構成の操作試作 — 帰還・編成・探索先・探索

版0.1／2026-09-16。UI-PLAN-001、継続Work `20260910-ui-readability`、枝 `ui/readability-20260910`。

ユーザーの「ではこの方向で、改めてUI設計してみて」を受領し、[全画面構成](../../全画面構成.md)を具体的な配置と一巡の操作にした。**配置の確認用。全30項目の実装完了・正式採用・ユーザー受入ではない。**

## 操作できる範囲

最初は探索終了後の帰還結果。実Campaignの自然帰還保存例から、着想+3・合計3、素材M、余力回復、記録に加わった札を表示する。札の解放を所持・無料編成可能と同一視しない。終了本文は結果内に置き、追加の必須本文選択ページを挟まない。任意詳細は閉じたまま。

| 場面 | 配置と主操作 | 変更の見え方 |
|---|---|---|
| 帰還 | 同じ場所へ出発、札組、心得、探索先へ直接 | 増えた着想・素材、回復前後、記録への追加。受取ボタンなし |
| 編成・札組 | 対象のすぐ下の＋／−、名前から詳細 | 対象ごとの現在枚数と案、合計枚数、差分。所持札も同じ一覧に内包 |
| 編成・心得 | 4基礎の効果・条件・装備枠、覚えて装備、外す | 同じ場所で習得と装備を指定。忘れる操作は対象詳細内。返還と外れる装備は公開比較で表示 |
| 共通の編成要約 | 現在の着想→変更案、対象名付き差分、確定／確定して出発 | タブ切替は保存・破棄しない。比較は任意に拡大。失敗時は現在値を保つ |
| 探索先 | 現在公開されている1件の目的と編成を同じ場面で確認 | 再訪と解決状態は実view。複数候補・未公開の行き先は捏造しない |
| 場面・探索 | 実本文をそのまま表示。既存の公開view接続探索部品へ続く | 実legal_actions・予測・出札・撤退・帰還。正式v0.15への完全移植は継続課題 |
| 共通の窓 | 対象詳細、比較、記録、メニュー、表示、案内、書出し | 固定した詳細を残し、非固定だけ差し替える。小幅では前へ積み、末尾を切らない |
| 中断・再開 | メニュー→中断、続きから→元の場面 | 未完成の札組もsave_draftで保持。今回は開いている間の一時メモリーのみ |

文字を減らすため、対象名と数値・効果を中心にし、操作のない「準備」「購入」等を各欄へ繰り返さない。「習得→取得」「修正する」「次の準備へ」は使わない。数値の前後は矢印で示す。実演アニメーションを増やす段階ではなく、変更した値の短い動きと対象の選択状態を付けた。動きを抑える設定あり。

画面移動の設計は、帰還→心得1操作、札組↔心得片道1操作・確定0回、覚えて装備1選択、枚数変更1操作。これは検査用DOMで通した特定経路であり、探す時間・スクロール・物理入力を含めた操作量短縮の実測ではない。

## 実接続と試作の境界

- `src/runtime/campaign.mjs`の実Campaignと設計所有`test/runtime/support.mjs`のMemoryStoreを使用。公開view、previewPreparation、execute、公開探索部品、既存sessionを再利用する。独自の経済式・ゲーム処理・保存アダプター・非公開辞書は新設しない。
- 会話内の実行に必要な既存ES Modulesを`build.cjs`で閉じた一式に組み立てる。対応外の構文・外部import・循環は拒否。元runtime・content・保存・シナリオは変更しない。自然帰還保存は起動注入だけに使い、描画側へはcontrollerだけを渡す。
- **実API＋一時メモリーの試作。実IndexedDB・実セーブ接続版ではない。** 閉じた後の保存を保証しない。従来の実セーブ入口`../index.html`を置き換えず、保存未対応時の模擬フォールバックにも使わない。
- 場面の実表示はIntersectionObserverから`continue_scene({advance:false,displayed_text_ids})`へ送る。主本文だけ自動表示、任意詳細は開いた内容だけを対象にする。不可視・未選択の詳細は既読にしない。
- 一つの「出発」意図でも、終了本文の進行→ack_return→必要時commit_preparation→departは順次成功を確認する。返還・習得等の現在値は成功応答後だけ変える。途中で確定済みなら巻戻しを装わず、失敗した要求を同request_idで再送して残りへ進む。
- D03の購入・変換・修飾は未対応理由を表示。実offers・ownedを補完しない。素材Mの用途は新設しない。
- 地名は既存`flow/fixtures.json`の表示名を再利用する。この1件の試作タイトルであり、未知の探索先辞書を増設しない。

探索部品で見つかった毎手の対象再指定を修正した。初回は公開された合法対象から通路を優先し、次の手でも有効な対象を保持する。合法対象が変わった場合だけ、公開候補から選び直す。固定`interaction/`原本は無変更。`co-u02/exploration.js`と再生成distだけに反映する。

## 生成と検証

```sh
node docs/検証/UI/readability/co-u02/journey/build.cjs /workspace/crossweave-journey-design.html
CW_JSDOM_PATH=/path/to/jsdom node docs/検証/UI/readability/co-u02/journey/verify.cjs docs/検証/UI/readability/co-u02/journey/checks.json
```

会話内の提示は正規のvisualize参照で行う。生成HTMLの添付や静止画を操作画面の代わりにしない。検査結果は[checks.json](checks.json)、対象・版・ハッシュは[code-freeze.json](code-freeze.json)。新しい変更だけを対象にし、旧28件等を引継ぎのために再実行していない。

1024／736／600／320px向けに親幅のcontainer queryで列数を減らし、詳細窓は小幅で前へ積む。新しい一覧・詳細・確定操作は文書フロー内に置き、全体縮小・末尾の切り隠しは使わない。DOMで4幅のresizeイベント中に窓・下書きが残ることを検査する。

**JSDOMは描画しない。実際の4幅での収まり、長い一覧の探索量、詳細末尾・確定ボタンへの物理的到達、実タッチ、フォーカス操作、会話内ホストの表示は未確認。** 既存のBrowserはローカル入口をERR_BLOCKED_BY_CLIENTで拒否した記録があり、今回も別経路で回避していない。DOM合格を実表示合格とはしない。

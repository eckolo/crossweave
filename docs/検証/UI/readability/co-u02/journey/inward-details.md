# 選択元に対する詳細窓の左右を統一

2026-09-26（日本時間）／UI0.14.6。

0.14.5の配置変更が敵・地形だけに適用され、手札・場の札には従来の空き領域探索が残っていた。そのため右半分の札から右へ開く経路があった。前回の適用範囲不足を修正する。

## 共通規則

- 手札・場の札・予測・敵・地形・行動順から開く窓は、表示中の選択元の中心が画面の左半分なら右、中央以右なら左へ開く。対象と窓の基本間隔は16px。
- 左右判定を `placeBesideWindow` へ共通化。札は選択元の脇へ置き、他の空きを理由に逆側へ出さない。相手は従来の隣枠回避を同じ側の範囲に限定し、空きがなければ選択元を隠さずその側へ置く。
- 手札・場・予測の窓は520×480pxを維持。縦位置は選択元の上端を基準に、下部帯より上へ収まるよう制限する。札の詳細とその予測は同じ位置になる。相手は416×384px・上端16pxを維持する。
- 1920×1080の論理座標で計算し、全体表示の倍率では規則を変えない。メニューや親子窓の配置は既存方式を使う。

元の選択対象と操作ボタンを保つこと、左右規則の維持を優先する。窓幅の空きがない密集場面では、別の札・相手へ重なる可能性がある。全要素の非重複を保証したものではない。

## 不具合の範囲

0.2には、固定した外枠の中に旧探索UIの画素単位の最低高さが残り、内部が枠より大きくなる組合せがあった。また、ヘッダー・状態帯等の非表示時にGridの自動配置先が変わり、伸縮領域へ主画面が正しく割り当たらない箇所があった。外枠16:9は維持し、領域の明示配置と内部の組み替えで対応する。全体の縮小で文字・操作を小さくする方式は使わない。

調査記録は公開`knowledge_views`の初期構成と観測札、公開`details`の解放札だけを読む。観測から初期枚数や現在の手札を作らず、非公開の辞書・経済・保存処理を増設しない。親と子の表示は閲覧のみで、本体のrevisionを変更しない。

## 検証

[新検査](interaction-review-checks.json)35件。実Campaign＋設計所有MemoryStore、自然帰還例と入口保存例を使用。記録31項目の詳細、親の保持、心得選択と札組切替、4種の値と記号、対象指定と参照の分離、実legal_actionsの実行を確認した。1024／736／600／320px相当の寸法入力で、16:9の高さ指定・位置計算の枠内保持・空所がある場合の呼出元回避・表示モード切替を検査。

JSDOMは描画しない。矩形を注入した位置計算は実ブラウザーの矩形計測ではなく、上下切れ・末尾到達・読みやすさの合格としない。実タッチ・ホスト描画・IndexedDB・ユーザー受入も未確認。既存のローカル入口のブラウザー拒否を別経路で回避しない。過去の28件・32件は当時の履歴を維持し、再実行していない。

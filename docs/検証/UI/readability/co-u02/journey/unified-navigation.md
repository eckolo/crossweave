# 同じ取得・編成画面と共通操作へ統合（UI0.15.0）

2026-09-26。Work `20260910-ui-readability`／`ui/readability-20260910`。

## 原因と修正

前回了承された取得UI5.3は独立した確認入口のままになっていた。UI0.14.9の探索先選択からは、D03の旧契約につながる「札組／心得／購入／構成を見る」が開き、見た目だけでなく管理の考え方も前回へ戻っていた。新しい管理UIを別に作る理由はなく、提示する導線の接続漏れだった。

今回、取得UI5.3の `app.js`・`layout.js`・`gestures.js`・`structure.css` をそのまま共通の原本として、独立入口と埋込み入口から使う部品にした。取得・編成の描画や操作を別に実装していない。札／心得のタブ、取得可能／所持／編成、352×80pxの共通枠、仮の輪郭・時計印、二段階確認、ホールドと横移動を継承する。

探索先画面の上部左側に「編成」を一つ置く。「購入」は取得可能の欄、「構成を見る」は編成の欄へ集約し、独立した入口を出さない。帰還結果は右下の「進む」で送り、直後の探索先画面から同じ「編成」に入る。編成画面で「戻る」を押しても、分類・取得予定・編成・確定済みの確認用状態を同じインスタンスで保持する。

## 画面別の配置照合

現行提示の帰還・探索先・取得編成・出発本文・探索・中断・調査記録・メニュー／設定・詳細／確認窓を照合。起動／保存読込みはソース上の配置を照合した。実ブラウザーの描画を確認した表ではない。

| 機能 | 修正前の差・重複 | 今回の共通位置・扱い | 同じにしない範囲と理由 |
|---|---|---|---|
| 取得と編成への入口 | 探索先下部に札組・心得・購入・構成を見る | 探索先の上部左側「編成」一つ。内部は同じ取得UI | 探索中の構成変更は本編の許可がないため入口を出さない |
| 札と心得の切替 | 独立した旧画面・旧タブへ遷移 | 編成画面上部の札／心得。画面構造・状態を共有 | 取得・所持・編成は分類タブにせず同時表示の置き場 |
| 共通メニュー | 探索中は下部、他は上部 | 右上。共通部品・CSSで上4px、右24px、56px高 | 保存未読込みの起動画面には、保存に属する機能を置かない |
| 調査記録 | 探索中はメニュー内、他は右上 | 右上のメニューの左。全読み込み済み画面で同じ並び | 対象の詳細からその対象の記録を開く操作は、対象に隣接する文脈付きの入口 |
| メニュー内の共通項目 | 探索メニューと設定・保存メニューが別階層 | 先頭を調査記録・表示・遊び方・保存データ・文章の記録で固定 | 目的・状況・行動順・山札・履歴・操作・中断は探索中だけ追加する |
| 前の画面へ戻る | 編成と本文・保存読込みで下部にも配置 | 左上。編成・任意表示の本文・保存読込みを修正 | 帰還の「進む」は結果処理を進める操作なので右下 |
| 窓を閉じる／親窓へ戻る | 取得確認窓の下部にも「戻る」が重複 | 閉じるは窓右上、親へ戻るは窓左上。下部の重複を除去 | ピンは開いたまま別対象を操作できる窓だけ。取得確認のモーダルには不要 |
| 出発・進む・確認・確定 | 画面移動と同じ帯で混在 | 場面を進める操作として下部右側。費用はボタンの近く | 意味の異なる操作を一つのラベルへ統合しない |
| 編成変更の「戻す」 | 画面移動の「戻る」と混同しやすい | 編成の下部操作帯で変更を取り消す。移動は上部左 | 作用範囲が違うため同じボタンにしない |
| 札の取得・編成・外す、探索の行動 | 対象ごとに画面内座標が変わる | 各対象への近接位置を維持 | 対象操作を全画面の固定座標へ離すと、何に作用するか分からなくなる |

共通操作は [common-navigation.js](../common-navigation.js) と [common-navigation.css](../common-navigation.css) に集約。探索の行動順領域には右上ボタン分の空きを確保する。窓の場所は既存の位置決定を継承し、閉じる／戻るの窓内位置を統一する。

今後は、機能UIを追加するたびに他画面の同機能・近い機能、位置・並び・開く先を必ず照合し、差を残す理由を記録する。[操作表示原則](../../操作表示原則.md)に必須規則として保存した。

## 本編接続との境界

画面と導線を同じ実装へ統合したが、統一された所持・取得費・保存移行の共通契約は未提供。取得・編成は従来の確認用入力であり、UI内での確定を本編の支払い・保存に接続したとは扱わない。開始時の着想だけは出発前の公開残高に揃える。所持の数量・編成・追加候補価格は確認用で、正式な配布・経済値・本編の現在編成を示すものではない。

未確定・確定済みを問わず確認用の取得・編成が初期状態から変わった後は、実探索への出発を表示と処理の両方で停止する。異なる本編編成へすり替えて出発しない。未確定変更を「戻す」で戻した場合は制限を解除でき、未変更なら既存の出発を維持する。この試作の境界はゲーム外の確認帯で明示する。

旧D03に直接つながる画面は接続検証の互換入口として保存し、現行ユーザー提示の導線からは外す。ユーザーへの再提示には下記統合入口を使い、古い接続検証入口を新画面として提示しない。設計契約受領後は、この同じ取得・編成UIの確認用状態を実公開情報・一括確定へ置き換える。[UI-ACQ-INT-01](../acquisition-preview/integration-handoff.md)が本編接続の残件。

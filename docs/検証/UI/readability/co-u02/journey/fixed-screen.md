# 16:9の主画面と小窓 — 操作試作0.4

2026-09-16。Work `20260910-ui-readability`／`ui/readability-20260910`。

ユーザーは16:9を了承し、主画面全体をスクロールさせず枠内へ配置するよう指定した。小さな窓の中の縦スクロールは許容される。旧0.2〜0.3の「外枠を固定して主画面の内容をスクロールさせる」構成を現行要件にしない。16:9の了承と具体画面の受入を区別する。

## 配置

| 場面 | 常に枠内へ置くもの | 小窓・一覧の扱い |
|---|---|---|
| 帰還 | 結果、着想の増分と残高、余力の前後、素材・記録の追加要約、札組・心得・拠点への操作 | 主本文だけの小窓を要約の横に置く。素材・新記録・喪失の全内訳は要約から開く。本文表示後の移動は従来どおり1操作 |
| 札組・心得 | 共通タブ、選択中の枚数／使用枠、現在→案の着想、対象の増減／装備、確定・出発 | 一覧を表示枠でページ分割。長い変更内容は比較窓。対象の詳細は従来の小窓 |
| 探索先 | 現在の行き先、目的の要点、札組・心得・出発 | 長い目的と構成は行き先から開く小窓。別の行き先を捏造しない |
| 場面 | 場所の背景、本文だけの小窓、下部の続行 | 本文と任意詳細だけが窓内でスクロール。主画面の進行操作は動かさない |
| 探索 | 0.3の相手・場・手札・実行・メニュー配置を継承 | 既存の対象帯の横送りと参照窓を維持。今回、正式探索原本と共有探索コードは変更しない |
| 起動・共通状態 | 続きから、状態に応じた主操作 | 案内・保存データ・記録は小窓。通知は主配置を押し下げず、その内容だけスクロール可能 |

札組／心得は上部44px、下部44pxの操作帯を先に確保し、残りの高さと幅から列・行・ページ件数を算出する。対象の操作ボタンは44pxを維持し、画面全体の拡縮はしない。主画面のoverflow指定だけで対象を消すのではなく、公開一覧の全対象をページに割り当てる。名前が長い場合は一覧で省略表示しても、同じ対象の詳細とアクセシブル名から全文へ到達できる。

| 親幅 | 16:9の高さ | 札一覧の1ページ上限 | 自然帰還後の札10種 |
|---|---|---|---|
| 1024px | 576px | 24件 | 全10種を2行で表示 |
| 736px | 414px | 8件 | 2ページ |
| 600px | 337.5px | 6件 | 2ページ |
| 320px | 180px | 2件 | 5ページ |

数値は配置関数の入力・計算値であり、実ブラウザーの測定ではない。ページ送りによる追加操作も今後の操作量評価へ含める。広げて全件が見える状態を経由しても、再び狭めれば元のページへ戻る。札組と心得のページ位置を別に保持し、共有下書き・固定詳細・任意本文の開閉と窓内の読書位置を維持する。

購入・修飾・変換はメニューから対応待ち理由を参照できる。空所持・資金不足と取り違えない。経済・保存・非公開データ辞書はUIへ追加していない。

## 検証と限界

[新変更32件](fixed-screen-checks.json)を実Campaign＋設計所有MemoryStoreとJSDOMで確認。自然帰還保存から札10種・心得4種の末尾、4幅の寸法計算、ページ／下書き／固定窓の保持、現在と案の残高、無効な札枚数の拒否、比較→確定→出発→実探索→中断・再開を検査した。本文は明示した可視通知の後だけ記録し、未表示の任意詳細を一括既読にしない。対象・版・SHA-256は[固定目録](fixed-screen-freeze.json)。以前の検査群を今回分へ再計上しない。

**実際の描画、重なり・切れ・物理的な末尾到達、タッチ、IndexedDB、ユーザー受入は未確認。** 正規Browserのローカル入口拒否 `ERR_BLOCKED_BY_CLIENT` を別経路で回避しない。JSDOMと寸法計算は実描画を証明しない。会話内へ正規のvisualize参照で提示し、確認点は①枠内で主要操作が使えるか、②編成・比較・確定と帰還後の移動が分かるか、③現在・案・確定後の区別がつくか、に限定する。

会話内版は実API＋一時メモリー。実IndexedDB接続の確認版ではなく、閉じた後の保持を保証しない。固定のUI-R-002 v0.15、旧UI-F/G、PT-Z/PT-NTは無変更。遊び方の本格構成・全画面の残実装・D03の実取得は継続事項として残す。

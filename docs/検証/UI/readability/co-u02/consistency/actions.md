# 心得・札の管理と操作

2026-09-22／UI0.13表記追補。WorkID：20260910-ui-readability。
今回の依頼は「覚える」への表記変更と、現状の管理・操作・結果の整理。以下は現在の仕様・試作の説明であり、管理方式の新規採用ではない。

## 1. 何を管理しているか

心得には「種類を習得しているか」「入手した個体を持っているか」「今回どれを装備するか」の三つがある。札には「使える基本札」「入手した札の個体」「次の探索の札組」がある。さらに画面上には確定済みの現在と、まだ確定していない変更内容が同時に存在する。

| 管理対象 | 心得 | 札 |
|---|---|---|
| 基本の利用条件 | 基礎の種類ごとに着想で習得する。習得すると、その種類の基本版と所持している派生版を装備できる | 初期から使える基本札は、個体を購入せず札組に入れられる。札に習得・習得解除はない |
| 所持品 | 購入等で得た心得を1個ずつ持つ。修飾・性能・枠消費が異なる。所持と基礎の習得は別 | 購入等で得た札を1枚ずつ持つ。同じ種類でも別の個体として持てる |
| 今回の編成 | 装備枠の範囲で使う心得を選ぶ。習得済みでも未装備ならその心得の効果は働かない | 山札の枚数・同じ種類の上限を守って札組へ入れる |
| 解放・記録 | 知っていることと、習得・個体所持・装備は別 | 記録や候補への解放があっても、その札を所持したことや無料で使えることを意味しない |

修飾付き心得を買っても、基礎の習得費は別途必要。反対に、基礎を覚えるために同名の所持品を買う必要はない。基礎習得は個体ごとではなく種類全体に対して一度行う。

同じ種類の心得を複数同時に使うことは容量内で可能。ただし同じ所持個体を二重装備できない。札も一つの所持個体を複数枚扱いで投入できない。初期基本札の繰返し選択とは区別する。枚数・容量・価格等の具体値は現在の試行値で、製品値の採用とは別。

## 2. 心得でできること

次の表は、その変更を確定した後の結果。覚える・忘れる・装備のボタンを押した時点では、まず変更内容を編集する。

| 操作 | 対象と結果 | 着想 | 所持品 |
|---|---|---|---|
| 覚える | その種類を習得する。装備には入れない | 習得費を支払う | 変わらない |
| 覚えて装備 | その種類を習得し、選んだ基本版または所持個体を装備する | 未習得なら習得費を支払う | 変わらない |
| 装備 | 習得済みの種類から、選んだ基本版または個体を装備する | 変わらない | 消費しない |
| 外す | 選んだ心得を装備から外す。習得は残る | 返還なし | 残る |
| 忘れる | その種類の習得を解除し、その種類の装備も外す。再び覚えるまで、その種類の基本版・所持派生版は装備不可 | **習得に実際に払った額を全額返す** | **残る**。購入代金は返らない |
| 購入 | 候補の個体を1個入手。習得・装備は自動で行わない | 購入費を支払う | 1個増える |
| 保護／保護を解除 | 所持個体を「着想に変える」対象にできるかを切り替える | 変わらない | 残る |
| 着想に変える | 選んだ所持個体を手放す。基礎の習得は変えない | 見積り額を得る。習得費の返還とは別 | 選んだ個体を失う |

「忘れる」は、採用済みの無料取り直しをUIで表現したもの。忘却を目的とする遊びではなく、習得へ使った着想を戻し、別の心得等へ振り分け直すための操作である。過去の探索・報酬・知識・札解放を巻き戻さない。

所持品の変換は習得解除と異なり、その個体を失う。保護中・装備中・札組で使用中・保存した変更内容で使用中の個体は変換できない。使う予定から外す必要がある。最後の修飾個体を失った場合、その性能の個体は再入手が必要。

## 3. 札でできること

| 操作 | 結果 |
|---|---|
| ＋／札組に入れる | 次の探索へ持ち込む構成に加える。札を購入する操作ではない |
| −／札組から外す | 次の探索の構成から外す。所持品は失わない |
| 購入 | 候補の札を1枚入手。札組には自動で入らない |
| 保護／保護を解除 | 所持札を「着想に変える」対象にできるかを切り替える |
| 着想に変える | 所持札を1枚手放して着想を得る。基本札の無料選択権や解放そのものは変換しない |
| 探索中に使う | その探索内で場・回収山・消耗等のルールに従う。探索内での消耗は、拠点の所持台帳から個体が消えることとは別 |

札には心得の「覚える／忘れる」に相当する操作はない。所持札の1枚と、探索中に循環している札の状態を分けて扱う。

## 4. 「案を戻す」の実際の意味

「案」は未確定の変更内容を指す。現状はゲーム内の行動と編集を取り消す操作に、似た言葉を混在させている。

| 現在の表示 | 実装上の意味 |
|---|---|
| 習得案を戻す | 今回追加した「覚える予定」を取り消す。まだ支払っていないため返金はない。その種類を装備する予定も外す |
| 忘れる案を戻す | 今回追加した「習得を解除する予定」を取り消す。まだ習得は解除していないため、覚え直す費用はない |
| 比較 | 確定済みの現在と、変更後の状態・着想を比べる。確定はしない |
| 確定 | 習得・解除・装備・札組等の変更をまとめて実際の状態に反映し、保存する |
| 拠点へ戻る／画面を閉じる | 画面の移動。未確定の変更を取り消す操作とは異なる |

**現在の「忘れる案を戻す」には、装備を元に戻さない問題がある。** 例えば装備中の心得に「忘れる」→「忘れる案を戻す」を順に押すと、習得は維持する予定へ戻るが、装備を外す予定は残る。「その操作を取り消す」と期待した場合の結果と一致しない。これは習得取消のゲーム仕様ではなく、UIの変更内容の戻し方の問題。

もう一つの問題は、個体の行にある「忘れる」がその1個だけでなく、同じ基礎の全個体の装備可否へ影響すること。現状の画面では作用範囲が分かりにくい。

限定確認の「守りからの設置」では、忘れる予定を選ぶと「習得 −2」も併記された。これは未習得になる予定から習得費の表示が再び出るためで、実際の習得取消で着想を追加支出する意味ではない。返還の方向を伝えにくい表示として改善点へ残す。[実行時の表示記録](actions-check.json)。

## 5. 今回の変更と、整理から見えた改善点

- 指定どおり「覚えるだけ」を「覚える」に変更。一覧・詳細の共通ボタンと遊び方へ反映。操作の処理は同じ。
- 習得・所持・装備・変更内容の区別を本書に記録。採用済みの無料取り直しや経済ルールは変更しない。
- 今後のUI改善案：習得の解除を種類単位の操作として示し、返ってくる着想を併記する。未確定の操作取消は「覚えるのをやめる」「習得解除をやめる」等の行動が分かる語で示す。「取り消す」はその操作の装備への影響も含めて戻す。
- 上記改善案は今回の表記修正とは分けた提案。管理方式や取消範囲を全面変更した扱いにしない。ユーザーが仕組みを判断できるよう、先に現状を整理して提示する。

# CO-U02：方向性の了承と残作業（0.11反映）

2026-09-17。Work `20260910-ui-readability`、枝 `ui/readability-20260910`。

0.11提示後、ユーザーから左下のプレイヤーパラメータにも予測増減を出す要望と、「他は身構えと軽減の統一案以外問題無さそう」を受領した。提示範囲のその他の部分は問題なし。直近の表示上の残件は左下の全能力予測と身構・軽減の統一。予測は本人の解決後値の追加公開が必要で、統一案とは別に残る。[具体条件](journey/exploration-save.md)。以下の未提供機能・実保存確認・統合作業が完了した意味には広げない。

ユーザーから「細々した気になる点はあるものの、おおむねこの方向でよいと思う」を受領した。操作試作0.9の画面構成・操作の方向性への了承として記録する。細部がすべて確定した、4幅の全操作を検証した、永続保存やCO-U02全体を受け入れた、という意味には広げない。

## 今回済んだこと

0.11で[探索だけの中断と編成の確定時保存](journey/exploration-save.md)へ変更。中断・書出しで未確定案を保存する0.10の導線を外した。履歴にはそのセッションで公開された札名、予測詳細には消費前の機転加算を表示。今回の変更20項目を確認。0.10の49件は当時の記録として保全し再実行していない。通常入口の実IndexedDB確認は引き続き未了。

会話内の操作画面を復旧し、帰還→拠点→札組／心得→出発→探索の主経路を具体化した。最新の探索配置修正はコードコミット `2d37177385082a102cb62b46d196fdf490328ee3`、保存記録は `194f11338a0f6a969b2403e46a574aa71d9e3756`。同じUI枝への保存・GitHub読戻し・設計への統合依頼を済ませている。

新しい操作試作は実Campaign・公開view・legal_actions・previewAction・executeを使う。pending、重複送信抑止、再試行、古い応答の排除、下書き保持は既存sessionを継承する。これは実APIに接続しているが、会話内の保存先は設計所有の一時MemoryStoreである。

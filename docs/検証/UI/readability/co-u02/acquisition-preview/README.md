旧「取得」タブは、札と心得の入手候補をまとめて選ぶための画面だった。物の種類と操作を同じナビゲーションへ混在させたため廃止する。主分類は「札」「心得」の2つとし、各分類に次の置き場を同時に表示する。

| 置き場 | 表示構造 | 含める物 |
|---|---|---|
| 左の候補棚 | 棚板の上に並ぶ札。費用を札の表面へ表示 | 今回選べる未取得の札・心得 |
| 中央の手元 | トレーと重なった札の形。複数枚は数量を表示 | 所持・取得予定のうち編成していない分 |
| 右の編成枠 | 枠に収まった札とチェック印。札枚数／心得容量を表示 | 編成に入れた分 |

同じ1個を手元と編成へ重複表示しない。取得・編成・取り外し・取消で置き場が変わる。移動先が一覧の表示範囲外なら、その物が見える所までスクロールする。未払いの物は点線・斜線・時計印を保ち、確定で通常の輪郭へ変わる。色や説明文だけに依存しない。

## 動かせる操作

| 操作 | 配置と結果 |
|---|---|
| 取得 | 候補の直下。未払いのまま手元へ移る。正式所持・実残高は変わらない |
| 編成 | 手元の札の直下。同じ個体が編成へ移る |
| 外す | 編成された札の直下。同じ個体が手元へ戻る。取得予定と費用は残る |
| 取消 | 未払いの札の直下。その予定分だけ候補へ戻す。既存の所持品には作用しない |
| 戻す | 画面全体の下端。取得予定と編成の変更をまとめて最後の確定状態へ戻す |
| 確認する | 画面全体の下端。支払いと、取得先・編成の差分を表示する |
| 確定する | 確認窓の下端。隣に費用を置き、制約を満たすと支払い・正式取得・編成を一括反映する |
| やり直す | 操作案の外側。確認用の固定入力とスクロール位置へ戻す |

対象と費用はボタンの外へ置く。詳細は札の表面から開き、操作を窓下端に固定する。札・心得の切替、詳細の開閉で未確定内容を失わない。確定後も無料で編成を出し入れでき、所持は残る。

## ドラッグとスクロール

探索画面と同じ、**220ms保持して移動／保持前のスワイプはスクロール／短いタップは詳細**の分け方を使う。ボタンからの操作も維持する。

| 移動元 → 移動先 | 結果 |
|---|---|
| 候補 → 手元 | 未払いで取得 |
| 候補 → 編成 | 未払いの取得と編成を一緒に反映 |
| 手元 → 編成 | 編成 |
| 編成 → 手元 | 外す。取得予定・所持は保持 |
| 未払いの物 → 候補 | 取得取消。予定分の編成も外す |
| 正式所持の物 → 候補 | 移動不可。売却・返還・削除にならない |
| 同じ領域、領域外、中断 | 内容を変えない |

ドロップ可能な領域を枠と操作名で示す。保持中に一覧の端へ寄せると自動スクロールする。移動後の余分なクリックで詳細を開かない。Esc、ポインター取消、capture喪失、フォーカス喪失、別ポインター、表示サイズ変更で移動を中断する。

ページ送りは廃止し、全ての物を同じ大きさで詰めて並べる。余白ドラッグ、保持前のスワイプ、ホイール、一覧内での左右キー、通常のスクロールバーで連続スクロールできる。分類切替・詳細の開閉で位置を保持する。

16:9固定とし、ゲーム全体は縦スクロールさせない。標準幅1024pxの設計配置は候補1列・手元2列・編成4列、3段。最初の札組12枚は一度に並ぶ。狭幅でも物自体を縮小せず、盤面内の横スクロールと各一覧内のスクロールで残りに到達する。実際の表示数と触りやすさは実描画での確認を残す。詳細・確認窓は本文だけスクロールし、操作を下端に固定する。

## 設計寸法と提示倍率

ゲーム部分は **1920×1080、16:9固定**。会話の幅へゲームを再配置せず、外側の確認用表示だけを拡大・縮小する。

- 「全体」：利用可能な表示幅へ縮小。幅1024 CSS pxなら約53%、736 CSS pxなら約38%。縮尺を上部に明示する。これは1920×1080の配置を見るための縮小提示で、文字の原寸評価・スマホ対応の検証ではない。
- 「原寸」：1設計pxを1CSS pxで表示。狭い提示枠では外側のスクロールで各部を確認する。OSの表示倍率・devicePixelRatioがあるため、1CSS px＝ディスプレイの物理1画素とは限らない。
- 表示倍率の変更で編成・取得予定・一覧のスクロール・開いた詳細を変えない。縮小中のドラッグ像と余白パン、項目移動のアニメーションは縮尺を補正する。
- 外側の原寸確認用スクロールは、ゲーム内部の全体スクロールではない。ゲームは同じ1920×1080内へ収まる。原寸表示は主に文字と余白、全体表示は領域間の移動を見るために使える。

## 分類と横並びの置き場

主分類は「札」「心得」。それぞれの画面に3領域を同時表示する。

| 置き場 | 基準寸法での幅・列 | 表示構造・含める物 |
|---|---|---|
| 左の候補棚 | 376px・1列 | 棚板、費用。今回選べる未取得の札・心得 |
| 中央の手元 | 735px・2列 | トレー、同じ物の数量。所持・取得予定のうち未編成の分 |

同じ個体を手元と編成に重複表示しない。未払いの物は点線・斜線・時計印を維持し、確定で通常の輪郭へ変わる。色や説明文だけに依存しない。個体は移動しても同じ大きさを保つ。

## 共通枠と容量

- 札・心得は全領域・移動中で **352×80設計px**。名称は20px・24px行高の2行、名前の幅260px。右端の主要操作は72×76px。最大25文字に対して26全角文字分の寸法を確保する。[名称調査と寸法](name-metrics.json)。フォント実測は未確認。
- 名称48px高＋補助値20px＋上下余白8px＝本文76px、上下枠線4pxで高さ80px。前版をそのまま拡大せず、1920×1080の表示密度に合わせて名称・操作・間隔を配分し直した。
- 項目間隔8px、領域間20px。候補を1列にして、手元・編成はそれぞれ2列へ配分。少数の項目を引き伸ばさない。
- **候補4件・手元20種類・編成12枚**を同時に収める設計。各一覧の高さ878pxに対し、必要高は候補348px・手元876px・編成524px。全てDOMへ描出し、ページ送り・間引きをしない。
- 容量を超えた分は各一覧の縦スクロールで保持する。20種類はUIの容量検証目標であり、ゲーム上の所持上限・通常所持数の実測値ではない。現行M1の候補2〜4件、1群から取得1点、札組12枚を引き継ぐ。

## 動かせる操作

| 操作 | 配置と結果 |
|---|---|
| 取得 | 候補の右端。未払いのまま手元へ移る。正式所持・実残高は変わらない |
| 編成 | 手元の札の右端。同じ個体が編成へ移る |
| 外す | 編成された札の右端。同じ個体が手元へ戻る。取得予定と費用は残る |
| 取消 | 未払いの札の詳細下端、または候補棚へ戻すドラッグ。その予定分だけ候補へ戻す。既存の所持品には作用しない |
| 戻す | 画面全体の下端。取得予定と編成の変更をまとめて最後の確定状態へ戻す |
| 確認する | 画面全体の下端。支払いと、取得先・編成の差分を表示する |
| 確定する | 確認窓の下端。隣に費用を置き、制約を満たすと支払い・正式取得・編成を一括反映する |
| やり直す | 操作案の外側。確認用の固定入力とスクロール位置へ戻す |

対象と費用はボタンの外へ置く。詳細は札の表面から開き、操作を窓下端に固定する。札・心得の切替、詳細の開閉で未確定内容を失わない。確定後も無料で編成を出し入れでき、所持は残る。

## ドラッグとスクロール

探索画面と同じ、**220ms保持して移動／保持前のスワイプはスクロール／短いタップは詳細**の分け方を使う。ボタンからの操作も維持する。

| 移動元 → 移動先 | 結果 |
|---|---|
| 候補 → 手元 | 未払いで取得 |
| 候補 → 編成 | 未払いの取得と編成を一緒に反映 |
| 手元 → 編成 | 編成 |
| 編成 → 手元 | 外す。取得予定・所持は保持 |
| 未払いの物 → 候補 | 取得取消。予定分の編成も外す |
| 正式所持の物 → 候補 | 移動不可。売却・返還・削除にならない |
| 同じ領域、領域外、中断 | 内容を変えない |

ドロップ可能な領域を枠と操作名で示す。保持中に一覧の端へ寄せると自動スクロールする。移動後の余分なクリックで詳細を開かない。Esc、ポインター取消、capture喪失、フォーカス喪失、別ポインター、表示サイズ変更で移動を中断する。

ページ送りは廃止し、全ての物を同じ大きさで詰めて並べる。余白ドラッグ、保持前のスワイプ、ホイール、一覧内での上下左右キー、通常のスクロールバーで連続スクロールできる。分類切替・詳細の開閉で位置を保持する。

16:9固定とし、ゲーム全体は縦スクロールさせない。詳細・確認窓は本文だけスクロールし、操作を下端に固定する。初期の候補・手元・札組、および上記の容量確認用ケースを配置計算とDOMで確認した。実ブラウザーの表示幅・文字の収まり・操作感は確認を残す。

## 動かせる操作

| 操作 | この画面で確かめる結果 |
|---|---|
| 取得予定に加える | 札・心得とも未払いの予定へ追加。支払予定と確定後の着想が変わり、実残高・正式な所持・確定編成は変わらない |
| 編成の＋／− | 所持品と取得予定を同じ編成へ出し入れする。未確定の物にも別の習得は不要。外しても取得予定と費用は残る |
| 取得をやめる | その予定と費用を取り消し、予定分を編成からも外す。同種の既存所持品と装備には作用しない |
| 取得・札組・心得の切替、詳細を閉じる | 同じ未確定内容を維持する |
| 変更をすべて取消 | 取得予定と編成の変更を一緒に破棄し、最後に確定した状態へ戻す |
| 比較・確定 | 支払い、正式取得する物、編成に入れず取得する物、編成の差分、変わる心得の条件と効果を表示する |
| 着想○を使って確定 | 残高・札組・同種枚数・装備容量を満たす場合だけ、一時的な確認状態の中で支払い・取得・編成を一括反映する |
| 取得後の編成変更 | 支払いなしで出し入れでき、所持は残る |
| 最初から | 本編外の確認操作。固定入力へ戻し、別の選択を試せる |

一覧は名前から詳細、下端から操作する既存原則と配色を継承。16:9固定、ページ全体を縦スクロールさせず一覧をページ切替。詳細・確定窓の本文だけスクロールし、閉じる・取得・確定の操作は固定する。狭幅では一覧を一列にし、見通しを比較窓へ集約する。

## 確認してもらう短い経路

1. 心得「属性連携」を取得予定に加え、詳細の＋と−で出し入れする。着想が未払いで、外しても予定が残ることを見て「取得をやめる」。
2. 札「軽い・汐留め」を取得予定に加え、編成へ入れる。札組から1枚外して12枚に戻す。
3. 「比較・確定」で支払いと編成を確認し、確定する。着想と所持が予想どおりに変わるかを見る。「最初から」で再試行できる。

見る点は、未払いと正式取得を見分けられるか、編成から外す操作と取得をやめる操作を迷わず使えるか、確定結果を事前に把握できるか。価格の良否や本編の通し試遊は今回の確認に含めない。

**現在の防御処理（2026-09-19）：[D56・張り直し方式と効果別管理](../appendix-d56/README.md)。** rules/engine/public契約0.3、旧保存互換・43項目の限定確認。以下の過去の版・結果は固定履歴として読む。

2026-09-19 JST／追補0.1。Work `20260909-design-assembly`、作業・統合先 `dev_design_tmp_assembly`。ユーザーの残件続行指示により、承認済みD55だけを実装した。CO-D02Rの保存・公開追補は既に提出済み。

## 変更と版

`src/runtime/core.mjs`で、合法な一致攻撃の効果適用後に有限身構の回数を1減らす。体勢未到達、攪乱で削り0、身構で0ダメージでも消費し、最終回も今回の攻撃へ適用してから解除する。他者への攻撃・設置・回復では被攻撃として消費しない。本人一致による従来の身構解除・置換は維持する。

機転の消費はダメージ解決時のまま。回数消費と同時に移動して、回避成功だけで機転まで失う変更にはしていない。予測は同じGame.playを使うため同じ新規則で計算し、UI側の演算追加は不要。

| 項目 | 今回 |
|---|---|
| 規則／engine | `CW-M1-rules-0.2`／`CW-M1-engine-0.2` |
| 保存／公開契約 | `CW-M1-save-1`／`CW-M1-public-0.2`を維持 |
| 内容・カード・試行値 | 入力0.1・SCN001内容0.1を維持。生成スクリプトと生成物へD55の版・出所だけを追記 |
| 公開予測 | 既存の`actor_changes`と`guard_uses`に新しい消費結果を返す。形は変更なし |
| UI入口 | 既存`co-u02/entry.mjs`がruntimeのversionsを参照するため、通常入口のUI原本変更なし |

環境からの付与札、効果別管理、持続防御の回数制限なし、再付与、回数表示は未実装。既存の防御札は試行値の2回を維持し、D54を使う新しい付与札が実装済みになったとはしない。

## 旧保存の扱い

`validateDocument`は既知の旧規則0.1・engine0.1の組だけを、同じ内容のまま新しい版の組へ変換する。残り回数を回復・再計算せず、過去のHP・履歴・乱数・領収・候補保留等を再演算しない。旧保存の次の行動からD55が働くので、旧規則のまま残りの探索を続ける変換ではない。

変換はメモリ上の検証済みコピーへ適用する。open・inspect・previewでは保存装置へ書かず、通常の成功した更新または空slotへの明示輸入で新しい版を保存する。エクスポートする検証済みコピーの版は新しい組となる。書込み失敗では元の保存を維持する。未知版・新旧版の混在・壊れた保存は拒否し、互換と称して検証を緩めない。

## 残る判断とUIへの引渡し

[防御効果案0.3](../../../../仕様案/カード探索ゲーム_防御効果の重ね合わせ.md)に、独立回数・本人一致での共通解除を主案として、同じ発生源からの再付与を累積させるか張り直すかの比較をまとめた。推奨は最新の三値への張り直し。これは新しい遊び方の判断であり、今回の実装へ先取りしない。

UIへ渡す差分は、公開予測の形を維持したまま`guard_uses`の結果がD55へ変わったこと、版の取得をruntimeに従わせること。効果別管理や回数表示の実装依頼とは分ける。長文常設・毎手の詳細窓確認を避ける条件は維持する。残る追加公開APIの描画接続はUI担当の次単位へ。D03・UI描画改修へ自動続行しない。

「持って受けた」は適用対象だった回数であり、毎回HP損失を防いだという意味ではない。HPには敵の攻撃札が減ること、場と循環・手順が変わることも影響する。効果なし対照と区別し、元の環境とのHP差を全て防御効果へ帰属させない。

- 2枚では20/32経過で一度も発動しなかった。発動した経過でも初回は本人8〜12手目。4枚では未発動8/32、初回1〜11手目。**通常循環だけで常時有効・初手有効にはならない。** 採用済みの「札を使う」方式を覆してパッシブへ戻す根拠にはしない。
- 4枚の54付与アクションはV0が42、本人が4、敵E1が8。共有循環で別主体へ渡ることと、現在の使用者が発生源・付与対象外になることを自然な進行で確認した。本人が使うと環境・敵側を助ける局面もある。
- 本人への50付与（4枚条件）のうち、既存の同枠を張り直したものは12。1回条件の終了は本人一致16・回数終了22、2回条件は本人一致30・回数終了8。どちらも終了時残存0。`50 = 張り直し12 + 最終的な終了38`であり、50個の独立効果が同時に存在した意味ではない。
- 2枚では1→2回にしても被攻撃への適用6回・行動数・HPが変わらなかった。4枚では適用が22→30回、平均HPは+0.125。回数を延ばしても本人一致では消えるため、回数だけを増やして常時化する発想は合わない。
- 本人防御1回／無制限の対照では、各付与条件で付与回数・被攻撃適用回数・終了HPが同じだった。この方策と区間で差が出なかった記録であり、あらゆる構え・回避・人の戦略が同等という証明ではない。

次の**数値試行の出発点**には、発動と借用を観測しやすい4枚・1回を推奨する。製品値の採用ではなく、2枚・2回等の正式承認をここで求めない。場補正の方式が変われば量と頻度の評価を更新する。

## 次の判断：全員付与札の場補正（CO-D02R-J02）

既存の基本設計4.7では、通常防御は場札の攻撃補正を身構、命中補正を攪乱へ加える。D56の全員付与処理は検査仮条件として量を固定しており、ここへの適用は採用していない。回数・退場の回答を、この例外の承認には広げない。

**推奨：通常防御と同じ対応を全員付与にも使う。** 今回付与する一組を `身構=max(0,札の付与身構+場の攻撃補正)`、`攪乱=札の付与攪乱+場の命中補正` とし、その一組を使用者以外の各活動主体へ渡す。回数は付与札の指定のまま。受け手の一閃は従来どおり、後の防御解決時にだけ身構合計へ適用する。

次は属性Bの付与札（身構2・攪乱10・1回）と、同じ属性の場札の**説明用計算**。自然進行でこの候補規則を試した結果ではない。

| 一致材料 | 場の攻撃／命中補正 | 推奨：各受け手への付与 | 代案：固定量 |
|---|---|---|---|
| 補正なし | 0 / 0 | 身構2・攪乱10・1回 | 身構2・攪乱10・1回 |
| 踏み込み | +6 / 0 | 身構8・攪乱10・1回 | 身構2・攪乱10・1回 |
| 重撃 | 0 / −20 | 身構2・攪乱−10・1回 | 身構2・攪乱10・1回 |

推奨は、場の正負の補正と張り直し時の量の増減を通常防御と揃えられる。一方、+6は受け手ごとに乗るため全体への影響が大きく、負の攪乱なら被攻撃時に体勢を削られやすくなる。弱い一致材料で張り直せば旧い強い付与を置換する。固定量の代案は付与量が安定するが、全員付与だけ場補正を無視する例外が残る。

**採否待ち1件。** この資料では全員付与の演算・本編配置を変更していない。適用を採用する場合、共通演算と公開予測を同時に更新し、正負の材料・張り直し・版互換に絞って確認したうえで試行値を見直す。数値、表示方式、D03の着手を同時承認したことにはしない。

## 採用した演算

全員付与札が手札から一致したとき、今回付与する組を通常防御と同じ対応で作る。

- 身構：`max(0, 付与札の身構 + 場札の攻撃補正)`。
- 攪乱：`付与札の攪乱 + 場札の命中補正`。負も保持する。
- 回数：付与札の指定を維持。場の補正や受け手の回数を借用しない。

この組を使用者以外の活動主体それぞれへ渡す。使用者・各受け手の機転を付与時の量へ掛けない。身構には後の防御解決時に受け手の一閃を適用する。同じ使用者・同じ効果種は弱くなる場合も最新組へ張り直し、別発生源とは加算する。

| 属性Bの一致材料 | 身構2・攪乱10・1回からの付与 |
|---|---|
| 補正なし | 身構2・攪乱10・1回 |
| 踏み込み（場+6/0） | 身構8・攪乱10・1回 |
| 重撃（場0/−20） | 身構2・攪乱−10・1回 |

不一致は設置のみ。付与札を場材料として使っても、その全員付与という主効果は発動しない。付与済み効果は、受け手の有限回数消費・一致・退場で終了し、付与元だけの退場では消えない。D54〜D57は再判断・変更していない。

## 旧セーブを保全する接続

既知のrules/engine 0.1〜0.4と内容0.1の保存を、検査済みコピー上で現在版へ正規化する。外側の内容IDはインストール済みの内容0.2を示すが、**進行中の探索と各領収書は出発時の内容IDを保持**する。

| 対象 | 移行時の扱い |
|---|---|
| 進行中の0.1探索 | 札・回数・乱数・初期目録・対象を維持。付与札を途中で追加しない。後から入る対象や精算も0.1へ固定 |
| 既に付与済みの効果 | 保存された身構・攪乱・回数を保持。過去の場札を推測して量を再計算しない |
| 次の出発 | 内容0.2を使用。新しい初期構成と目録版で開始 |
| 過去の領収・報酬・知識 | 内容ID・署名・本文・取得記録を維持。過去の初期目録を新しい構成の全開示へ流用しない |
| open / inspect | 正規化して返すが保存装置へ書き込まない。次の成功更新または明示importで保存 |
| 不正な版・値 | 未知版・旧engineと新内容の混在・NaN/Infinity・回数欠落・目録版の不一致を拒否。黙って初期化しない |

同じ対象でも旧版・新版の経験があれば公開の `knowledge_views` に両方が入る。参照は `key`（target IDとcatalogue versionから構成）で行い、探索中の主体からは `knowledge_key` を使う。内容0.1の完全目録は残るが、未経験の0.2構成は未判明のまま。

## 接続した処理

取得保持を確定した帰還から、候補の保存、購入による個体加算、準備案の比較・確定、次探索の実札・心得、保存再開までを接続した。札の解放だけでは所持個体を作らない。無料選択権・所持・習得・装備可能・使用中を独立して投影する。

候補生成は既存ATの重み付き抽選順を維持し、CO-01Aの名前空間・入力・台帳を注入する。閲覧や購入で再抽選しない。適格な次帰還では未購入の旧候補も置き換え、敗北や保持報酬のない撤退では購入済み状態を含め維持する。候補不足・空プールを重複や無料個体で埋めない。

購入・変換・ロックを既存のrevision／view token／request ID／保存CASへ接続した。候補消費と支出・所持加算、変換の所持減算と資源加算はそれぞれ一体で保存する。失敗時の部分反映、同一要求の二重適用を防ぐ。

BD準備はコピー上で取消・購入・習得・装備・札組を実行し、成功した場合だけ全体を確定する。購入前の取消で実払習得費を返す処理と、個体の低効率変換益は別である。購入予定品 `$purchase` は購入後の準備でだけ利用できる。所持品の参照は確定構成と保存済み案の正確なUIDから導出し、期限切れ候補や消失個体を名前で別品に付け替えない。

修飾後の札性能・行動間隔・心得効果・容量・詳細を同じ合成処理へ接続した。行動間隔の修飾を二重加算せず、同基礎の別個体の効果は合算する。最後の個体の変換は利用権喪失を見積りに明示し、知識・札解放・基礎習得・無料選択権を消さない。

# AN1：体勢版での成長節目と全習得の検討

2026-09-10。基点 `050d146d0b7e54347c0048f940e624d0e65caeca`。D48の体勢版AM1・`terrain40_p40`を固定し、止まっていたAK1の検討を実際の報酬と探索へ接続した。**今回の結論は、候補の段階追加を第一案とし、全習得を防ぐ制限はまだ採用しないこと。最終的な全習得を許すかは遊び方の判断として提示する。**

## 1. 何を確認したか

| 区分 | 条件と件数 | 答えられること |
|---|---|---|
| 序盤の反復 | 初期0pt、A・初期札guard3。最初の保護済み成果で撤退。貯蓄／買える習得を追加の2方針×16開始位置、計32経過・272回の探索 | Aクリア・C解放なしに全習得費用8ptへ達するか |
| 習得数の比較 | A/B/C×2公開方策×16seed×4集合＝384回。集合はなし／PS02／PS01+02／全4種。全て初期札guard3 | 現在の4種を同時に使った場合の限定的な攻略差 |
| 通常進行の再集計 | 保存済みAMの自然32開始、27件のC挑戦と5再挑戦。新しい戦闘の実行ではない | ポイント残高と支出を合わせた実獲得総量 |
| 節目の予算例 | 上記結果を受けて6候補の具体案を作り、2段階×9予算×2方式＝36条件の購入可能集合を列挙 | 候補追加と上限の違い、取り直しによる全額返還の帳尻 |

新規の探索実行は計656回、プレイヤー18,069行動。保存復元と同じ続行結果631件、反復側の重複精算不変272件、打切り0を確認。全行動の個別予測を新たに網羅照合した件数ではない。既存AMのエンジン・札・報酬・HP・体勢・パッシブを変更していない。

## 2. 通常の進行と、序盤を繰り返す進行

| 進み方 | 確認した総獲得 | 全4種に必要な8ptとの関係 |
|---|---|---|
| AからCを初回クリア | 12件全て3+3＝6pt | 3種類まで選べる。全習得まで2pt |
| BからCを初回クリア | 10件全て2+3＝5pt | 2種類と残り1pt。全習得まで3pt |
| Aの最初の踏破で帰り、ポイントを貯める | 16経過全て8〜9出発で8pt。総行動105〜130、平均116.75 | A未クリア・C未解放のまま全4種の購入が可能 |
| 同じ反復で、獲得に応じて習得する | 16経過全て8〜9出発で8pt。総行動101〜131、平均114.56 | 同じく全4種を購入可能 |

反復2方針とも、各16経過の合計は撤退128・死亡8。成功例だけを選ばず、死亡で今回の成果を失った回も含む。開始位置は同じ16seedをずらした感度確認で、独立した32人・確率標本ではない。途中で使ったポイントも総獲得へ含め、返還を新しい報酬として数えていない。

旧AK1の「A→Cで7pt」は旧式AJの保存記録に対応する。体勢版の今回の進行へ転用しない。C死亡後の再挑戦も含むAM全記録では、A起点は総量0が1件・3が1件・6が14件、B起点は0が4件・5が12件である。

反復で8ptに達することは、今の試作が正のポイントを繰り返し得られ、候補が有限であることの帰結。全習得費用を14・20へ上げても、十分な反復で届く性質は変わらない。反復を禁止すべき、初回以外の報酬をゼロにすべき、という結論までは導かない。初期4種類が揃う前に次の候補が見える通常進行を作れるかと、長く準備した人にも取捨選択を強制するかを別に決める必要がある。

## 3. 全4種を同時に使った場合

各セルは32条件のクリア数。初期8ptとCへの入場を比較用に付与した値であり、自然に育てた32人の攻略率ではない。

| 探索先 | 習得なし | PS02 | PS01+02 | 全4種 |
|---|---:|---:|---:|---:|
| A | 25/32 | 23/32 | 25/32 | 26/32 |
| B | 24/32 | 25/32 | 30/32 | 30/32 |
| C | 17/32 | 22/32 | 27/32 | 27/32 |

CでPS02と全4種の両方がクリアした同じ19組は、平均42.47→44.32行動。全4種で新たにクリア8件、逆に失ったクリア3件があり、「追加すると常に速く楽に終わる」という結果ではない。時間変更・回復・行動方策から循環と相手の行動も変わる。熟練者なら必ず同じ差になるとはいえない。

今回の4種では、PS01+02に対してPS03+04を足してもB/Cのクリア件数は変わらなかった。これは両スキルが不要という証明ではなく、単純方策と初期構築で価値を拾える範囲が限られることも含む。全4種にしてもCで5件失敗があり、この小さな候補集合だけを根拠に恒久的な上限を必須化する材料は得ていない。一方、候補を全部習得すればその集合内の購入選択が終わること自体は変わらない。

## 4. 次の具体案

[探索全体の設計26章](../../../仕様案/カード探索ゲーム_探索全体の設計.md#growth-milestones-an)に、節目で候補を増やす第一案、上限付きの代案、D/Eの内容と追加2候補を記載した。追加候補は戦闘実装前の案。

| 節目の例 | 候補費用 | その時点で選べるもの |
|---|---|---|
| 初期 | 4種×2＝8pt | AMと同じ。通常の初帰還で1種を試し、無料で取り直せる |
| Cクリア帰還 | 初期4種＋新2種×3＝14pt | 5ptなら初期2種、または初期1種＋新1種。6ptなら初期3種、新2種、初期1種＋新1種と残り1pt等 |
| 同じ段階を十分探索した後 | 全6種で14pt | 制限なし案では全6種を認める。次の地域で追加する際も、別の対処と内容を一組で設計する |

初期上限4・C後上限8という代案では、全6種の費用14を獲得しても使用できるのは8pt分・最大4種まで。長く準備しても取捨選択を残せる代わりに、進行待ちのポイントが発生する。10pt獲得・6pt習得・手元4ptから全額返還すると手元10pt、使用可能8pt・待機2ptとなる。無料返還が上限を増やすことも、超過を消すこともない。

第一案は、段階追加と十分な成長後の全習得を認める方式。理由は、自己強化で既知の探索が楽になるD45と、単純な習得・無料取り直しD47を活かせること。全習得後も取捨選択を残すなら札構築・行先・現地行動で担わせ、パッシブだけを永久に排他にする目標は追加しない。この目指す遊び方は正式採用前にユーザーへ確認する。

## 5. 再現と限界

- [conditions.json](conditions.json)は探索の実行前に固定、[study.cjs](study.cjs)が実行、[results.json](results.json)に全経過と参照ハッシュを保存。
- [milestones.json](milestones.json)は探索結果を受けた具体案、[milestones.cjs](milestones.cjs)・[milestone-results.json](milestone-results.json)が36件の費用列挙。探索条件の事前固定と混同しない。
- D/E・PS05/06の戦闘、候補の解放処理、成長上限、装備枠は今回の実装に含まない。新しい人評価・実端末評価もない。
- 仮のHP・値・費用・報酬を製品値へ採用しない。AM・AK以前の結果は変更せず、今回の全結果で成功と失敗を残す。

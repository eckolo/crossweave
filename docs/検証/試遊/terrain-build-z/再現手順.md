## 組立

試遊ブランチのリポジトリルートで次を実行する。Node.jsの標準機能だけを使い、出力先の親ディレクトリを事前に用意する。

```sh
node docs/検証/試遊/terrain-build-z/fixed/build.cjs /workspace/crossweave-playtest-z.html
```

出力は会話内で操作するHTMLフラグメント。利用環境のvisualize手順で表示する。通常のWebサイトとして公開する工程ではない。組立出力の期待SHA-256は `8eb15d38e90d5a69e5149240a756fb2221892e4d19de3d9488e1a9bc14bcdafa`、225,311 bytes。

## 記録と限界

[試遊記録](試遊記録.md)へ、選んだ構成・到達段階・所感と実際に取得したログを区別して残す。生成したコードは途中状態のセーブではない。開始時点でユーザーの操作ログ・互換セーブ・選択列は未取得。既存画面は会話をまたぐセーブ受渡しを提供していない。

確認したのは、固定元とのバイト一致、既存buildの正常終了と出力の読み戻し。端末別描画・操作は未確認。旧X回復局面や自動比較Z0〜Z7を今回の途中状態・seed32へ流用しない。運用ブランチの同期によって、この固定入力や進行中のHP・札を差し替えない。

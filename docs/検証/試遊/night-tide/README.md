# PT-NT-001：夜潮の排水路

2026-09-13（日本時間）。担当 `20260909-playtest-terrain-build-z`。一往復を操作できる専用試遊。人の試遊・所感は未取得。

[試遊ファイル](crossweave-night-tide.html)を保存してブラウザーで開く。会話内にも同じコードから組み立てた操作画面を提示する。初期の札組はそのまま使え、出発前の「持ち込む札を整える」で変更できる。札を選び、対象と予測を確認して札の下のボタンで実行する。短いホールドからのドラッグも正式UIの実装を継承。

## 今回遊べる範囲

依頼・札の準備 → 逆流する地下水路＋任意の漂着した潜水服 → 港の発見 → 奥の水門の復旧 → 帰還結果。クリアは水門の復旧であり、潜水服撃破は必須ではない。港での帰還、水門の原因を見た後の帰還、余力0の緊急脱出を区別する。別の試行を明示的に始めると初期状態へ戻り、周回成果を累積しない。

T1踏破で既得成果を保護し、生きた潜水服を後ろに残す。前半の余力・札・場・循環を引き継ぐ。港の本文閲覧に回復・再配布・新しい保護を追加しない。水門の本文を読んだ時間ではNPCが行動しない。写し元の退場時、捨て場の由来札は即消滅、他の領域の由来札は捨てる時に消滅する。

観測した札と初攻略で開いた初期構成は区別し、撤退・緊急脱出後も記録を保持。未攻略の潜水服の全構成や撃破報酬は取得済みにしない。帰還後の余力は40へ回復し、探索終了時の余力も記録に残す。内部の `defeat` に世界観上の緊急脱出を接続し、精算規則は変更しない。

## 正式UIからの差分

相手・場・手札、可変枠、予測線、行動順、窓、右下の履歴、220msホールドを継承。旧PT-Z演算への接続を新体勢・A経路へ変更し、隠蔽の固定100表示と旧2倍計算を修正した。対象ごとの道のり／余力／復旧残量と、進む／攻撃／調えるを表示する。

追加情報の公開時点：依頼時は粗い傾向だけ。初遭遇時に水路と潜水服、T1踏破時に港、次の確認で水門の原因、T2踏破時に復旧を示す。代表札を初めて借りて手札で使える時だけ短い写しの本文を履歴へ出す。初攻略まで相手の初期構成を隠す。本文の確認は時間を消費せず、港での帰還判断に関与する。

正式UIにまだなかった準備・場面文・帰還・セーブ欄を専用追加。650px以下は下帯を2段にして自分の余力が切れにくくした。これらは本試遊の差分であり、正式UIの新しい採用版としない。画像は既存水路見本を全体縮小・WebP圧縮し、表示枠内の拡大で比較用文字を外した。画像内容の描き直しはしていない。

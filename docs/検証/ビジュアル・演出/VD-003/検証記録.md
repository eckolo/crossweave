## 実施した確認

1. 原画像6点のSHA-256・容量を元の照合JSONと比較し、公開固定入力の画像・制作指示・原照合JSONに差分がないことを確認。
2. 生成直後の6出力を個別に実見。方位磁針はローカル画像表示の原寸指定でも再確認。題材名と「修正版・比較案」の日本語ラベル、部品接続・向き・道・色面・境界・筆触を確認した。ゲーム画面の倍率や実端末は固定していない。
3. 生成元PNGと保存コピーのバイト一致、SHA-256・容量・寸法・Git blob、制作指示のハッシュを照合。後加工はしていない。機械照合結果は[保全確認JSON](保全確認.json)。
4. 原画像を左、R1を右に参照する[比較資料](../../../仕様案/ビジュアル・演出/別題材6種の修正版.md)を用意。画像を加工した比較ボードは作成せず、生成原本を参照する。

## 結果と限界

全6点のラベルと元画像への対応を確認。方位磁針の単方向の針、底抜けの部品接続、獣の四足と大きな角、背景の足場・道が残っている。巻き糸・葉・角内景色は大きな面へ整理された。駅は雲・床の細かな筆触が多く残り、草原の透過と反射の対応は弱い。方位磁針の外周もほぼ一周追える。全体に粒状の筆触が残り、方針の適用が十分安定したとは判定しない。

これらはAIの目視所見。R1へのユーザー所感・個別素材の正式採用は未確認。DBの具体造形、アイコン寸法、画風の一本化を新たに採用していない。UIの文字・数値・記号へ輪郭省略を一律に適用する変更もしていない。

元画像と異なる指示による改稿を各1回行った結果であり、同条件の反復再現性は検証できない。縮小時の識別、正式UIとの合成、独立した透過素材、潜水服、逆流を伝える動き、ゲーム性能・面白さは別課題。VD-001の静的試験やVD-002の原本確認を、R1の合格実績へ転用しない。

再開は照合JSONと[引継ぎ](../../../作業資料/ビジュアル・演出/引継ぎ.md)の最新状態から。6出力の再生成は不要。

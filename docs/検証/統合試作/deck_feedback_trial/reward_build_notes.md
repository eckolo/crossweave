# AI：報酬を使う構築と再挑戦

2026-09-10（UTC）。基点`194c5f73915230113d77e402d8402aa6e9cfa538`。基本設計0.47・D47を前提にした追加比較。**試行値・機械方策による結果であり、製品仕様の採用や人の試遊結果ではない。**

A/Bの片側だけで得た報酬を使い、Cを攻略する経過を両方で確認した。一方で、報酬札を多く入れることが一律の改善にはならず、以前使っていないseedでは構築の順位も変わった。報酬は新しい対処の候補として扱い、入替えで失う役割も準備で示す。C前半を短くする案は、前半の作業量と到着状態を改善する比較候補として残す。

## 再現・固定条件

```bash
node docs/検証/統合試作/deck_feedback_trial/reward_build_study.cjs
```

- [入力](reward_build_inputs.json)、[乱数生成](reward_build_inputs.py)、[準備と出発処理](reward_preparation.js)、[再現・集計](reward_build_study.cjs)、[全結果](reward_build_results.json)。AH以前の実装・入力・結果を変更しない。
- 主比較は9構築×4習得集合×2方策×2内容×8 seed＝1,152経過。AHと同じseed 0〜7を使用する。別に未使用のseed 8〜15を、3構築×2習得×2方策×2内容で192経過実行。**計1,344経過**。後者も実行前に条件を固定し、結果に合わせた調整はしない。
- ポイント総量は全構築2。無習得は2を残し、PS02/PS03/PS04はそれぞれ2で習得する。HP・札性能・スキル効果・報酬額はAHと同じ。比較プロフィールの札解放は統制用で、自然獲得したと扱わない。
- C32はAHと同じ。C24は入口通路V0のHPだけ32→24。S・敵・報酬・行動間隔・共有循環・パッシブは同じ。効果を混同しないためPS02の値を同時に弱めてはいない。
- 方策はAHの目標先行/支援先行。公開中の手札・場・主体と今回予測から選び、隠れた札や未来乱数は使わない。設置した報酬札を誰が利用するかを先読みして最適化するAIではない。
- 自作可能な枚数指定APIへ、設計側が事前に作った9構築を入力した。人が自由に組んだ結果、全合法構築の探索、最適構築の決定ではない。
- 札構築が変わると札種の正規順と初期シャッフル結果も変わる。同seedの勝敗差を、その一枚の局所効果だけの因果証明にしない。C32/C24間は同じ構築・初期札順でHPだけを変える。

## 構築の狙いと交換する役割

基準は防御3枚の攻撃8/防御3/回復1と、防御5枚の攻撃6/防御5/回復1。全て12枚・同名2枚上限、属性A4/B4/C2/D2を維持した。報酬札を1枚取得したことを物理札1枚だけ使える在庫制へ変更せず、解放後の構築上限内で1/2枚を比較する。

| 案 | 入替え | 増える手段 | 失うもの・負担 |
|---|---|---|---|
| Aの保証報酬を1枚 | 重撃1→踏ん張り1 | B属性の防御、場に置いた場合の威力補助 | 威力12の攻撃が1枚減り、期限は3から1になる |
| Aの保証報酬を2枚 | 重撃2→踏ん張り2 | B属性防御を厚くする | 重撃がなくなり、突破の手段を大きく減らす |
| Bの報酬を1枚 | 重撃1→溜め打ち1 | 期限4の保持、場で威力+4 | 自分で攻撃する威力12→9、命中30→20 |
| Bの報酬を2枚 | 重撃2→溜め打ち2 | 長く保持する攻撃を厚くする | 瞬間火力・命中の低い札の割合が増える |
| Aの任意敵報酬を1枚 | 牽制1→鋭撃1 | 威力3→8、場の命中補助30→40 | 命中70→40、期限2→1。Aクリアだけで得たと扱わない |

2枚案と任意敵案は防御3枚基準だけ。全効果・名称は既存の試行値で、世界観の確定名ではない。

## 結果と、過大に読まない点

| 構築 | C32・クリア/64 | C24・クリア/64 |
|---|---:|---:|
| 初期札・防御3 | 31 | 32 |
| A報酬1枚・防御3基準 | 28 | 29 |
| B報酬1枚・防御3基準 | 44 | 37 |
| 初期札・防御5 | 32 | 36 |
| A報酬1枚・防御5基準 | 26 | 40 |
| B報酬1枚・防御5基準 | 32 | 38 |
| A報酬2枚・防御3基準 | 21 | 14 |
| B報酬2枚・防御3基準 | 37 | 32 |
| A任意敵報酬1枚・防御3基準 | 29 | 40 |

防御3枚基準ではB報酬1枚がC32で31→44クリアだったが、2枚では37。A報酬2枚では21、C24では14に下がった。防御5枚基準のA報酬1枚はC32で32→26、C24では36→40だった。**報酬札の枚数だけでも、札単体の性能だけでも、準備の良し悪しは決まらない。**

未使用seedでは、初期札/A報酬1枚/B報酬1枚のクリアがC32で18/16/17（各32）、C24で17/18/22。旧seedでのBの大きな優位は、そのまま再現しなかった。弱点や得意条件を探す材料であり、推奨順位の確定には使わない。

C前半のHP32→24では主比較のクリアが280→298/576、未使用seedでは51→57/96。両条件で敵参加へ届いた同じ540経過を比べると、前半は平均4.76行動短く、到着HPは平均4.52高かった。未使用seedの同じ92経過では4.11行動短く、HP3.22高い。比較する生存経過が異なる平均だけから改善と推定したものではない。

ただし主比較で新たにクリアした96経過に対し、以前のクリアを失った78経過もある。未使用seedでは21対15。短い前半が全構築・同じ方策で必ず良くなるとはいえない。数値を24に確定するのではなく、前半を長い消耗の壁にしない内容案として次の操作比較へ残す。

単独PS02のクリアは主比較C32で85/144、C24で92/144。PS03は67/68、PS04は65/70、無習得は63/68。新seedでもPS02がPS03を上回る。報酬札の構築を広げても習得の偏りは残り、無料取り直しだけで解消したとはいえない。PS04の回復時点等を十分活用しない単純方策の制約も残す。

P由来の報酬札はPが2,161回、NPCが1,613回使用した（設置・一致を合計、重複する経過を含む）。報酬札の性能は共有循環で他主体も利用する。習得パッシブの補正はPの札に焼き付かないので、札解放とパッシブ習得の役割を同一視しない。

## 自然獲得から、片側だけの準備と再挑戦

追加の連続経過は、初期ポイント0・防御3枚基準でAまたはBをseed sで目標先行攻略。8 seedを省略せず実行し、クリアした帰還から「初期札を維持」と「得た保証報酬を1枚使用」を分岐させる。どちらも実獲得ポイントだけでPS02を習得し、C32のseed (s+1)%8へ。Cで死亡した場合だけ、無料でPS04へ取り直し、同じ構築でseed (s+2)%8へ一回再挑戦する。これは同じ帰還からの比較分岐で、報酬の二重取得ではない。

| 最初の探索 | 入口クリア/開始8 | 初期札のままCクリア/入場 | 報酬1枚でCクリア/入場 | C死亡後のPS04再挑戦 |
|---|---:|---:|---:|---|
| Aのみ | 5/8 | 3/5 | 5/5 | 初期札の2失敗から1クリア・1死亡。報酬分岐は死亡なし |
| Bのみ | 7/8 | 3/7 | 5/7 | 初期札の4失敗から2クリア・2死亡。報酬分岐の2失敗は両方再死亡 |

入口で死亡したAの3経過・Bの1経過はCへの成功率の分母から消さず、入口結果として記録する。報酬分岐の初回C到達成功は、最初の入口から数えるとA5/8、B5/8。**選ばれた成功帰還に条件付けた5/5を、一般的な100%攻略保証とは扱わない。** 両側の固有札を持つことや、反復して点数を増やすことを必須にしなくても、片側準備でクリアする具体経過があるという到達点である。

例として入口seed1後のC seed2では、初期札維持は33手死亡、A報酬1枚は39手クリア、B報酬1枚は35手クリア。構築変更後は初期の引き方も変わるため、防御増加や期限延長だけに勝因を断定しない。前回AHの防御5枚・C seed1の死亡はその条件の記録として保持し、今回の成功へ上書きしない。

死亡後は今回の報酬を失うが、過去の解放・素材・ポイントと知識を維持した。無料振り直しで新たなポイントや素材を増やす処理はない。知識はデータとして次へ運ばれたが、機械方策はそこから戦略を学ぶものではなく、人の学習を実証していない。

## 準備変更の情報を、一つの案として扱う

`reward_preparation.plan`は現在のプロフィールと変更前後の札枚数・習得集合を受け、全条件を満たす次プロフィールと変更内容を返す。未解放札・枚数違反・不足ポイント・探索中変更を拒否し、失敗時に元プロフィールを変更しない。札の入替えと習得の取り直しを別々に途中確定する画面の実装ではない。

表示に渡す項目は、入替える札と両方の性能、攻防/属性構成の前後、外す/覚える/維持するスキル、返還と支出と残ポイント、保持済み素材と解放札。相手の未知札・未来の出現順や推定勝率を用いて推奨する機能は含めない。札とスキルを維持する操作も成立し、全ポイントの消費を強制しない。

確認した範囲は9構築の準備変更、59,825回の選択行動の予測/実行、1,316回のC前半から敵戦への接続。C32がAHと同一の出発状態を作り、C24が通路HP以外を変えないことも照合した。

関連点検で、C32/初期札防御3/無習得/seed1の26行動後、敵由来の小突きが手札にあるのに知識へ残っていない漏れを確認した。AHを過去条件として保持し、AIの`Game.refill`で、借り札が自分の手札へ来た時点に未記録の種類・効果だけを記録する。観測者はPで、敵が使用したという事実や初期山札の全開示を捏造しない。保存復元と死亡精算fixtureでもこの記録を維持することを確認した。修正前後の1,344経過と自然獲得・再挑戦の戦闘結果は不変で、知識を含む状態署名は更新された。

実際の操作画面・表示の理解・手触りは未評価。UI-R-002の固定ZをAH/AIへ接続済みとしない。次に人へ確認する場合は、本人が狙いを決めて枚数を変更し、「変えた準備が何に効いたと感じたか」「再挑戦で何を変えたいか」を短く取れる形へ接続する。

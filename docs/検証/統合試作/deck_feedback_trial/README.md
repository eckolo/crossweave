## 追加Xの比較範囲と結果の読み方

## 山札と属性枠

自分の未ドロー札を種類・属性・性能ごとに集計し、残数、主効果、会心増加、場の攻防／命中回避補正、期限、設置／一致コスト、消滅条件を表示。手札枚数と初期持込枚数は別欄。初期札は残0枚でも残し、共有循環から受け取った種類を追加する。消滅予定の山札内枚数も表示。メニューは最初から開き、開閉状態を操作のたびに戻さない。

場は属性ごとの枠を維持。自分の現在の山札・手札と公開された場で確認した属性を保持し、未知の属性が場へ出たら枠を追加する。世界全体の属性一覧や、相手の非公開札から枠を作らない。これは今回の表示候補であり、今後出現し得る属性の完全な予告ではない。空枠の保持・イベント切替時の整理は今後のUI検討として残す。

## 追加Xの被弾後局面（過去の再現用）

入口を長くするだけでは被弾しない試遊もあり、前回の人評価は消滅心理を評価できない条件だった。補助試遊は、HPを操作せず、同じ入口から合法な行動で到達した状態を使う。

選定条件を事前に固定：`roles`、山札再構築1回以上、PのHP20〜44、回復16が現在成立、後続敵が生存、後続環境HP30以上、回復以外の手札2枚以上、回復期限3以上。プレイヤーの選択乱数seed0〜127を昇順、各最大40手で調べ、最初の該当を選ぶ。終端結果で選別しない。前置きは回復札以外の合法手から抽選するため、通常プレイの代表例・推奨方策とは扱わない。

最初の該当は選択seed6、P16手目、HP36/60、再構築1回、回復草残6手。回復16、見切り防御1・回避30、踏み込み設置が選べる。`recovery_checkpoint.json` に15手の前置き、全状態、乱数、公開記憶を記録し、入口からの再実行で一致を確認。X作成時の操作画面の「被弾後の判断局面から」は、この前置きを実行していた。Yでこの入口を外し、保存ファイルは過去の再現用として保持する。任意のHP差替えはしない。通常入口からの継続も残す。

その後、回復選択がほぼ定型的との人の所感を受領した。現在防御なし・即ダメージ攻撃なしという選定の不足を統合検討77章へ記録し、この局面への追加回答を現在の作業の前提にしない。回復の必要性だけで心理圧を確認済みにせず、回復後のHP保持と攻撃機会・防御維持を含めて評価する。

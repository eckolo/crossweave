## 比較範囲と結果の読み方

Wと同じ入口seed32を4プロファイル×2対象優先×3防御優先で24経過比較。対象優先は環境／岩。防御を選ぶ際は防御量／回避／会心加算の各優先で比較し、回避や会心の個性を防御量だけの順位で評価しない。攻撃は今回のHP減少、命中蓄積、札威力、期限の順。回復は欠損16以上、または期限1で正回復できるとき。他の手があれば回復を残す。判断に相手の非公開札や未来乱数を使わない。

同じ入口・同じ後続方策の条件比較。重複する経過を含み、24人・24独立標本ではない。全結果と指標の分母は `results.json`。攻撃札のない手札、防御だけの手札、その連続回数、該当防御札の出現元、会心を伴う命中攻撃、実回復、被害、手数を別計数。HP収支も照合する。「攻撃札なし」は回復札等も含むため「防御札だけ」と同義ではない。

表示残数と実際の山札・手札の一致、全4,429合法手の今回予測、161回のJSON保存復元を確認。山札順の入替と相手の非公開属性の改変で自分の一覧が変わらないこと、後続敵にも札の会心値が適用されること、3防御構築の枚数・属性・同名上限を検査する。机上比較の結果は[統合検討73章](../../../作業資料/カード探索ゲーム_統合検討.md)へ記録。

## 山札と属性枠

自分の未ドロー札を種類・属性・性能ごとに集計し、残数、主効果、会心増加、場の攻防／命中回避補正、期限、設置／一致コスト、消滅条件を表示。手札枚数と初期持込枚数は別欄。初期札は残0枚でも残し、共有循環から受け取った種類を追加する。消滅予定の山札内枚数も表示。メニューは最初から開き、開閉状態を操作のたびに戻さない。

場は属性ごとの枠を維持。自分の現在の山札・手札と公開された場で確認した属性を保持し、未知の属性が場へ出たら枠を追加する。世界全体の属性一覧や、相手の非公開札から枠を作らない。これは今回の表示候補であり、今後出現し得る属性の完全な予告ではない。空枠の保持・イベント切替時の整理は今後のUI検討として残す。

## 被弾後から続ける回復判断

入口を長くするだけでは被弾しない試遊もあり、前回の人評価は消滅心理を評価できない条件だった。補助試遊は、HPを操作せず、同じ入口から合法な行動で到達した状態を使う。

選定条件を事前に固定：`roles`、山札再構築1回以上、PのHP20〜44、回復16が現在成立、後続敵が生存、後続環境HP30以上、回復以外の手札2枚以上、回復期限3以上。プレイヤーの選択乱数seed0〜127を昇順、各最大40手で調べ、最初の該当を選ぶ。終端結果で選別しない。前置きは回復札以外の合法手から抽選するため、通常プレイの代表例・推奨方策とは扱わない。

最初の該当は選択seed6、P16手目、HP36/60、再構築1回、回復草残6手。回復16、見切り防御1・回避30、踏み込み設置が選べる。`recovery_checkpoint.json` に15手の前置き、全状態、乱数、公開記憶を記録し、入口からの再実行で一致を確認。操作画面の「被弾後の判断局面から」もこの前置きを実行する。任意のHP差替えはしない。通常入口からの継続も残す。

この局面で消滅が理由に影響するかは人の評価が必要。回復の必要性と、回復札を消す将来負担は別の問いであり、実回復ができることだけで心理圧を確認済みにしない。

## 最初に確認・保全すること

手順資料だけが追加された枝HEADでも、apps/crossweave-godotが基準e480ef45と完全一致なら同本編として検査できます。その場合は実HEADと基準SHA、全本編path/blobの一致を別々に記録してください。manifestのHEADを別SHAへ書き換えないでください。

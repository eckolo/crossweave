# 今回版の確認入口

[README](README.md) → [ID台帳](UI対応表.json) → [暗色原寸対](comparisons.json) → [実測/切出し](id-comparisons.json) → [結果](results.json) → [残件](必要群と残件.json) → [固定提出](publication.json)。同じMain.tscn／GameScreen／FileGameSessionを使い、新しい本編・配布物は作らない。

通常起動は了承暗色へ固定。`--ui-theme=light`は隔離検証専用の過去診断条件で、通常表示や配布条件ではない。`normal-and-human-final`はtheme引数を使わず、OS明色/暗色相当の選択関数と実Mainの開始/準備/探索/帰還・共通窓を確認する。実OS設定は変更していない。

`approved-dark-final`11modeは今回の追加証拠と取得画面の共通窓。`rendered-dark`19成功caseは変更外の使用先に再利用し、未登録検査modeによる同manifestの失敗は保全。再利用理由はresults.json。`related-final`24modeは一巡、別プロセス再開、確定/再送、拒否/不明/復旧、スクロールとドラッグ取消の限定影響確認。

Windowsの実描画は既存background_desktop.pyから切り替えない検査desktopへ隔離。input desktopの前後一致を各background-desktop.jsonへ記録。実GPU/Viewportとviewport-local InputEventを使い、物理入力・DPI・音・GPU性能の受入とは分ける。通常セーブへ向けず、検査だけの新しいslotを作る。

候補表示のrepro-mountain-reviewは元dtoに触れないmetadataから既存Lucideを同じ描画器へ渡す。通常起動から呼べず、候補は未採用。人に開発環境導入・ビルド・通常保存編集を要求しない。

# 固定修正を読むためのコード解説

読む順はGameScreen.cs → Layout.cs → AcceptedStyle.cs → Preparation.cs/Exploration.cs → AcceptedWindows.cs/ReviewFixes.cs → UiAutomation.FixedRecheck.cs。すべてapps/crossweave-godot/Godot/Application/配下。同じpartial classをファイルで分け、sessionやゲーム規則は増やしていない。

C#/.NETのpartial、Dictionary、Task、LINQは言語/実行環境の機能。GodotのControl、Label、Container、Theme、TextureRect、FontVariation、Shader、InputEvent、FramePostDrawはエンジン機能。1918×1078の内側座標、公開値の事実表、原本CSSの用途別値、親scroll保持、120/220msの意味は本作の表示契約。

通常の配色はNormalThemeIsDarkで了承暗色へ固定し、初期化とRenderの両方で適用する。OS値は相当条件の検査入力に留める。cpとcjは同じlight hexでもdark paperが違うためColorScopeで区別する。原本の実DOMと後勝ちselectorを確認し、cw-drawerの最終実値はopaque #202820。上流宣言の#202820e6を全窓へ一律適用しない。共通menu/記録は取得画面から開いてもcj。

LineBoxFontは元のYu Gothic UI face/sizeを維持してbaselineだけを実測3px上げる。Controlと入力範囲は動かさず、64pxglyph/Georgiaへこの測定値を流用しない。文字縮小・省略で合わせない。Ledgerは折返し用Paragraphを数値へ使わず、実文字幅とnowrapを確保。取得詳細の元footerはflex:1相当の均等幅にし、追加owned機能の配置は個別判断待ちとして保全する。

GradientSurfaceはUVの内積をpixel空間へ換算してCSS角度を再現する。背景は元webpのcoverとobject-positionからAtlasTextureの切出しを求め、素材を再制作しない。consumeは消費予測、changedは別のselectorなのでdanger線へ混同しない。消滅を伴う入力の確定安全条件は変更しない。

閲覧・hover・候補描画はcommand0、DTO/revision/RNG/保存hash不変。確定は既存Send→FileGameSessionの一回確定へ渡す。拒否/不明/worker待機と復旧を保持。検査の保存中は既存BeforeReplace故障入口でworkerを止め、実Mainの描画と二度押し非重複を確認し、解除後にCore期待値と実ファイルを照合する。

検査記録のLINQは窓close前にToArrayで値へ固定する。遅延列挙を残すと解放済みGodotノードをReport時に読む。初期の登録漏れ・遅延列挙・期待case_idの検査失敗は旧フォルダに残し、ゲーム保存失敗の実証へ読み替えない。cueは16msずつの実時計と実FramePostDrawを記録し、PNG圧縮は入力列の後。論理frameと収録待ち込み実時間を性能合格にしない。

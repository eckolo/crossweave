## DEC-UI-03 — 原本挙動と基準の差を整理／人の個別判断待ち

期待値：pin/clickは維持、単なるhoverはcommand/revision/保存不変。開くdelay180、閉じるdelay160の適用境界とpreview入口を明示する。

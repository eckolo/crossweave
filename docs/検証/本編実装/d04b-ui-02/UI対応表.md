## 対象外と根拠

- 仮画像の画風合わせ、新規札画像、演出仕上げはart-hold／card-framesで後続扱い。既存素材の画素は変更しない。
- interaction-proposal.mdは未採用提案。全操作体系の変更はしない。
- 複数探索先はUI-DEST-INT-01、全画面30単位は本依頼の対象外。単一M1本編を維持する。
- GodotとHTMLの文字組・標準スクロールバーなどの差は実画像へ残す。「許容差」の自己認定はせず、独立UI-GODOT-REVIEW-01の入力とする。
- 物理マウス／タッチ、DPI、音・GPU性能、配布物差替の受入は今回の自動実行合格に含めない。

## 最小公開view追補

`Expedition.View`に現在出現済み主体のid・purpose・knowledge_profile_idと本人の札集計、`GameApplication.PublicKnowledge`に既存観測profileの表示名・用途を加えた。地形・既存画像を名前から推測せず、記録を内部IDだけで表示せず、本人の札内訳を保存DTOへ直接アクセスせず描画するため。敵の現在の札・引く順序・将来乱数は渡さない。保存DTO・規則・価格・Content・乱数処理は変更しない。追加テストは読取前後のDTO不変・未遭遇非公開・本人枚数・敵私有札非公開を検査する。

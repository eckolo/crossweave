## 後続へ渡す契約

02Bは `FileGameSession` を起動から終了まで所有する。通常 `user://saves/local/m1.json` をGodot側で絶対OSパスに解決し、Open／明示CreateNewへ渡す。表示にはInspect／ExecuteのViewを使い、DTOを画面の状態原本にしない。Executeのcommittedを受けて確定表示、保存失敗で旧Viewを維持、indeterminateでは通常操作を止めてReload／再起動へ進む。同じ要求は同じRequestIdと内容で再送する。

起動失敗で自動新規作成しない。破損復旧は説明を伴う明示RecoverBackup、終了はDisposeで進行中の同期確定を待つ。詳細は[接続契約](接続契約.md)。読む入口は [FileGameSession.CreateNew／Open／Execute](../../../../apps/crossweave-godot/Infrastructure/Application/FileGameSession.cs) → GameApplication.Execute → ApplicationFileStore.Write／Reconcile。[コード解説](コード解説.md)は上記コードSHAに対応し、Godot固有部分と純C#／.NET・本作独自の設計を分けて説明する。

# 検証資料一覧

ルートREADMEから分離した、分野別の報告・入力・再現資料の索引。必要な検証に取り組むときだけ参照し、全資料の読み込みや全試験の再実行を開始条件にしない。

## 読み始める場所

作業ブランチと担当は[Work分担](../作業資料/Work分担.md)、次の論点は[要検討事項](../作業資料/カード探索ゲーム_要検討事項.md)、採用状態は[基本設計](../確定仕様/カード探索ゲーム_基本設計.md)を確認する。試遊担当は[試遊Work引継ぎ](../作業資料/引継ぎ/カード探索ゲーム_試遊Work_引継ぎ.md)から、登録済みの試遊ブランチの原記録・固定版へ進む。

この一覧は、2026-09-09のREADME分割時点の分野・依存資料を引き継いだもの。下表の「現行」「今回」や件数は、記載された各試験の範囲に限る。進行中の試験ID・コード・条件は引継ぎと試験記録で確認し、一覧を読んだだけで固定版を変更しない。結果の詳細や解釈はリンク先で管理する。

継続編集するコード・入力・小規模な結果はGitHub。[外部成果物一覧](外部成果物.md)の対象だけDropboxから取得し、対応する版と依存資料の組合せを確認する。数値結果・試行値・採用仕様を混同しない。

## この一覧の更新

分野・報告・再現資料への入口や依存関係が変わったときに更新する。通常の試験ログや結果の全文をここへ追加しない。既存の設計検討・検証資料の担当を維持し、担当外Workは自Workへ変更案を保存して受け渡す。

以下は旧READMEの「検証と原案」を相対リンクの付け替え以外は保持したもの。末尾の「このREADME」は移設元の[ルートREADME](../../README.md)を指し、分野別の入口は本一覧である。

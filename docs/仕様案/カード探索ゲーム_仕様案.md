回復1枚を置き、期限と後続供給を比較した履歴を保持する。製品の同名上限を1枚へ変更しない。67章の2手試遊の所感を68章で取得し、温存判断を測るには短いとの指摘を受けた。71章への所感を72章で取得したが、被弾せず回復が不要だったため温存心理は未評価。その後75章で、回復はこの枚数では存在感が薄く、余剰が出ないなら使用、上限を超えそうで期限が近ければ防御的に設置する、という選択の定型化が報告された。77章に従い、旧HP36局面の消滅心理を繰り返し問う方針を改め、総回復量と他の行動を見送る負担を評価する。数値と補給イベントは引き続き未採用であり、現在追加の基本方針の判断待ちはない。

## 2.20 札性能・回復の役割と長期評価【未決定詳細・0.39対応】

71章の長期試遊ではユーザーは被弾せず、回復草の消滅を気にして行動する機会がなかった。回復草の設置は負の場効果を用いた防御的判断であり、消滅への対応行動とは記録しない。長さと、回復の必要性・将来残す価値を分ける。試験選定では再構築だけでなく、実際のHP欠損と回復の合法手、継続する相手、他の行動との競合を確認する。75章の追加所感と77章の評価方針を現在の続行条件とする。

会心が溜まりすぎ、高耐久・高防御を狙う方が高回避より楽に感じたとの所感を72章で記録した。73章では通常会心50→25等を比較したが、対象のHP・軽減・回避を揃えた性能比較ではないため、対象間バランスが改善したとは結論しない。未命中時の会心保持という採用規則を勝手に変更せず、札値・敵環境の配分・進行時間を調整対象とする。

防御札だけの手札の硬直は、持込配分、共有循環での供給、材料不足、未命中蓄積を分ける。環境の初期札や生成札へ防御を多く入れる案には、この停滞リスクを評価項目として付ける。環境に防御札を持たせることを全面禁止した決定ではない。73章の防御3枚構築では攻撃札なしの手札は減ったが敗北も増え、減らすだけで解決したとはしない。

攻防共用札は未採用候補。既存の場補正は他者の攻撃にも防御にも利用できるが、主効果が防御だけの手札で直接攻撃できない問題は残る。具体比較候補は、(a)弱い攻撃と小さな防御を一度に行う札、(b)一致時に攻撃／防御を選ぶ札。前者は攻撃後の防御成立順と万能化、後者は追加操作と使い分けの薄まりを検討する。今回いずれも実装・採用していない。既存規則で個性と配分を改善した試遊にも、弱札・防御への偏りで双方が動きづらくなる所感が75章で残った。76章では弱札の命中を20/50で比較した。威力2を維持して命中蓄積へ役割を持たせる調整案だが、敵・環境も強くなり、防御回避や負の威力による停滞は残る。数値調整で残る問題と、新しい主効果方式の必要性を分けて扱う。

弱札の課題は、(1)攻撃札を引けない、(2)一致材料がない、(3)一致できても命中加算0、(4)命中しても威力・軽減によりHPが減らない、を区別する。未命中中にも会心が増えるため、待つ側が有利な蓄積を得る構造を含めて評価する。命中の最低保証・会心上限や減衰・弱札の一律除去は未採用。命中した0ダメージ攻撃には防御回数や相手の会心を消費させる用途もあるが、所感の硬直をそれだけで解消した扱いにしない。

回復については、上限に収まる分を今HPへ変えれば、回復分は札の消滅後もHPとして残る。待つほど量が増える等の条件がなければ、消滅自体は温存の理由を作らない。使用によって見送る攻撃機会、現在の防御終了、材料・期限の競合を評価する。探索全体での回復可能量と構築枠の負担も別に評価し、枚数増加だけで選択の定型化が解消するとしない。回復を分かりやすい補助行動として位置付ける可能性を残し、すべての札に複雑な迷いを強制するための新規則は足さない。具体比較と限界は統合検討77章。

78章で、弱札命中50なら硬直中も全体に少しずつ命中を積めるという所感を取得した。現在のカードプールの試行基準に維持し、全弱攻撃札の製品値を50に固定しない。支援による停滞そのものを一律に解消する必要はなく、大岩は厄介な地形として除去を促す個性を許容する。支援源自身は対象外とするD39に従う。

突破イベントと敵戦で攻防配分を選び分ける目標を、初期持込・実際の流入・イベントの脅威で具体化する。79章では防御5/3/0を比較したが、敵戦の防御0持込でも共有回収山から防御札を受け取った。「持込0」と「探索中に防御できない」は同義ではない。防御を削ると突破が速くなる一方、後続の敵戦まで含めると不利になる組合せがあり、一本道の初区間だけで構築を採点しない。

準備時に探索先の大まかな傾向（突破主体、敵戦が多い、混在など）を初訪問にも示す基本方針は、D40・基本設計0.40で採用した。具体的な情報の根拠と更新・表示を本書6.4で検討する。具体的な未来札や全遭遇順の確定公開とは別に扱う。苦手なイベントで多少効率が落ちることと、有効な手が長く来ない負担を分けて評価する。同じ探索の途中で自由に初期山札へ戻す仕組みや、防御を必須にする専用攻撃は今回追加しない。

追加AA/ABでは、敵撃破後の環境継続と後続の対象優先を分けた。環境経由・防御0は到着HPのみ満タンでもクリア1/16のまま、後続を環境優先にすると8/16だが敵報酬持帰り0だった。低い元クリア数だけで防御の持込必須、途中回復、攻撃札保証や攻防共用札の新設を決めない。踏破・敵の個別成果・撤退での確保という目的別に、構築と状況に応じた対象切替を評価する。詳細と対照の限界は統合検討81〜83章。

#### 性格・構成傾向・現在の状態を混同しない【情報設計の検討】

性格は、現在使える候補の中で何を選びやすいか・誰を狙いやすいかを表す。札の威力・命中・属性の傾向は、初期構成や観測した札に関する情報であり、性格から保証される能力値ではない。共有循環で借り札を得た主体は、同じ性格でも異なる性能の札を使い得る。

公開済みの現在の補正は、自分の今回の行動結果へ反映できる。一方、光源を除く場合に確定するのはその補正が失われることであり、次の敵攻撃が必ず外れることではない。一致材料を先に消費する場合も、現在のその属性の一致先を消すことと、敵が他属性で行動できないことを区別する。

実際に公開された札・行動履歴を用いる比較では、観測した札の性能と、当時の場補正・命中蓄積を分ける。使用した回数はAIの選好や一致機会で偏るため、そのまま現在の山札構成や次の行動確率にしない。履歴のない既存局面へ都合のよい履歴を後付けしない。

比較を優先するのは、敵札を完全に特定せず複数の行動候補へ備える選択と、その消費・進行の遅れ。全敵の性能上限や発動中能力を初見から保証付きで公開する新仕様は採用していない。基本設計6.2・6.4〜6.7の範囲で仮比較を続ける。統合検討42〜43章を参照。

## 9.1 終了条件の一般化【未採用案・未決定詳細】

移動元：[基本設計](../確定仕様/カード探索ゲーム_基本設計.md) 9.1節。

敵との遭遇を踏破イベントの一種とし、障害物への対処・複数環境の同時存在を認める方針は基本設計0.32で採用済み。以下は具体化が残る範囲。

- 破壊・迂回など各終了条件の達成時に、どの対象が退場・継続し、どこへ進むか。解決方法の名前だけから参加者や進捗をリセットしない。
- 複数環境の終了条件がどの主体を参照するか。一部の対処、複数条件の組合せ、別経路の選択を個別に定義する。主環境・副環境、全環境踏破必須、いずれか一つの踏破で全体終了といった一律方式は未採用。
- 大岩破壊と迂回のどちらでも報酬獲得につなげる方針は基本設計0.33で明確化。その具体内容・量・帰属・獲得時点を定める。敵撃破の報酬処理を名前だけ替えて自動適用しない。
- **保護拡張の判断は終了：踏破以外の終了結果に個別の保護設定を持たせる案は見送り。** 保護は環境踏破でまとめる。岩破壊だけを環境踏破へ読み替える新定義も追加しない。比較記録は統合検討53〜54章。
- 複数環境の一部を踏破する場合の保護・後続・残る環境との関係。環境を増やせば安全な保護機会が増えると一律に扱わない。同時終了・報酬時点は9.7の残課題へ接続する。

仮のイベント構成例・面白さの比較は統合検討35〜39・54〜56章。54章では保護の個別設定を外し、報酬・攻略の負担・残存効果で選び分けを作る方向へ整理した。55章では岩破壊後に同じ環境を継続する/別環境へ進む二構成を、既存P12/P24の初期山札から後続敵・環境まで接続した。56章では二つの環境の同時存在を接続した。具体的な札・数値・分岐結果は正式採用ではない。

55章の試行では、岩破壊の成果を未保護で持ち越し、後の環境踏破でまとめて保護する処理を確認した。後続へ入った510入力中422で、旧環境由来札が他者の手札/山札/場に残った。切替で場や山札を初期化する補助規則は追加しない。岩後の同環境継続は追加踏破の成果と負担を持つ個別構成とし、全岩イベントの必須手順へ固定しない。

56章・追加Nでは、二環境の一方だけを踏破して残る環境を続ける構成と、どちらの踏破でも同じ次領域へ進む構成を比較した。前者の部分踏破でも踏破報酬を含む既得分をまとめて保護し、残る主体・場・予約は継承する。後者では未達成の他対象の報酬は取得しない。領域移動を全体クリアへ読み替えず、主環境/副環境や全環境踏破必須の共通規則も追加しない。

低HP側でも同じ後続へ進める仮構成では、軽い出口へ有利さが偏った。報酬内容・価値は未設定なので、両方に報酬があるだけで選び分けが成立したとはしない。具体的な報酬や後続の違いを次に比較する。一方、双方の命中を抑える霧の仮例では、踏破して早く保護を得る/抑制を残す双方に利点と負担が出た。霧へ準備した同じ32局面の初手比較は敗北回避2・逆に敗北5であり、一律の除去推奨や霧効果20の正式採用とはしない。

対象選択時の表示候補は、今回のHP/命中の確定結果、踏破報酬と共通の保護、残る対象と進行条件、消える存在効果を結び付ける。場へ出す札の負効果を防御にも使えるというユーザー所感を保持する。相手の次札を確定予告せず、現在の既知効果がどう変わるかを示す。実画面・情報負担・習熟は未検証。

新規主体の初回時刻を遷移時刻に置く/10後に置く仮比較では、次PまでのNPC行動が3〜4回/1〜2回となった。次の試験基準は+10とし、継続主体の予約は維持する。正式な初回時刻、同時刻順、初期手札の決定はR03で継続する。後続を遅らせた全経過が有利になるという結論ではない。

報酬内容の候補と再出発は57〜59章へ進めた。両経路で異なる札解放を狙う理由と、浅い踏破帰還による成長を区別する。追加O/Pは単一環境の後続へ接続した比較であり、56章の同時二環境で各報酬を取りに行く最適方策まで検証したものではない。保護条件はD33のまま維持する。

大岩の遮蔽はD39・基本設計4.7に従い、大岩自身を対象から除外する。追加Zでは大岩以外の生存主体へ回避20を与え、後から登場する主体にも適用し、岩退場で解除する。岩自身の軽減8は保持する。旧Yの自己支援は当時の比較入力として残す。現プールでは強い停滞を生むため除去したくなる性質を、この地形の個性として許容する。環境効果全般が凶悪・除去必須という方針へ広げず、他の地形は札構成・報酬・通行負担と併せて個別に比較する。

#### 札で周囲へ作用する天候【候補として保持・詳細未採用】

全体効果の対象範囲、命中・会心・防御の多対象処理、持続・重複・解除は未決定。天候の強い作用を恒久的に保証する専用供給も未採用。具体的な試験へ接続するときに範囲を記録する。今回の光源比較は天候札の検証を兼ねない。

#### 存在中の作用を持つ対象【ユーザー例を受けた検討候補】

ユーザーは、大岩が存在中に環境へ回避支援を維持し、大火力で岩の防御を突破する／高命中で環境を踏破するという例を提示した。対象のHP差だけでなく、対象間の作用を含むバリエーションを検討する。具体的な能力方式の正式採用とは区別する。

## 11.1 札ごとの行動コスト【未採用案・未決定詳細】

移動元：[基本設計](../確定仕様/カード探索ゲーム_基本設計.md) 11.1節。

回数均衡へ向けた比較候補は、全主体に共通する基礎待ち時間に小さな札ごとの差分を加える方式。基礎待ち時間の有無・値、差分との合成、最低待ち時間、端数、同時刻の順、入退場時の扱いは未確定。過去の検証に用いた8・10などを正式値として採用しない。

対策の追加候補【未採用】は、早く動いた後に遅延を負担する方式や、再行動の前に他主体の行動を最低1回挟む方式。前者は回数差を抑えても、先に得る自己再利用の利益を消さない。後者は直接の連続行動を防げるが、介在者がその属性を使えなければ自己再利用は残る。全員の行動を毎回待つ方式を含め、新たな順番制限は採用していない。

表示の比較候補【未採用】：

- 用語説明では、札を出した後、次に自分が行動するまでの待ち時間へ反映する値だと示す。
- 札選択時に現在の場で「設置／一致」のどちらになるかを示し、今回適用する側のコストを強調する。
- 現時点の予定に基づく次の自分の行動位置を示す。敵の将来の札選択まで確定した行動列としては扱わない。
- 一致コストを「命中するための費用」や、資源不足なら一致を選べない仕組みとして説明しない。新たな支払用リソースは導入していない。

許容する差・頻度・成立条件、通常札と例外効果の境界は未確定。

## 12.5 探索報告の候補と統合後の検証【未採用案・未決定詳細】

移動元：[基本設計](../確定仕様/カード探索ゲーム_基本設計.md) 12.5節。

以下は確認済みの具体仕様ではなく、有力な比較候補・検証方針として扱う。

- まず大きな全滅専用報酬を追加せず、個別報酬・踏破報酬・有限の回復手段で攻略方針の選び分けを作る。全滅専用報酬を禁止したわけではない。
- 全滅は残る敵の成果も得て、その敵からの攻撃を止める利益を持つ。特定敵だけの攻略は欲しい成果へ消耗を集中できることを狙い、撃破だけでイベントを終えるか、その後に逃走を要するかはイベントごとに決める。
- 報酬の系統・必要性に差を持たせ、現在の構成や欲しい成長によって狙う敵・終了条件が変わるかを確認する。
- 逃走の負担は逃走成立までに限定せず、その後の環境突破まで含めて比較する。
- 敵残HP2・環境残HP4など、敵の方が残HPが少ない局面でも、場札・手札・欲しい報酬によって環境を先に狙う理由が生まれるかを具体的な札で比べる。この数値自体は仮の局面例である。

## 14. 上書き済み・比較止まりの案【上書き済み・比較止まり】

移動元：[基本設計](../確定仕様/カード探索ゲーム_基本設計.md) 14節。

| 過去の案 | 現行での扱い |
|---|---|
| 大岩破壊など、踏破以外のイベント終了結果ごとに獲得済み報酬の保護を設定する | 基本設計0.33で見送り。両解決経路に報酬獲得を持たせ、保護は環境踏破にまとめる。細かな保護条件による理解負担を増やさない |
| 能力強化を獲得後から今回の探索へ反映し、持帰り分だけ継続する | 比較案にとどめる。能力強化は帰還後反映を採用（2.14） |
| 残り手札を毎回すべて回収 | 使用期限に従って保持・回収する |
| 最古1枚を自動回収 | 札ごとの使用期限へ移行 |
| 対象もすべて自動決定し、札選び以外を許容しない | 常設ターゲットをプレイヤーが切り替える方向へ修正 |
| 退場時に札をすべて回収して、そのまま永続的に流通 | 出現元退場による消滅予定・回収山内消滅を適用 |
| 敵の初期山札を最初からすべて共通回収山で用意 | 新しい敵は専用初期山札を持ち込む |
| 初期山札の一部を最初から回収時消滅札にする | 比較案。出現元の退場後に消滅予定となる方式を採用 |
| 通常札数の供給上限に応じて持込札を使い捨てへ変える | 比較案。固定の供給上限は採用していない |
| 環境HP0なら常にその場で区間が終了するという一律の扱い | 環境踏破をイベント終了条件に含める。ボス戦では緩めの新環境へ交代して戦闘を継続できる |
| HP0の同一環境が行動を続け、攻略後の状態へ変化する | 旧環境が退場し、新しい緩めの環境が参戦する方式へ更新。交代後も環境という行動主体は参加し続ける |
| 同じ行動で条件を満たした各主体の離脱をすべて確定する | 条件はまとめて判定し、イベント別優先順位で一つを選ぶ。敵単独の逃走も選ばれた場合だけ実行する |
| 下限判定から消滅予定札を除く | 最新指示により不採用。存在している間は数える |
| 下限判定から補填専用札を除く | 最新指示により上書き。補填専用札も数える |

# カード探索ゲーム — パッシブの装備と重複

2026-09-11（UTC）。D52・基本設計0.52で採用するのは、同種の同時利用をある程度認め、何らかの制限を設ける基本方向。以下の方式・容量・費用・重複処理は具体案。方式比較は[AQ1](../検証/装備制限/aq/検討結果.md)、探索と取得の接続は[AR1](../検証/装備制限/ar/検討結果.md)。

<a id="recommendation"></a>

## 1. 第一候補は総装備コスト

各パッシブが装備中だけ容量を使い、合計を装備可能コスト以内に収める方式を推す。同じ基礎や同じ性能でも、必要な個数を持っていれば複数選べる。その分だけ別の効果を外すため、集中と分散の交換関係ができる。

基礎パッシブは全習得できるD50を維持する。全習得は選べる手段を揃えることで、同時に全てを働かせることとは分ける。D51の重複所持と不要品の低効率変換も維持し、重複品には「重ねて使う・別構成用に残す・売る」の選択を残す。

最初の試行は**総コストのみ**。固定枠数や同種数の上限を併設するかは、軽い効果の多積み、極端な集中、準備操作の負担を確認して判断する。個別の装備コストは小さい正の整数とし、習得ポイント・売却価格・行動時間とは別の表示にする。

## 2. 七つの方式を比較する

| 方式 | 生まれる選択・利点 | 制約・調整上の注意 | 今回の位置付け |
|---|---|---|---|
| 同種ごとの個数上限 | 特定効果の重ねすぎを直接抑えられ、説明も短い | 別種類を増やせば装備総量も増える。全体の構成選択は残りにくい | 単独の主制限には推さない |
| 固定の装備枠 | 選ぶ個数が分かりやすく、効果数と準備操作を抑えられる | 小さな便利効果も強い複合効果も1枠なら、前者を選ぶ理由が弱くなり得る。各枠の価値を近づける調整が必要 | 分かりやすさを最優先する有力な代案 |
| 総装備コスト | 軽い効果を多めに使う構成と、重い効果へ集中する構成を作れる。同種も容量内で重ねられる | 効果間・組合せ間の費用調整が必要。残り容量に合う品を探す操作も発生する | **第一候補** |
| 総コスト＋固定枠 | 総合的な強さと、同時効果の個数を両方抑えられる | 二つの条件を覚える必要があり、容量が余っても装備できない。軽い補助を多く積む構成を削る | 多積みが実際に問題なら追加比較 |
| 同種の追加分ほどコスト増 | 同種1個目を使いやすく、重ねるほど別構成との交換が重くなる | 集中構成を追加で不利にする。表示コストが現在の装備によって変わる | 同種集中が費用に比べて強すぎる場合の調整候補 |
| 役割別の装備枠 | 攻撃・防御・補助等を揃える理由と、準備の型を作れる | 役割区分が曖昧な複合品を扱いにくく、特化・探索用構成を制限する | 今の自由な組合せには優先度低め |
| 重複効果の逓減 | 重ねることを認めたまま、2個目以降の伸びを小さくできる | 単独では装備総数を制限しない。追加効果が正なら、全て付けるのが有利なままにもなる。予測も複雑になる | 必要ならコスト制の補助として検討 |

枠を使うなら、最初は一個につき一枠が明快。強い品だけ二枠・三枠を占める方式は、実質的に整数の装備コストを枠で見せる表現でもある。「8容量のうち6使用」のような表示と比較できるが、両方を別の制限として数えない。

同種の追加負荷を試すなら、2個目＋1、3個目＋2という増加例がある。今回はコスト8で「通常PS02を2個＋PS01」が8→9となり、成立しなくなった。重複が可能というだけで追加罰を付けず、この集中が実際に強すぎる場合に使う。

逓減も全パッシブへ一律に掛ける必要はない。数値加算には適用しやすいが、条件を解放する効果や一回限りの救済効果には別の重複定義が要る。効果量の下限・発動回数・クールダウンなど、機能に合う処理を個別に定める。

## 3. 容量8で構成の交換関係を試す

全て試行値。現在の4基礎の通常版を、PS01＝2、PS02＝3、PS03＝2、PS04＝2と置く。体勢を削るPS02には、閾値を越える手を作れる価値を見込み、まず他より1重くした。適正価格を実証したものではない。

| 構成例 | 合計コスト | 容量8での扱い・狙い |
|---|---:|---|
| 同じ削り補助PS02を2個＋配置補助PS01 | 3＋3＋2＝8 | 同種の集中を許す。防御・回復補助は外す |
| 削りPS02＋防御PS03＋回復PS04 | 3＋2＋2＝7 | 異なる局面へ備え、残り1は無理に埋めなくてよい |
| 借り札用の強い削りPS02＋防御＋回復 | 4＋2＋2＝8 | 条件付きの強い品に置き換える例 |
| 配置PS01＋防御PS03を2個＋回復PS04 | 2＋2＋2＋2＝8 | 軽い補助を4個。3枠を併用すると装備不能 |
| 通常版の全4基礎 | 2＋3＋2＋2＝9 | 全習得済みでも、一度に全部は装備できない |
| 通常PS02を3個 | 3＋3＋3＝9 | 個別の同種禁止がなくても容量で止まる |
| 強い条件付きPS02を2個 | 4＋4＝8 | 重い同種2個へ全容量を使う。取得も2個必要 |

通常PS02の条件を満たす攻撃では、1個で削り＋20、2個で＋40。命中50の札なら合計70／90で、最大体勢100・累積0の対象にはまだHPダメージが入らない。借り札限定・強引な版は一個＋40と行動時間＋1を一組として扱う試行で、二個なら削り130。累積70の対象へ使うと合計200、最大体勢100との差が100となり2倍になる。累積0なら削り切り直後の1倍であり、旧即2倍の式へ戻さない。

低体勢の道では、少し削りを増やしても倍率境界へ届かずHP進行量が変わらないことがある。霧や敵では削りの差が突破の手数を変えるため、装備コストは一つの局面のダメージ換算だけで決めない。行動時間短縮・回復・防御にも別の利点があり、探索全体で費用に見合うかを後続で確認する。

## 4. 接頭辞と装備コスト

基本案は、基礎コストに、その修飾の組合せに定義した増減を適用する。小さい整数を保ち、接頭辞が一つ増えるたび機械的に重くする方式にはしない。費用に収まる良い組合せを探すことも収集の目標になる。

- 横方向の変化や条件付きの得意不得意は、まず同コストで比較する。複数の修飾が付いた品も、その個数だけでは高コストにしない。
- 明確に強い機能や、複数の役割を一個で十分担う組合せは重くする。AQでは「強引な」を含む品に＋1を置いた。どの組合せも常に加算だけで適正化できるとは考えず、相性のよい組合せは個別に見直す。
- **マイナス効果が付けば自動でコストを下げる扱いは推さない。** 例えば借り札を使う構成では「自分の札では働かない」欠点が軽い。条件を満たす工夫の利益は残しつつ、欠点の文字数だけで容量を得られるようにはしない。
- コストを下げる「軽量」系の修飾自体は候補にできる。その場合も弱体と割引を一組で定義し、最終コストは1以上にする。装備容量を増やす効果・0コスト・負コストは今回の基本試行に入れない。
- 売却額と装備コストは別。高く売れる品が常に重い・強いとは限らず、安い品にも組合せ上の使い道を残す。

欠点だけを外した未取得の性能へ作り替えることは認めない。通常版も一緒に装備して用途を補う構成なら、その通常版の個数とコストを別に使う。

## 5. 習得・所持・装備・売却の接続

| 操作・状態 | 推奨する具体案 |
|---|---|
| 基礎習得 | 成長ポイントで基礎を一度習得し、その基礎の品を選べるようにする。基礎は全習得可能 |
| 習得した通常版 | 売却できない通常版の選択肢を一個分得る。習得しただけで同じ通常版を何個も装備できる扱いにはしない |
| 追加個体・修飾付き品 | 持帰り済みの所持品を個数分だけ選べる。同じ性能2個にも別の所持実体が必要 |
| 装備・付替え | 帰還後に追加支出なしで選び直す。容量は占有し、ポイントは消費しない。未装備の習得済み基礎は効果を出さない |
| 使用中の品を売却 | 先に装備から外す。別の同性能品を売っても、装備中の個体は残る |
| 基礎の取り直し | 実際に支払った習得費を全額返還。取消した基礎の装備は外し、取得品の数量・修飾は残す |
| 再習得 | 残してある取得品を再び選べる。売却済みの品は戻らず、装備は勝手に復元しない |

取得物ごとに追加の習得費を払う代案もある。ただし、良い接頭辞を得てもすぐ試せない負担と、完全重複の個体ごとの支出・全額返還の管理が増える。まずは基礎だけの習得費と無料の付替えで、取得による構成変更を試しやすくする案を推す。全習得後の余剰ポイントの用途は残る課題で、装備制限のためだけに追加料金を採用しない。

所持上限や整理画面は装備可能数とは別の論点。同じ取得品の性能を一行にまとめて「所持3・装備2・未装備1」と読めるようにし、異なる修飾を同名というだけで一括処分しない。習得による通常版は「基礎から1個使用可」と別に示し、売却できる所持数へ混ぜない。画面実装はUI担当との後続課題。

## 6. 重複効果の処理

AQの数値補助は、各装備が同じ行動前の状態を見て条件判定し、成立した寄与を加算してから、札の行動を一回だけ解決する。あるパッシブが増やした分を、別個体の新しい発動条件として再帰的に使わない。

PS02の削り・PS03の防御・PS04の回復を加算し、PS01の行動時間短縮も合計後に既存の最小行動時間を適用する。最大HP等の通常上限も最終結果へ適用する。借り札一致後の防御補助や防御後の配置補助は、個数分の独立した待ち回数を作らず、共有の待ち状態を一行動で一回更新する。

例えばPS01を4個積む試行では、配置時間8から合計8短縮しても、既存の下限により行動時間1となる。装備コストが正でも、非常に速い行動が攻略を支配しないかは別のバランス課題。この特化の強さを探索で確認し、必要なら当該効果の費用・合計短縮量・逓減を調整する。境界処理が正しいことだけで適正としない。

機能追加型・一度だけ無効化・追加行動など、今後の数値以外のパッシブは、その効果ごとに重複を定義する。総コスト制の採用だけで、全機能の無制限な加算まで承認されたとは扱わない。

## 7. 容量の成長と次の判断

容量は、まず固定8で比較する。節目で有限回だけ広げる代案は6→8→10。AQの固定所持プールでは、容量6／8／10で性能の組成が46／93／158通り、最大装備数3／4／5、通常PS02を含む同基礎の最大数2／2／3となった。空構成を含み、同じ性能の個体交換だけは重複計数しない。この数字は遊びの豊かさや強さの順位ではない。

容量10なら現在の全4通常版は収まる。それ自体を禁止する必要はないが、将来の候補・同種重複・強い修飾を含めても選択が尽きない範囲で上限を調整する。売却ポイントで容量を際限なく買う方式は、長く遊ぶほど装備制限を消すため第一案にはしない。

AQ時点の方式比較・独立検証は完了。正式方式の第一候補は「総装備コストを主制限とし、同種も個数と容量の範囲内で重ねる」。具体的な容量・価格・修飾ごとの増減・容量成長は試行値のまま扱う。[プロジェクト設定](../作業資料/プロジェクト設定.md#current-settings)の正式ルールはユーザー判断という区分に従い、D52にはこの具体方式まで先に書き込まない。

後続ARで探索の開始から終了までと、取得・付替えへの接続を確認した。実際の準備の分かりやすさ、少量の空き容量の煩わしさ、本人が構築や探索先を変えたくなるかは人の評価に残す。固定4枠は操作負担を比較する対照候補として保持する。

## 8. 探索と取得経過での比較【AR1】

[AR1の全条件・結果](../検証/装備制限/ar/検討結果.md)では、装備を与えた1,152探索、短縮連携を狙う384探索、0pt・取得品なしからの256探索を分けた。総コスト8、基礎コスト2／3／2／2、強引な修飾＋1を維持する。新しい説明では世界観Workの正式呼称「心得」を使い、既存の識別子・固定入力名は保つ。

探査補助PS02を2個に集中した構成はA32/32・C23/32、探査と速効の身構・回復を組み合わせる構成はA29/32・C26/32だった。探索先で得意不得意が変わり、同種集中を一律禁止する根拠にはならない。4枠の探査4個はコスト換算12であり、容量8と同じ予算の比較として扱わない。

配置短縮PS01を4個使う追加比較は、連携を狙って38→41クリア／48条件。発動行動は72→146、時間1の行動は14→39だが、新規クリア7に対して失ったクリア4もある。防御・配置を選ぶ手数や他主体の介在があるため、最大短縮量だけで費用増・同種上限・共通逓減を加えない。今回の機械方策での結論で、最適攻略や人の楽しさは未確認。

取得経過では、持帰り済み個体を装備した出発158回、うち修飾付き93回。32経過全てで全4基礎習得とCクリアを確認した。「既存装備を維持」は111/128クリア、「毎回全体を選び直す」は114/128で、同じ開始条件16組の内訳は改善6・悪化3・同数7。付替えが常に得という結果ではない。

変換は未装備の完全重複が同時使用可能数を超えた場合だけ行う仮方策。通常品25％の変換、基礎習得の全額取り直し、死亡で今回分を失う扱い、保存からの一度だけの精算を接続した。8探索後の未使用習得点は平均10.41／10.94ptで、変換の寄与は平均0.72／0.75pt。直接報酬由来の余剰が多く、変換率だけで後半の資源用途を調整しない。

第一候補は引き続き総装備コスト。具体方式の正式採用はユーザー判断、容量・価格・報酬の仮調整は継続可能とする。取得札の山札への差替え、自由な変換判断、新しい操作画面、実端末・人評価は未接続。全習得後も比較する取得品があることと、習得点の使い道が十分あることを分けて次へ進める。

後続の[習得点の用途案](カード探索ゲーム_習得点の用途.md)では、容量制限を維持する補助取得経路を比較した。固定ARの予算再集計であり、装備費・容量・ARの探索結果は変更していない。

# 方針の下で描き方を試すための手順

版：0.3／2026-09-12。Work：`20260912-visual-direction`。ファイル名は初版から継続。

**最新の方針：大きな形・面を優先し、さらにデフォルメしてよい。描き方を一つに絞って収束させることより、方針の下で多様な描き方を試してサンプルを出す。** Dは現状で近い参考の一つであり、絶対基準ではない。輪郭はDよりぼんやりさせてもよい。初回の[封緘の試作](見本/seal-soft-study.png)はまだ写実性が強過ぎる、夜潮の排水路も細かく描き過ぎとの所感を受領。[封緘の描き方比較](見本/seal-style-explorations.png)で3案を追加した。どの案も最終採用や統一画風の確定ではない。

## 1. 目標となる描き方と参照

**優先するのは、大きな形・面で題材を表し、細部と写実性を積極的に省くこと。** 比率・輪郭・陰影をデフォルメし、道具の識別に必要な特徴を残す。材質の物理的な再現や現実的な立体感は必須にしない。色面、丸い形、にじみ、簡潔な筆致など複数の描き方を試す。「しっとり」は柔らかな輪郭や光などに幅を持たせ、暗さ・低彩度・濡れた表面だけに限定しない。写実的な下地に絵筆の粒子を増やすだけでは、この省略を満たさない。

- 出発点の参照：[D・日本語ラベル稿](見本/direction-d-labeled.png)。Git blob `7fe9e43a8090609bca974935da738eec23c22de3`。固定版の記録は比較に使った画像を特定するためであり、Dの輪郭や描写密度を上限・下限にする意味ではない。特定場面の色も全作品へ固定しない。
- 道具への適用では、D左下の木の机・照明・水筒・机上小物を特に参照。形の整理、柔らかな光、控えめな材質描写を見る。右下の冷たい金属表現も補助にする。
- 形の参照：[道具の旧見本](見本/tools.png)。Git blob `504c30517e6161ff90ccf13f4068702ac2f9fcab`。道具の種類・対応・配置を読み、質感・照明・札材質を引き継がない。
- [D制作時の指示](../../作業資料/ビジュアル・演出/制作元/しっとりした表現.txt)も根拠にする。そこにある柔らかなガッシュ・薄塗りの方向は、Dを説明する制作語彙として用いる。
- 夜潮の排水路や封緘は派生案。Dとの違いを把握しつつ、意図した改善と意図しないずれを区別する。Dと違うという理由だけで戻さず、最新のユーザー所感と目標を優先する。

## 2. 共通方針と試作で変える範囲

| 観点 | 制作指示 | 出来上がりで見ること |
|---|---|---|
| 形と色面 | シルエットと大きな面を先に決める。部品の比率は大胆に変えてよい | 細部がなくても道具の種類や特徴が読める。写実的な形を守り過ぎていない |
| 立体と陰影 | 陰影を大きくまとめる。平面的な色面、少数の淡い陰、簡潔な筆塗りも試す | 現実的な立体の再現や精密な連続階調に引き戻されていない |
| 輪郭 | 識別に必要な縁、接合部、作用点は読ませる。陰側や背景へ続く縁は部分的になじませる | 全周が均一に鋭い／全周がぼける、のどちらにもなっていない |
| 材質 | 木・金属・糸を色、面、光の受け方、少数の特徴で描き分ける | 金属の細い鏡面反射、全面の木目・傷、一本ずつの繊維が主役になっていない。材質差自体は残る |
| 筆致 | 面の内部へ控えめな色むらと筆触を置く。細部を等密度に描かない | 写実描写の上に紙目や粗い粒子を重ねただけになっていない |
| 光と色 | 光源の向きと暖冷を揃え、柔らかな反射光を使う。強い明暗差は必要な箇所へ絞る | 物だけが撮影照明を浴びたように浮かない。暗部にも形と色が残る |

明るさ、色相、時刻、天気、遠近、場面の親密さ・壮大さは題材に合わせて変えてよい。形の丸め方、面の数、陰影の段階、輪郭の有無、筆触・にじみも試作ごとに変え、違いのある案を残す。具体的な色数・面数を一試作で指定しても、全作品共通の規則へ昇格させない。大きく見せる比較画像でも、細部を埋めるために描き込まない。

道具類の実画面での用途はアイコンに近いものを想定する。試作ボードの寸法・解像度・ラベル配置をそのまま実装へ流用しない。表示サイズ、切り出し、透過背景、実装用の密度は画面での使い方に合わせて別に決める。今回の比較を完成アイコンの作成・縮小時の可読性検証としない。

文字、属性記号、選択表示は読み取りを優先する。Dの柔らかさをそのままUI文字へ適用しない。Dに似た机・暗青色・紙の額縁を毎回足すことも、画風を揃える条件にはしない。

## 3. 制作する順序

以下は制作指示を組み立て、出力を確認する順序。画像生成モデルが内部でこの筆順を実行することを保証するものではない。

1. **題材と用途、試す違いを決める。** 名称、識別に必要な特徴、変えてはいけない設定、将来の用途を記す。比率や写実的な構造まで固定せず、今回はどの省略やデフォルメを試すかを各案に書く。新しい能力・人物は追加しない。
2. **参照の役割を分ける。** Dを「画風の出発点」、旧見本を「形・配置」の参照として指定する。「今回は輪郭をDよりなじませる」等の調整幅も明記する。複数画像を渡すだけで両者の見た目を平均させない。
3. **残す形と省く細部を列挙する。** 各道具について、識別に必要な形を先に書き、細密な傷・繊維・反射などを省略対象として書く。
4. **大きな面・明暗・光を指定する。** 主な面の分け方、光源方向、陰の色、材質を見分ける手掛かりを決める。背景と道具の照明を整合させる。
5. **輪郭と筆致を仕上げ条件として指定する。** どの縁を明確に残し、どこを弱めるかを書く。全体へのぼかし、濃霧、セピア化、紙目の追加を修正の代わりにしない。
6. **日本語ラベルと札の条件を独立に指定する。** ラベルは絵の外の説明として正確に対応させる。札の半透明性などの設定適合を、画風適合とは別に確認する。
7. **参照と目標の両方から確認する。** Dと並べて色面・明暗・輪郭の差を把握し、その差が今回意図した調整かを判断する。小物が同程度の大きさになるよう見比べて材質と省略を見る。実際の用途に近い縮小表示では道具の識別を確認する。Dとの一致度や拡大表示だけの精密さで合格にしない。
8. **案の違いを残して比較する。** 方針からの意図しないずれは具体的に直すが、異なる描き方を一つへ揃えるために繰り返し修正しない。「もっとDらしく」ではなく、「細かな反射を一つの明るい面へ省く」等を指定する。試作ごとの残す特徴を確認し、ユーザー所感から次に試す幅を決める。新しい画像というだけで基準を更新しない。

## 4. ⑥が外れている点と描き直しへの指定

旧⑥は、金属の強い反射、細密な木目・擦り傷、糸の繊維、滑らかで精密な曲面陰影が目立つ。制作指示にも「studio background」「painted 2.5D」や細かな物理素材の指定があり、Dそのものを画風参照として固定していなかった。これは出力と指示の比較による分析で、生成内部の原因を断定するものではない。

| 対象 | 残す特徴 | Dへ寄せる具体的変更 |
|---|---|---|
| 宛先のない矢印 | 輪のある丸い方位磁針、空いた文字盤、一本の特徴的な針 | 真鍮は黄土と鈍い明部でまとめる。細い鏡面反射や微細な傷を減らす。針と外形は明確に残す |
| 底抜け | 円筒の糸巻き、連続する一本の糸、先端の錘 | 巻いた糸は束と帯の面で表す。一本ずつの繊維や全面の木目を省き、糸と錘のつながりを優先する |
| 封緘 | 握れる木の柄、平らな金属の底面、対応する押印 | 柄は少数の木色と柔らかな陰影で描く。磨いた木の艶や真鍮の鋭い反射を抑える。握りと押す面を読ませる |
| 上段の札 | 各道具に対応する絵・図、同じ列の対応関係 | 現行設定の薄い半透明の長方形へ変更。厚い不透明板、切欠き、彫刻のような溝を引き継がない。透明なガラス板や強いホログラム発光にも固定しない |
| 比較ボード | 3列、上段に札、下段に対応する道具という読み順 | 道具間の光と描写密度を揃える。日本語名を絵の外へ付ける。強い撮影用スポット、余計な小物や舞台の追加は避ける |

明るさと色をD左下へ合わせるだけでは、上記の描写方法の差は解消しない。逆に、材質をすべて同じ艶消し面へ潰すと木・金属・糸の区別を損なう。

初回の適用確認は、形が比較的単純で木と金属を併せ持つ「封緘」一点から始める案とする。Dと並べた比較で手順の不足を確認してから3道具へ展開し、最後に札との対応を含む⑥全体を組む。これは作業順の提案で、単品試作を⑥全体の描き直し完了とは扱わない。

## 5. 毎回の制作指示のひな形

```text
用途・題材：［今回の用途、名称、必要な部品・構図］
参照1：Dの日本語ラベル稿。現状で最も近い出発点の参照。
今回の調整幅：［例：Dより輪郭をぼんやりさせ、陰側を背景へなじませる］
参照2：［必要なら既存の題材画像］。形と配置だけを参照。

共通の方針：
大きな形・面を優先し、写実性と細部を積極的に省く。
部品の比率や陰影はデフォルメしてよく、物理的な材質再現は不要。
同じ方針の下で、色面・丸い形・にじみ・簡潔な筆致などを試す。
今回試す描き方：［案ごとの具体的な省略、比率、塗り方］
識別に必要な縁・部品・作用点を明確にし、陰側の一部の縁は
周囲の色になじませる。金属の反射は広く控えめに、木目・傷・
糸の繊維は少数の手掛かりへ整理する。

今回残す特徴：［識別に必要な形］
今回省く細部：［精密描写へ戻りやすい箇所］
光・色・背景：［題材に合う明るさ、暖冷、光源方向］
ラベル：［正確な日本語名。作中の物体へ刻まず、説明として配置］
維持する設定：［現行の札材質、部品の対応など］
避ける仕上げ：精密な商品写真、プラスチックの3D仕上げ、
硬い多角形の陰影、均一な太線、全面のぼかし、粗い紙目の重ね掛け。
```

共通段落を毎回作り直さず、可変欄を更新する。道具以外では木目・繊維などの例を対象の材質へ置き換え、省略と光の原則を保持する。

## 6. 確認記録と比較の扱い

| 項目 | 確認する問い |
|---|---|
| 題材 | 名称・部品・対応関係・世界観の前提を保っているか |
| 色面 | 細部より先に大きな形と明暗が読めるか |
| 輪郭 | 残す縁と弱める縁があり、必要な箇所は識別できるか |
| 材質・光 | 今回意図した描写密度と柔らかさになり、材質差も残るか |
| 画風 | Dとの違いは意図した調整か。より目標へ近づく変更を、一致しないだけで排除していないか |
| 札・文字 | 半透明札の設定と日本語ラベルが正しく、読み取れるか |

題材の誤りや文字の不備は修正対象とし、描き方の差は観察と比較の対象にする。省略が進んだ点、まだ写実的な点、次に試せる幅を記録する。参照の固定版、指示、候補画像、確認範囲も残す。Dへの一致や一つの画風への収束を合格条件にしない。

初版ではD・⑥・両方の制作指示を照合して手順を作成。本版はDの扱いを修正し、封緘一点を試作した。3道具の統一感、札との組合せ、反復生成時の再現性は未検証。ユーザーの所感を受けて本書を改訂する。

- 参照：Dを柔軟な出発点、旧道具見本の右下を封緘の形の参照として指定。封緘の木の柄、真鍮の丸い印面、簡素な封の折れ線を保持。日本語ラベルは「封緘」「道具表現の試作」。今回は札を含めず、道具単体の描き方を比較する。

## 9. 背景へ広げた省略の比較

2026-09-13（日本時間）、同じ方針で[夜潮の排水路の3案](夜潮の排水路の背景.md)を追加。Dや旧背景を画像参照として渡さず、場面の文章条件を共有して①少数の色面・②丸く誇張した形・③にじむ色の塊を試した。石積み・配管・細かな泡を省けた一方、①②は塗り方と構図が近く、③にも細かな質感は残る。違いの不足も比較結果として扱い、画風の収束や完成を宣言しない。

道具の用途はアイコンに近いが、今回の背景や比較板の寸法を道具に流用しない。逆流の伝達、UIとの合成、動きは別の検討として維持する。

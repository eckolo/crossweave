# 描き方の制作手順：基本②・背景③

版：**1.0・正式版**／2026-09-13（日本時間）。Work：`20260912-visual-direction`。ユーザーが修正版6点の方向性を了承し、本手順の正式登録を指示した。自Workの担当範囲と既存リンクを保つため、保存先・ファイル名は初版から継続する。本書の現行手順は採用済みとして扱う。

**現在の制作方針は、基本を②「少数の筆で拾う」、背景を③「輪郭を途切れさせる」とする。** 最新の[輪郭を省く比較](輪郭を省く比較.md)へのユーザーの選択を反映した。「大きな形・面」「輪郭を線で一周説明しない」「しっとりした感触」を共通に、読ませる対象と背景で形を残す強さを変える。

**正式に登録する範囲は、基本②・背景③の描き方、制作の順序、用途に応じた指定を受け取る工程、出力確認と記録の手順。** 幅・高さ・背景透過などの値は素材ごとの入力として受け取り、本書で一律に固定しない。共通文書への接続は設計・世界観・UIの各担当へ渡す。

[修正版6点](別題材6種の修正版.md)への「方向性としては良い」は受領済み。各画像は制作例として保持し、個別の完成素材採用は別に記録する。量産再現性・実表示での識別・UI合成の確認状況は、手順の採用状況と分けて管理する。

### 制作前に受け取る用途別の指定

題材の制作を始める前に、次の欄を依頼・素材仕様・UI担当の参照版から埋める。指定済みの条件は引き継ぎ、素材ごとの値と出典を記録する。未指定の比較試作は仮条件を明記して進められる。実用素材の納品条件が未確定なら、その項目を未確定として残し、比較用の値をそのまま完成仕様にしない。

| 指定欄 | 記録する内容 |
|---|---|
| 素材ID・日本語名・用途 | 背景、道具アイコン、札絵、人物／敵の独立素材、演出用など。比較用／実用の区分、表示先、仕様の担当・参照版 |
| 納品する縦横サイズ | **幅px × 高さpx**をこの順で記す。要求する縦横比も併記し、数値と矛盾があれば制作前に解消する。差分サイズが必要なら用途と対応させて列挙 |
| 実際の表示サイズ | 表示領域の幅・高さと単位、縮小／拡大条件。納品ピクセル数と区別し、未定なら未定と記す |
| 構図と余白 | 対象の占有範囲、欠けてはいけない部品、上下左右の安全余白。配置に必要な原点や接地位置は指定がある場合に記す |
| 比率への収め方 | 全体を収める／余白を足す／指定領域の切り抜きを認める等。切り抜き可能範囲を記録し、指定外の欠けや縦横別倍率の変形を避ける |
| 背景の扱い | **不透明の背景を描く／背景を透過する**を用途ごとに指定。部分透過の場合は透過する領域と残す部分も記す。確認用の敷き色は実用画像の背景とは別欄 |
| 影・光・付随物 | 接地影、光、煙、台座などを含める／別素材にする／省く。透過する余白へ意図しない背景や影を焼き込まない |
| 出力形式 | 納品形式と透過の要否を対応させる。透過指定にはアルファを保持できる形式（例：PNG）を使う。原本・実用出力・確認用表示を識別できる名称にする |
| 日本語ラベル | 正確な題材名と状態（比較案／採用素材など）、確認画像での位置、実用画像への焼き込みの有無。実用の画素寸法にラベル領域を含めるかも記す |
| 確認条件 | 実表示サイズ、重ねる背景・UIの参照、通常／選択等の対象状態。確認できなかった条件を分けて記録 |

背景にも分離した前景層など透過を必要とする用途があり、アイコンにも不透明な地を含む用途がある。種類名だけで透過の有無や縦横比を決めない。今回の見本の1024×1536、1536×1024、1254×1254pxは制作履歴上の属性で、上表の既定値にはしない。

| 用途の例 | 構図・サイズで優先すること | 透過指定で決めること |
|---|---|---|
| 場所の背景 | 表示領域の比率、足場・道・灯り、UIが重なる範囲、切り抜き可能範囲 | 一枚の不透明な背景か、透過した前景・効果を分けるか |
| 道具・小さなアイコン | 実表示サイズでの種類・向き・接続、余白、形が欠けない範囲 | 対象外の透過、台座や接地影の有無、背景付き枠を含むか |
| 人物・敵の独立素材 | 全身の収まり、向き、接地位置、姿勢差分での位置合わせ | 体の外側、半透明な角などの内側、影を同じ画像に含むか |

### 透過背景と、しっとりした描き方の両立

透過指定でも、基本②は部品の接続と向きを保つ。背景色へなじませていた縁は、色面の省略や必要箇所だけの柔らかな透過縁で表し、全周を均等にぼかさない。対象の輪郭を消すために体や部品を欠損させない。

背景透過は画像のアルファで扱う。白い地や市松模様を描いた画像を透過済みとは判定しない。明るい地・暗い地と指定された使用背景へ重ね、白縁・黒縁、不要な背景の色残り、接続の消失を確認する。確認用の地は別に表示する。

硝子や半透明札などの**材質の透け方**と、**対象外の背景透過**は別条件。材質の反射色・形を残し、素材全体を一律に透明化しない。アルファを使う範囲は題材と用途に応じて記録する。

全素材を日本語名と状態ラベル付きで提示・索引化する。比較画像では絵の外の余白へラベルを置く。実用画像へ文字を焼き込まない指定の場合も、同じ素材IDの日本語ラベル付き確認表示を対応させ、何を描いた素材か分かる状態を保つ。

## 2. 描き進める順序

### ① 題材と、読ませる特徴を決める

日本語名、用途、②／③の適用、世界観で維持する条件と、1章の用途別指定を先に書く。幅・高さ・余白・透過の条件に合わせ、形を説明する特徴を少数に絞る。封緘なら握る柄・押す印面・両者のつながり、水路なら足場・水の帯・奥へ続く空間を残す。実在する物の細部や、未確定の設定を足して埋めない。

### ② 大きな形と色面を置く

細部を描く前に、全体の形、明部・暗部、主な色のまとまりを作る。部品の比率や曲がり方をデフォルメしてよい。材質を精密に再現することより、形のまとまりと題材らしさを優先する。輪郭線を完成させてから内部を塗る進め方を基本にしない。

### ③ 色面のつながりと陰影を整える

明暗は大きくまとめ、隣り合う面の色・明るさを近づける場所を作る。対象と背景で光源の向きや暖冷を整合させる。細い鏡面反射、滑らかで精密な立体陰影、全面の木目・石目・波紋を増やさない。明るさや色相は異界・情景ごとに変えてよく、暗青色・低彩度・濡れた質感を作品全体へ固定しない。

### ④ 必要な形を少数の大きな筆跡で拾う【基本②】

柄の曲がり、部品の接続、印面の向きなど、識別を助ける場所へ筆跡を置く。筆の方向と面の重なりで形を感じさせる。縁を残す部分でも外周を線で囲わず、影側や余分な縁は周囲へなじませる。表面全体へ細かな筆触を散らして描画密度を上げない。

### ⑤ 背景は境界をさらに途切れさせる【背景③】

背景では、④の筆跡を足し過ぎず、接する面の色と明暗をなじませて縁そのものが見えない区間を広げる。奥の壁やアーチは色の塊へまとめる。手前の足場、灯り、水の流れる帯など、場所を読む手掛かりは部分的に残す。全ての境界を均等に消すことも、絵全体へのぼかしだけで済ませることも避ける。

### ⑥ 描き足す前に、描き込みを減らす

細かな粒子、傷、泡、均一なかすれ、反射線、不要な縁を見直す。しっとりした感触は色のなじみ、柔らかな光、筆跡の間の落ち着いた面で保つ。②の筆運びは残してよいが、乾いた細かなかすれで全体を覆わない。縮小して識別が弱い場合は、まず大きな形・明暗差・部品の間隔を調整する。

### ⑦ 用途と方針を確認し、記録する

絵だけを見て題材が読めるか、基本②と背景③の関係が保たれたかを確認する。納品ファイルの実際の幅・高さ・縦横比・形式と、指定した透過範囲を確認する。寸法や透過を制作指示へ書いたことだけで、条件を満たしたとは扱わない。

制作ツールの出力サイズが指定値と異なる場合は、生成サイズと納品サイズへの調整方法を記録する。原本を保全し、指定された切り抜き・余白・比率の条件に従って実用出力を別版として整える。加工を実施した場合は内容と使用手段を残し、生成原本と加工後の画像を取り違えない。満たせない指定を黙って別の値へ置き換えない。

日本語ラベル付き確認表示、生成原本、正確な制作指示、参照箇所、実用出力、所見を素材IDで対応させて保存・提示する。実用出力をまだ作っていなければ未制作と記す。比較用の大きな画像での確認と、実表示サイズ・使用背景での確認は分けて記録する。

この順序は制作指示と出力確認の手順。画像生成モデルの内部の筆順を保証するものではない。色数・筆数・省略率は題材ごとの目安とし、固定数値の規格にはしない。

## 3. 二つの題材での具体例

| 工程 | 封緘：基本② | 夜潮の排水路：背景③ |
|---|---|---|
| 大きな面 | 木色の柄、鈍い金属色の印面、広い影 | 壁と奥の暗がり、水の帯、保守用足場、灯りの暖色 |
| 必要な筆跡 | 柄の曲がり、短い接続、印面の向きと簡素な封の折れ線 | 足場の縁の一部、手前の明暗、灯り、水の大きな曲がり |
| 消す境界 | 柄の影側や印面の外周の一部。柄と印面のつながりは保つ | 奥のアーチ・壁・水際の一部。色のまとまりで奥行きを残す |
| 省く細部 | 木目、細かい傷、細い鏡面反射、精密な厚み | 石積みの一本ずつの目地、配管の細部、小さな波や泡 |
| 完了と区別する点 | 完成アイコンの寸法、透過処理、縮小時の識別は別確認 | 逆流方向の伝達、動き、対象との分離、正式UIとの合成は別確認 |

封緘の具体形・刻印は比較で使った形の維持であり、世界観上の最終造形を追加決定しない。水路へ人物・潜水服・未提示の事件情報を描き足さない。道具の実用途はアイコンに近いが、試作の解像度やラベル配置をそのまま実装へ流用しない。

```text

納品サイズ：［幅px × 高さpx］　縦横比：［横:縦］
表示サイズ：［幅 × 高さ・単位／拡縮条件／未定］
生成サイズ：［指定できるサイズ／納品サイズと異なる場合の調整方法］
構図・余白：［占有範囲／欠けてはいけない特徴／安全余白／必要な原点］
比率への収め方：［全体を収める／余白を足す／切り抜き可否・範囲］
背景：［不透明・描く背景の内容／透過・対象外または指定領域］
材質の半透明：［対象・範囲／なし］
影・付随物：［含める／別素材／省く］
納品形式：［形式／アルファの要否］
確認する使用背景・状態：［参照版／明暗の地／表示状態／未定］
今回の基本：［② 少数の筆で拾う／背景③ 輪郭を途切れさせる］
作画参照：［最新比較画像の正確な名前と②・③の箇所］
形の参照：［必要なら既存資料。引き継ぐ形や構図を限定する］

大きな形・色面を先に置き、比率・陰影はデフォルメしてよい。
少数の大きな筆跡で必要な形を感じさせ、外周を線で一周描かない。
基本②の対象は、種類・向き・部品の接続を読ませる箇所だけ拾う。
背景③は、隣り合う色と明暗をなじませ、境界が消える区間を広げる。
背景にも足場・水・灯りなど、空間を読む手掛かりを部分的に残す。
色のなじみと柔らかな光でしっとりした感触を保つ。

今回残す特徴：［少数の識別点］
今回消す境界：［影側・奥・背景と接する部分など］
今回省く細部：［対象に即して列挙］
光と色：［場面に合う明るさ・暖冷。固定の暗さへ寄せない］
維持する設定：［部品の対応、札を含む場合は半透明性など］
日本語ラベル：［正確な題材名・状態／確認表示での位置］
実用画像へのラベル焼き込み：［有無／文字領域を納品寸法に含めるか］
原本・実用出力・確認表示の対応：［素材IDと保存先。未制作ならその旨］
今回試す幅：［筆跡の方向、色のなじみ、形の比率など］
避ける処理：精密な商品写真の陰影、全面の細かな筆触・紙目、

```

毎回の指示は、対象に不要な例を削って使用する。道具単体なら背景③の指定は周囲を描く場合に限る。UIの文字・記号を作画の省略対象へ含めない。

## 5. 確認基準と調整の順序

| 確認すること | ずれがある場合の調整 |
|---|---|
| 細部より大きな形が先に読める | 細部を削り、面の数・比率・明暗をまとめ直す |
| 基本②の種類・向き・接続が読める | 大きな形や必要箇所の明暗差を戻す。全周の線を足す処理へ直行しない |
| 背景③の境界が部分的に消え、空間は読める | 奥の面をなじませ、足場や水の手掛かりを必要箇所だけ残す |
| 筆運びがあっても、細かなかすれが主役にならない | 小さな筆触をまとめ、落ち着いた面を増やす |
| 色・明るさが情景に合う | Dや水路の色へ機械的に戻さず、当該場面の光を整える |
| 試作と実装の確認範囲を分けている | 実表示サイズが未定なら未検証と記録し、解像度を勝手に確定しない |
| 実ファイルの幅・高さ・比率が納品指定と一致する | 原本を残して指定の収め方で調整し、出力を再確認する。図柄を縦横別倍率で歪めない |
| 必要な部分が収まり、指定の余白を守る | 対象の大きさ・位置・構図を戻す。部品を無断で切り取らない |
| 透過指定と実際のアルファ・形式が一致する | 背景の描き込みと透過を区別し、対象外・材質・影の指定範囲を確認する |
| 実表示サイズと使用背景で特徴・縁・接続を読める | 大きな形、明暗差、部品の間隔、縁の処理を調整する。未確認の表示条件は残す |
| 日本語名・状態・原本・実用出力が対応する | 確認表示と素材IDを照合し、ラベル付き画像を意図せず実用出力へ混ぜない |

基本②・背景③を共通の出発点にしても、異界や情景に応じた描き方の幅は維持する。筆跡の向きや色、デフォルメの比率まで全素材へ一律に固定しない。最新のユーザー方針を未選択へ戻さず、この方針の下で必要な差を比較する。

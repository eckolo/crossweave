# Dを基準にする画像制作手順

版：0.1／2026-09-12。Work：`20260912-visual-direction`。

**受領済みの方針：今後は基本的にDを軸とし、描き方を一定の範囲へ収める。次の対象は道具見本⑥。先に制作手順を規定する。** 本書の具体的な基準・工程はそのための提案。今回は画像を生成・改変していない。Dの基準化を未回答へ戻さず、細かな画材指定や道具完成稿の採用とは分ける。

## 1. 基準の定義と固定する参照

**Dは、大きく整理した色面を土台に、穏やかな中間色と控えめな筆致で形・光・輪郭をつなぐ絵画表現。** 物の形と材質を読み取れる程度の立体感を保ち、細部は役割に応じて省略する。「しっとり」を単なる暗さ・低彩度・ぼかし・濡れた表面として指示しない。

- 主参照：[D・日本語ラベル稿](見本/direction-d-labeled.png)。Git blob `7fe9e43a8090609bca974935da738eec23c22de3`。全3場面に共通する描写を基準にし、特定場面の色だけを全作品へ固定しない。
- 道具への適用では、D左下の木の机・照明・水筒・机上小物を特に参照。形の整理、柔らかな光、控えめな材質描写を見る。右下の冷たい金属表現も補助にする。
- 形の参照：[道具の旧見本](見本/tools.png)。Git blob `504c30517e6161ff90ccf13f4068702ac2f9fcab`。道具の種類・対応・配置を読み、質感・照明・札材質を引き継がない。
- [D制作時の指示](../../作業資料/ビジュアル・演出/制作元/しっとりした表現.txt)も根拠にする。そこにある柔らかなガッシュ・薄塗りの方向は、Dを説明する制作語彙として用いる。
- 夜潮の排水路はDを適用した派生案。派生案を次々に唯一の参照へ置き換えるとずれが蓄積するため、今後もDそのものへ戻って照合する。

## 2. 共通に守る描き方

| 観点 | 制作指示 | 出来上がりで見ること |
|---|---|---|
| 形と色面 | シルエットと大きな面を先に決める。曲面にも大まかな面のまとまりを残す | 木目や傷を隠しても、道具の種類・向き・主要部品が分かる |
| 立体と陰影 | 明部・中間部・陰部を大きくまとめ、境を穏やかな筆致でつなぐ | 立体は読めるが、全表面が精密な連続階調や硬い多角形に支配されていない |
| 輪郭 | 識別に必要な縁、接合部、作用点は読ませる。陰側や背景へ続く縁は部分的になじませる | 全周が均一に鋭い／全周がぼける、のどちらにもなっていない |
| 材質 | 木・金属・糸を色、面、光の受け方、少数の特徴で描き分ける | 金属の細い鏡面反射、全面の木目・傷、一本ずつの繊維が主役になっていない。材質差自体は残る |
| 筆致 | 面の内部へ控えめな色むらと筆触を置く。細部を等密度に描かない | 写実描写の上に紙目や粗い粒子を重ねただけになっていない |
| 光と色 | 光源の向きと暖冷を揃え、柔らかな反射光を使う。強い明暗差は必要な箇所へ絞る | 物だけが撮影照明を浴びたように浮かない。暗部にも形と色が残る |

明るさ、色相、時刻、天気、遠近、場面の親密さ・壮大さは題材に合わせて変えてよい。描写密度も背景・近接道具・人物で同一にしないが、どれも上表の省略と光の扱いに従う。近接画だからといって精密な商品写真の質感へ戻さない。

文字、属性記号、選択表示は読み取りを優先する。Dの柔らかさをそのままUI文字へ適用しない。Dに似た机・暗青色・紙の額縁を毎回足すことも、画風を揃える条件にはしない。

## 3. 制作する順序

以下は制作指示を組み立て、出力を確認する順序。画像生成モデルが内部でこの筆順を実行することを保証するものではない。

1. **題材と用途を固定する。** 名称、主要部品、必要な対応関係、変えてはいけない設定、背景の有無、表示用途を短く記す。画風調整を理由に新しい能力・装飾・人物を追加しない。
2. **参照の役割を分ける。** Dを「画風」、旧見本を「形・配置」の参照として指定する。複数画像を渡すだけで両者の見た目を平均させない。
3. **残す形と省く細部を列挙する。** 各道具について、識別に必要な形を先に書き、細密な傷・繊維・反射などを省略対象として書く。
4. **大きな面・明暗・光を指定する。** 主な面の分け方、光源方向、陰の色、材質を見分ける手掛かりを決める。背景と道具の照明を整合させる。
5. **輪郭と筆致を仕上げ条件として指定する。** どの縁を明確に残し、どこを弱めるかを書く。全体へのぼかし、濃霧、セピア化、紙目の追加を修正の代わりにしない。
6. **日本語ラベルと札の条件を独立に指定する。** ラベルは絵の外の説明として正確に対応させる。札の半透明性などの設定適合を、画風適合とは別に確認する。
7. **Dと並べて確認する。** 全体表示で色面・明暗・輪郭の印象を見る。小物が同程度の大きさになるよう見比べて材質と省略を見る。実際の用途に近い縮小表示では道具の識別を確認する。拡大表示だけの精密さで合格にしない。
8. **差の原因を一つずつ直す。** 「もっとDらしく」ではなく、「真鍮の細い白反射を広い鈍い明部へ置き換える」等で修正する。名称・部品・構図など維持条件を再掲し、修正後に全項目を再確認する。候補のうち最新画像というだけで基準を更新しない。

## 4. ⑥が外れている点と描き直しへの指定

旧⑥は、金属の強い反射、細密な木目・擦り傷、糸の繊維、滑らかで精密な曲面陰影が目立つ。制作指示にも「studio background」「painted 2.5D」や細かな物理素材の指定があり、Dそのものを画風参照として固定していなかった。これは出力と指示の比較による分析で、生成内部の原因を断定するものではない。

| 対象 | 残す特徴 | Dへ寄せる具体的変更 |
|---|---|---|
| 宛先のない矢印 | 輪のある丸い方位磁針、空いた文字盤、一本の特徴的な針 | 真鍮は黄土と鈍い明部でまとめる。細い鏡面反射や微細な傷を減らす。針と外形は明確に残す |
| 底抜け | 円筒の糸巻き、連続する一本の糸、先端の錘 | 巻いた糸は束と帯の面で表す。一本ずつの繊維や全面の木目を省き、糸と錘のつながりを優先する |
| 封緘 | 握れる木の柄、平らな金属の底面、対応する押印 | 柄は少数の木色と柔らかな陰影で描く。磨いた木の艶や真鍮の鋭い反射を抑える。握りと押す面を読ませる |
| 上段の札 | 各道具に対応する絵・図、同じ列の対応関係 | 現行設定の薄い半透明の長方形へ変更。厚い不透明板、切欠き、彫刻のような溝を引き継がない。透明なガラス板や強いホログラム発光にも固定しない |
| 比較ボード | 3列、上段に札、下段に対応する道具という読み順 | 道具間の光と描写密度を揃える。日本語名を絵の外へ付ける。強い撮影用スポット、余計な小物や舞台の追加は避ける |

明るさと色をD左下へ合わせるだけでは、上記の描写方法の差は解消しない。逆に、材質をすべて同じ艶消し面へ潰すと木・金属・糸の区別を損なう。

初回の適用確認は、形が比較的単純で木と金属を併せ持つ「封緘」一点から始める案とする。Dと並べた比較で手順の不足を確認してから3道具へ展開し、最後に札との対応を含む⑥全体を組む。これは作業順の提案で、単品試作を⑥全体の描き直し完了とは扱わない。

## 5. 毎回の制作指示のひな形

```text
用途・題材：［今回の用途、名称、必要な部品・構図］
参照1：Dの日本語ラベル稿。描き方の主参照。
参照2：［必要なら既存の題材画像］。形と配置だけを参照。

共通の描き方：
大きく整理した色面を基礎に、穏やかな中間色と控えめな筆致で
形・光・輪郭をつなぐ、柔らかなガッシュと薄塗りの絵画表現。
大まかな立体と材質差を残し、細部の描写を必要な箇所へ絞る。
識別に必要な縁・部品・作用点を明確にし、陰側の一部の縁は
周囲の色になじませる。金属の反射は広く控えめに、木目・傷・
糸の繊維は少数の手掛かりへ整理する。

今回残す特徴：［識別に必要な形］
今回省く細部：［精密描写へ戻りやすい箇所］
光・色・背景：［題材に合う明るさ、暖冷、光源方向］
ラベル：［正確な日本語名。作中の物体へ刻まず、説明として配置］
維持する設定：［現行の札材質、部品の対応など］
避ける仕上げ：精密な商品写真、プラスチックの3D仕上げ、
硬い多角形の陰影、均一な太線、全面のぼかし、粗い紙目の重ね掛け。
今回の修正点：［差分修正時は原因を特定して記す］
変更しないもの：［再生成でずらしたくない題材・構図・対応］
```

共通段落を毎回作り直さず、可変欄を更新する。道具以外では木目・繊維などの例を対象の材質へ置き換え、省略と光の原則を保持する。

## 6. 確認記録と合格の扱い

| 項目 | 確認する問い |
|---|---|
| 題材 | 名称・部品・対応関係・世界観の前提を保っているか |
| 色面 | 細部より先に大きな形と明暗が読めるか |
| 輪郭 | 残す縁と弱める縁があり、必要な箇所は識別できるか |
| 材質・光 | Dの小物と同程度の省略に収まり、材質差も残るか |
| 画風 | 色や明るさの差を除いても、Dと同じ作品の絵として並べられるか |
| 札・文字 | 半透明札の設定と日本語ラベルが正しく、読み取れるか |

各項目を「適合／要修正／未確認」で記録し、根拠と具体的な修正箇所を添える。Dと題材画像の固定版、使用した指示、候補画像、確認した表示条件も残す。平均点で設定違反や画風の大きなずれを相殺しない。

今回はD・⑥・両方の制作指示を照合し、本手順を作成した段階。手順を使った新画像の再現性、3道具の統一感、札との組合せは未検証。最初の適用結果とユーザーの所感を受けて本書を改訂する。

## 今後のラベルの付け方

新しい見本は、画像内で日本語の名称と題材が分かるようにする。世界観DB・正式用語の現行名を確認し、未確定の固有名を勝手に付けない。固有設定のない情景は説明的な名前と「仮」を使う。複数場面をまとめた画像では各場面にラベルを付ける。AIの画風比較名と作中の舞台名を別にする。

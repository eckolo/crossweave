## 現行設定との差分

上記は初回制作時のラベル。世界観1.7〜1.8では、拠点は先代が営む古道具屋として採用済み。旧「辿り屋の仕事場（仮）」は古道具屋の奥の机の参考として読むが、間取り・内装・店名まで一致した完成見本ではない。新しい拠点見本では「先代の古道具屋」と説明し、内装案であることを添える。既存画像の文字を書き替えたことにはしない。

## 今後のラベルの付け方

新しい見本は、画像内で日本語の名称と題材が分かるようにする。世界観DB・正式用語の現行名を確認し、未確定の固有名を勝手に付けない。固有設定のない情景は説明的な名前と「仮」を使う。複数場面をまとめた画像では各場面にラベルを付ける。AIの画風比較名と作中の舞台名を別にする。

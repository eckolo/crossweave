# UI接続条件

版：0.4／2026-09-12。UI Workへ渡す提案。道具のアイコンに近い用途と、比較画像の寸法を実装へ固定しない条件を追記。配置・入力・情報公開の採用変更ではない。

## 接続基準

[UI正式参照版1.0](https://github.com/eckolo/crossweave/blob/4b9034a6fe445fa2fce62fad7ac154de45f94e94/docs/検証/UI/readability/正式参照版.md)／UI-R-002 v0.15を基準として照合。ユーザー判断により現行UIの正式版へ進んだことを確認した。相対する配置・可変の場枠・必要な領域の横送り・札の短いホールド・薄い予測・右下帯直上の履歴・必要時に開く窓という採用済みの方向に接続する。各値・配置の正本はUI Work。固定UI試験は旧PT-Z-001の演算を維持しており、本WorkのD48準拠の意味付けをそのまま動作確認済みとしない。

ユーザーの「もう少しだけしっとり」へ対応し、背景の輪郭・光・明暗を柔らかくする。文字や選択表示までぼかす提案にはしない。異界ごとに筆致・色・描写密度を変える。世界観1.6の半透明札は絵の表象へ反映し、数字やラベルの可読性はUI側で保持する。

| 接点 | 提案する表現条件 | UI側の確認 |
|---|---|---|
| 背景 | 場所感は全面で保ち、細部は上方と外側へ寄せる。中央や下端の可読性は、実際の対象・手札数で確認 | 静的な中央空白だけを前提にせず、可変数・横送り後も読めるか |
| 対象 | 背景と分離した輪郭・独立素材・作用を受ける位置を持つ。明暗両背景で小さな輪郭を読める形 | 対象表示と実景内の点を二重の選択対象にしない。必要なアンカーをUIが決める |
| 主体の同一性 | 場面の対象と行動順は同じ絵の特徴を共用。環境のアイコンは場所の特徴、敵は個体の形を残す | 行動順で選んだ主体、常設対象、出札の選択を混同しない |
| 選択 | 静止した囲みや印で示す。予測は薄い線、実行は短い動き。色だけで三状態を区別しない | 既存のつかみ・選択・予測・実行の各状態と一対一に対応するか |
| 札と道具 | 札絵・場札・道具の輪郭を共有。場の補正を担う札と今回の主効果の道具を分ける | 場の通常「突破・探査」、防御一致予測中「身構・攪乱」の短縮を維持 |
| 属性 | 属性ごとの形＋短い名前、色は補助。仮記号案は流動＝曲線、重圧＝積層、変容＝形の移り、境界＝切れ目のある囲い | 内部A〜Dに割り当てない。四種が上限と決めない。由来や札役割と色を混同しない |
| 使用後 | 実際の移動先へ短く移り、通常移動と消滅を分ける。共有札は置いた主体だけの色に固定しない | 捨て場を常設しなくても移動の意味が伝わるか。表示窓が閉じている時の扱い |
| 残量 | 道のりの減少は前へ進んだ結果、耐久の減少は対象の損耗。既定は余力 | ゲージ・詳細・履歴は対象別名称。道のりを実距離に換算しない |
| 隠蔽 | 今回働きかける箇所の不明瞭さ。解決後は焦点を移し、進んだ跡は残す | 一閃、機転、探査と別の状態を表示し、情報を失ったように見せない |
| 窓・履歴 | 装飾の動きは文字やドラッグ札の下へ。右下の履歴位置を空ける | 仮の一律安全領域で固定せず、実際の窓矩形・スクロールへ追従 |
| 背景移動 | 行動主体の交代と場所の全切替を同一視しない。残る敵は同じ輪郭・位置関係を保持 | 主体IDと処理結果から必要な層だけ替える。新対象へ前の作用を流用しない |

## 最小素材の受け渡し案

一地点を実装へ渡す際は、背景の前・中・後景、独立対象、通常／作用後の対象差分、道具の携行絵と作用絵を候補単位とする。素材ごとに原点・縮小時の輪郭・作用アンカー・残せる変化を添える。特定のエンジン形式や最終画面比率は、この案では固定しない。

固定見本は1536×1024の比較ボード。正式UIの16:9基準を置き換える比率ではない。初回の模式演出とUI-R-002との実合成・タッチ入力・文字への干渉は未検証。

## 世界観側の回答が必要になる点

1. WB16-03・04：印象の半透明札と作用としての道具という原則は受領済み。残るのは、どこからか取り出す具体的な所作と絵・図の様式。基本形を再質問しない。
2. WB16-05：幼く、無口で表情の少ない人物という方向は受領済み。残るのは具体的な年齢・性別・顔・衣装。立ち絵や全身動作の量産前に必要。
3. WB16-10：「不思議で切ない」を基調とし各異界のテーマを優先する方針は受領済み。全世界を灰青と黄土へ固定しない。今回のユーザー所感に沿う柔らかさの程度を比較する。

属性A〜Dの割当は正式用語集1.1本文で未固定。現段階は表現記号の検討に留める。上記回答待ちは初回比較の停止条件にしないが、全札共通の材質・主人公の完成モデルなどの正式制作前には確認する。

## 再開時に受領した世界観1.8・用語集1.2

- 他主体の札は行動・作用の表示、主人公の札には実体がある対応は1.7で採用済み。全主体が道具札を物理的に展開する表現へ揃えない。
- 主人公は低学年程度。具体年齢・顔・衣装は残るが、年齢感まで未決定へ戻さない。拠点は先代が経営する古道具屋であり、既存の仕事机は過去の内装参考に位置付ける。
- 習得点相当の「着想」は正式名候補の仮置き。今回の背景・模式演出に新しい資源表示は追加しない。
- 再開後の代表案件の接続は[夜潮の排水路の背景](夜潮の排水路の背景.md)に分離する。正式UIやシナリオ側の原本は更新しない。

成果整理時には世界観1.9も照合した。先代の相棒は普段姿を見せず、必要時に人に化けて店を手伝う方向。拠点の背景へ常時いる固定店員として描き込まず、先代自身も不思議への対処能力を失った人物として描かない。具体的な正体・姿・所作は未決定。今回の水路と模式演出への影響はない。

## 道具の用途と試作画像の扱い（2026-09-12追記）

ユーザーから、道具類は実画面ではアイコンに近い形で使う想定と受領した。今回の描き方比較を完成アイコンへ寄せ切る必要はなく、試作の画像寸法・解像度・ラベル配置をそのまま実装に使わない。

大きな形・面とデフォルメを優先して描き方を試し、実装時は実表示サイズ・背景との関係・識別したい差に応じて、細部、切り出し、透過背景、書出し寸法を検討する。具体的なピクセル数は今回固定しない。小さな表示での読み取りを確認した実績はまだなく、UIの既存配置・操作実装を変更していない。

## 今回の制作・納品条件

| 指定欄 | VD-COV01-BG01 | VD-COV01-BG02 |
|---|---|---|
| 日本語名／状態 | 先代の古道具屋／実装候補・内装案 | 夜潮の排水路／逆流する地下水路・実装候補 |
| 用途 | 拠点・準備用。不透明の場所背景 | 本文・探索用。不透明の場所背景 |
| 指定出力 | 幅1536px×高さ1024px、3:2、PNG | 幅1536px×高さ1024px、3:2、PNG |
| 指定値の根拠 | 1024 CSS pxまで1.5倍程度の解像度を持つ制作原本。現行主領域と探索で異なる切抜きを同一原本から行う。旧2倍案は採らず、1536pxを超える表示は別確認 | 同左。生成後に実寸を測り、指定との一致を記録する |
| 重要な形・安全域 | 棚と大きな道具の塊、机の面。x=10〜90%、y=30〜70%内に識別点。中央右を主にし、左下は低密度 | 奥へ続く暗い空間、足場、水の帯、局所の灯り。x=10〜90%、y=30〜70%内に識別点。水の続き・天井・手前は切れてよい |
| 切抜き | cover・中心50% 50%。拠点・本文の最狭318×90では上下約28.8%ずつを切る。左右切抜きは今回不要。伸長変形なし | **cover・位置50% 40%**。生成後の灯りの位置に合わせ、中央から少し上へ寄せる。本文318×90では上約23.0%・下約34.5%、探索318×178では上約6.4%・下約9.6%を切る。灯り・奥・足場のつながりを保持 |
| UIとの重なり | 左下に行先・目的、準備では札・枚数・着想・詳細窓が重なる。背景内に機能や数字を持たせない | 本文は左下、最大42字程度の行幅、最大240px高。狭幅は主領域ほぼ全幅。探索では相手→場→手札、詳細窓が重なる |
| 透過・半透明 | 不透明。アルファは不要（RGBAなら全画素255）。背景のしっとり感は色面で表す | 不透明。水の材質表現と背景アルファを混同しない |
| 影・光・付随物 | 左上からの柔らかな日常光、物自体の大まかな影を絵に含む。UI窓の影・暗幕を焼き込まない | 局所的な暖色の照明と冷たい水・壁。光のにじみは色面へまとめ、細かな泡や粒子は足さない。UI用暗幕は別 |
| 文字・ラベル | 原本・実用出力へ文字、数字、店名、札枠を焼き込まない。確認表示と索引にID・日本語名・「実装候補」を添える | 同左。比較板・分割画像・凡例も画像内へ入れない |
| 画風と世界観 | 正式手順1.0の背景③「輪郭を途切れさせる」。明るく温かい日常。人物なし、相棒なし、魔法道具の新設定なし | 背景③。暗さを一律基準にせず、足場・水・奥を読ませる。人物・敵・解決の答えを追加しない |

制作時の上下30%は「空白」ではなく、切れても場所の判別が失われない補助の色面。生成後は水路の灯りが指定の中心より上に出たため、PNGを加工せず表示位置で調整した。実用の切抜きは上表と [source_rect_px](../../検証/ビジュアル・演出/CO-V01/asset-checks.json) を優先する。重要物を中央80%に置くだけでは最狭主領域の欠けを防げない。背景の細部がUIの後ろへ隠れることは許容し、ゲーム情報を絵だけに担わせない。

## 確認と受渡し

原本と実用ファイルが同一なら、その事実とハッシュを記す。生成後の再描画・縮小・切抜き・透過加工を行ったことにはしない。表示時のcover・UIレイヤーを、納品PNGの加工と区別する。

確認記録・日本語名付き画像・原指示・実用出力の入口は [CO-V01納品](../../検証/ビジュアル・演出/CO-V01/README.md) に集約する。UIの実装候補ファイルを明記し、原本と確認用合成の取り違えを防ぐ。現行UIに対する合成表示、コードからの寸法計算、実ブラウザーでの測定・操作を分けて報告する。

後続の順序は、①今回2背景の設計側受領・UI導入、②CO-U02-Bの公開表示に合わせた札絵・心得・状態記号の用途確定、③必要があれば帰還小景・潜水服の独立素材・逆流の動き。正式採用や全CO-V02完了を先取りしない。

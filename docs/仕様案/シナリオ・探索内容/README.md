## IDと更新

案件は `SCN-001`、場面は `SCN-001-S01`、案件内素材は `SCN-001-CRD01` 等で識別する。既存のWB-IDと正式用語集のIDは維持し、新しい素材をWB-IDとして勝手に登録しない。世界観DBの本文は複製しない。参照先の採用状態・版・確認SHAは検討記録に集約する。

SCN-001は既存A案の具体化であり、「必ず最初に遊ぶ案件」やゲームの総量の採用ではない。以後の案件を設備修理の型に揃える基準にも用いない。

# SCN-001 場面と進行

版：0.1／2026-09-12。全場面は内容案。`S01`等は `SCN-001-S01` の略。T1・T2・Eαは[対象表](対象と手段.md)を参照。本文IDは[本文](本文.md)に対応する。

## 通常の流れ

| 場面・入る条件 | 最初に見えるもの | 得られる手掛かり | 判断・操作の意味 | 進展と次へ残る状態 |
|---|---|---|---|---|
| S01 依頼受領。探索前 | 上に積み直した商品、白い塩の跡 | 雨のない夜にも浸水。流入口は古い排水路らしい | 攻略傾向を読んで出発準備。受諾のための新しい契約ルールは置かない | 症状・場所・仮の目的を知る。真相や札の入手先は未知 |
| S02 水路へ。探索開始 | 下り坂に逆らう流れ、揺れる照明、漂着した潜水服 | 壁の堆積物が奥から手前へ伸びる。潜水服は流れに流されず立つ | 環境へ進展を与える／潜水服を狙う。場の一致材料と対象は別に選ぶ | T1とEαが行動。札は共有循環へ。手掛かりの閲覧だけで報酬や探査値を増やさない |
| S02a 任意。Eαが先に撃破された | 潜水服が力を失い、水音が聞き分けやすくなる | 当該識別対象の基本構成が開示。実際に得た報酬候補が分かる | 得た成果を守るためT1を進む／未保護分を失っても撤退する | Eα退場、由来札の処理。T1とプレイヤーの状態継続。撃破単独では保護・クリアなし |
| S03 T1踏破 | 通路の先、頭上へ広がる海と港の荷揚げ場 | 壁の水位線と同じ高さの印が港にもある。水門側で白い水が噴き返す | ここまでの保護済み成果と残り余力を見て帰る／T2へ続ける | T1踏破報酬を含む既得報酬を保護。T1退場。Eαが生存なら移動に伴い退場し、撃破報酬なし。T2参加。回復・手札の再セットなし |
| S04 T2の作業区画 | 連絡水路の方へ開いた逃がし口、噛み込んだ鎖、使われた工具棚 | 正常時の摩耗線と鎖の位置がずれる。流れの先はS02の水路とつながる | 流れと作業箇所を見極め、T2へ有効に働きかける。有限回復の使用、続行・撤退を判断 | T2の残量が減る。隠蔽の再設定は次の有効箇所を捉え直す意味。知った真相は忘れない |
| S05 T2踏破・探索クリア | 鎖が戻り、逃がし口が閉じ、港の正規水路へ水が流れる | 日常側への流入が止まる。水門の裏に管理用連絡路の表示 | 追加の正解選択や、報酬保護だけの作業を挟まない | 今回の獲得報酬は未保護分も持帰り。Aクリア実績と案件解決の表示を接続する案 |
| S06 帰還・精算後 | 店主が地下へ空の棚を戻す。地図に港の書込みが増える | 相談の症状が収まったこと、なお続く往来の手掛かり | 持帰れたものと記録を分けて確認。習得・取得・装備・見送りを選ぶ | 帰還時に余力全回復。恒久成果と記録を準備へ。港の夜景を見る演出だけで別報酬は加えない |
| S07 次の準備 | 今回使える札・心得、実際の所持品、確認済み記録 | 潜水服や水路の観測、まだ不明な渡り場の存在 | A再訪／別の未解決案件／条件を満たして開いた探索先へ | 新探索は入口から。未取得品や前回の借り札を持参できるとはしない |

S03・S04の説明は新たな戦闘区間を数えるものではない。初回到着時の短文と任意詳細へ分ける。表示のために何手も待たせる、本文を読んだ時間だけNPCが進むといった仕様は追加せず、UI側で現在の進行と整合させる。

## 必須の手掛かりと任意の深まり

| 手掛かり | 分かること | 取得位置／取り逃し対策 |
|---|---|---|
| CL01 塩と逆流の跡 | 雨水の流入だけでは説明できない | S01・S02の短い本文。詳細閲覧を進行条件にしない |
| CL02 二つの場所に続く水位線 | 日常の浸水と港の水位異常がつながる | S03の必須描写。見回り役の話を読まなくても見える |
| CL03 正常時の摩耗線と鎖のずれ | 深部の切替機構に局所的な異常がある | S04開始時。Eα撃破・特定札・ランダムな引きを条件にしない |
| CL04 戻った流れ | 対処が原因へ作用したことを確認できる | S05。単なる「ボスを倒した」通知に置き換えない |
| CL05 管理用連絡路の案内 | 次の土地を調べる関心が生まれる | S05の任意詳細。見ただけで別探索が開いたことにしない |

見回り役の証言・工具棚の使われ方・古い連絡路の名は補強情報。本文を飛ばすと進行不能になる謎解き鍵にしない。「探査」の数値は有効な作用箇所を見極める処理であり、CL01〜05の文章をアンロックする独立スキル値へ転用しない。

## 対象を選ぶ分岐

| 経路 | 何を得られる／手放すか | 接続区分 |
|---|---|---|
| T1を先に踏破 | 前半の長居を抑えやすいが、Eαの撃破成果と未開示構成は得ない。早い・安全かは数値と局面次第 | 既存Aの未採用内容案。対象選択・生存退場は採用規則 |
| Eαを攻略してからT1 | 追加成果を得た場合はT1踏破で保護できる。対処に使う余力・期限・有限札と交換になる | 同上。とどめをプレイヤーが刺すことは報酬条件にしない |
| Eαをしばらく残しT1と並行して扱う | Eαの札が一致材料・借り札として使える可能性と、Eαが行動する負担が共存する | 共有循環で成立する範囲。特定札の供給保証・常在の支援効果なし |
| EαをT2まで継続させる | 前半で残した敵の作用を水門でも使える代案 | 初稿には入れない。Aの後続指定の変更提案が必要。主体数・移動の理由・試験入力も再検討 |

## 途中帰還・失敗

| 終了位置・結果 | 成果 | 記録・再開 |
|---|---|---|
| T1踏破前に任意撤退 | 今回の未保護成果は失う。Eα攻略済みでもそれだけでは保護されない | 開示・観測済み知識は残る。再出発は入口。案件未解決 |
| T1踏破直後に任意撤退 | T1分と、それ以前に得たEα分など保護済みを保持 | 港を見た記録は残るが、水門の未観測の原因は埋めない。Aクリア実績なし |
| T2の途中で任意撤退 | 保護済みを保持。最後の保護より後に新たに得た成果は失う | 見た範囲の原因は分かっても復旧済みにはしない。T2直前から再開しない |
| 死亡 | 今回の報酬を保護済みも含め喪失。以前の恒久成果は維持 | 観測済み知識は保持。死亡を「無料の救出」と断定する会話は書かない。物語上の復帰説明は世界観Workへ |
| セーブ中断 | 精算・喪失・追加保護なし | 同じ探索の保存状態を継続。途中帰還の本文を出さない |

## 解決後の再訪例：管理用連絡路の確認

初回クリアを記録済みの場合の別内容案。既存のAと同系統の探索として、入口から連絡路へ向かう。直った水門は背景に見え、目的は「消えかけた通行標と管理用の道のつながりを確かめる」。T1相当は潮の影響が残る地下水路、T2相当は使われなくなった連絡路の踏査に差し替える。今回は進行対象の道のりを削り切ることでその調査の区切りとなり、同じ水門を再故障させない。

港の人は再び荷揚げをしている。前回より詳しく潜水服の働きを知りたい、別の修飾の手段を持ち帰りたいという個人の副目的も成立するが、出現・取得は保証しない。案件完了フラグによる文面・対象セットの切替、別探索先として分けるかは未実装の内容選択案。最初の二環境の傾向を保つ意図であり、現行Aの固定試験を書き換えた結果ではない。

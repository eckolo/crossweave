# SCN-001 夜潮の排水路

版：0.1／2026-09-12。区分：一往復の内容草案。正式採用・実装・試遊は未実施。

## 一件の仕事

雨の降らない夜にも、商店街の地下へ海水が入り込む。商品は避難済みだが、地下が使えず仕事に支障が出ている。辿り屋は古い排水路に入り、水が流れ込む側へ進む。通路を抜けた先は、空にも海のある港だった。

向こうでは潮の満ち引きに合わせて舟を繋ぎ、荷を上げ下ろしする生活がある。今は水位の乱れで荷揚げが止まっている。日常の浸水と港の不調をつなぐのは、奥の水門。現地の痕跡を追うと、本来は閉じるはずの旧連絡水路へ、満潮の水が逃げていると分かる。

深部では、流れを切り替える連結鎖が噛み込み、逃がし口が誤った向きに固定されている。流れを避け、作業箇所を確かめ、機構を戻す。日常への流入は止まるが、港も水の不思議も残る。管理用の連絡路には、まだ知らない渡り場への案内がある。

これは案件用の局所的な真相。全異界の異変を「境界設備の故障」で説明する設定ではない。水門の故障原因のさらに奥に黒幕を必ず置くこともしない。

## 狙う体験

| 段階 | プレイヤーの問い | 帰結として狙う感触 |
|---|---|---|
| 依頼・入口 | 雨でもないのに、どこから水が来る？ | 知っている町に、確かめる価値のある違和感がある |
| 水路 | あの潜水服を調べるか、流れの先を優先するか？ | 目標を倒す順番が、自分の目的・消耗・得るものと結び付く |
| 港の見える場所 | こちらだけでなく、向こうも困っているのか？ | 景色が広がり、異界にも生活があると分かる |
| 水門 | 今の札と余力で作業を続けるか、一度戻るか？ | 前半で使った資源、見つけた手段、帰る判断がつながる |
| 帰還 | 何が直り、何が分かり、次に何を持っていくか？ | 仕事を果たした実感と、まだ知らない場所への関心 |

「復旧してよかった」と「もっと知りたい」を両立させる。悲劇や大きな謎の追加で感情を強制しない。上記は設計意図であり、人がそう感じたという測定ではない。

## 最初の一往復の範囲

- 進行の基本案は既存Aの **T1＝逆流する地下水路 → T2＝奥の水門**。任意の敵Eα＝漂着した潜水服はT1と共存する。
- 港を望む場面はT1とT2の間の描写。別の探索、全回復の拠点、新たな保護地点は増やさない。
- クリア条件はT2踏破。水門へ着いただけでは未解決。潜水服撃破は必要条件にしない。
- 専用の正解札、QTE、会話選択肢による好感度、酸素・潮位ゲージ、実時間の救助期限はこの草案の成立条件にしない。
- 数値・初期山札・報酬量は未固定。本筋の試験値をこの案件の正式値とする資料ではない。

## 日常と再訪

依頼人は地下の品を上へ移し、入口への立入を止めている。急いで解決したい理由はあるが、他の案件や途中帰還を選んだだけで人命被害が確定する構成にはしない。

初回解決後は、水門の同じ故障を繰り返さない。港の管理用連絡路を調べ、古い通行標を読める位置まで進む再訪例を置く。新しい探索は選んだ探索先の入口から始め、以前の手札や削りかけの対象を引き継がない。解決済みの水門は背景として流れを分け続ける。

再訪時の敵や細部は変わり得るが、「水の流れと圧力に対処し、環境突破を重ねる」という準備の根拠を保つ。潜水服やその報酬の再出現は保証しない。再訪内容の切替処理は[接続表](接続と素材.md)で未実装として扱う。

主人公は名前・年齢・一人称・経歴を指定しない。依頼人は「商店の店主」、現地側は「水路の見回り役」という仮の役割名を使う。会話相手を既存の人物へ差し替えても進行が変わらないようにする。

## 画面に必要な内容

| 内容の単位 | 必要な情報 | 常時性・扱いの要求 |
|---|---|---|
| 探索前 | 症状、場所、攻略傾向、実際に使える手段 | 未観測の札α・真相・全遭遇順は初回に列挙しない |
| 現在の対象 | 名称、残量、隠蔽、行動名、実際の作用 | T1の道のり、Eαの余力、T2の復旧残量を区別。対象別表示の仕組みを用いる |
| 現在の目的 | 本文の短い目的文を一つ | 複数の長い依頼文を盤面へ積まない。配置はUI担当へ |
| 手掛かり | 一度読む短文と任意詳細 | 内容を読まないままでも、現在のゲーム操作へ戻れる。開閉方式は決めない |
| 札の出所 | 出現元、消滅予定、主効果と場効果 | 物語上の由来説明と、現在の一枚の出現元情報を分ける |
| 帰還 | 観測記録、保護・喪失を反映した持帰り、解放・所持・装備 | 未取得候補を使用可能品へ混ぜない。候補数の増加に対応できる情報単位にする |

UI-R-002 v0.15の、選んだ主体を軸とする行動順、右下帯直上の一時履歴、予測内容に合わせた場札の短縮表示を参考とする。シナリオ側から窓の位置や常設の説明欄を新設せず、固定Z試験をSCN-001の実装結果と呼ばない。

## 背景・対象・道具・演出の素材一覧

必要なのはゲーム内容を識別する条件。画風・材質の最終選定や大量制作はビジュアルWorkの担当。表の「必須」はこの内容案を絵で示す場合の要件で、正式採用済みアセットではない。

| 素材ID | 内容・必要な差 | 優先と利用場面 |
|---|---|---|
| ART-BG01 | 商店の地下。塩の跡と避難した棚／水が引き棚を戻す差分 | 必須、S01・S06。画面で依頼の変化を見せる |
| ART-BG02 | 逆流する地下水路。傾斜と流れの逆向き、奥への抜け | 必須、S02。札・対象の視認性を確保する |
| ART-BG03 | 水路の出口から望む港。空の海、舟底の影、荷揚げの痕跡 | 必須、S03。別の生活圏へ出たことを一場面で伝える |
| ART-BG04 | 奥の水門。異常位置／正常位置の鎖と逃がし口 | 必須、S04・S05。流入が止まる因果が見える |
| ART-ACT01 | 潜水服。流れに耐える足、伸ばす腕、停止した姿 | 必須。撃破と生存して置き去る差を描く。魂や中身の正体は確定しない |
| ART-OBJ01 | 噛み込んだ連結鎖と正常時の摩耗線 | 必須、対象詳細。独立の敵枠・耐久バーは初稿では不要 |
| ART-CRD01 | 返し潮：櫂の形、逆向きの流れの働き | 代表例。一致成立・単なる設置・使用後の処理を区別 |
| ART-CRD02 | 潮底の踏み足：重い靴底、足を据える動き | 任意攻略・借り札の見本。潜水服全体の複製にしない |
| ART-CRD03 | 汐留め：二股の留め具、圧を受け止める動き | T2の守りの働き。一律の常在バリアにしない |
| ART-PROP01 | 仕事机の地図、持帰り内容、準備中の札 | S06・S07。世界共通の特殊装置を勝手に設けない |
| ART-FX01 | 探査のみ／進展あり／一閃の作用差 | 重要。見極めただけで対象を移動・修理済みにしない。数値確定後に同期させる |
| ART-FX02 | 供給元退場と、由来札の後の消滅 | 重要。対象退場で全領域の札を即座に消す映像は避ける |
| ART-SND01 | 地下の反響、港の荷揚げ、水門の軋み、復旧後の流れ | 任意。音を聞けなくても手掛かりと成功結果が分かる |

最初の見本はBG02→BG03の場所の広がり、BG04の復旧前後、CRD01の札と櫂の関係を優先する。読み物の全場面へ個別一枚絵を要求しない。

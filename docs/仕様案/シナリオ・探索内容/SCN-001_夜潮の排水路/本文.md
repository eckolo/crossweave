# SCN-001 短文本文

版：0.1／2026-09-12。プレイヤーに読ませる本文案。人物の固有名・主人公の一人称を固定しない。台詞・地の文・UI文言の採用や配置は未決定。

## 本文：節目で一度読む

| ID・時機 | 本文 |
|---|---|
| TXT01／S01 依頼人 | 「雨は降っていないんです。それなのに夜になると、地下から潮の匂いがして。品物は上へ移しましたが、いつまでも使わないわけにはいかなくて」 |
| TXT02／出発前の見通し | 流れに逆らい、障害を越えて奥へ進む探索。途中の相手を調べる余地もある。 |
| TXT03／S02 到着 | 水が、下り坂を上ってくる。壁の白い筋を辿ると、照明の途切れた奥へ続いていた。 |
| TXT04／Eα初見 | 古い潜水服が流れの中に立っている。足元の水だけが割れ、こちらへ重い腕を伸ばした。 |
| TXT05／S03 初到達 | 通路を抜けると、頭上に海があった。遠い舟底の影が、港の屋根をゆっくり横切っていく。 |
| TXT06／S03 必須の手掛かり | 港の壁にも、地下で見た水位の筋がある。奥の水門で噴き返した白い水が、こちらの通路へ流れ込んでいた。 |
| TXT07／S04 原因の確認 | 鎖が歯車に噛み込み、逃がし口を開いたまま留めている。擦れた正常位置は、そのすぐ隣にあった。 |
| TXT08／S05 復旧 | 噛み込んだ鎖が外れ、水門がゆっくり戻る。足元へ向かっていた水が曲がり、港の水路へ流れていった。 |
| TXT09／S06 報告後の依頼人 | 「地下の水、引きました。まずは空の棚から戻してみます。……奥には、港があったんですか」 |
| TXT10／S07 帰還の余韻 | 地図に描き足した港は、まだ小さな点だ。その脇に、見覚えのない渡り場の名が残った。 |
| TXT11／解決後の再訪 | 水門は今日も、二つの流れを分けている。荷揚げの声を背に、今度は古い連絡路の印を辿る。 |

TXT10は連絡路の表示を観測した場合のみ。未観測なら「地図に描き足した港は、まだ小さな点だ。調べていない場所は、その外へ広がっている。」へ差し替える。

## 任意詳細：知りたいときに開く

| ID・対象 | 任意の本文 |
|---|---|
| DETAIL01／商店の地下 | 塩を含んだ水は、乾いても白く残る。床には何度も拭いた跡があり、低い棚だけが空になっている。 |
| DETAIL02／潜水服・未攻略 | 窓の内側は暗く、中に何があるのかは分からない。潮が引いても、重い靴だけは床から離れない。 |
| DETAIL03／港の見回り役 | 「上の潮が満ちると、ここも上がる。それはいつものことだよ。おかしいのは、引く方の水まで、あの古い口へ吸われることだ」 |
| DETAIL04／工具棚 | 長く使われた工具と、乾かしかけの手袋が並ぶ。錆びた遺構の一部も、ここではまだ毎日の仕事場らしい。 |
| DETAIL05／連結鎖 | 正常な位置だけが磨かれている。壊して取り払うより、ずれた鎖を戻せば流れを切り替えられそうだ。 |
| DETAIL06／連絡路の案内 | 水門の裏に古い案内板がある。港の名の隣に「渡り場」の文字。使われなくなっても、道筋は残っているらしい。 |

証言を読まなくてもTXT06・07で因果は追える。潜水服の全構成開示は、ゲーム側の初攻略条件で扱い、DETAIL02を開いたことでは代替しない。世界間の共通言語が未決定のため、見回り役との会話形式は案件用の仮表現。通訳等が必要になった場合も、水位線と機構の観測で必須情報は代替できる。

## 条件付き：実際に起きたことだけを読む

| ID・条件 | 短文 |
|---|---|
| COND01／CRD01が初めて使える札として手元へ来た | 逆らう水の働きが、掌ほどの櫂に収まる。今なら、この流れを使えそうだ。 |
| COND02／CRD02を初めて手元で確認 | 靴底を重ねると、足元が沈むように落ち着く。あの潜水服が立っていた理由の一端が分かった。 |
| COND03／Eα撃破 | 潜水服の腕が下がる。重い靴はそこに残り、水だけが脇を抜けていった。 |
| COND04／T1先行・Eα生存退場 | 通路の角を越える。振り返ると、潜水服はまだ、同じ流れの中に立っていた。 |
| COND05／S03で任意撤退・報告 | 「水の来る側に、別の港がありました。奥はまだ調べ切れていません」 |
| COND06／S04で原因確認後に任意撤退・報告 | 「奥の水門が戻らなくなっています。原因は分かりましたが、まだ直せていません」 |
| COND07／T1踏破前の任意撤退・報告 | 「流れは奥から来ています。今回は、そこまでを確かめて戻りました」 |

COND05〜07は報告内容の見本。固定主人公の口調として採用しない。主人公台詞を使わない方針になれば、同じ情報を報告要約へ変換できる。COND07は逆流を観測した場合のみ使用し、未観測なら「今回は奥へ進まず、戻った。」とする。

## 設計者向け注記

本文と任意詳細を一度に全面表示しない。基本は場面本文一つ＋必要な目的、詳しい事情は対象の詳細へ渡す。文字数はUIへ渡す目安として節目本文おおむね90字以内、詳細おおむね120字以内に置いたが、製品の表示上限ではない。

移動距離・残り作業の数値は実際の対象データから表示する。札が単なる設置に終わったとき、作用が通らなかったとき、供給元が退場しただけのときに、それぞれ「道を進んだ」「機構を直した」「撃破した」と誤表示しない。進行中に連結鎖の位置を段階表示するなら、演算結果に対応する別の演出仕様が必要。

死亡後の帰還会話は初稿の対象外。死亡の作中での意味を先取りせず、既存の精算結果と保持記録を示す内容だけを渡す。

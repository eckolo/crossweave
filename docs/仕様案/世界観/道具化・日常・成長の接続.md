# crossweave — 道具化・日常・成長の接続

版：0.1／2026-09-12。担当：世界観Work `20260910-worldbuilding`。

状態：ユーザーの想定を基にした具体化案。[世界観設定1.6](../../確定仕様/世界観/世界観設定.md)の現行前提と、本書で追加する説明・拠点・呼称の候補を区別する。ユーザー原文は[検討記録22章](../../作業資料/世界観/検討記録.md)。

## 1. 今回の軸と、既に得られた前提

今回の第一案は、**取り込んだ不思議は、以後は主人公自身の不思議として支えられる**、という説明でまとめること。元を写した道具の減衰と、他人に貸した道具の減衰を、働きを支える存在との関係として読める。これはユーザーが述べた関係の説明案で、距離・時間・新しいゲージを定める規則ではない。

| ユーザーから得た前提 | 追加で具体化すること |
|---|---|
| 写すだけでは元の存在に影響しない | 印象を写し取れる契機、作用との結び付け方 |
| 写しただけでも使えるが、元の影響が弱まれば霧散する | 現行の出現元・退場・消滅処理に対応する描写 |
| 己へ取り込めばその後も利用できる。心得も同様 | 成果の獲得・保護・帰還後の定着をどうつなぐか |
| 札化と展開は主人公だけ。道具貸与は意思と影響範囲を要する | 他主体の札表示、共有作用と道具の貸与の違い |
| 札は印象の表象、道具は作用の具象 | 山札・手札・場・捨て場と取り出しの説明 |
| 幼く、生来の能力を自覚する無口で不愛想な人物 | 年齢感、生活を支える人、表の立場、初期の知識 |
| 辿り屋は知られるが胡散臭く、不思議経験者には関わりが直感できる | 看板・紹介・例外的な不思議の受付 |
| 余力切れは最初の危機で作った道具による緊急脱出 | 保護済み成果も失う理由、任意帰還の準備との区別 |

## 2. 写し・保護・取り込みを段階で分ける第一案

| 段階 | 世界内での説明案 | ゲーム上の対応 |
|---|---|---|
| 現地で写す | 目の前の不思議の印象と作用を捉え、元の影響を借りて道具にする | 他主体・環境由来の札を探索中に利用する。恒久取得とは別 |
| 成果を得る | 後で自分のものにできそうな印象・作用のまとまりを掴む | 報酬獲得。現在の手札に入ることや即時の恒久強化とは別 |
| 持帰りに備える | 辿ってきた関係を整理し、意図した帰還で失わない形にまとめる | 既存の環境踏破による報酬保護。独立の梱包操作を追加しない |
| 帰還後に取り込む | 元の場所から離れても、自分の不思議として維持できる形へ定着させる | 保持できた成果を解放・所持・習得等に反映する |

「保護済み」は主人公への取り込みが完全に終わった状態にはしない。この区別により、保護済みでも緊急脱出では失い、以前の旅で既に取り込んだものは残る、という精算とつながる。

一度目にしただけで全てを恒久取得できる、深部で記録を取れば必ず特定札を得る、という保証は足さない。何を成果として得るかは本筋と内容設計に従う。記録として事実を覚えていることと、作用を再現できることも分ける。

### 2.1 退場と霧散

元の存在が今の探索へ影響しなくなると、写しを新たに支える力が薄れる。手元や場に形を保っているものはすぐ全て消えるのではなく、使い終えたり輪郭をほどいたりする段階で霧散する、という描写を第一案にする。

現行仕様では、出現元退場時に捨て場の由来札は即時消滅し、他主体の手札・山札・共有の場では残り、後に捨て場へ移る際に消滅する。「だんだん薄れる」という世界観から、札の威力を時間で減らす処理や、別の寿命タイマーへ変更しない。

元の存在が退場することと、その不思議が世界から消えることは別。道を通り抜けて影響圏を離れる、敵対者を振り切る、流れが変わる、といった場合でも説明できる。一般的な不思議の影響とゲーム上の出現元がどこまで一致するかは、内容ごとの対応を残す。

## 3. 主人公だけが札を扱うことと、共有循環

写す対象については、世界ごとに「普通」が異なることと、主人公が何を不思議として写せるかの関係が次の論点になる。主人公が知らないものなら何でも複製できるとも、主人公の町の物はすべて対象外とも、今は定めない。由来を狭めず、具体的な作用と出会いから事例を比較する。

ここは今回の設定をゲームへ接続する際の重要な論点。ゲーム上は全主体が同じ札の仕組みに参加するが、世界内で敵も札を取り出して道具を展開すると、主人公固有の能力に反する。

第一案は、**他者の行動・環境の作用も札として表され、主人公が写して取り出した札は実体を持つ**という対応。敵や環境が札を使う処理は、その存在が自分のやり方で作用を起こすこととして描く。

| 対応 | 描写の第一案 |
|---|---|
| 他主体の手札・山札 | その存在が起こしうる行動・作用のゲーム上の表現。本人が実体のカードを所持するとは限らない |
| 主人公が現地由来の札を取り出す | その作用を主人公の表象として写し、カード状に具現化する |
| 共有の場 | その場に出ている作用や、その手掛かりが交錯する。どの主体も機会・状況を利用する |
| 他者が主人公由来の札の働きを利用する | 主人公の道具を無断で展開するのではなく、生じた作用や状況を自分の行動に利用する |

たとえば、主人公が流れを変えれば、その流れは相手の動きを助ける場合もある。道具の起動を許すことと、既に周囲へ生じた作用が相手にも利用されることを分ける。この区別は追加の説明案であり、主人公の貸与意思を無効にする抜け道として扱わない。

この読み方でも、あらゆる札の主効果が他主体へそのまま渡る部分にはゲーム上の抽象化が残る。敵が主人公用の水筒を勝手に飲む、といった一対一の道具描写を全効果へ強制しない。代表札で接続できない例が出たら、同じ効果を別の行為で表す案を先に比較する。共有循環そのものの変更を黙って採用しない。

### 3.1 貸与と実際の結果

貸与できるのは主人公が展開した道具で、札化・展開能力を相手へ渡すわけではない。道具の機能は主人公の意思と影響に依存する。どこまで届くかは具体化前で、固定半径や常時の意識集中を今は要求しない。

既に起きた結果まで、意思の撤回ですべて巻き戻るとはしない第一案を置く。道具を使って動かした普通の椅子が元へ戻る、治した傷が再び開く、といった一般化は避け、維持を要する現象と普通の結果の違いを別途詰める。これはユーザーから既に確定した細則ではない。

## 4. 山札は「取り出しに備えた印象のまとまり」とする第一案

完全に取り込んだ不思議でも、いつでも全てを同じように取り出せるとは限らない。出発前に今回扱う印象と作用の結び付きを整えておき、その時々に輪郭の立つものを取り出す、と説明する。名称としては山札・手札を維持する案。

| ゲーム上の領域・状態 | 世界内での説明案 |
|---|---|
| 恒久的に得た札の選択肢・所持個体 | 主人公に取り込まれた不思議の型や、癖を含むまとまり |
| 初期構築 | 今回取り出すために、あらかじめ結び付きを整えた組合せ |
| 山札 | 次に取り出せる候補が巡っている状態。物理的な束の保管場所を必須にしない |
| 手札 | 今、表象として輪郭を保ち、扱える状態になった札 |
| 使用期限 | 現在の表象をそのまま保っておける限度。持っている知識や恒久の型を忘れる意味ではない |
| 捨て場 | 一度手放した輪郭や作用が、再び巡る手前にある状態 |
| 回収・山札の補充 | 手放したものが次に取り出せる候補へ巡る。現地由来の作用も混ざる |

取り込み済みの型と、今回取り出した一枚を分ける。一枚が消費・消滅しても、以前の探索で確保した型を失う説明にはしない。消費型を次の探索へ補充できることも、毎回の取り出しの準備として表せる。

代案は「取り込んだ記憶を順に呼び出す」。分かりやすい一方、覚えているのに必要な道具を選べない理由や、他主体から混ざる札との対応が弱い。鞄内の実物を引く案は今回の取り出し像から外れる。第一案にもドローの順序を厳密に説明しきる必要はなく、実際の出せる札・期限・場はゲームの規則を優先する。

### 4.1 同じ型と、別の個体

修飾や同種心得の複数所持は、同じ作用にも取り込み方や出会い方の違いがある、と読む候補を置く。所持個体・習得の利用権・探索中の一枚は本筋の区分を維持する。「型を覚えたから修飾付き個体を無償で何個でも増やせる」とはしない。重複する心得を同時に使う意味は、具体的な装備方式に合わせて後続で詰める。

## 5. 日常の窓口と表の立場

### 5.1 第一案：先代の古道具屋を拠点に、主人公が店番と辿り屋をする

表向きは普通の古道具の売買に、預かり物や取り次ぎが混ざる小さな店。主人公の道具を商品として永久販売する店にはしない。物の来歴、昔の客、持ち込まれた品、近所の頼みごとから、幅広い相談を受けられる。

店と辿り屋の看板・相談経路を先代から受け継ぐ。能力は主人公自身の生来のものなので、先代が同じ能力を持つ必要はない。先代の専門性は、裏道の知識、聞き取り、現地の知り合い等でも成立する。

幼い主人公の生活を支える形としては、**先代が健在で店や暮らしを支え、危険な現地調査は主人公が担う**案を最初に比較したい。家族・保護者との関係や引退理由は未選定。先代の失踪・死亡を、初めから主筋へ追加する必要はない。先代にも知らない土地があり、未知の答えや入手先を全部教える役にはしない。

| 表の立場・拠点案 | 活かせるもの | 気になる点 |
|---|---|---|
| 古道具屋＋預かり・取り次ぎ | 品の来歴、昔の客、生活用品から広い不思議へつなげやすい | 全ての不思議が古い物に宿る話へ偏らないよう、人や土地からの依頼も入れる |
| 修繕を取り次ぐ小店 | 困りごとが持ち込まれる自然さ、町の職人との関係 | 主人公を万能修理職人にしない。異界の案件を全て設備修理へ寄せない |
| 古書・地図の店 | 行き先、伝承、記録、旅の手掛かり | 夢・物語・解読に印象が寄りやすく、身体的な探索も見せたい |
| 手紙・荷物・伝言の預かり店 | 客の事情や行き先のない相談、異界の別業種との接点 | 配達そのものを毎回の探索目的に固定しない |
| 小さな宿・間貸しの家 | 帰る場所と旅人、異なる生活の交流 | 来客や部屋の管理など、扱う人物・日常の量が増えやすい |

### 5.2 相談経路は、普通の入口と例外的な入口を組み合わせる

基本案は店先の小さな「辿り屋」の看板と、先代から続く口伝・紹介。不思議に出会った人には、以前から見ていた看板が急に頼るべき場所だと感じられる。仕事の全貌を理解していない近所の人でも、困った人を「あの店」へ案内できる。

不思議な経路は少数の例外として足せる。たとえば宛先に困った手紙が店の預かり物へ紛れ込む、異界で受け取った古い店の広告がこちらでも入口になる、など。書かれるのは依頼人が知る症状と事情で、真相・正解・未知の品の所在を全知的に届ける装置にはしない。具体方式や固有の受付道具は未採用。

### 5.3 通学と人物像で、今決めると有効な項目

| 先に決めたいこと | 今必要な粒度 | 後からでもよい細部 |
|---|---|---|
| 年齢感と自立の程度 | 店番や町歩きをどこまで一人で行い、どこを大人に支えられるか | 正確な誕生日・学年 |
| 日常を支える相手 | 先代・家族・店の大人等がいるか、主人公が何を任されるか | 詳細な家系や過去の事件 |
| 話し方と感情の出し方 | 「話せるが必要なことしか言わない」を第一案にする。無口と発話不能、表情が少ないことと感情がないことを分ける | 一人称、個別の口癖、全会話文 |
| 初期の知識 | 自分の能力の普段使いは分かるが、各異界の理屈や事件の真相は未知、という案 | 全ての訪問歴 |
| 通学の有無と扱う量 | 通っている設定を置き、ゲーム内では生活の背景に留める案を比較 | 学校名、友人一覧、学校中心の筋書き |

通学している設定は、友人関係の全設定や学校パートの実装を必須にしない。休日・帰宅後に店番をする場面などで生活が分かればよい。探索の長さと日常の時間の対応は未決定なので、毎日の締切や異界の時間停止をこの案から追加しない。

困っている人へ短く悪態をつきながら必要な道具を置く、もう帰ると言いながら最後の一人を待つ、といった行動なら、表情や長い独白を増やさず人物像を見せられる。具体的な口調・行動例はシナリオ側の素材案として扱う。

## 6. 習得・取得は帰還後の取り込みを軸にする

同業市場を基本の供給元にせず、**帰還後に、持ち帰った不思議をどんな形で自分へ取り込むかを選ぶ**方式を第一案にする。異界の人から教わる・譲り受ける・取引する場面は、特定の旅先の出来事として共存できる。

札は外へ作用させる道具、心得は自身の身のこなしや対処に馴染ませた作用、と分ける候補を置く。心得の全てを主人公以外も読めば即使える教本や装身具にする必要はない。ただし後者の具体的な意味は、ユーザーの「心得も同じく」を受けた提案であり、全心得の設定を自動改訂しない。

| 操作・成果 | 世界内の第一案 | 保持する処理の区別 |
|---|---|---|
| 基礎の心得の習得 | 得た不思議を、今回使える基本の作法へ馴染ませる | 習得への配分と所持個体の取得は別 |
| 帰還後の候補から取得 | 持帰りを整理する過程で、取り込めそうな具体的な形や癖の候補が見える | 候補に見えるだけでは未所持。支出・価格・更新条件は本筋に従う |
| 無料の心得の組み直し | 同じ基盤の不思議を、別の基本の作法へ振り向け直す | 基礎習得費は全額戻る。買った個体を破棄して同額を戻す操作ではない |
| 取得個体の低効率変換 | 固有の形や癖をほどき、別の取り込みに生かせる部分を取り出す | 個体を手放す。元の支出全額の返還とは別 |
| 今回の装備変更 | 今回同時に働かせる作用・作法の組合せを整える | 所持・習得は保持。容量方式等は本筋の未決定を維持 |

### 6.1 習得点の意味と名称を再比較する

共通資源の説明案は「取り込んだ不思議を、まだ用途を固定せず別の働きへ生かせる蓄積」。既に知った事実や通常のお金とは区別する。ここから先に、世界に別のエネルギー物質や全世界共通通貨を追加する必要はない。

新しい前提では、自分の内側で印象と作用を結び、形にする **着想** が以前より有力になる。ただし、心得への配分や個体変換まで着想と呼ぶ比喩は残るため、現行正式名を即置換しない。

| 名称 | 今回の設定との接続 | 弱点・扱い |
|---|---|---|
| 着想 | 不思議をどんな働きへ結び付けるか、未確定の可能性を形にする意味 | 純粋な思いつきの数にも読める。変換で戻る理由と、蓄積できる意味の説明が要る。今回の再比較では第一候補 |
| 知見 | 辿り屋が知り、理解したものを次の手段へ生かす意味 | 恒久の調査記録と混ざり、支出・喪失が知識の消去に見えやすい。前回の第一案として引き続き比較 |
| 習得点 | 既存の操作理解を保ち、使い道が分かる | 札の個体取得まで含む用途全体に対して名称が狭い。維持も選択肢 |

「余韻」は不思議の雰囲気には合うが、今回の写しの減衰とも重なり、持帰り済み資源まで自然消滅する印象を与えやすいので、この段階の第一案にはしない。

同業の少なさを踏まえ、前回の「渡り場での持寄り」を日常的な大市場へ広げない。取得候補数が難度によって変動するD53の大枠を維持し、心理描写だけで候補更新や無料再生成を増やさない。正式用語の改称は未実施。

## 7. 緊急脱出と準備した帰還

最初の危機で生まれた道具は、主人公を危険から引き離す働きを優先する、と説明する第一案。緊急時は今回の探索でまとわりついた、まだ己の一部になっていないものを切り離す。通常の帰還では持帰りの準備を反映できる、と分ける。

| 終了・状態 | 描写案 | 現行の保持・喪失 |
|---|---|---|
| 余力が尽きて緊急脱出 | 主人公自身を戻すことを優先し、今回の不安定な成果を切り離す | 今回の保護済み・未保護報酬をともに失う。過去の持帰り成果と調査記録は保持 |
| 任意に途中帰還 | 辿ってきた関係を整理し、まとめておいた分を伴って戻る | 保護済み成果を保持し、未保護分を失う |
| 探索クリア後の帰還 | 探索の目的を果たし、今回分を持ち帰れる状態で戻る | 今回分すべてを保持 |
| 保存中断 | 遊ぶ時間を区切るだけ | 新しい保護・喪失・帰還の出来事にはしない |

準備は、第一案では環境踏破時の既存の保護へ対応させる。ボスが残っていても環境踏破で保護が成立するので、「安全な場所で長く梱包する」とは説明しない。現地の手掛かりや辿った道筋をまとめられたこととして読める。緊急時の全損は、準備不足ではなく本人を優先する脱出の性質による。

専用道具の正式名は未選定。「緊急帰還」は現時点では説明語で、従来資料の死亡・敗北終了へ対応する呼称候補。主人公が文字通り死亡してから蘇る設定は今回の前提にしない。NPCや敵の死亡まで同じ道具で救う設定も足さない。

今後必要なのは、帰還先との結び付き、緊急時の起動条件、本人以外を連れ帰れるかの範囲。現行の任意撤退を保つため、まず手札に引けた場合だけ使える札にはしない案を置く。新しい装備枠・回数・消費費用、緊急時の損失軽減を正式採用したものではない。

## 8. 異界のテーマと、その後の暮らし

「不思議で切ない」を作品全体の基調としつつ、個々のテーマは別に置く。切なさを毎回の死別や消滅へ依存させず、旅人と住民の時間・普通・帰る場所の違いからも作れる。

- 解決した後も不思議な店は営業を続けるが、主人公には自分の町へ帰る時が来る。
- 依頼人は以後その不思議と付き合う。他方で、もう一度も遭遇せず普通に暮らす人もいる。
- 愉快な土地、荒々しい探索、生活上の小さな選択を主題にしてよい。異界ごとのテーマを決めた結果、切なさが薄い土地があってよい。

世界間の交流は地域ごとに異なり、知っている専門家がいる土地も、他世界の存在をほとんど知らない土地もある。主人公の日常の道具や習慣が、旅先では不思議として受け取られる場面も作れる。全世界を一つの同業ネットワークへ統合しない。

## 9. 各WorkとDBに渡す差分

[設定更新の連携事項](../../作業資料/世界観/設定更新の連携事項.md)に、現行前提・提案・担当別の影響をまとめる。SCN-001の具体的な数値・進行の追加検証は本筋と内容Workへ残す。

既存DBには世界観1.6以前の案がある。特にWB-NPC-004「鑑札商の燈子」、WB-CUL-004「鑑札商の鑑定帳」は、主人公の札が一般商品として流通する前提から再評価する必要がある。元の不思議や展開済みの道具、主人公が見せる表象を鑑定する役へ変える案なら人物の魅力を残せるが、今回名前・本文を一括採用し直さない。

WB-KNW-009「道具を貸す手」は意思ある道具貸与と、敵も利用できる共有作用を区別して見直す。WB-MOD-004等の「手を渡った」描写も、主人公の札が独立流通した履歴なのか、元の物・不思議の履歴なのかを区別する。旧案は案として保持し、各個別ファイルに今回の見直し観点を追記する。

# crossweave — 道具化・日常・成長の接続

版：0.7／2026-09-12。担当：世界観Work `20260910-worldbuilding`。

状態：採用済みの前提と追加説明案の接続資料。[世界観設定1.12](../../確定仕様/世界観/世界観設定.md)に従い、他者の札表示と主人公の実体札の対応、先代が経営する古道具屋、低学年程度の主人公と通学は採用済み。着想は正式名候補として仮置き。場と捨て場は不思議そのもの、深く多面的な相互影響で写しが深まること、着想へ細密な設定を求めないこと、通常帰還までを含む救出を現行の方向とする。山札や共有作用の個別描写は説明案。原文は[検討記録22〜28章](../../作業資料/世界観/検討記録.md)。

## 1. 今回の軸と、既に得られた前提

今回の第一案は、**取り込んだ不思議は、以後は主人公自身の不思議として支えられる**、という説明でまとめること。元を写した道具の減衰と、他人に貸した道具の減衰を、働きを支える存在との関係として読める。これはユーザーが述べた関係の説明案で、距離・時間・新しいゲージを定める規則ではない。

| ユーザーから得た前提 | 追加で具体化すること |
|---|---|
| 写すだけでは元の存在に影響しない | 印象を写し取れる契機、作用との結び付け方 |
| 写しただけでも使えるが、元の影響が弱まれば霧散する | 現行の出現元・退場・消滅処理に対応する描写 |
| 己へ取り込めばその後も利用できる。心得も同様 | 成果の獲得・保護・帰還後の定着をどうつなぐか |
| 札化と展開は主人公だけ。他主体の札表示は行動・作用を表し、主人公の写した札には実体がある | 共有作用の個別描写と道具の貸与の違い |
| 札は印象の表象、道具は作用の具象 | 山札・手札・場・捨て場と取り出しの説明 |
| 低学年程度、先代に拾われて暮らす。必要なことだけ話し、能力の普段使いは分かる。先代の店を手伝い通学する | 生活と学校の細部、先代の現地との距離 |
| 辿り屋は知られるが胡散臭く、不思議経験者には関わりが直感できる | 看板・紹介・例外的な不思議の受付 |
| 余力切れは最初の危機で作った道具による緊急脱出 | 保護済み成果も失う理由、任意帰還の準備との区別 |

## 2. 写し・保護・取り込みを段階で分ける第一案

| 段階 | 世界内での説明案 | ゲーム上の対応 |
|---|---|---|
| 現地で写す | 目の前の不思議の印象と作用を捉え、元の影響を借りて道具にする | 他主体・環境由来の札を探索中に利用する。恒久取得とは別 |
| 成果を得る | 後で自分のものにできそうな印象・作用のまとまりを掴む | 報酬獲得。現在の手札に入ることや即時の恒久強化とは別 |
| 持帰りに備える | 辿ってきた関係を整理し、意図した帰還で失わない形にまとめる | 既存の環境踏破による報酬保護。独立の梱包操作を追加しない |
| 帰還後に取り込む | 元の場所から離れても、自分の不思議として維持できる形へ定着させる | 保持できた成果を解放・所持・習得等に反映する |

写しの深まりは、不思議との関わりを何度も・深く持つ過程として扱う。日々の探索で札・道具として使い、帰還後に着想で獲得する流れ自体に、その関わりの深まりが含まれている。全道具に独立の体験場面を用意する必要はない。写す行為自体が元へ影響しないことと、現地での相互影響は区別する。会話や手伝い等の個別場面は任意の表現例として扱う。背景の複数回利用を、新しい使用回数ゲージ・候補解放条件・専用イベント必須へ変換しない。

「保護済み」は主人公への取り込みが完全に終わった状態にはしない。この区別により、保護済みでも緊急脱出では失い、以前の旅で既に取り込んだものは残る、という精算とつながる。

一度目にしただけで全てを恒久取得できる、深部で記録を取れば必ず特定札を得る、という保証は足さない。何を成果として得るかは本筋と内容設計に従う。記録として事実を覚えていることと、作用を再現できることも分ける。

### 2.1 退場と霧散

元の存在が今の探索へ影響しなくなると、写しを新たに支える力が薄れる。手元や場に形を保っているものはすぐ全て消えるのではなく、使い終えたり輪郭をほどいたりする段階で霧散する、という描写を第一案にする。

現行仕様では、出現元退場時に捨て場の由来札は即時消滅し、他主体の手札・山札・共有の場では残り、後に捨て場へ移る際に消滅する。「だんだん薄れる」という世界観から、札の威力を時間で減らす処理や、別の寿命タイマーへ変更しない。

元の存在が退場することと、その不思議が世界から消えることは別。道を通り抜けて影響圏を離れる、敵対者を振り切る、流れが変わる、といった場合でも説明できる。一般的な不思議の影響とゲーム上の出現元がどこまで一致するかは、内容ごとの対応を残す。

## 3. 主人公の実体札と、場を巡る不思議

異界視点で普通のものでも写せる。関わりを深めるほど自分のものとして写せる一方、触れてみて不思議さが薄れるものは大きな効果の道具になりづらい。作用と印象の両方に沿う道具を、個別の幅を残して設定する。

今回の採用前提は、**主人公が写して取り出した札には実体があり、場と捨て場の札は不思議そのものを表す**という対応。他者の手札・山札の表示はその存在の行動・作用で、実物のカードを持つ必要はない。主人公は手札を一致させたり場へ出したりして、道具の不思議を放つ。

画面には従来どおり札を表示してよい。主人公のイメージで不思議を札として捉えている、と説明できる。領域ごとの材質・形状の切替や、新しい表示方式を必須にしない。

| 対応 | 存在上の扱いと説明案 |
|---|---|
| 主人公が現地由来の札を取り出す | 不思議を主人公の表象へ写し、実体のある札として取り出す |
| 他主体の手札・山札 | その存在が起こしうる行動・作用の表現 |
| 場の札・捨て札 | 実体札の束ではなく不思議そのもの。両者の循環上の状態の違いは4章の説明案 |
| 他主体が主人公由来の不思議を使う | 放たれた働きを、その存在の行為へ結び付けて利用する説明案。主人公の札化能力を得る意味にはしない |

**展開した道具の貸与と、放たれた不思議の利用を分ける**と既存の共有循環へ接続しやすい。たとえば主人公が手鏡から放った反射を、相手も身を隠すために使う。手鏡を無断で展開・操作した場面に置き換える必要はない。この切り分けは今回の前提から導く説明案であり、貸与意思が必要という既存設定を撤回しない。

回復の札なら、相手が主人公の匙や襟巻きを盗んで使うと描くのでなく、放たれた温もりや休息の働きを、その存在の回復として描く案がある。ただし、放っただけで周囲が自動的に回復する規則は足さない。主効果・場の効果・使用者・対象・消費はゲームの規則に従う。全ての効果を一つの物理的な所作へ対応させる必要はない。

### 3.1 貸与と実際の結果

貸与できるのは主人公が展開した道具で、札化・展開能力を相手へ渡すわけではない。道具の機能は主人公の意思と影響に依存する。どこまで届くかは具体化前で、固定半径や常時の意識集中を今は要求しない。

既に起きた結果まで、意思の撤回ですべて巻き戻るとはしない第一案を置く。道具を使って動かした普通の椅子が元へ戻る、治した傷が再び開く、といった一般化は避け、維持を要する現象と普通の結果の違いを別途詰める。これはユーザーから既に確定した細則ではない。

## 4. 取り出しと循環の短い説明案

まず、**今回使う不思議を整え、その時々に取り出せる印象を札にし、放った不思議が再び巡る**程度の説明に留める。山札の順序・手札の期限を全て物理法則や心理の制限で説明し切る必要はない。採用された場・捨て場の存在上の扱いと、下表の循環の比喩は区別する。

| ゲーム上の状態・操作 | 世界内の説明案 |
|---|---|
| 恒久的な選択肢・所持個体 | 以前の関わりを通じ、自分の手段になった不思議の型や癖 |
| 初期構築 | 今回の探索で使う手段を整える |
| 山札 | これから取り出せる不思議のまとまり。物理的な束を持ち歩く必要はない |
| 主人公の手札 | 今、表象として取り出し、扱える札 |
| 一致先がなく場へ出す | 不思議を放ち、その場で他の働きと結び付けられる状態にする。ここで主効果が成立したとはしない |
| 一致して行動する | 場の不思議へ手元から放つ働きを結び付け、主効果と場の効果が成立する |
| 捨て場 | 一度使ったり手放したりした不思議が、再び巡りうる状態。今、一致先として使える場とは区別する |
| 回収・山札の補充 | 巡ってきた不思議が次の手段へ入る。主人公なら再び札として取り出せる。現地の他者へも巡る |
| 使用期限 | 今手元に保つ札を手放す区切りとして描く。知識や恒久の手段を忘れる設定にはしない |

一致では通常、出した札と材料の場札が捨て場へ移る。一致先があれば一致が必須、不一致なら主効果なしで場へ残るという既存規則を保つ。「不思議が放たれる」ことを、設置だけで主効果が先に起こる変更にはしない。

回収で巡るのは今回の探索の不思議で、恒久的な取り込みや追加報酬ではない。回収のたびに深い交流の場面を挟む必要もない。元の存在を何度も写し直す儀式や、主人公の意思で全ての巡り先を選べる設定は加えない。

一枚が消費・消滅しても、以前の探索で確保した手段や所持を失う説明にはしない。世界観上の古い由来と、今回の出現元も別。出発時に主人公が持ち込む札は、その主人公を出現元とする。

具体的な道具を出す・放つ・札へ戻す所作やフレーム順はビジュアル側の比較へ残す。[写しと札の循環の具体例](写しと札の循環の具体例.md)で、異なる由来を既存DB6案へ接続する。

### 4.1 同じ型と、別の個体

修飾や同種心得の複数所持は、同じ作用にも取り込み方や出会い方の違いがある、と読む候補を置く。所持個体・習得の利用権・探索中の一枚は本筋の区分を維持する。「型を覚えたから修飾付き個体を無償で何個でも増やせる」とはしない。重複する心得を同時に使う意味は、具体的な装備方式に合わせて後続で詰める。

## 5. 日常の窓口と表の立場

### 5.1 採用：先代が経営する古道具屋＋預かり・取り次ぎ

店の経営者は先代であり、主人公はお手伝い程度の店番をする。天涯孤独だった低学年程度の主人公が先代に拾われ、生活を支えられる関係を採用した。店と辿り屋のつながりは継承できるが、店の経営権や能力が主人公へ丸ごと移る前提にはしない。

普通の古道具の売買と預かり・取り次ぎを通じ、物の来歴、昔の客、持ち込まれた品、近所の頼みごとなどから広い相談につなげられる。主人公の展開道具を独立した恒久商品にはしない。先代は探索の一線を退いた隠居で、人間以外も含むつながりは残る。かつての付き合いと相棒を軸に、自身の不思議への対処能力と、現在の渡航の負担を分ける方向を採用した。相棒は普段姿を見せず、ときどき人に化けて手伝う。詳細は[先代の辿り方と主人公の単独探索](先代の辿り方と主人公の単独探索.md)0.3で具体化の方向への支持を記録した。先代の痕跡読みと作用の扱い、相棒の道・帰路の支え、出発ごとの渡航準備が基盤となる。能力名・相棒の正体・具体的な準備物・店名等は未決定。

比較した修繕取り次ぎ店、古書・地図の店、手紙・荷物の預かり店、宿の案は0.1の経緯としてGit履歴に残る。現在の拠点を未選択の五案へ戻さない。店の具体的な役割分担と暮らしは[主人公・先代・通学の背景](主人公・先代・通学の背景.md)で詳細案を用意した。

### 5.2 相談経路は、普通の入口と例外的な入口を組み合わせる

基本案は店先の小さな「辿り屋」の看板と、先代から続く口伝・紹介。不思議に出会った人には、以前から見ていた看板が急に頼るべき場所だと感じられる。仕事の全貌を理解していない近所の人でも、困った人を「あの店」へ案内できる。

不思議な経路は少数の例外として足せる。たとえば宛先に困った手紙が店の預かり物へ紛れ込む、異界で受け取った古い店の広告がこちらでも入口になる、など。書かれるのは依頼人が知る症状と事情で、真相・正解・未知の品の所在を全知的に届ける装置にはしない。具体方式や固有の受付道具は未採用。[相談経路と異界への往来0.1](相談経路と異界への往来.md)で、普通の窓口・旧知・不思議な伝言と、渡り方の比較を進めた。

### 5.3 採用：人物像・初期知識・通学

小学校低学年程度で、一人の町歩きと手伝い程度の店番ができ、暮らしは先代に支えられる。話せるが必要なことしか言わず、不愛想でも困っている人を見捨てられない。自分の能力の普段使いは分かるが、異界や案件の真相は未知である。

先代の知識が全て継承される必要はない。他者の知識・経験がそのまま役立つ度合いも、不思議との関係によって柔軟に扱える。この点は先代が必ず無知・経験が必ず無効という一律の設定ではない。

通学することを採用し、ゲームに表れない背景も組む。[生活の背景案](主人公・先代・通学の背景.md)では、学校との連絡、平日の生活、授業と読み書き、先生・同級生との距離、不思議の知られ方、探索の時間との対応を一通り用意した。正確な学年・学校名・さらに別の店員や、細部の第一案までは採用していない。

## 6. 着想と習得は、探索から得たものを次へ生かす営み

ユーザーの想定に従い、**探索で得た着想から、今後の探索の心得を習得する動作をゲームのシステムで表す**ことを説明の基盤にする。写しから取り込みまでは、不思議との深く繰り返される相互影響として扱う。帰還後の支出や返還の各点に、実体のあるエネルギーや専用の儀式を割り当てる必要はない。

札は外へ作用させる道具、心得は自分の振る舞いや対処へ生かした学び、と読める。後者は説明案であり、不思議を己に取り込む従来の前提と共存できる。全心得を普通の技能だけへ狭めたり、装身具や教本へ統一したりしない。

| ゲームで分けるもの | 説明するときに保つ違い |
|---|---|
| 習得 | 探索で得たものを、今後の心得として生かす |
| 候補からの個体取得 | 具体的な札・心得の個体を得る。候補が見えることと所持は別 |
| 基礎習得の無料取り直し | 今後の心得の組合せを考え直せるシステム。過去の体験を消す描写は必要ない |
| 個体の低効率変換 | 所持個体を手放して既存資源へ変える処理。習得費の全額返還と混ぜない |
| 今回の装備・構築 | 所持や習得の中から、今回使う組合せを整える |

0.5までの「基盤の不思議を振り向ける」「癖をほどいて部分を取り出す」等は比喩の候補としてGit履歴に残す。これらの細密な仕組みの確定を次の検討の条件にしない。取得候補の生成・価格・数や装備方式は本筋の採用状態に従う。

### 6.1 着想（従来：習得点）の仮置き

名称は引き続き**正式名候補として仮置き、本決まり前**。今回の説明方向への支持だけで正式採用へ変更しない。今後の検討では着想を使い、従来の習得点との対応を保つ。[正式用語集1.3](../../確定仕様/世界観/正式用語集.md)と[成長用語0.5](成長・取得・心得準備の用語.md)へ説明範囲を反映した。

「必要着想」「戻る着想」等の表示案は、操作が分かるかを軸に検討できる。世界全体に着想の市場や共通通貨を置く必要はない。既存UI・コードへの一括改称や、新しい成長規則の実装は今回の担当外。

## 7. 緊急脱出と準備した帰還

最初の危機は先代に拾われる前である。そのとき生まれた道具は、主人公を危険から引き離す働きを優先する、と説明する第一案。当時の脱出先をまだ知らない先代の店に固定せず、今の帰還先との関係は先代の具体化資料7.2で案を置く。緊急時は今回の探索でまとわりついた、まだ己の一部になっていないものを切り離す。通常の帰還では持帰りの準備を反映できる、と分ける。

| 終了・状態 | 描写案 | 現行の保持・喪失 |
|---|---|---|
| 余力が尽きて緊急脱出 | 主人公自身を戻すことを優先し、今回の不安定な成果を切り離す | 今回の保護済み・未保護報酬をともに失う。過去の持帰り成果と調査記録は保持 |
| 任意に途中帰還 | 辿ってきた関係を整理し、まとめておいた分を伴って戻る | 保護済み成果を保持し、未保護分を失う |
| 探索クリア後の帰還 | 探索の目的を果たし、今回分を持ち帰れる状態で戻る | 今回分すべてを保持 |
| 保存中断 | 遊ぶ時間を区切るだけ | 新しい保護・喪失・帰還の出来事にはしない |

準備は、第一案では環境踏破時の既存の保護へ対応させる。ボスが残っていても環境踏破で保護が成立するので、「安全な場所で長く梱包する」とは説明しない。現地の手掛かりや辿った道筋をまとめられたこととして読める。緊急時の全損は、準備不足ではなく本人を優先する脱出の性質による。

専用道具の正式名は未選定。「緊急帰還」は現時点では説明語で、従来資料の死亡・敗北終了へ対応する呼称候補。主人公が文字通り死亡してから蘇る設定は今回の前提にしない。NPCや敵の死亡まで同じ道具で救う設定も足さない。

他者の救出は、ユーザーの「緊急脱出せず連れて帰る」までを含む方向で具体化する。相手を見つけた後、通れる帰路を探す、道中で付き添う、相手が暮らせる側へ送り届ける等が個別案になる。発見や主人公だけの緊急脱出では救出完了とせず、往路で知った不思議を帰路へ生かす体験を作れる。

これは救出対象を報酬の保護状態へ機械的に対応させたり、緊急脱出時に必ず死亡させたりする規則ではない。同行の操作、救出判定、失敗後の相手の状態は内容・本筋で個別に検討する。通常の帰還方法と緊急脱出道具の同行可能範囲も区別する。

今後必要なのは、帰還先との結び付き、緊急時の起動条件、緊急脱出で本人以外を伴えるかの範囲。現行の任意撤退を保つため、まず手札に引けた場合だけ使える札にはしない案を置く。新しい装備枠・回数・消費費用、緊急時の損失軽減を正式採用したものではない。

## 8. 異界のテーマと、その後の暮らし

「不思議で切ない」を作品全体の基調としつつ、個々のテーマは別に置く。切なさを毎回の死別や消滅へ依存させず、旅人と住民の時間・普通・帰る場所の違いからも作れる。

- 解決した後も不思議な店は営業を続けるが、主人公には自分の町へ帰る時が来る。
- 依頼人は以後その不思議と付き合う。他方で、もう一度も遭遇せず普通に暮らす人もいる。
- 愉快な土地、荒々しい探索、生活上の小さな選択を主題にしてよい。異界ごとのテーマを決めた結果、切なさが薄い土地があってよい。

世界間の交流は地域ごとに異なり、知っている専門家がいる土地も、他世界の存在をほとんど知らない土地もある。主人公の日常の道具や習慣が、旅先では不思議として受け取られる場面も作れる。全世界を一つの同業ネットワークへ統合しない。

## 9. 各WorkとDBに渡す差分

[設定更新の連携事項](../../作業資料/世界観/設定更新の連携事項.md)に、現行前提・提案・担当別の影響をまとめる。SCN-001の具体的な数値・進行の追加検証は本筋と内容Workへ残す。

既存DBには世界観1.6以前の案がある。特にWB-NPC-004「鑑札商の燈子」、WB-CUL-004「鑑札商の鑑定帳」は、主人公の札が一般商品として流通する前提から再評価する必要がある。元の不思議や展開済みの道具、主人公が見せる表象を鑑定する役へ変える案なら人物の魅力を残せるが、今回名前・本文を一括採用し直さない。

WB-KNW-009「道具を貸す手」は意思ある道具貸与と、敵も利用できる共有作用を区別して見直す。WB-MOD-004等の「手を渡った」描写も、主人公の札が独立流通した履歴なのか、元の物・不思議の履歴なのかを区別する。旧案は案として保持し、各個別ファイルに今回の見直し観点を追記する。

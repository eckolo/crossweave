## 4. 踏破の動機を保ちながら、全てを仕事へ変えない

| 素材の置き方 | 深部まで進む理由の例 | 描く量 |
|---|---|---|
| 主な探索案件 | 原因の現地確認、未踏経路の踏査、出口の確保、奥の観測位置への到達 | 案件として目的と到達を組む |
| 道中の対峙 | 進路を塞ぐ捕食者、競う相手、意思を無視する作用 | 本筋の道中に一体・一場面を置ける |
| 土地の普段の姿 | 遊び、参詣、脱皮、獣の休息、動き続ける機関 | 背景や短い出来事だけでもよい |
| 札や心得の背景 | 見た印象と作用、探索での利用、帰還後の取り込み | 既存の利用・取得の流れに含めて成立する |

主な動機である辿り屋の異変調査は保つ。新しい素材を出すたびに、職業全体を競技者や宗教者へ変える必要はない。踏査・記録等の副目的を厚くし、探索中に見える暮らしや自然の側も増やす。

競争・危険・不気味さを増やすことは、敵を倒すことだけを中心に戻す意味でもない。見極めて通る、押し返す、対決する、見て戻るなど、探索と突破の共通概念の中で幅を持たせる。相手を理解したら必ず仲良くなることも、全ての不思議が最後には消えることも求めない。

## 5. 似通いを見つけた時の戻り方

たとえば直近の三案が全て「届け物の誤りを直して感謝される」なら、名詞だけを雨・手紙・色へ変えても体験は近い。その時は、同じ品を競技の目印にする、使われ方を観測する、誰にも使われず存在する景色として置く、といった別の関わり方を試す。

逆に、今までの案と似た語でも、役割や後味が違えば残せる。「雨の配達違い」と「雨の受取人」は同じ土地に関わるが、前者は異変への対処、後者は解決後に他の土地へ届いた影響を調べる案である。新しさだけで既存案を捨てず、何が違うかを本文で説明する。

今回の追加群にも、物の擬人化、比喩を地形にする案、小さな技術を巨大にする案が多い。この傾向まで万能の作り方にしない。今後は日常そのものの小さな違和感、身体の内側の感覚、明快な悪意、贅沢や見栄、偶然の美しさなど、別の入口にも戻れる。未解明さも全部へ要求せず、はっきり原因が分かって気持ちよく解決する案件を残す。

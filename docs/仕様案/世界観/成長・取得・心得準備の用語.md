## 2. 資源名は「着想」を仮置きする

説明の第一案は、**旅で触れた不思議を、自分の新しい手段へ結び付けるための蓄積**。札として外へ働かせることにも、心得として自分の対処へ取り込むことにも使える。単なる発明の回数に絞らず、印象と作用を結び付ける主人公の能力を軸に読む。

| 名称 | 世界観への適合 | 分かりやすさ・気になる点 | 現在の扱い |
|---|---|---|---|
| 着想 | 不思議の印象と作用を、新しい具体的な手段へ結び付ける意味に合う | 蓄積・支出・返還をどう読むかの説明が必要 | **ユーザー指定で正式名候補として仮置き。本決まり前** |
| 知見 | 辿り屋の調査・経験・現地の学びを広く受け止める | 記録と混ざり、支出が知識の消失に見えやすい | 0.1の第一案。現在の仮置き名ではない |
| 経験 | 旅から得る成長資源として理解しやすい | 一方向のレベル上昇へ寄り、組み直し・個体取得との対応は弱い | 以前の比較候補 |
| 習得点 | 用途が直接伝わり、既存資料との対応が容易 | 札の取得まで含めると語の示す用途が狭い | 従来名として着想との対応を保持 |

表示例は「着想 12」「必要着想 4」。仮置きの状態は資料側に明記し、見本の数値欄へ毎回「（仮）」を付けることまでは要求しない。数値は仮例であり、桁・単位・価格を決めない。

| 資源の動き | 世界内の説明案 | 維持する区別 |
|---|---|---|
| 成果として得る・帰還後に使う | 不思議の働きを自分の別の手段へ結び付けられる余地が増える | 今回の未精算成果と、以前から保持する資源は別 |
| 習得や取得に使う | 未配分の可能性を、選んだ手段へ振り向ける | 見た事実や調査記録は消えない |
| 基礎の心得を組み直す | 基礎へ振り向けた分を、別の基礎へ配分し直せる状態に戻す | 本筋の無料取り直し・実支出の全額返還を維持 |
| 個体を変換する | 固有の形や癖をほどき、別の働きへ生かせる部分を戻す | 所持個体を失い、取得費の全額返還とは別 |

以上は名称を支える説明案。普通の授業や工作で思いつくたびにゲーム資源が増える、頭の中で考えれば無限生成できる、他人の経験談を聞けばそのまま同額を得る、といった取得規則は追加しない。世界共通通貨や、自然に霧散する別物質を作る必要もない。

## 3. 装備は「備える」、容量は「心得容量」、個別費用は「負荷」

学んだ心得の全部を同時に意識して使えるわけではなく、今回の探索で働かせる組合せを整える、と表す。持っている心得、習得して扱える心得、今回備えている心得を区別できる。

| 概念 | 第一案 | 意味 |
|---|---|---|
| 総装備容量 | 心得容量 | 今回同時に働かせられる心得の範囲 |
| 個別の装備コスト | 負荷 | その心得を備えている間に占める量 |
| 現在のコスト合計 | 使用負荷 | 備えている心得の負荷の合計 |
| 残り容量 | 空き容量 | 心得容量から使用負荷を引いた量 |
| 心得を装備する | 備える | 今回使う組合せへ入れる |
| 装備済み | 使用中／備えている心得 | 今回使う構成に含まれる。説明では備えている心得、短い状態欄では使用中とする |
| 装備を付け替える | 心得の入れ替え | 習得は維持して、今回使う組合せを変える |

表示例は、全体欄を「心得負荷 6 / 8」、個別欄を「負荷 2」とする。6は占有中の量、8は心得容量。行動するたびに負荷を支払う意味ではなく、外せば空き容量が戻る。以下を別欄で扱う。

- **着想**：習得・入手などへ支出する資源の仮置き名。
- **心得容量と負荷**：準備中の占有と上限の名称案。
- **余力・道のり・耐久**：行動主体の残量表示。HP相当で、心得の装備上限ではない。
- **行動間隔**：次の手までの時間。装備負荷とは別。

「負荷」は同時に扱う作法や働きの重さを読む比喩であり、新しい疲労ゲージや精神ダメージを追加しない。心得の所持個体が具体的に何へ記されるかは別に検討でき、全てを装身具にする設定も不要。

| 容量名の代案 | 利点 | 気になる点 |
|---|---|---|
| 器量 | 人が抱えられる働きの幅として短く、世界内の語感がある | 人物全体の能力評価にも読め、何の上限かが初見では弱い |
| 心得枠 | 固定個数制なら分かりやすい | 重い一つが多く使う総コスト案では、枠の個数と混同しやすい |
| 余裕 | 複数のことへ気を配る意味は自然 | 既存の余力と近すぎる |
| 心得容量 | 何をどれだけ同時に扱えるかが明確。世界設定に余分な身体器官や魔力を設けない | 他の短い語よりゲーム上の説明語に寄る |

第一案は心得容量。具体方式が固定枠へ決まった場合は心得枠の方が適する。命名のために総コスト方式を先に確定しない。

## 4. 取得は「入手する」を軸にする

設計上の「購入」は、資源を支出して所持個体を増やす処理を表す。現時点では売り手・通貨・売場が決まっていないため、共通の操作名は **入手する**、候補の名称は **入手候補** を第一案にする。必要な資源の欄を併記し、無償配布には見せない。

| 概念 | 第一案 | 区別する内容 |
|---|---|---|
| 取得候補 | 入手候補 | 今選べる個体。未選択の品は所持していない |
| 同時に提示された一組 | 候補一覧 | 三つ等の個数を名前に含めない |
| 個体を選び資源を支払う | 入手する | 説明では「着想を使って入手」。従来名を併記する場合は「習得点を使って入手」 |
| 取得価格 | 必要着想 | その入手に必要な支出。装備負荷と別 |
| 何も選ばず終える | 見送る | 支出しない。既に入手したものを手放す操作ではない |
| 提示内容の切替 | 候補の更新 | 更新条件に従う処理。任意の再抽選ボタンの存在を意味しない |
| 不要品を資源へ戻す | 変換 | 現行の呼称を維持。必要な数量の所持品を手放す |
| 変換で得る点 | 得られる着想 | 入手費や習得費の返還とは異なる額 |

「交換」は物々交換を中心にするなら合い、「購入」は売場で代価を支払うなら合う。「伝授」は人から心得を学ぶ場面には合うが、札を含む個体取得全般へは狭い。「再現」は既知の型を自分で作る方式へ決まった場合の候補で、現行の候補取得だけから自由な複製や再制作を追加しない。

世界内の見せ方は次の三方向を比較できる。共通UI名を入手候補にしておけば、地域ごとに供給者や所作が違っても扱える。

| 見せ方の案 | 具体像 | 決める必要が残るもの |
|---|---|---|
| 渡り場での持寄り | 辿り屋や現地の専門家が品・記録・扱い方を持ち寄り、その帰還で紹介できる手段が並ぶ | 誰が何を渡すか、紹介と資源支出の関係。共通組合や全世界市場は必須にしない |
| 帰還後の試作 | 成果を調べ直す過程で、形にできそうな札や身につけられる作法がいくつか見える | 未選択の候補の扱い、制作で得る所持個体と探索用札の違い |
| 現地の教えと譲り受け | 交流した相手が、道具や自分のやり方を候補として示す | 札と心得で所作をどう描き分けるか、依頼達成との結び付き |

共通の候補一覧の雰囲気を付けるなら「品定め」も使えるが、必須の機能名にはしない。三方向のどれも、事前に未知の土地の特定報酬を保証する仕組みにはしない。

## 6. 短い表示へ当てはめる

次は語の読み分けだけの仮例。名称・数値・画面配置を正式採用したものではない。

| 場所 | 表示例 | 伝えること |
|---|---|---|
| 資源欄 | 着想 12 | 今使える資源 |
| 心得の習得欄 | 習得：2着想 | 基礎を扱えるようにする支出 |
| 準備の全体欄 | 心得負荷 6 / 8 | 使用負荷と心得容量 |
| 個別の心得 | 負荷 2／所持 2／使用中 1 | 支出する点と、占有する量・個数を分ける |
| 入手候補の詳細 | 必要着想 4／負荷 2 | 入手できることと今の構成へ入ることは別 |
| 候補の操作 | 入手する／見送る | 選択と支出の確定、または支出なし |
| 変換の詳細 | 得られる着想 0.5 | 取得物を手放す対価 |
| 基礎の組み直し | 戻る着想 2 | 実際に支払った習得分の返還 |

「外す」だけで何でも同じ返還をする説明にはしない。備えから外す場合は空き容量が戻り、基礎の習得を外す場合は実支出が返還され、入手品の変換では別に定義した量が得られる。語を分けた上で、必要な詳細をその操作の近くへ出す。

## 7. 今回の到達点

資源名は着想を仮置きする。これは他の候補と同列の未選択状態から一歩進んだユーザー判断であり、正式採用済みとは区別する。心得容量・負荷・備える・入手候補・入手するや、各説明文の細部は引き続き提案。関連の数量欄はGT-001に従う表示案として着想へ揃えた。

既存の心得・習得・所持数・変換・心得の組み直し・調査記録・成果は意味を保つ。D53の取得経路の大枠は採用済みであり、総装備コスト等の未決定方式と分ける。名称変更のためだけに、専用通貨、無限の容量成長、札の自由な複製、修飾の再抽選を追加しない。

# crossweave — 先代の辿り方と主人公の単独探索

版：0.3／2026-09-12。担当：世界観Work `20260910-worldbuilding`。

状態：0.2で提示した具体化の方向にユーザーの支持を受けた。痕跡を読む先代と道・帰路を支える相棒の分担、現在の渡航準備の負担、暮らしから仕事へ関わる来歴を採用方向として扱う。具体的な品・台詞・所作、能力名・正体・費用は案を維持する。正本は[世界観設定1.10](../../確定仕様/世界観/世界観設定.md)、生活背景は[主人公・先代・通学の背景](主人公・先代・通学の背景.md)、原文は[検討記録24〜26章](../../作業資料/世界観/検討記録.md)。0.1の三案全文はGit履歴に保持する。

## 1. 今回の採用方向と、残る具体化

- 不思議な相手との付き合い・かつての相棒との旅を先代の軸にする。先代自身にも、不思議と相対する力や手段がある。
- 現在は異界へ渡ることが難しい、または負担が大きい。一方、不思議を相手にすること自体は今もできる。
- 古道具の使いこなし、痕跡を読む等の要素を組み合わせてよい。0.1の002・003の隠居理由まで同時に採用する意味ではない。
- かつての相棒が店を手伝う。普段は姿を見せず、人手が足りないときに「仕方ないな」という調子で人に化けて手伝う。
- 隠居後、昔の知り合いから子どもの話が届き、町側で主人公と出会って引き取る来歴を具体化の基盤とする。
- 最初の危機と脱出道具の成立は、拾われる前。拾われるまでの不思議との遭遇は複数回あってもよい。

| 比較ID | 現在の位置付け | 具体化する範囲 |
|---|---|---|
| WB-PRE-001 | 主軸として採用 | 付き合いと相棒との旅。先代自身の力を持たせ、渡航と現地での対処を分ける |
| WB-PRE-002 | 要素の併用を許容 | 古道具の目利き・手入れ・使いこなし。道具一式や老いによる機能低下は未採用 |
| WB-PRE-003 | 要素の併用を許容 | 痕跡を読む能力。過去の痕跡が重なり能力が使えなくなるという旧引退案は未採用 |

先代の種族・能力の名称や由来、相棒の正体と姿、渡航の負担の正確な仕組みは未決定。完全な通行不能や、同行者を伴う帰還の禁止も決めていない。

## 2. 先代自身の力：関わりの痕跡を読み、作用を扱う

先代には、物・場所・存在に残る関わりを読み取る力がある。どこかから持ち込まれた気配、同じものに触れた跡、今も別の場所へつながっている作用を、手掛かりとして捉える。これに長年の経験、古道具の扱い、現地で覚えた作法を合わせて対処する。

読めるのはつながりの手掛かりであり、全ての過去や正体がそのまま再生されるわけではない。何が起き、誰がどう困っているかは、相手の話や現物と照らして判断する。痕跡が薄い、複数の来歴が重なる、本人も知らない働きがある、といった場合には分からない部分が残る。

| 具体例 | 見極めること | 対処の案 |
|---|---|---|
| 預かった箱から、別の場所の風が吹く | 箱の傷みと、離れた場所につながる働きを読み分ける | 留め具や置き方を整え、店へ漏れる作用を落ち着かせる。つながる先の調査は別途必要 |
| 客について来た影が戸口から動かない | 客を追っているのか、品について来たのか、通してほしいのかを確かめる | 話をつける、品を離して置く、境目を一時的に保つ等を選ぶ |
| 道具が元の用途と違う働きをし始める | 壊れた箇所と、後から付いた不思議な性質を見分ける | 手入れや使い方を変え、何ができる品かを確かめ直す |

手入れで扱えるのは、そこにある物や作用。主人公のように不思議を写して札へ具象化する力は持たせない。札化・展開は主人公固有のまま維持する。物や相手を問わず全ての結び付きを自在に切れる能力にもせず、具体的な作用と対処ごとに範囲を定める。

先代の腕は、店で不思議に関わる一場面でも見せられる。主人公が取り出した道具を見て、異界の全容は知らなくても「これは使い終わった後に向きを戻しておけ」と性質を見抜く、といった助言ができる。その観察だけで札の全性能・現地の正解を確定する演出にはしない。

## 3. 現役時代：先代が見極め、相棒が渡りを支える

先代は不思議の痕跡を追い、相手と話し、道具や土地の作用を使って問題へ対処していた。相棒は、見つけたつながりを実際に渡れる道へ整え、旅の間も帰路を支えた、という分担を採用方向にする。

| 旅の過程 | 先代の役割 | 相棒の役割 |
|---|---|---|
| 入口へ向かう | 症状・品・証言から、関わりが続く先を見立てる | その境目を渡れる状態に整える |
| 異界を探索する | 現地で見極め、交渉し、道具と作用を使って進む | 先代と道を渡り、移動や退路を支える |
| 帰ってくる | 調べたことと必要な対応を持ち帰る | 旅の間に保っていた帰路を使えるようにする |

相棒が道を渡せても、その先の事件の原因や解決方法が分かるとは限らない。昔の知り合いも、自分が関わる範囲を知っている存在として扱う。入口や紹介を足場に、奥へ行って初めて分かることを調べる辿り屋である。

古道具を譲り受けたり、現地の流儀を教わったり、相手の困りごとを引き受けたりする中で、人間以外も含むつながりが増えた。店の預かり物・伝言・客の中には、その旅の続きが混じっている。

## 4. 現在：対処する力はあるが、渡航の準備が重い

先代の隠居は、**異界への行き来を日常的に続けることから退いた状態**として具体化する。店に持ち込まれた品、町側で起きた不思議、訪ねて来た存在には今も相対できる。

渡航の負担の基盤は、かつて相棒が旅の間に担っていた道と帰路の確保を、現在は出発ごとに準備しなければならないこと。先代がつながりを見つけても、長く渡っていられる道と帰ってこられる手段は別に整える必要がある。

| 現在できること | 準備・負担の案 |
|---|---|
| 店や町で不思議を調べ、対処する | 先代自身の能力、手元の道具、知っている作法を使える |
| 顔なじみへ相談・紹介を求める | 相手の都合とつながりが届く範囲に応じる。全世界へ即時連絡できるわけではない |
| 慣れた異界へ短く渡る | 利用できる道や先方の助力があれば可能な余地を残す |
| 未知の異界を長く探索する | 印や道具、入口での手順、帰路の支えを一件ずつ整える。継続的な遠征には重い負担になる |

準備の日数・費用・使用する品はまだ固定しない。主人公の着想や成果を支払う新しい渡航料金にはしない。生命や記憶を恒常的に削る対価も、この段階では必要としない。

相棒の現在の性質は、店を居所に定め、旅に同行して道を支える働きから離れた、という方向を基盤とする。店で人の姿を取って手を貸すことは、その場での働き。異界まで先代を伴い、探索中ずっと道を保つことには、別の準備と負担がある。人手が足りないときに化けられることを、すぐに昔と同じ旅を再開できることへ結び付けない。

この性質の正確な理由は未決定。敷居に根づいた存在という具体像は候補であり、店から一歩も出られない絶対的な法則として確定していない。

## 5. 主人公が普段一人で探索する関係

主人公は、出会う前から自分の不思議で危機を切り抜けている。先代の紹介や助言を受けながら、現地では自分の手段で進み、帰ってくる。先代が毎回同行するには、もう一人分の渡航と帰路を用意する負担があり、普段の探索は主人公が担う。

前案の「主人公は同行者を連れ帰る使い方がまだ分からない」は補助候補に留め、単独探索の理由をそこへ依存させない。本人以外の緊急帰還・救出の範囲は未決定である。現地の案内、一時的な協力、必要な場面での先代の介入も、個別に扱う余地を残す。

先代は何もできずに待つ人物にはしない。相談の切り分け、持ち込まれたものの調査、相手への取り次ぎ、帰還後の道具の見立てを担う。主人公の未熟さは暮らしや読み書き、交渉経験などに残り、旅へ出られる特性がそのまま全分野で先代を上回ることにはならない。

また、先代の難しい渡航を主人公に代行させる事情だけを主な動機にはしない。主人公自身が困った相手へ関わり、辿り屋として進む意思を持つ。その仕事を続けられる足場を、先代と店が支える。

## 6. 相棒の日常：見えない居候、ときどき手伝い

かつての相棒が今も店にいること、普段は姿を見せず、人手が足りないときに人へ化けて手伝うことは今回の採用方向。名前、性別、人の姿、本来の正体は未選定。追加の常勤店員を前提にしない。

細かな日常の第一案は、先代と主人公にはそこにいることが分かり、姿がなくても時々声だけで返事をする、というもの。普通の客には、基本的には先代と子どもで営む店に見える。

| 場面案 | 相棒の振る舞い | 見せられる関係 |
|---|---|---|
| 先代が相棒に品の場所を聞く | 姿のないまま、短く「その棚の裏」と答える | 店で長く暮らし、会話が日常になっている |
| 客と荷物が重なる | 奥から人の姿で出てきて「仕方ないな」と受け取りを手伝う | 働き者の常勤店員にはならず、必要なときに手を貸す |
| 主人公がいつもより遅く戻る | 帰る直前まで戸口へ注意を向け、戻った後は特に大げさなことを言わない | 素っ気なくても気に掛けている |
| 昔の旅仲間が訪れる | 姿を出すより先に、古い呼び方へ返事をしてしまう | 主人公の知らない長い付き合いがある |

客が人の姿を見る場合は、店主の知人が手伝いに来たように受け取れる案を置く。毎回違う姿で混乱を起こすことや、不自然さを記憶消去で隠す規則は追加しない。人の姿の固定・変化はビジュアル側の比較に残す。

「仕方ないな」は協力の仕方の調子であり、ずっと主人公を邪魔者扱いする性格には寄せない。先代との掛け合いと主人公を気に掛ける所作を、少ない台詞で作れる。上表の声・台詞・所作は今回の場面案で、全ての出演を決めたものではない。

## 7. 出会いから、店が帰る場所になるまで

次の段階に沿う来歴の方向への支持を受けた。暮らしを支える関係が先に始まり、主人公の意思で仕事へ関わる流れを基盤とする。各段階の台詞・小道具・正確な期間は案であり、ゲーム開始前に全て見せる必要はない。

| 段階 | 具体化案 | 保つ人物像・関係 |
|---|---|---|
| 1. 出会う前 | 最初の危機を自分の道具で脱出する。ほかにも道を教わる、助けを借りる、避けるべきものを覚える等の遭遇があってよい | 生来の力と自覚があり、全てに無知でも全てに慣れているわけでもない |
| 2. 話が届く | 昔の知り合いが「人の通らない道から子どもが出てくる」と先代へ伝える | 人脈が生きている。能力の後継者を探す依頼にはしない |
| 3. 町側で会う | 先代は子どもに残る不思議の気配を察し、短い会話から帰る先がないことを知る | 先代の見極める力はあるが、生い立ちを全て読めるわけではない |
| 4. 店へ迎える | まず食事と休める場所を用意する。主人公は多くを語らず、先代も急いで全てを聞かない | 保護と暮らしが先に始まる。仕事をすることを住む条件にしない |
| 5. 暮らしが続く | 通学の支度や食事、簡単な手伝いが日々のことになる。姿を見せない相棒にも慣れる | 身近な関係は少数のまま、帰ってよい場所ができる |
| 6. 力を知り合う | 先代が主人公の道具を見立て、主人公も先代が不思議を扱う様子を見る | 主人公の能力を先代が授ける筋にはしない。互いに得意なことが分かる |
| 7. 辿り屋の仕事に関わる | 店への相談を聞き、放っておけずに調べたことを持ち帰る。先代が聞き取りと報告、引き際や支度を教える | 主人公の意思と、仕事として続けられる足場を接続する |

最初に届く話の相手や、最初に関わる案件は固有名未定の素材。代表案件SCN-001の前日譚や冒頭へそのまま追加採用する指定ではない。幼い主人公の長期放浪や、身寄りを失った原因も未決定のまま残す。

### 7.1 短い出会いの場面案

> 先代「帰るところは」
>
> 主人公「……ない」
>
> 先代「そうか。飯は」
>
> 主人公は答えず、少しだけ目を逸らす。

長い身の上話よりも、日常の問いから暮らしが始まる案。主人公が全てを受け入れるまでの距離感や、先代の口調は後続で整える。

### 7.2 帰還道具と帰る場所

最初の道具は店を知る以前に成立している。最初は「その危機から外へ抜ける」働きで、店が帰る場所になった後に、そこへ戻る働きへ結び付いた、という方向で具体化を続ける。帰る場所ができる変化と能力の細かな機構を分け、初回の脱出先や同行者への適用は未決定とする。

変化を見せるなら、初めはどこへ戻ったかを気にしていた主人公が、ある時から店へ帰ることを当然と思っている、といった所作で表せる。帰還先が変わる演出と、現行の確実な帰還・成果精算は別に管理する。

## 8. 次の具体化と受け渡し

- 先代の力と相棒との分担、道と帰路を出発ごとに用意する負担は、支持された方向を維持する。能力の呼称・由来・細かな範囲、準備の具体物、相棒が旅を終えた事情は未選定。これらの詳細決定を次の探索内容の前提条件にしない。
- 相棒の普段の居方は採用方向に従い、声・気配の表し方と人の姿をビジュアル・シナリオへ渡す。敷居の存在という正体は候補に留める。
- 出会いの経緯は採用方向として進め、固有の知り合い、学校へ通い始める時期、最初の相談を必要な範囲で具体化する。

正式用語集1.2の着想は引き続き仮置き。渡航の説明から、追加資源、日数制限、先代同行のゲーム機能、帰還の追加料金や救援保証を導入しない。各担当への差分は[設定更新の連携事項](../../作業資料/世界観/設定更新の連携事項.md)で案内する。

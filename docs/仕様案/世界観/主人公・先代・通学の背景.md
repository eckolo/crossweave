# crossweave — 主人公・先代・通学の背景

版：0.2／2026-09-12。担当：世界観Work `20260910-worldbuilding`。

状態：採用された生活の骨格を基にした詳細案。1章のみユーザー判断の整理で、2章以降は未採用の第一案・比較材料。全案をゲーム内に登場させる予定表ではない。正本は[世界観設定1.8](../../確定仕様/世界観/世界観設定.md)、原文は[検討記録23・24章](../../作業資料/世界観/検討記録.md)。

## 1. 今回採用された骨格

- 主人公は小学校低学年程度。町歩きとお手伝い程度の店番はできるが、暮らしは大人に支えられる。
- 天涯孤独だった主人公を辿り屋の先代が拾った。初期の人間関係は広くせず、旅による世界の広がりを重視する。
- 拠点は先代の古道具屋＋預かり・取り次ぎ。経営者は先代、主人公は手伝う側。追加店員は必須ではない。
- 主人公は話せるが必要なことしか言わない。自分の能力の普段使いは分かるが、各異界や事件の真相は知らない。
- 先代の知識・経験が全て継承される必要はなく、不思議に対して他者の経験がどれだけ役立つかは柔軟に扱える。
- 通学しており、ゲーム上は生活の背景。表に出さない関連設定も用意する。具体的な不都合が出た場合には再検討の余地を残す。

- 最初の危機と脱出道具の成立は先代に拾われる前。拾われるまでの不思議との遭遇は複数回あってもよいが、回数・内容は未確定。
- 先代は人間以外も含みうる人脈を残し、辿り屋の探索業務の一線を退いた隠居。現在は店と主人公の暮らしを支える。

人に化けた不思議の手伝い役は、ユーザーが挙げた候補。存在・正体・人数は未採用。

## 2. 店と暮らしの第一案

店に続く住居で先代と暮らす。表には古道具の棚、奥には預かり物の棚と取り次ぎ用の帳面。居住側には主人公の寝床と学校用品を置く場所がある。二階建てか、奥に居室が続く平屋かはビジュアル側で比較できる。

| ID | 背景項目 | 詳細の第一案 |
|---|---|---|
| WB-LIFE-001 | 店と生活の責任 | 先代が仕入れ・値付け・会計・預かりの約束・生活費を担う。相談の金銭的な約束も先代が整理する |
| WB-LIFE-002 | 主人公の手伝い | 客を呼び入れる、先代を呼ぶ、軽い品を運ぶ、棚を拭く、簡単な伝言を預かる。難しい見積りや高価な品の売買判断は先代へ回す |
| WB-LIFE-003 | 一人の店番の範囲 | 先代が奥で作業する間などの短い留守番。分からない客には「待ってて」と言って呼びに行ける。学校中の店は先代が開けている |
| WB-LIFE-004 | 家での関係 | 先代は食事・衣服・通学の支度を支え、主人公は生活の小さな手伝いをする。拾われた恩を返すために働く関係を基本動機にしない |
| WB-LIFE-005 | 店の紹介の仕方 | 町では「古道具屋の子」として知られ、辿り屋の看板は店の一角にある。相談相手としての主人公を知る人の範囲は、普通の顔なじみより狭い |
| WB-LIFE-006 | 初期の人間関係 | 深い関係は先代を中心にする。先生・同級生・近所の人との浅い接点はある。天涯孤独という生い立ちを、現在も誰とも接点がない状態にはしない |

主人公が札から展開する道具を店の恒久商品にはしない。普通の古道具に混ざって、元々不思議な来歴を持つ品が預けられる余地はある。古道具屋の設定から、全ての案件を古い物の鑑定や修理へ寄せる必要はない。

### 2.1 先代の経験は、何を助けるか

先代は、話の聞き方、旅の支度、人や土地との付き合い方を教えられる。「前はこの橋を渡れた」「あの人なら話を聞く」という経験は手掛かりになるが、現在の通行、相手の態度、主人公との相性までは保証しない。

主人公には自分で確かめる余地を残す。先代が黙って正解を出し惜しみすることを、未知探索の常套的な理由にはしない。知っていることは話し、それが今回どこまで役立つかを現地で見極める。先代が探索の一線を退いていることは採用済み。現役時代の手段と隠居の理由は[先代の辿り方と主人公の単独探索](先代の辿り方と主人公の単独探索.md)で、付き合いと相棒・古道具・痕跡読みの三方向を比較する。

### 2.2 幼さと探索を両立させる案

先代は、相談の入口を整え、主人公が知っている手段や帰還の見通しを一緒に確かめる役を担う。主人公は、自分が辿れると感じた手掛かりや、放っておけない相手に対して進む意思を持つ。日々の食費を稼ぐため、難しい仕事を幼い主人公へ割り当てる構図には寄せない。

危険な旅に出られる能力と、幼い身体・生活上の未熟さは共存する。札の効果だけで学力や社会経験まで大人並みにはしない。先代は普段の探索業務から退いている。その具体的な理由と現在できる支援、主人公の帰還手段をどう信頼しているかは、上記の比較案と初期案件を合わせて具体化する。毎回無断で出掛けることや、大人の承認を取るゲーム操作はここから追加しない。

## 3. 学校生活の背景一式

舞台の町にある普通の小学校へ通う第一案。現実の特定自治体・制度へはまだ固定せず、学齢期の子が通学し、大人が暮らしと学校との連絡を支える生活を基準にする。正確な学年を選ぶ必要が出るまでは「低学年」を維持する。

| ID | 背景項目 | 詳細の第一案 |
|---|---|---|
| WB-LIFE-007 | 入学と保護者との連絡 | 現在の学校生活は落ち着いている。先代が学校との連絡窓口や提出物を担う。身寄りを失った事情・引き取る際の経緯は別の過去設定として残す |
| WB-LIFE-008 | 通学路 | 店から歩いて通える距離。朝夕に通る商店や角があり、主人公は普段の道を一人で辿れる。道順・距離・集団登校の有無は町の見取り図と合わせる |
| WB-LIFE-009 | 平日の生活 | 起床・朝食・登校、授業と昼食、下校、家で宿題や休息、短い手伝い、夕食と就寝。毎日必ず探索へ出る日課にはしない |
| WB-LIFE-010 | 読み書きと学習 | 年齢相応に学んでいる。難しい文字や長い文書は先代や現地の人に読んでもらう余地がある。印象を写す能力と文字の解読は同一にしない |
| WB-LIFE-011 | 授業中の様子 | 自分から長く発表することは少ないが、呼ばれれば短く答える。課題には取り組む。無口であることだけから全教科の苦手・優秀を決めない |
| WB-LIFE-012 | 得意さの候補 | 道順や小さな変化に気付く、実物を触ると理解しやすい。図工・観察・工作に表れる案。ただし満点の地図記憶や異界の自動看破にはしない |
| WB-LIFE-013 | 先生との関係 | 担任は寡黙さを普段の性格として知り、意思の確認を急かさず待つ。疲れや欠席が続けば先代に連絡する。事情の全てを知る必要はない |
| WB-LIFE-014 | 同級生との距離 | 名前を知る相手、隣の席、短く話す相手はいるが、初期の親密な友人集団は置かない。「静かな古道具屋の子」程度の印象。いじめや全面的孤立を必須の背景にしない |
| WB-LIFE-015 | 不思議の話 | 主人公は自分から詳しく語らない。友達から何をしたか聞かれたら「店の手伝い」「道を見てきた」と短く答えられる。強制的な秘密の誓いや他人の記憶消去は設けない |
| WB-LIFE-016 | 学校と能力 | 普段の用事は普通の道具で済ませる案。学校で能力が絶対使えない規則は設けず、必要な場面が出たら見られ方や影響を個別に考える |
| WB-LIFE-017 | 持ち物と居場所 | 通学用の鞄、教科書・ノート・筆記具、家の宿題用の場所がある。通学鞄を札の保管場所にはしない。制服・ランドセル等の具体形は見た目と合わせる |
| WB-LIFE-018 | 行事・休日・休み | 通常の行事や長い休みは背景に存在する。先代が必要な連絡に応じる。学校名、先生や同級生の固有名、行事ごとの本文は必要なものから付ける |

### 3.1 探索と通学の時間

**第一案は、短い用事は放課後、まとまった探索は休日や長い休みに入る生活を背景に置き、出発と帰還の間にゲームで描かない日常の時間を挟めるようにすること。** プレイヤーの連続した探索操作が、作中でも同じ夕方に連続しているとは限らない。

| 場面 | 背景での対応案 | 後続で確かめること |
|---|---|---|
| 店で相談を受ける | 帰宅後や休日。先代が先に受け、主人公へ伝えてもよい | 相談受付を出発即時の緊急事態へ毎回固定しない |
| 何度も帰還・再出発する | 間に普段の生活が続いている。ゲームは次の準備と出発を続けて見せられる | 「今夜中」等の期限が本文にある案件は、必要な往復を個別に点検 |
| 長い旅 | 休日等を使う案と、その異界固有の時間の進み方を使う案を比較できる | 全異界共通の時間停止・時間差にはまだ決めない |
| 帰還が遅れる・消耗する | 先代が帰りを待つ。学校への連絡や休息は生活の出来事として扱う | 欠席が繰り返されても誰も気にしない状態にしない |

通学の背景から出発回数、日数、門限、宿題、登校の操作やペナルティを新設しない。逆に、全探索が必ず夕食までに終わるとも断言しない。世界ごとの時間差と、場面を省略する語り方は別の選択である。

### 3.2 表に出す量は少なくても、世界の広がりを感じられる

具体例はいずれもシナリオ素材案。

- 旅に出る前は、学校で聞かれても「別に」と答えていた。後には、旅先の食べ物を思い出して「……似てるの、食べた」と一言だけ足す。
- 普段は伝言を先代へ渡すだけだったが、以前に会った依頼人には自分から椅子を出す。
- 異界で見た橋をノートの端に描く。図は主人公の見た範囲で、世界の完全な地図にはならない。

旅の成長を、急に饒舌になることや学校に友人を大量追加することだけで表さない。短い言葉や、誰を気に掛けるかの変化で扱える。学校の出来事を全て異界への伏線にする必要もない。

## 4. 不思議の手伝い役を加える場合の比較案

先代と主人公だけで基本の生活が成立した後に加えられる。名前・性別・外見・能力はまだ採用しない。

| 案 | 店での役割と、不思議の現れ方 | 世界に加わる広がり |
|---|---|---|
| 人の姿を借りた古い雨傘 | 雨の日に店を手伝い、濡れた預かり物の世話をする。主人公が作った道具ではなく、以前から存在する不思議 | 天候によって訪ねてくる、近所に住むような不思議 |
| 取り次ぎを手伝う異界の旅人 | 普段は人に見える姿で伝言や荷物を扱い、ときどき自分の世界へ帰る | 拠点から見た来訪者にも、こちらに見せない生活がある |
| 帳面の余白から現れる店員 | 預かり物の整理を手伝うが、帳面に書かれていない事情は本人も知らない | 物語や記録から生じた存在との日常的な共生 |

旅を広く保つなら、第二案は古道具に由来を寄せず、往来の一例を拠点に置ける。第一案は一人増えるだけで暮らしの景色が変わる。第三案は預かり・取り次ぎと結びつくが、万能の照会役にしない工夫が要る。どれも主人公の札化能力を共有せず、同業組織の代表にも自動設定しない。

## 5. 次に詰めると効果が大きい点

1. **先代の現役時代の手段と隠居の理由。** 隠居自体は採用済み。[専用比較](先代の辿り方と主人公の単独探索.md)の三案から、単独探索と現在の支援へつながる手段を詰める。
2. **拾われた具体的な経緯と、当時の脱出先。** 最初の危機が拾われる前という順序は確定。引退と出会いの前後関係、脱出道具が今の帰還先へ結び付く過程は案として比較する。
3. **通常の相談が主人公まで届く短い一場面。** 先代が受け、主人公が関わる形を基本例として、主人公へ直接頼む例と比較する。

学校の背景は本書で一通り仮組みした。学校名・全時間割・同級生名簿の完成を次の探索内容作成の条件にはしない。個別の場面・人物の本文はシナリオWork、姿と空間の比較はビジュアルWorkへ、本書の採用区分とともに接続する。

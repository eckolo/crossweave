## 1. 今回の検討で保つこと

異界では普通でも写せる。深く、多面的に関わることで自分のものとして写し取れる。ぱっと見だけの不思議が触れることで薄れる場合、大きな効果の道具にはなりづらい。道具の形は作用と印象に沿い、個別の余地を残す。場・捨て場には不思議そのものがあり、札として表示することを許容する。

この前提から、以下の二つを説明上分ける案にする。

- 関わるほど、不思議の手応えや違う面が見える。親しむこと・仕組みや手順を知ることが、そのまま力の減少にはならない。
- 関わってみると、初めに感じた不思議がほどける。たとえば夜道の白い影が単に干された布だと分かる場合、最初の驚きだけから大きな力が生まれるとはしない。ただし必ず写せない、効果がゼロとまでは定めない。

「未知であるほど強い」「同じ操作を反復すれば強くなる」という能力にはしない読み方が合う。深まりを札の強さ・扱いやすさ・道具の違いのどこへ表すかは個別に検討し、一律の数値換算や修飾獲得条件はまだ設けない。元の存在の全貌を説明し尽くすことも、写す条件にはしない。

### 底抜け

**出会い：** 降りるほど、足場の下へ重さが抜ける乾いた深海。最初は足を取られる怖さとして出会う。

**関わりの深まり：** 荷を持って通る、現地の者の歩き方を見る、沈みかけた物を引き上げるなど、違う側から同じ深さへ関わる。落ちる力だけでなく、どこで支えが抜け、どこへ重さが渡るのかが身体の印象として残る。

**写す作用と印象：** 深さへ重さを預ける働き／足元が抜ける感触。

**道具化：** 錘付きの糸巻き。既存案の「下へ重さが抜ける」作用へ、沈み方を手元で辿る印象を重ねる。

**場への接続案：** 場へ放つのは重さの抜ける不思議。他者は足場や姿勢へ働きかける機会として使える。

<a id="wb-copy-002"></a>

### 反照

**出会い：** 硝子の草原で、獣より先を歩く像を見る。最初は光のいたずらにも見える。

**関わりの深まり：** 見る角度を変え、像を追って迷い、今度はその先回りを利用して獣と距離を取る。見破って消える錯覚ではなく、本体と居場所がずれる働きが、怖さと頼もしさの両方から残る。

**写す作用と印象：** 居場所の輪郭をずらす働き／追っても重ならない像。

**道具化：** 裏表のある手鏡。像と本体の距離を鏡を返す所作へ写す。

**場への接続案：** 放たれた反射は相手も隠れるために使える。主人公の鏡を勝手に操作した描写を必須にしない。

<a id="wb-copy-003"></a>

### 帰り際の温度

**出会い：** 古い給湯室に、誰かのために温かいまま置かれた一杯がある。

**関わりの深まり：** 自分が迎えられた後、別の帰ってくる相手を待つ側にもなる。温め直したからではなく、待つ時間が冷めずに残る働きへ触れる。事情を聞いて理解しても、その温もりの不思議は薄れない。

**写す作用と印象：** 待つ間の温度が残る働き／帰ってよい場所の温かさ。

**道具化：** 一杯をかき混ぜる匙。大きな異変でなくても、関わりによって確かな印象が残る例。

**場への接続案：** 他者へ巡るのは温もりの働き。回復として使う際も全員に自動付与せず、札の使用者・対象・消費を守る。

<a id="wb-copy-004"></a>

### 遠雷

**出会い：** 鋳造所で、振り下ろした後から重い雷鳴が届く。現地では日々の仕事の一部。

**関わりの深まり：** 音を聞くだけでなく、材料を支え、出来た品へ触れ、音の届かない工程と比べる。職人から手順を教わっても、遅れた響きが物の奥へ届く不思議は残り、道具としての手応えになる。

**写す作用と印象：** 後から奥へ届く響き／待った後に来る一撃。

**道具化：** 鐘を打つ短い槌。技術として知られていることと、主人公が不思議を写せることが両立する例。

**場への接続案：** 響きが他の働きへ重なる案。遅れはまず描写で扱い、遅延ダメージ等の新処理を足さない。

<a id="wb-copy-005"></a>

### 宛先のない矢印

**出会い：** 未着の港で、宛先をなくしても届こうとし続ける手紙に関わる。

**関わりの深まり：** 断片を追い、待つ者の話を聞き、誤った宛先にも辿り着く。正しい場所を一度に示す力ではなく、手掛かりから次の関わりへ向かう働きを、自分が届けようとする体験を通じて写す。

**写す作用と印象：** 届く方向を探す働き／まだ誰かへ続いている感覚。

**道具化：** 文字盤の空いた方位磁針。元の物が手紙でも、印象と作用に沿って別種の道具になる例。

**場への接続案：** 場に放たれた方向づけは別の主体も利用できる。未訪問先の真相・報酬を自動で知る力にはしない。

<a id="wb-copy-006"></a>

### 子守の余韻

**出会い：** 歌い終わった後も、肩を包むような安心が残る盆地。

**関わりの深まり：** 自分が休む側になり、次には眠れない相手のそばに居る。歌い手の呼吸や、歌が止んだ後の静けさにも触れる。歌詞を覚えるだけでは得られない、包まれる働きの印象が残る。

**写す作用と印象：** 声の後にも続く安心／肩を包まれる感触。

**道具化：** 声の染みた襟巻き。音そのものを鳴らす楽器だけが道具化の答えではない例。

**場への接続案：** 放たれた余韻を他者が休息に使う案。歌い手本人を取り込まず、歌の権利や土地の問題も札一枚では解決しない。

## 3. 一巡をどう読めるか

「手元の札から道具の不思議を放つ → 場の働きに結び付けて行動する、または場に留まる → 使う・手放すことで捨て場の側へ巡る → 回収で次の手段に入る」という説明案。

一致しない設置では主効果はまだ起きない。一致時は主効果と材料の場の効果を合わせて扱い、通常は両方が捨て場へ移る。不思議を放つことと、その主効果が解決する時点を区別する。

具体例として反照の不思議を主人公が場へ放ったなら、相手はその反射を自分の動きへ利用できる。その際に主人公の実物の鏡を借りたり、札を道具へ展開する能力を得たりした描写は要らない。既存の「主人公の意思が必要な道具貸与」との切り分けとして、この説明を提案する。

捨て場は今すぐ一致に使える場とは違い、一度使ったり手放したりした不思議が再び巡りうる側として表す。回収は現地の循環であり、恒久的な取り込みではない。見せ方は従来の札で足り、場に物理的なカードが散乱する設定も、新しい粒子表示も必須にしない。

## 4. 検討結果と次の焦点

6案とも、元の作用だけでなく、主人公が何を経験したかを加えることで道具の形へ接続できる。底抜け・遠雷の大きな力だけでなく、温もりや歌のような静かな不思議にも具体的な関わりを置ける。大きく派手な現象ほど上位、日常に近いものほど下位という序列は不要。

着想は、こうした探索を今後の心得へ生かすゲーム表現として扱えばよく、上の体験を一つずつ点数へ換算する設定は必要ない。救出については、相手を見つけた後も通常の経路で連れて帰る方向を維持する。

次の主題は、**相談が店へ届く経路と、主人公や他の者が異界へ入って帰る条件**。写しの基本像を使い、深部へ進む理由・帰路・再訪へ接続する。道具貸与と放たれた不思議の利用、山札の短い説明は今回の提案として保存し、全ての個別効果へ一対一の物理説明を完成させることを進行条件にしない。

## 1. 今回の第一案

**古道具屋へ普通の相談が届き、先代から続くつながりや不思議な伝言もそこへ混じる。主人公は、不思議が作るつながりを道として辿り、自分の足で異界へ渡れる。**

店は暮らしと相談の足場。入口は町のあちこちや旅先にもあり、店の中から全世界へ直通する一つの施設に固定しない。主人公の渡り方は、札化・道具化と並ぶ不思議との関わり方として提案する。毎回、渡航用の札を取得してから出発する条件にはしない。

背景設定として共通に持ち、相談の聞き取り・入口への移動・帰路の全てを毎回の操作にする必要はない。見せたい場面や判断に関わる箇所だけを本文や探索へ出せる。

## 2. 相談が届く経路

以下は共存できる案。第一案は001・002を日常の土台、003・004を先代のつながり、005・006を世界の広がりとして混ぜる。

| ID | 経路案 | 届く内容の例 | 活かせること |
|---|---|---|---|
| WB-ROUTE-001 | 店の看板・近所の紹介 | 「夜になると、家の廊下が長くなる」。何の不思議かは分からないまま相談に来る | 辿り屋の名前は知るが仕事の実態は知らない一般人が頼れる |
| WB-ROUTE-002 | 古道具の預かり・取り次ぎ | 売りたい箱の中から、持ち主の知らない場所の音がする | 店の本来の仕事から案件が生まれる。全ての預かり品を不思議にはしない |
| WB-ROUTE-003 | 先代の旧知からの口伝 | 昔の旅先の知人が、途絶えた道の向こうを確かめてほしいと言う | 先代の現役時代が現在の仕事につながる。知人も現状の真相は知らない |
| WB-ROUTE-004 | 異界側の使い・不思議な伝言 | 閉じた預かり品の中へ返事が加わる、昔の預かり証を持った使いが来る | 店の預かり・取り次ぎを不思議の側へ広げる。経路は相手や品ごとに異なる |
| WB-ROUTE-005 | 以前の依頼人・旅先の顔なじみ | 解決した土地の住人が、別の困りごとを紹介する | 同じ土地が案件後も続き、知り合いが新しい旅へつながる |
| WB-ROUTE-006 | 主人公が日常や旅先で関わる | 帰り道に、来たはずの道へ戻れない人と出会う | 困った相手を見捨てられない主人公が、自分の意思で仕事へ入る |

不思議な伝言にも、依頼人の知る範囲・勘違い・伝え損ねがある。書かれた症状から入口を探せても、深部の真相や得られる札まであらかじめ分かる必要はない。

### 店で誰が受けるか

普通の客には、まず先代がいる古道具屋として相談してもらえる。主人公が聞いた相談や拾った手掛かりは、店へ持ち帰って一緒に考えられる。先代は品の見立て、昔の知人への取り次ぎ、依頼人との連絡を担い、主人公は現地で辿る役を担う。

店を支える日常の料金・謝礼は、必要なら普通のお金や品で扱う。異界の相手なら、現地の宿、案内、修繕や後日の助力が返礼でもよい。これは生業の背景案で、着想を現実の貨幣と同一にせず、新しい取引システムや全依頼共通の料金表も要求しない。幼い主人公が一人で契約や店の経営を処理する場面を前提にしない。

## 3. 入口を知ること、渡ること、探索できること

三つは別の得意分野として扱う案にする。

| 立場 | 入口への関わり | 渡った後と、帰り道 |
|---|---|---|
| 一般の人 | 開いている道に迷い込む、知っている入口を使う、案内されて渡ることがある | 一度入れたことと、未知の場所を進んで帰れることは別 |
| 先代 | 物・場所の関わりを読み、入口や関係先の見当をつけられる | 不思議への対処は熟練しているが、現在の長い渡航は道と帰路の準備が重い |
| 主人公 | 人には道と気づきにくい不思議のつながりを辿り、自分の足で渡れる第一案 | 現地で手段を写しながら進める。どこへ通じるか、何が起きているかは探索して知る |
| 異界の住人・旅人 | 生活圏の渡り方や、仕事で使う道を知っている場合がある | 馴染んだ道の往来と、未知の異界を探索する能力は同じではない |

一般の人を完全に不思議から締め出さず、迷い込みや相談の発生を保つ。同時に、入口が開けば誰でも全ての探索をできるとはしない。主人公の専門性は渡航・現地での対処・帰還を続けられることに置く。

### 主人公の渡り方の比較

| 比較ID | 仕組みの案 | 良い点・検討点 |
|---|---|---|
| WB-CROSS-001 | 既にある不思議のつながりを、進める道として辿れる | 今回の第一案。初めての場所へ入れること、生来の遭遇、辿り屋の職業名に合う。既存のつながりを見つける過程を描ける |
| WB-CROSS-002 | 関わった品や相手との縁を足場に、境目を渡る | 古道具や手紙から旅へ入る場面に合う。縁づくりを毎回の必須イベントにすると出発が重くなるので、個別の道の性質として併用しやすい |
| WB-CROSS-003 | 道や住人に迎え入れられやすく、通れるようになる | 童話的な親しさを出せる。一律の仕組みにすると道の好意次第に見えやすいため、土地ごとの反応に使う候補 |

001を土台に、002・003を個々の入口へ使うことを勧める。主人公の能力で新しい世界や目的地への道を自在に作る設定までは置かない。つながりがどこへ続くかを辿るため、未知の探索と両立する。

先代が「箱に離れた場所からの気配がある」と見立て、主人公はその箱に落ちる影の続きへ踏み込める、といった場面が一例。先代が無力なのでも、主人公が事件の全容を見通すのでもない。個別の入口と所作は未採用の例である。

## 4. 道のあり方にも幅を持たせる

| 道の型の案 | 具体像 | 世界に生まれるもの |
|---|---|---|
| 日常に接した裏口 | 忘れ物窓口の向こう、使われなくなった階段、店の奥 | 暮らしのすぐ脇に旅の入口がある |
| 往来を支える道 | 土地の者が手入れする渡り場、便局の使いが通る経路 | 地域に限った交易・案内・仕事が育つ |
| 現象に伴う道 | 干潮時の井戸、特定の雨でだけ続く路地 | 土地の周期や不思議の性質が旅に関わる |
| 品や相手を介す道 | 元の場所へつながる預かり物、差出人との間を行き来する伝言 | 遠く離れた土地の関係が店へ届く |
| 一時的・途絶えかけた道 | 偶然つながった帰り道、前と違う場所へ出る通路 | 迷い込み、道の調査、再訪時の変化が生まれる |

同じ世界にも複数の入口があってよく、一つの入口がいつも同じ条件で開く必要もない。案件の途中で異界をまたぐ場合も、境目を越えただけで回復・精算しない現行仕様を保つ。

入口の時刻や干潮は、物語内の出発条件・場面の特徴として扱える。実時間で待つ操作、日数制限、出発費へ直結させない。通学を含む生活と探索の間は省略でき、全異界共通の時間停止で辻褄を合わせる必要はない。

## 5. 普通に帰ることと緊急脱出

通常の帰還では、戻れるつながりを確かめ、持ち帰れる分を伴って戻るという説明を基盤にする。現在の任意帰還・精算は維持し、毎回歩いて逆走する区間や帰還用札を要求しない。帰路の支度と移動は背景として省略できる。

緊急脱出は既存の専用道具による危機からの離脱で、今回の成果を失う。最初の成立は拾われる前であり、初回の脱出先と今の店への帰還の具体的な結び付けは引き続き未決定。通常帰還を描くために、緊急脱出道具の全機構を先に決める必要はない。

### 救出案件の場合

救出では、相手が帰れるところまで含めて目的を立てる。目的地は必ず主人公の町でなくてもよく、相手の暮らす土地や安全に引き継げる場所でもよい。

- 深部で相手を見つけ、相手も通れる道を整えてから一緒に帰る。
- 往路の障害を解いたことが帰路にも役立ち、帰還の場面は短くまとめる。
- 帰路そのものが案件の中心なら、そこで道具や現地の協力を生かす。

これらは内容の候補であり、全救出案件への護衛フェーズ追加ではない。主人公だけが緊急脱出したことを救出完了とせず、相手のその後・再救出条件・同行の処理は個別に扱う。

一度の依頼で世界の全てを説明せず、窓口・現地の人・解決後のつながりを少しずつ増やせる。複数回使った不思議が帰還後に札として得られる過程は背景で成立し、この一往復に全札の専用習得場面を挟む必要はない。

## 7. 現時点で選ぶ部分と後へ残せる部分

まず比較したいのは、**普通の窓口へ不思議な相談が混じる店**と、**既にあるつながりを道として辿れる主人公**という組合せ。採用済みの店・人脈・幼い主人公と、未知の踏破へ向かう仕事をつなげる第一案である。

店名、看板の文言、固有の受付道具、渡航能力の名称、全異界共通の言語・時間の法則は今の必須決定にしない。言葉や時間差が個別案件の主題になるとき、その土地に必要な分だけ具体化できる。

この方向が定まれば、次はDBの人物・品・依頼のつながりを増やし、同じ住人が別の立場で再登場する、店へ預かり物が一つ増える、主人公から顔なじみに声を掛ける等の、旅が日常に残る変化へ進める。

# crossweave — 背景断片

版：0.1／2026-09-10。状態：[世界観の決定稿](../../確定仕様/世界観/世界観設定.md)に加えられる案。以下の細部は未採用。

ユーザーの「まとまり無くて良いので出しておいて」に応じた、今後の人物・場所・案件へ使える断片。全てを同時に世界共通の法則へする必要はない。

## 日常の側

- 調査の窓口は、普通の修理業者が「自分の仕事ではなかった」と判断したときに紹介されることがある。同じ相談でも、最初の書類では漏水、鍵の不具合、行方不明の備品と書かれている。
- 町には、普通の商売と越境者相手の仕事を兼ねる人がいる。靴の修理、地図の綴じ直し、旅先で拾った文字の読み取りなど、道具化能力がなくても必要とされる技能がある。
- 不思議を知る人も、自分が使う入口以外には詳しくない。古書店主が宿の裏廊下を知っていても、河川敷の入口については主人公に相談することがある。
- 相談者が最初に望むのは原因の全解明とは限らない。「この部屋をまた使えるようにしたい」「雨の日に店を閉めずに済ませたい」という生活の要求が、調査の始点になる。
- 事務所には、仕事用の地図と個人的に気になった場所の地図が重なっている。旅先からの礼状や使い道の分からない土産が、帰る場所の風景を少しずつ変える。

## 旅の痕跡

- 境目を知る旅人が残した印には、正式な道標だけでなく、戸口の傷や石の積み方もある。風化や誤読があり、印を見つけただけで安全が保証されるものではない。
- 途絶えた道の向こうでも暮らしは続いていた。こちらでは廃駅でも、向こうでは待ち合わせ場所として覚えられている、といった認識のずれがある。
- 渡り場には、行先ではなく「帰ってきた人が何を持っていたか」で呼ばれる出口がある。潮の匂い、白い砂、長持ちする花などが、未訪問の土地を知る手掛かりになる。
- 古い宿の帳簿には、住所欄へ地名以外の目印を書いた客がいる。「三度目の朝に開く坂の上」など。入口の条件は地域ごとの手掛かりにでき、世界全体の普遍法則にする必要はない。
- 交通の回復には利益と困り事の両方がある。商いが戻る一方、静かな場所へ人が増える。通れるようにした後、誰がその道を手入れするかも新しい関係になる。

## 異界の暮らしと仕事

- 夢の街でも、住人は毎日の仕事や約束を持つ。外から来た主人公には奇妙でも、住人にとって大事なのは店の開店時間や隣人との関係だったりする。
- 物語に沿って起きる現象でも、住人がその役を望むとは限らない。終幕を止めたい人と、終わらせたい人がいる案件を作れる。全ての物語世界で同じ役割強制を用いる必要はない。
- 巨獣の背の住人には、土地の揺れを読み分ける生活の知恵がある。主人公が持つ探索術と、住人が長年培った知識が、それぞれ調査に役立つ。
- 遺構は当時の目的のまま使われているとは限らない。古い観測設備が物干し場になり、用途不明の通路が子どもの近道になっている。現在の生活を調べると、過去の機能にたどり着くこともある。
- 対価は旅先によって物品、宿泊、案内、記録の提供などを含められる。共通のゲーム報酬を全世界共通の通貨へ直結させず、具体的な経済制度は必要な案件で定められる。

## 不思議と道具

- 道具の形には、見出した働きと主人公の理解が現れる。「道を隔てる」という不思議が、巨大な壁の複製ではなく、持ち運べる盾や留め具として形になる、といった縮約ができる。無制限な任意変換を保証する規則ではない。
- 取り込みを、必ず元の世界や存在を食い尽くす行為にする必要はない。働きを受け取る、残ったものを拾う、相手から分けてもらうなど、関係によって描き方を変える余地がある。対象への影響は個別に検討する。
- 同じ働きの道具でも、由来の違いが外見や音に残る。潮の流れから得た道具と、芝居の退場から得た道具が、どちらも何かを遠ざける用途を持つ、といった共通性を作れる。
- 持ち帰った知識と、次の探索で安定して用意できる道具は別の成果になる。「何が起きたかは覚えているが、再現する準備はまだない」という経験を描ける。
- 異変を直しても、不思議まで消し去る必要はない。漏水が止まった地下には潮の音がわずかに残り、宿の裏廊下は事情を知る旅人が使い続ける、といった余韻が残せる。

翻訳の万能能力、どこでも使える帰還術、固定の時間差、死亡を必ず救出へ読み替える制度などは、この断片から自動追加しない。これらは探索や失敗の意味を大きく変えるため、必要になった時点で具体化する。

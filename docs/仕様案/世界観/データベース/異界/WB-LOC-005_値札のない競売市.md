# 値札のない競売市

品物に値札がなく、手放すものを互いに宣言して取引する街。

## 具体像

一晩の宿と知らない道の情報が交換される。所有者が曖昧な物ほど大きな声で呼び込みをする。入口は閉店後にも会計を待っている店。

## 活かし方・接続案

主人公の帰路が競売に出ている。市場の全員を敵にせず、売り手の権利と落札された経緯を地下の保管帳で確かめる。

# 未着の港

届かなかった手紙が船になり、宛先を待つ港。

## 具体像

停泊船には届かなかった理由ごとに違う住人が生まれる。配達が彼らの消滅を意味するとは限らず、航路を得ることもある。入口は差出人へ戻った封筒。

## 活かし方・接続案

受取人が配達を望まない便が、勝手に出港を始める。灯台の奥で手紙に付け足された宛先を調べる。

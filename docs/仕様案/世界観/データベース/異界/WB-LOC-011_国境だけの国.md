# 国境だけの国

隣国との境目だけが連なり、国の内側へ入れない土地。

## 具体像

検問所の間に学校と市場が育ち、住人は複数の入国印を持って暮らす。争いもあるが通訳や仲介を生業にする人も多い。入口は住所の境界線上にある家。

## 活かし方・接続案

迷子を連れ帰るには、誰の国へ帰すかを先に決められない。複数の門を辿り、本人が暮らしていた場所の関係を調べる。

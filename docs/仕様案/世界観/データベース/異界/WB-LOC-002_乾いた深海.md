# 乾いた深海

水のない海底で、海だった頃の水圧だけが残っている。

## 具体像

魚は空気の中を泳ぎ、沈船が崖に突き刺さる。住人は浮標の高さで住所を示す。干潮時だけ、町の井戸の底から入れる。

## 活かし方・接続案

深いほど圧が増すが、上へ行くほど帰り道が安定するとは限らない。海底から聞こえる救難信号の発信場所を探る。

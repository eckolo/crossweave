# 残響の盆地

声の余韻を畑に蒔き、季節をかけて育てる盆地。

## 具体像

住人は食糧と同じように笑い声や子守歌を蓄える。大声が豊作とは限らず、休ませる畑も必要。入口は何年も前の声が残る山彦。

## 活かし方・接続案

売られた子守歌は買い手を眠らせる一方、歌った家から休息を奪う。発生源を消す前に、歌の育ち方と利用の取り決めを谷底の音蔵で調べる。

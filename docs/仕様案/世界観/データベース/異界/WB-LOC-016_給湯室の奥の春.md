# 給湯室の奥の春

使われなくなった給湯室の奥に、持ち寄りの庭と小さな春がある。

## 具体像

元の職場の人だけでなく、建物を知らない旅人も茶を飲みに来る。新しい住人が来れば家具も増える。入口は冷めない一杯分のお湯。

## 活かし方・接続案

建物の改装が決まり、庭の水源が途絶えそうになる。奥の根元まで辿って接続先を確かめ、誰が世話を続けるかを相談する。

# 赤錆の冬眠都市

巨大な保守機構と街が交代で冬眠し、わずかな熱を分け合う都市。

## 具体像

錆は劣化だけでなく眠りを守る膜にもなる。起きている地区の住人が、眠る地区の郵便と家の手入れを預かる。入口は真夏にも冷たい排熱口。

## 活かし方・接続案

全市を一度に起こす熱はない。急いで救う地区と保守機構への経路を調べ、誰を起こすか判断できる情報を持ち帰る。

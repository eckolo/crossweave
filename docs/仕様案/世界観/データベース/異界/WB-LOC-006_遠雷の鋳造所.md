# 遠雷の鋳造所

遠くで鳴る雷を型へ流し込み、道具や橋材を鋳造する巨大工場。

## 具体像

炉は冷えているが、鋳型に近づくほど轟音が重くなる。現地の職人は金属の色より鳴り方を検査する。入口は雷の日だけ鳴る廃工場の作業鐘。

## 活かし方・接続案

失われた音型が日常の機械へ誤って流れ込んでいる。奥の調律架でどの音が混ざったかを探し、稼働する区画を選んで通る。

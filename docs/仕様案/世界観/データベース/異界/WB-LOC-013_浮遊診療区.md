# 浮遊診療区

重力を取り除くことで傷を休ませる、空中の診療区。

## 具体像

担架が廊下を漂い、庭は患者の呼吸に合わせて揺れる。装置の意味を知らず使い続けている人もいる。入口は取り壊された病院の案内板。

## 活かし方・接続案

退院許可の出ない患者を巡り、救命と拘束の境が揺れる。中枢へ進んで判断条件を調べ、身体を支える機能を残して帰路を作る。

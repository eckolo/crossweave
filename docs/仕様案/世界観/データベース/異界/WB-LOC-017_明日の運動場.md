# 明日の運動場

まだ誰も走っていない競走路に、明日走るはずの足跡がうっすら浮かぶ運動場。

## 具体像

白線は丘を越えて立ち上がり、走者の影が観客席を駆ける。足跡は確定した未来ではなく、遊び手の期待によって食い違う。入口は学校に限らず、公園で遊び終えた後の白線の続きにも現れる。主人公の通う学校そのものとは決めない。

## 活かし方・接続案

普通に遊びや競走が行われる場所として成立する。探索の仕事なら、まだ誰も完走していない新しいコースの行き先を確かめる。相手が強い、足場が変わる、道を読む必要があることで奥への手応えを作れる。晴れやかな勝負や負けた悔しさを主題にでき、事故や悲劇を開催理由にしなくてよい。未来予測表示や専用レース機能は別途の採否とする。

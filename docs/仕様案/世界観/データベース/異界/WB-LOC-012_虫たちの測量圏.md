# 虫たちの測量圏

測量する虫の群れが、物の長さを日々測り直している領域。

## 具体像

測り違いが積もると椅子の脚や道の幅が変わる。群れは悪意なく帳尻を合わせ、住人は定規を共同で保管する。入口は昨日と寸法が違う引き出し。

## 活かし方・接続案

町の橋が毎晩少しずつ短くなる。巣の基準尺まで進み、単位の変更と女王の誤測を区別する。

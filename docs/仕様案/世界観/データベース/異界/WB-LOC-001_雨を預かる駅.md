# 雨を預かる駅

降り切らなかった雨が、荷物として集まる駅。

## 具体像

雲を詰めた貨車を雨番が各地へ送り出す。乗客用の時刻表より、作物や屋根の都合が優先される。入口は日常の駅の忘れ物窓口。

## 活かし方・接続案

奥の集水塔を調べれば、町に降る潮混じりの雨が誤配か自然な混入かを確かめられる。駅の停止は旱魃を招くので、全設備の破壊では片付かない。

# 絵具の雨林

色が栄養として循環し、塗り重ねられた地層に森が育つ。

## 具体像

赤い実を食べた鳥が夕焼けを落とす。白は無ではなく、色を休ませる季節の一つ。入口は描きかけの絵の乾かない部分。

## 活かし方・接続案

村の色が失われても、単純な敵の吸収とは限らない。奥の白い沼で休眠と略奪を見分け、どの色を戻すかを住人と考える。

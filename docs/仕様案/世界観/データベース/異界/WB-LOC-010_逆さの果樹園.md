# 逆さの果樹園

果実が熟すほど軽くなり、根の方が空へ伸びる果樹園。

## 具体像

収穫期には畑の上下が入れ替わる。住人の家は天井にも玄関がある。入口は地下室で天井まで伸びた一本の芽。

## 活かし方・接続案

通常の上下交代が町の建物へ広がった。中央樹の根を調べ、成長の異常か収穫の取り残しかを確かめる。

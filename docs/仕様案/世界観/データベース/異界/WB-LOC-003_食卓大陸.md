# 食卓大陸

誰かの食卓ほどの大陸に、麦畑と配膳のための街道がある。

## 具体像

山は焼き立てのパン、川は日によってスープになるが、住人には家も畑も生活の土地。彼ら自身が食べ物とは限らない。入口は人数の合わない夕食の空席。

## 活かし方・接続案

次の配膳で集落ごと皿へ移される。食卓を止めるのか、配膳経路を変えるのか、住人と奥の給仕機構を調べて判断する。

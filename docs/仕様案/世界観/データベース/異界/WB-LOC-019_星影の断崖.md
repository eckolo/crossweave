# 星影の断崖

空の星が崖へ影を落とし、見える星と影の数が一致しない土地。

## 具体像

断崖には古い観測台が点在し、地平線の下にあるはずの星の影も岩壁を横切る。何を遮って影ができるのかは分からない。晴れた晩に座って眺めるだけの訪問もあり、観測台の全てを修理して回る必要はない。

## 活かし方・接続案

深部の別角度から見なければ区別できない重なりが、踏破の目標になる。世界の起源を解くことと、一つの影の動きを記録できることを分ける。観測が進んでも説明し切れない範囲を残せる。昼夜は場面の条件として使え、実時間待機や全異界共通の天文法則にはしない。

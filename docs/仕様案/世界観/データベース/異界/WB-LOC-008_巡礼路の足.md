# 巡礼路の足

巡礼者が歩くほど、道そのものも別の土地へ歩いていく。

## 具体像

道端の宿は地面へ杭を打たず、歩幅に合わせて脚を折り畳む。目的地は神殿だけでなく、会いたい人の家でもよい。入口は履き潰した靴が向く小径。

## 活かし方・接続案

道が止まると住人は休めるが、次の水場へ届かない。中心にある里程骨を見に行き、休止と再開を両立できる場所を確かめる。

# 硝子の草原

草も獣の角も透明な高原。実体と反射像の距離が一致しない。

## 具体像

風が草を撫でるたび遠くの景色が近くへ映る。住人は光沢を落とした服で歩き、足跡の曇りを道として読む。入口は割れていない窓の欠片。

## 活かし方・接続案

獣を退けるだけでは反射した通路が残る。高い探査で実体を確かめる区間と、見つけた乾いた足場を突破する区間を組み合わせる。

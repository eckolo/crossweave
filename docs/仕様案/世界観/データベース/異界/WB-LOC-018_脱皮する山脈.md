# 脱皮する山脈

山肌が古い皮のように剥がれ、その内側に次の谷が育っている山脈。

## 具体像

岩盤の裂け目に白い柔らかな地面があり、剥がれた峰の殻が空洞の橋になる。ここを巨大な一匹の生き物と見る者も、土地そのものの更新と見る者もいる。住人の町や管理人がいなくても成り立つ景色である。

## 活かし方・接続案

新しい谷が何へ続くか、古い道がどこまで残るかを確かめる踏査が成立する。脱皮は故障ではなく、主人公が止めるべき事件とも限らない。まだ見られていない景色への関心と、進路を確かめる仕事を同居させる。鱗状の殻・風・圧・足場の感触から不思議を写せるが、各道具へ専用の採集場面を要求しない。

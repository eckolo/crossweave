# 風下へ祈る石

風下側にだけ淡い灯がともり、願いを書く面も答えを受け取る穴もない石。

## 具体像

掌を近づけると風の冷たさが少し和らぐ。旅人は灯を道標にし、住人はその傍らへ座って祈る。同じ石の前で誰かが喜び、誰かが黙り、別の誰かは通り過ぎる。

## 活かし方・接続案

用途を一つへ固定しない物として、祭礼・休息・風の観測へ使える。祈りの正解を当てる鍵や供物を払う自動販売機にしなくてよい。神秘の有無と、住人が大切にする理由の全てを一つの効果へ還元しない。回復地点や祈願報酬の実装は未採用。

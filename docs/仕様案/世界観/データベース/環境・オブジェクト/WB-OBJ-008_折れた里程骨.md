# 折れた里程骨

歩く道の中心に埋まった、距離の目盛りを持つ骨。

## 具体像

動物の骨か、昔の測量具かは分からない。折れ目に草が生え、その場所だけは道が休める。

## 活かし方・接続案

壊れたものを直せば正解とは限らない調査対象。休止を望む住人の理由と移動の必要を比較する。

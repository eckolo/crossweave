# 勝者のいない表彰台

競技が終わる前から立っているのに、勝った者が乗ると次の競技の方を向く表彰台。

## 具体像

一番高い段にはいつも違う方角から風が吹く。勝者を拒むのではなく、競い終えた先にも遊びがあることを示すように、次の道の白線が見える。称賛を受けて降りることも、その方向へ進むこともできる。

## 活かし方・接続案

勝利を奪う仕掛けにせず、達成の後に好奇心を残す物として使う。行き先を読む対象や背景の目印にできる。必ず次の競技へ連行される進行制限、強制周回、報酬の没収はこの案から追加しない。

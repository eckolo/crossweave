# 気圧の階段

段差は見えず、体に掛かる圧だけで高さが分かる階段。

## 具体像

軽い道具を落とすと途中で止まり、透明な踊り場の輪郭を示す。上りと下りで使える足場が違う。

## 活かし方・接続案

隠蔽を探査で捉え、突破で進む基本の題材。手掛かりの見せ方を段階的に変え、単なる高い残量にしない。

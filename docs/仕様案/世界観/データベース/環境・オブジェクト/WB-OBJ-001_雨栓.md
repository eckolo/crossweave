# 雨栓

雨の荷を一時的に留める、大きな蛇口の栓。

## 具体像

開けると通路は見やすくなるが、預かっていた雨の働きも場へ流れる。乾かしたい人と利用したい人で評価が違う。

## 活かし方・接続案

場の供給源として残すか踏破して外すかの候補。攻撃相当の表示は閉める、または開く。

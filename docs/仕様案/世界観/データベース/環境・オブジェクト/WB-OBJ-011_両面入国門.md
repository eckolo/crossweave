# 両面入国門

表からも裏からも入国扱いになり、出国の記録が残らない門。

## 具体像

門番は規則を守っているが、外へ出た人の住所が消える問題に困っている。

## 活かし方・接続案

門を壊す以外に、別の出口や過去の記録を探す目的を作る。通過と案件解決を別の区切りにできる。

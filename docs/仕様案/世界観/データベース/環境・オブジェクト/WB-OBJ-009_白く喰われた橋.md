# 白く喰われた橋

色を失った部分だけが重さを支えられなくなった橋。

## 具体像

形の線は残り、橋の下には色を食べた生物が眠る。敵を倒しても、食べた色がそのまま戻るとは限らない。

## 活かし方・接続案

探査で支える線を確かめて渡る案と、色の循環を調べて直す案件案を別に持てる。

# 雷待ちの金床

落雷ではなく遠雷の順番を待って打たれる金床。

## 具体像

耳では静かでも、置いた道具に振動が溜まっていることがある。職人は空打ちで熱ならぬ音を抜く。

## 活かし方・接続案

機転や突破を補う場の供給源にする案。強い作用は敵にも利用されるため、残す価値と危険を持たせる。

# 無重力の隔離幕

幕を境に重さと埃の流れを切り分ける薄い膜。

## 具体像

患者には支えだが、旅人には方向を失う障害になる。幕の外へ出すだけで安全になるとは限らない。

## 活かし方・接続案

身構と攪乱の題材を区別できる環境。場の供給を止める時点と、患者を運ぶ内容の順序を検討する。

# 用途不明の空洞機関

中心に何も置かれていないまま、環だけがゆっくり位置を変える巨大な機関。

## 具体像

欠けた部品の跡にも、物を載せた痕跡にも見える窪みがある。動力や用途は不明だが、環の移動に伴う風と影は観察できる。作った者にとって完成品だったかどうかすら、記録なしには決められない。

## 活かし方・接続案

仕組みの一部を読み、環の間を進んで別の観測位置へ辿り着く。通り方が分かることと、全容を解明することを分けられる。壊れた設備と即断せず、修理を探索の唯一の結論にしない。関連する山脈・断崖は配置候補で、両方の世界をつなぐ必須装置にはしない。

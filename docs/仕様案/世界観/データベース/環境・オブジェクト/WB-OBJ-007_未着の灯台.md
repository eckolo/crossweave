# 未着の灯台

宛先のある船より、宛先が分からない船を強く照らす灯台。

## 具体像

光に照らされた船は航路が見えるが、別の船の記憶へ紛れ込むこともある。灯守の部屋は空席のまま。

## 活かし方・接続案

深部の調査目標。補助する光を消すか利用するかを経路と札供給の案へつなぐ。

# 上り水の井戸

汲んだ水が桶から空へ落ち、根を潤す井戸。

## 具体像

地下水が上へ向かうので深い場所ほど乾いている。住人は水を待つ網を頭上へ張る。

## 活かし方・接続案

水流の札供給を残すと移動しやすい側と押し戻される側がある。同じ場を双方が使う題材。

# 子守の余韻

歌い終わった後も肩を包む安心を、声の染みた襟巻きにした札。

## 具体像

巻くと歌詞ではなく息の間が聞こえる。歌い手本人を封じるのでなく、盆地で育った余韻の働きを取り込む。

## 活かし方・接続案

回復を行う消費札の候補。採用する場合は他の休息札との役割の違いを比較する。異界の文化を持ち帰れるが、同じ札で歌の販売問題が自動解決する設定にはしない。

## 写しの経験案（世界観1.11対応）

歌い終わった後も、肩を包むような安心が残る盆地。 自分が休む側になり、次には眠れない相手のそばに居る。歌い手の呼吸や、歌が止んだ後の静けさにも触れる。歌詞を覚えるだけでは得られない、包まれる働きの印象が残る。

作用と印象は「声の後にも続く安心／肩を包まれる感触」。声の染みた襟巻き。音そのものを鳴らす楽器だけが道具化の答えではない例。

放たれた余韻を他者が休息に使う案。歌い手本人を取り込まず、歌の権利や土地の問題も札一枚では解決しない。

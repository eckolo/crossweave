# 雨宿り

降り分けられる雨の境目を、一本の傘へ道具化した札。

## 具体像

開いた傘の内側だけは雨脚が遠のく。主行動は身構を支える。場では境界の働きが残り、利用できる者には相手も含まれる。傘の柄には預け主の名前でなく雨の匂いが残る。

## 活かし方・接続案

守りながら場を整える候補。高い突破を直接出す札とは役割を分ける。場に残す間は相手にも守る手段を渡す、という共有ルール内の判断を作る。

# 脱ぎ身

外側を残して内側が進む働きが、薄い外套を開く留め具になった札。

## 具体像

留め具を外す所作で、直前の輪郭を保つ抜け殻のような薄膜がほどける。印象は大きな山から新しい肌が抜け出すこと。主人公の身体を削ったり、生き物の皮を奪ったりして作る品ではない。

## 活かし方・接続案

主行動は攪乱を軸に、場では輪郭や薄膜が働きかけを受け流す身構・攪乱の方向を比較できる。共有の作用として双方に利用機会がある。別の行動主体を召喚する、標的を強制転換する、余力を費用にする等は新仕様になるため、この既存接続案に含めない。

# 食べごろ

ひと口に適した瞬間を見分ける働きを、試食用の小さな叉にした札。

## 具体像

触れたものの綻びが熟した実のように感じられる。高い探査で対象を捉えるが、大きな突破は出さない。岩が食べ物になるといった万能変換はしない。

## 活かし方・接続案

敵の隙、道の通り時、仕掛けの動作時を同じ使い方で描く。場に残る見極めの助けも共有されるため、主行動と場の順番を考える材料になる。

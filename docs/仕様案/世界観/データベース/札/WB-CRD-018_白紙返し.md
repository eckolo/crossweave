# 白紙返し

塗られた色が土へ戻る働きを、白い消し片にした札。

## 具体像

こすると物体そのものではなく、重なった作用の一層が剥がれる。人の記憶や調査記録まで消す道具にはしない。

## 活かし方・接続案

場札を一枚外す主行動の候補。新しい対象指定と除去処理が必要な新効果案。外した札の行先と由来、捨てる時の消滅は既存分類と整合させ、都合よく自分の山札へ奪わない。

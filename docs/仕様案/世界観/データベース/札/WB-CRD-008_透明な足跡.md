# 透明な足跡

光の中に残る足取りを、薄い硝子底の履物にした札。

## 具体像

歩くたび、今ある輪郭と少し前の輪郭が重なって見える。見えない未来を確定させず、対象が動いた差を辿る。探査を中心にした候補。

## 活かし方・接続案

草原の獣に限らず、迷路の歩き直しや動く岩の観察へ展開できる。突破を補う別の札が必要になる構成を想定する。

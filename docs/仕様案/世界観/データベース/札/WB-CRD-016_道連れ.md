# 道連れ

歩調が隣へ伝わる働きを、握り跡の多い杖にした札。

## 具体像

一人で振るう力は小さいが、地面へ立てると周囲の歩みが揃う。場で間隔を助ける札を想定し、誰に歩調を使われるかまでは選べない。

## 活かし方・接続案

場に出す判断を主役にする候補。敵の手数も助け得るため、供給源や現在の手札を見て置く時点を考える。所有者専用の場にはしない。

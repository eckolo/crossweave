# 手のひらの床

体を受け止める診療区の働きを、小さな床が開く手袋にした札。

## 具体像

手を差し出すと掌から一枚の床がせり出す。主行動では身構を助け、場では足場を定める働きが探査に向く。床そのものを持ち歩く能力へ広げず、一人を支える道具の形にする。

## 活かし方・接続案

浮遊診療区以外では崩れる足元や空中の荷物にも描写を転用できる。場の足場は相手も利用するため、長く残すほど一方的に有利とは限らない。

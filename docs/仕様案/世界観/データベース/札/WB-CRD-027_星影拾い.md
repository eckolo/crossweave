# 星影拾い

見えないものの影を重ねて位置を測る働きが、折り開く遮光板になった札。

## 具体像

板の穴から覗くと余分な光が落ち、離れた輪郭のずれが目印になる。作用は間接的な手掛かりを合わせること、印象は星そのものを見ずに星を探すこと。道具の形は精密機械に固定せず、大きな面と穴で描ける。

## 活かし方・接続案

主行動は探査に寄せ、場に残る目印も一致して使う側の探査を助ける候補。相手の非公開手札、山札順、乱数や未来の確定結果を表示する効果とはしない。探し当てる数量と描写だけでも成立する。数値・属性・専用の観測イベントは未採用。

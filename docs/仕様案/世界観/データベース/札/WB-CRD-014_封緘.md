# 封緘

宛先まで中身を保つ働きを、押し当てる封蝋印にした札。

## 具体像

空中へ印を押すと、触れた場所が封筒の内側のように守られる。中身を守る作用を身構として扱い、出来事を丸ごと無効にする効果にはしない。

## 活かし方・接続案

守る札として、破れやすい場面にも使える具体像を持つ。場に出した印は共有される。札の消滅を禁止する付加効果はこの案には含めない。

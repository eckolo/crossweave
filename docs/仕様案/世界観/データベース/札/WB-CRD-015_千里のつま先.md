# 千里のつま先

道が次の一歩を運ぶ働きを、左右で少し長さの違う靴にした札。

## 具体像

踏み出すと道の側が足先へ寄る。道なら進み、相手なら間合いへ入り、荷物なら押し出す動きになる。一歩を遠くする道具で、行き先を選べる瞬間移動ではない。

## 活かし方・接続案

短い間隔と突破を組み合わせる方向で検討する。探査や守りは別の札へ頼る役割にできる。

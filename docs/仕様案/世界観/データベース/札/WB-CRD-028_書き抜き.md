# 書き抜き

書かれた筋道の継ぎ目へ触れる働きが、余白へ差し入れる小さな紙切りナイフになった札。

## 具体像

目の前へ貼りつく役割や、続くはずだと思い込んだ筋の端を持ち上げる。作用は固まったつながりへ切れ目を入れること、印象は紙の本文の外にも先があること。

## 活かし方・接続案

突破を中心に、継ぎ目を捉える探査との配分を比較する。場へ残る切れ目も共有され、利用者を主人公だけにしない。人物の存在・過去・世界の法則を自由に消す能力や、全障害を飛ばす効果にはしない。対象別に壊す・探す・進むなどの共通行動へ接続できる。

# いただきます

食事の前に身を落ち着ける間を、膝に広げる布へ道具化した札。

## 具体像

布を広げると、席についたときの温かさが一度だけ戻る。料理を無尽蔵に生み出すものではなく、食べられる場所に着いたという安堵を取り込む。

## 活かし方・接続案

回復を行う消費札。ひと息の休息と役割が近いため、採用時は回復の量だけで増やさず、所要時間や場の働きの違いを検討する。数値と差別化は未決定。

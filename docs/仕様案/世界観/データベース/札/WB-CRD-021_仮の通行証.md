# 仮の通行証

所属の決まらない者を一度通す習俗を、空欄の残る胸章にした札。

## 具体像

胸章をかざすと、境目が次の一歩だけ余地を作る。実在の身分証を偽造する道具ではなく、留め切れない境界の働きを取り込む。

## 活かし方・接続案

突破の候補。手続きや相手の意思を全て無視する設定にせず、戦闘相当でも道でも一時の通りやすさとして描く。

# 遠雷

遅れて届く雷鳴を、鐘を打つ短い槌にした札。

## 具体像

振り下ろす動きより遅れて、重い響きが対象の奥へ届く。突破と機転に寄せ、一閃の大きな見せ場と相性のよい候補。遅れは描写だけで表すこともできる。

## 活かし方・接続案

高い探査で刻む札とは異なる役割。実際の遅延ダメージを入れるなら新仕様になるため、まず通常の解決時点のまま響きの演出で検討する。

鋳造所で、振り下ろした後から重い雷鳴が届く。現地では日々の仕事の一部。 音を聞くだけでなく、材料を支え、出来た品へ触れ、音の届かない工程と比べる。職人から手順を教わっても、遅れた響きが物の奥へ届く不思議は残り、道具としての手応えになる。

作用と印象は「後から奥へ届く響き／待った後に来る一撃」。鐘を打つ短い槌。技術として知られていることと、主人公が不思議を写せることが両立する例。

響きが他の働きへ重なる案。遅れはまず描写で扱い、遅延ダメージ等の新処理を足さない。

# 音止め

振動の逃げ道を押さえる技術を、小さな締め金にした札。

## 具体像

道具を鳴らす音だけでなく、迫る揺れの節を挟む。主行動では身構を支える。静かになったから相手が動けなくなる、という追加の停止効果は前提にしない。

## 活かし方・接続案

鋳造所では作業具、崩れかけた道では支え、敵には衝撃を弱める働きとして描く。場の締め付けを相手も使う構成が可能。

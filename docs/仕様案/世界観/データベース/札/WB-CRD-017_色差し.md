# 色差し

色の差が形を支える働きを、細い絵筆にした札。

## 具体像

ひと筋塗ると対象の輪郭と背景が分かれる。主行動は探査を助ける。描いた物を現実に増やす能力ではなく、既にある働きの差を色として取り出す。

## 活かし方・接続案

迷路、獣、機械で同じ概念を使える。場に残る色差しは相手の探査も助けるため、輪郭を得た後に残すかを考えさせる。

# 持ち主不在

誰にも属さない隙間を、小さな鍵へ道具化した札。

## 具体像

鍵は錠前の形を真似ず、守る手が届いていない継ぎ目に差し込まれる。身体への作用なら身構の綻び、扉なら留め具の隙間を使う。権利そのものを書き換える万能鍵ではない。

## 活かし方・接続案

突破に寄せた境界の札として検討する。身構を無視する追加効果まで付ける場合は新効果として別審議し、この案だけで貫通処理を確定しない。

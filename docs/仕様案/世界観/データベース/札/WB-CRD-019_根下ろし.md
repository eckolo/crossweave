# 根下ろし

空へ離れまいとする根の働きを、胸へ留める錨形の留め具にした札。

## 具体像

留め具の影が足元へ伸び、踏み止まる力を生む。主行動では身構を支える。どこでも絶対に動かなくなる拘束具ではない。

## 活かし方・接続案

浮く園でも風の強い裏道でも意味が通る。場の重さは相手も利用でき、動きを助ける札との組合せに向き不向きを作れる。

# 上の下

水と実が別の下へ落ちる働きを、向きの定まらない下げ振りにした札。

## 具体像

紐を垂らすと見る者の上下感覚が一拍ずれる。主行動では攪乱に寄せる。世界全体の重力変更ではなく、狙いを定める難しさとして表す。

## 活かし方・接続案

素早く避ける札と同じ数量概念で、惑わせる道具を作る。場の向きの乱れが自分の探査にも都合よく働くとは限らない。

# 泡のない息

深海の圧の隙間に残る空気を、一息分の吹き口へ道具化した札。

## 具体像

口に当てると冷たい空気が戻り、息苦しさがほどける。日常の酸素容器を採ったのではなく、空気を失わない隙間という不思議を取り込んだもの。

## 活かし方・接続案

余力を回復する消費札の候補。無限の潜水能力や恒久的な安全装備にはしない。消費と消滅の扱いは既存の消費札の分類に合わせ、回収だけで無限補給しない。

# 反照

像が本体より遠くを歩く現象を、裏表のある手鏡にした札。

## 具体像

鏡を返すと居場所の輪郭だけが別の角度へ映る。主行動では攪乱を助ける。透明化や別人への完全変身ではなく、探し当てる手間を増す道具。

## 活かし方・接続案

身構で受ける札と区別できる。場に残る反射も双方に作用する案として、使った後の探査の通し方まで考えさせる。

## 写しの経験案（世界観1.11対応）

世界観1.12の補足：以下は関わりを特に描きたいときの任意の場面素材。通常は探索中の札・道具の利用と帰還後の着想による取得に、その深まりが含まれる。専用場面や所定の利用回数を、この札の取得条件にはしない。

硝子の草原で、獣より先を歩く像を見る。最初は光のいたずらにも見える。 見る角度を変え、像を追って迷い、今度はその先回りを利用して獣と距離を取る。見破って消える錯覚ではなく、本体と居場所がずれる働きが、怖さと頼もしさの両方から残る。

作用と印象は「居場所の輪郭をずらす働き／追っても重ならない像」。裏表のある手鏡。像と本体の距離を鏡を返す所作へ写す。

放たれた反射は相手も隠れるために使える。主人公の鏡を勝手に操作した描写を必須にしない。

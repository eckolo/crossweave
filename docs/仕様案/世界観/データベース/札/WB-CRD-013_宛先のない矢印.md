# 宛先のない矢印

届く方向を探し続ける働きを、文字盤の空いた方位磁針にした札。

## 具体像

針は目的地の名前ではなく、今の手掛かりが続く方向を向く。情報がなければ揺れ、誤った手掛かりを信じればその先を示す。

## 活かし方・接続案

探査を支える札として、未知を消さずに探索の手段を増やす。未訪問先の報酬を表示する機能には結び付けない。場では別の主体にも方向を与える。

## 写しの経験案（世界観1.11対応）

未着の港で、宛先をなくしても届こうとし続ける手紙に関わる。 断片を追い、待つ者の話を聞き、誤った宛先にも辿り着く。正しい場所を一度に示す力ではなく、手掛かりから次の関わりへ向かう働きを、自分が届けようとする体験を通じて写す。

作用と印象は「届く方向を探す働き／まだ誰かへ続いている感覚」。文字盤の空いた方位磁針。元の物が手紙でも、印象と作用に沿って別種の道具になる例。

場に放たれた方向づけは別の主体も利用できる。未訪問先の真相・報酬を自動で知る力にはしない。

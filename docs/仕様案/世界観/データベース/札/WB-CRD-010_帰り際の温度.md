# 帰り際の温度

誰かを待って残った温もりを、一杯をかき混ぜる匙にした札。

## 具体像

匙を回すと飲み物が、帰宅した人へ出されたときの温度になる。単なる温かい飲料ではなく、待つ時間が冷めずに残る不思議を取り込んでいる。

## 活かし方・接続案

回復を行う消費札の候補。日常の小さな異界にも持ち帰る価値を置く。ひと息の休息などとの機能重複は採用時に比較し、風味違いの収集枠に留める選択もある。

# 底抜け

水のない深さが生む落ち込みを、錘付きの糸巻きにした札。

## 具体像

糸を伸ばすと触れた足場の下へ重さが抜ける。敵には崩す一撃、岩には割る力、道には沈みを越える作用として見せる。突破に寄せ、探査は不得手な候補。

## 活かし方・接続案

先に輪郭を掴む札と組む大きな作用。場に出した重圧を別の主体も使える。どんな障害も一度で消す設定にはせず、対象に応じて同じ働きを描き分ける。

## 写しの経験案（世界観1.11対応）

世界観1.12の補足：以下は関わりを特に描きたいときの任意の場面素材。通常は探索中の札・道具の利用と帰還後の着想による取得に、その深まりが含まれる。専用場面や所定の利用回数を、この札の取得条件にはしない。

降りるほど、足場の下へ重さが抜ける乾いた深海。最初は足を取られる怖さとして出会う。 荷を持って通る、現地の者の歩き方を見る、沈みかけた物を引き上げるなど、違う側から同じ深さへ関わる。落ちる力だけでなく、どこで支えが抜け、どこへ重さが渡るのかが身体の印象として残る。

作用と印象は「深さへ重さを預ける働き／足元が抜ける感触」。錘付きの糸巻き。既存案の「下へ重さが抜ける」作用へ、沈み方を手元で辿る印象を重ねる。

場へ放つのは重さの抜ける不思議。他者は足場や姿勢へ働きかける機会として使える。

# 冬眠の栓

眠る間も熱を逃がさない働きを、短い巻き鍵へ道具化した札。

## 具体像

鍵を回すと手元の力が急がず蓄えられる。一閃の前に間を置く道具という発想で、溜めたものが体温のように掌へ残る。

## 活かし方・接続案

機転を今すぐ使わず、次の有効な作用まで保つ補助案。ただし現行の隠蔽未達時の持越しは元からあるため、それと異なる発動抑制を設けるかは未決定。追加の保留操作は新効果として扱う。

# 配達不能の和平文

国の名が変わるたび宛先が失効し、停戦より長く旅する文書。

## 具体像

写しは両国にあり、内容は既に知られている。それでも原本の受領を誰が担うかが決まらない。未着便局は戦争を止める奇跡の手紙という宣伝を嫌う。

## 活かし方・接続案

届けば全て解決する品にせず、形式が残す関係を描く。国境の旧記録所と港を結ぶ横断的な副案件にできるが、二つの異界が常に直結する地理までは確定しない。

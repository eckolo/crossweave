# 海が消えた日を数えない

乾海では海の消えた年を起点に暦を作らない、という外来者の記録。

## 具体像

住人の中には一晩で消えたと言う人も、祖父の代には浅かったと言う人もいる。そもそも水を見たことがない家では、その日を数える理由がない。忘却の魔法という説明だけに統一しない。

## 活かし方・接続案

救難信号や古い船の年代を調べるときの背景。複数の証言を残し、世界全体の歴史を書き換える真相に直結させず局所的な調査を可能にする。

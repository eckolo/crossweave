# 失敗した天気の統一

全ての地域へ同じ順番で季節を送ろうとした計画の記録。

## 具体像

管理帳には成功とあり、農家の暦には飢えた年とある。育つ作物も欲しい雨も違ったため、後に天気を預かり分ける仕組みへ変わったという説がある。今の駅がその計画の直系かは不明。

## 活かし方・接続案

雨番組合の規則に理由を持たせる。標準化そのものを悪とせず、共有すると便利なことと地域差を残す必要を描く材料になる。

# 顔料採りのラル

雨林で余った色だけを採る、布を何重にも巻いた採集者。

## 具体像

鮮やかな色ほど高く売れるとは限らず、生活道具には落ち着いた色が必要だと言う。今期の収穫を失うと借家を出ることになる。

## 活かし方・接続案

生態系を守る抽象的な善と、今暮らすための必要を両方示す。白い沼への経路を知るが、中心部は未踏。

# 雨番組合

天候の預かりと配達を担う小さな組合。

## 具体像

雨を増やす能力より、必要な量を聞き取る経験が重視される。農家と洗濯屋で要望が食い違う。

## 活かし方・接続案

辿り屋に未登録の雨の由来を調べてもらう。万能の異界管理組織にはせず、一つの駅と配送圏を担当する。

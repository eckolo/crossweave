# 石灯りの祈り手

願いが叶ったかどうかを尋ねず、祈りに来た者のために石の灯を磨く人。

## 具体像

願いを持つ者にも、何も頼まない参詣者にも場所を空ける。探査のためなら祭具を何でも貸すわけではなく、見せてよいものと触れてほしくないものを自分の言葉で伝える。日々の作業や小さな冗談もある人物。

## 活かし方・接続案

信仰を迷信の暴露や便利な魔法の説明に限らず、人の営みとして置く。相談役にも意見の合わない相手にもなれる。主人公の能力や探索の有用性だけで、この人の価値観を裁定しない。灯の管理が壊れる事件を用意せず、普通に続いている祭礼の一場面から登場できる。

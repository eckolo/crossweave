# 巡礼路の修繕団

歩く道の傷を縫い、宿の脚を直して旅を続ける集団。

## 具体像

信仰する対象は一つではない。巡礼をしない荷運び人や、途中で旅をやめた人も仕事に加わる。

## 活かし方・接続案

道を止めたい人と進ませたい人の双方に知人がいる。修繕の材料集めを副目的に置けるが、事前に未知の道具の存在を保証しない。

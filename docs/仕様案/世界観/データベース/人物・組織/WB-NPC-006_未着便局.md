# 未着便局

手紙の配達先と、届けない意思の両方を記録する便局。

## 具体像

全てを配達することが善だとは扱わず、差出人がいなくなった便も調べる。局員同士で扱いが割れることがある。

## 活かし方・接続案

依頼は失くした荷物だけでなく、配達を止める理由の確認にもなる。便局は世界間の全通信を独占しない。

# 鋳造所の聞き耳工

炉の音を手袋越しの振動で読む職人。

## 具体像

耳が聞こえる者だけの仕事ではなく、複数の感覚で互いの判定を補う。音型を守るため、工場の全停止にも反対する。

## 活かし方・接続案

古い設備の誤動作と現地で続く工夫を区別する証言者。職人自身を技術の説明だけにせず、休暇や家族の事情も持たせる。

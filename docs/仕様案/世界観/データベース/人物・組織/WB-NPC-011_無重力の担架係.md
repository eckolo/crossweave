# 無重力の担架係

患者と荷物の軌道を読み、壁へぶつけず運ぶ係。

## 具体像

装置を止めるのが救出になる患者も、装置が必要な患者もいることを知る。辿り屋には装置の一括停止を求めない。

## 活かし方・接続案

# 影踏み走者のニカ

影のつながる足場を渡り、誰も通らなかった経路で先着することを楽しむ走者。

## 具体像

土地の道を知る一方、新しいコースでは読み違えもする。主人公の仕事に常に付き合うわけではなく、自分の記録や競争相手を追っている。案内の代わりに一勝負を持ち掛けることも、競技の公平さのためだけに注意を教えることもある。

## 活かし方・接続案

親切な依頼人・救出対象以外の人物関係を増やす。負けず嫌い同士の距離や、相手の上達に驚く再会が使える。辿り屋の同業者や主人公と同じ札化能力者ではなく、限られた場所の道を渡る独自の技術を持つ人物案。人名・年齢・姿・常設のライバル採用は未決定。

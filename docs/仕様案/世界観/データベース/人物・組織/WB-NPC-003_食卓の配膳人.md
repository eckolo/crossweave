# 食卓の配膳人

大陸の端で皿を並べ、住人の食事も用意する給仕。

## 具体像

集落を料理として扱う古い献立に疑問を持つが、献立を捨てれば別の土地が飢えることを知っている。

## 活かし方・接続案

敵の指揮者に固定せず、変えられる手順を一緒に探す依頼人にする。奥の主催者の存在自体も未確認でよい。

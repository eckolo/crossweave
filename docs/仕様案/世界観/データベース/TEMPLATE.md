# 個別案テンプレート

以下のコードブロックの中身を、分類ディレクトリの `WB-LOC-未使用連番_名称.md` などへコピーする。LOC以外は分類に応じた接頭辞に変える。IDは総合索引で未使用を確認し、削除済みIDの再利用も避ける。

```markdown
---
id: "WB-LOC-999"
name: "新しい案の名前"
category: "異界"
status: "案"
origins: ["由来不詳"]
tags: ["検討したいテーマ"]
related: []
scope: "描写案"
summary: "一文で、この案に固有の魅力を書く。"
---

# 新しい案の名前

一文で、この案に固有の魅力を書く。

## 具体像

どのような不思議で、誰がどう暮らし、何が見えるか。
札なら取り込む働きと具体的な道具の形を書く。
心得なら経験・作法とその考え方を書く。

## 活かし方・接続案

探索でどう出会い、奥へ進む理由や判断にどう関わるか。
効果を提案する場合は条件、使いどころ、代償、未決定部分を書く。

## 検討メモ

- 初稿：日付と作成理由。
- 採用判断：未実施。
```

関連する別案のIDは `related` に列挙する。生成マーカーの内側は索引更新時に埋まる。分類と状態の定義、接続区分の意味は[入口](README.md)を参照。

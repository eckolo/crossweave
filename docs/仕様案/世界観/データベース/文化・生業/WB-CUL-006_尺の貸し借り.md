# 尺の貸し借り

品物を貸す前に、それを測る尺も貸す習慣。

## 具体像

虫の巣ごとに基準が違うため、長さだけ伝える約束は不親切とされる。人の職人は換算札を腰へ下げ、蜂の使者は巣の一歩を踊って示す。測り方に冗談や見栄もある。

## 活かし方・接続案

単位の違いを障害だけでなく日常の作法にする。道具の貸し借り、建築、服の仕立てなど、小さな出来事へ広げられる。共通基準の導入が文化の消滅を必ず伴うとはしない。

# 鑑札商の鑑定帳

札の格付けより、働き方と癖の違いを記す帳面。

## 具体像

同じ名の札にも、場に置くと働く個体や急ぐ個体がある。鑑札商は強さだけでなく手放した理由も尋ねる。同じ心得を持つ品が複数あっても、同じ経験を丸ごと複製したとは限らない。

## 活かし方・接続案

重複品、修飾個体、変換を世界の仕事へ接続する候補。変換の出力、交換率、通貨、鑑札商の利用必須化は決めない。最後の一品や組み直しの扱いも設計側に残す。

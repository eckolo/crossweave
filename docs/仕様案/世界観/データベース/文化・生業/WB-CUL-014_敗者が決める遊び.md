# 敗者が決める遊び

勝負が終わったら、次に何で遊ぶかは負けた側が提案する作法。

## 具体像

走るのが得意な者へ、石積みや影踏みを持ち掛けてもよい。勝者の勝ちはそのまま認め、次の遊びに参加するかは互いに選ぶ。勝つことと、一緒に遊び続けることの両方を大切にする少数の遊び場の作法。

## 活かし方・接続案

敗北を常に慰めや悲劇へ結びつけず、次の挑戦へつなげる。勝負の途中で規則を変える権利ではなく、終わった後の相談として描く。主人公が帰還や休息を選べなくなる強制再戦や、ゲーム全体の敗北精算の変更は含めない。

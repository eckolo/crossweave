# 食卓の食べ残し権

一度食卓へ出た土地の残りを、誰が使えるかを定める取り決め。

## 具体像

配膳人、住人、片付け係で権利が異なる。パンの丘の端を削る仕事や、冷めた汁の水路を引く仕事がある。食べ残しという言葉に侮蔑の響きはない。

## 活かし方・接続案

食卓大陸に食材の見立て以外の社会を持たせる。集落移転の候補地、食事の誘い、残りを持ち帰る許可などへ展開できる。全住人が食べ物という設定は要求しない。

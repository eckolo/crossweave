# また来ると言わない別れ

道の行き先が変わる土地では、次の訪問日を約束する代わりに「道が合ったら」と別れる。

## 具体像

巡礼路の一部の集落では、旅人を引き留めず、来られるか分からない約束を求めない。「道が合ったら、次の話を聞かせて」と言い、残る側も自分の暮らしへ戻る。翌日に再会して笑うことも、長く別の道を歩くこともある。

## 活かし方・接続案

関係が続くことと、常に会えることを分けた後味を作る。主人公が別の土地でこの言い方を覚えて使う小さな変化にもできる。すべての道がやがて閉じる法則や、永久に再訪できない制限にはしない。別れを必ず悲劇にせず、再訪した時の何気ない挨拶と対で使える。

# 国境の二重姓

暮らす場所と訪ねてきた道の名前を、二つ並べて名乗る習慣。

## 具体像

順番を入れ替える人も、一つを省く人もいる。公的な忠誠の宣言というより、郵便や食事の席で通じる自己紹介。仮住まいが長いことを恥じる風習にはしない。

## 活かし方・接続案

人物の呼び方の変化だけで関係を描ける。迷子の案件では記録の姓名と本人の名乗りが違う理由になり、本人に一方だけを選ばせずに話を進められる。

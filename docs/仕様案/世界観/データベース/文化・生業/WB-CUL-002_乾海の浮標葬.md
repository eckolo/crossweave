# 乾海の浮標葬

亡くなった者の名前を、海のない場所に浮標として留める習慣。

## 具体像

浮標は墓でも航路標でもあり、家族は位置が変わると怒る。記念日には布を張り替え、子どもが名前を読み間違えて笑いが起こることもある。悲しみだけで日常を埋めない。

## 活かし方・接続案

探索の目印と土地の記憶を重ねられる。便利だから持ち帰る行為の意味を会話で示す。消息調査の記録と照らす副目的も生まれる。

# 願いのない参詣

何かを叶えてもらうためでなく、その場所が今年もあることを喜んで訪ねる参詣。

## 具体像

願いを持って来る者もいるが、持たない者も同じ道を歩く。石を磨き、季節の食べ物を分け、灯の揺れを眺めて帰る。何かを解決する仕事をしていない時間にも、住人の価値観と暮らしがある。

## 活かし方・接続案

信仰を対価と奇跡の交換だけへ閉じない文化案。場面の主調を静かな歓びや賑わいにできる。すべての異界の信仰をこの形へ統一せず、願掛けや異なる儀礼も残す。参詣回数・供物・祈願効果の成長システムを追加したものではない。

# 日常の町の帰還茶

辿り屋が帰ると、報告の前に同じ茶を一杯出す習慣。

## 具体像

危険の大きさにかかわらず湯飲みは同じ。依頼人へ言えない細部を話す日も、何も話さず洗い物だけする日もある。異界の土産は茶菓子になるとは限らない。

## 活かし方・接続案

全体進行の帰還を数字の精算以外で描く場。新しい紹介、成果の受け止め方、世話人の変化を置ける。特定の店を必須の機能拠点にする仕様までは含めない。

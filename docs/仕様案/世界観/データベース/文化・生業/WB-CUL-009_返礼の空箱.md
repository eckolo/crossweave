# 返礼の空箱

遠い土地へ送った品の箱が、向こうで使われた痕跡を少しだけ残して戻ってくる。

## 具体像

菓子を包んだ箱の折り目に薄い顔料がついている。修繕した食器の箱には、食卓の住人が屋根として借りた跡がある。言葉の礼状がなくても、確かに届いて、向こうの暮らしへ混じったと分かる。空箱を返すのは少数の顔なじみの作法で、全異界の義務ではない。

## 活かし方・接続案

店の棚や主人公の手元に短く映せる返礼。新しい依頼の手掛かりにも、単に無事を知らせる品にもなる。扱うのは通常の品や現地に実在する荷物で、主人公が展開した道具の永久譲渡や札の一般流通を前提にしない。必ず収集する記念品や成長資源にはせず、前の包みを次の贈り物に再利用してもよい。

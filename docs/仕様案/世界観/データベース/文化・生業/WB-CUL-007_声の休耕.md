# 声の休耕

よく響いた場所をしばらく静かにし、次の声を育てる習慣。

## 具体像

声を採る人は収穫量だけでなく、誰が何を語れる場所かを世話する。祭りの後は手振りで商いをし、音のない日を楽しむ。話せない人も身振りや振動の担い手として参加する。

## 活かし方・接続案

子守歌の案件の判断材料になり、静かな市場という平穏な滞在場面も作れる。沈黙を一律に恐怖や禁忌へ寄せない。

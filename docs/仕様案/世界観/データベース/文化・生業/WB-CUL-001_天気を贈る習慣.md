# 天気を贈る習慣

雨や晴れを丸ごと買わず、小さな天候の時間を贈る習慣。

## 具体像

入学の日の風、葬送の間だけの霧、昼寝を邪魔しない薄曇りなど、暮らしの都合に合わせた贈り物がある。受け取る側が開けない自由もあり、預け直された天気が駅に溜まる。

## 活かし方・接続案

異界で買う品を全て攻略道具にせず、会話や依頼のきっかけにする。町ではただ涼しかった午後が、実は誰かの贈り物だったと後から分かる場面も作れる。

# 帰りの伝言棚

古道具屋の棚に、次にその方面へ行く者へ託す小さな伝言が置かれる。

## 具体像

先代は知り合いから預かった便りを、行き先が合う時だけ託す。配達の途中に寄る使いも、何か月も姿を見せない相手もいる。主人公宛ての返事が一つ加わることで、先代のつながりの中に主人公自身の付き合いも育っていると分かる。

## 活かし方・接続案

連絡の遅さや相手ごとの作法が、顔なじみの少ない緩やかな往来を表す。急ぎの相談は別の経路を探せるし、宛先や内容を店の全客へ公開する必要はない。全世界から即時に依頼を集める網や、必ず確認する新しい掲示板画面にはしない。棚の描写自体を省略し、返事を手渡す一場面だけでも成立する。

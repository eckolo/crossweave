# 旅先の空席

久しぶりに訪れた食事の席で、主人公が座りやすい場所を誰かが覚えている。

## 具体像

乾海の休み場では浮きやすい荷物を留める紐が短く結び直され、食卓の端では幼い客でも届く位置へ小さな皿が寄せられる。主人公がいない間は他の客も座る。帰って来る日を約束していなくても、その場で一人分の居場所ができる。

## 活かし方・接続案

店以外にも、名前や好みを覚えてくれる場所が増えることを表す。会話を増やさず、席を指す仕草や主人公が迷わず座る行動だけでもよい。空席を常に死者の不在や永遠の待機へ結びつけず、相手自身の日常が続いている中の歓待とする。宿泊機能や回復地点の追加を、この描写だけで決めない。

# 主役を待つ鎧

着る者へ英雄の姿を与えようとするが、その人が別の生き方を望むことを理解しない鎧。

## 具体像

空っぽの鎧が自分で跪き、勇ましい名乗りや華麗な身振りを披露する。自ら望んで役を演じる客もいる。一方、途中で降りたい者へは物語を続けるよう迫り、同じ危機を呼び込もうとする。

## 活かし方・接続案

魅力のある不思議が相手の意思を置き去りにする場合を描ける。承認や親切だけで和解するとは限らず、鎧の働きを押しとどめて先へ進む対決も成立する。札の一般譲渡とは無関係な現地の存在。主人公へ特定の装備・台詞・人格を恒久的に強制する設定は採用しない。

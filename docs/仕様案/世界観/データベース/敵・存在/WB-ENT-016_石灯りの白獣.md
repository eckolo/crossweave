# 石灯りの白獣

石の灯りを伝って歩き、人が祈っていてもいなくても同じ場所で眠る白い獣。

## 具体像

祭礼では尊ばれるが、供物を食べる時も素通りする時もある。角の陰に小さな虫が住み、毛が灯の煤で少し灰色になる。神意と呼ぶ住人、生態として記す旅人、どちらとも決めず世話をする者がいる。

## 活かし方・接続案

祈りの対象も生き物として暮らす姿を描ける。善悪の裁定者や願いを処理する装置にせず、人がどう関わっているかを見せる。主人公が写せるのは出会った印象と作用であり、写したことで神格や信仰の真偽まで証明したとはしない。神か動物かを必ず結論づける案件にしなくてよい。

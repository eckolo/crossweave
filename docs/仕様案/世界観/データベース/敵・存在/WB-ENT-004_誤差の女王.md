# 誤差の女王

基準尺を抱いて眠り、寝返りで群れの測り方を変える虫の女王。

## 具体像

群れは女王を盲信しているわけではなく、複数の測量隊が誤差を持ち寄る。女王だけ倒すと基準がさらに散らばる。

## 活かし方・接続案

女王への対処と補助する測量隊の扱いを分ける。基準の写しを得て帰る目的も成立する。

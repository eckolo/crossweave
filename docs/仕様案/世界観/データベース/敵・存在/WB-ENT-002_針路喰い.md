# 針路喰い

魚の姿をしているが、獲物の肉より帰り道を食べる。

## 具体像

噛まれた場所そのものは残り、そこへ向かう目印だけが頼りなくなる。深海の住人は空の浮標を餌にして遠ざける。

## 活かし方・接続案

攪乱を伴う敵の案。環境の目印を残すか先に踏破するかが、その後の捉えやすさに関わる。

# 逆さ接ぎ木

落下しそうな果実を守ろうとして、人や荷車まで空へ結び付ける枝。

## 具体像

接いだ木の性質を複数持つため、同じ枝でも収穫期が違う。傷つけると果樹園の一部が枯れる。

## 活かし方・接続案

高い身構の環境寄りの相手にもできる。壊すより結び目を解く行動名が合う個体を設ける。

# 引用の群れ

手紙の一文を咥えて飛び、聞いた言葉を別の宛先へ運ぶ鳥の群れ。

## 具体像

運ぶ途中に文が欠け、謝罪が命令に変わることもある。鳥は意味を改竄したつもりがなく、落とした文字を巣に集める。

## 活かし方・接続案

姿より文脈が隠蔽になる相手の表現。群れの札を借りて通信の流れを利用できる。

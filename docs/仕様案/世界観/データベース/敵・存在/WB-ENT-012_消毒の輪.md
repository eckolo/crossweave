# 消毒の輪

廊下を漂う金属の輪が、患者以外の異物を静かに掃き出す。

## 具体像

道具化した不思議を異物と認識するため、辿り屋の旅支度と相性が悪い。職員の古い身分札には反応しない。

## 活かし方・接続案

攻撃表示は洗い流す等の内容にできる。回復に関わる場札を供給しながら排除もする、利用と危険の同居を狙う。

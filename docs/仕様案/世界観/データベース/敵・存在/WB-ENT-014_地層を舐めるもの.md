# 地層を舐めるもの

岩の新旧の境を舌で辿り、そこに残った体温や匂いごと削り取る捕食者。

## 具体像

目は見えず、平たい頭と長い舌だけが断層から出る。人が作った道と獣の通り道を区別しない。足場を調べた跡や、避難のために暖めた場所が餌の目印になることもある。

## 活かし方・接続案

説得や善意の確認が通じない危険として扱える。何を追うかは観察でき、避ける・惑わす・押し返す・必要なら戦うなどで対処する。すべての敵を事情のある協力者へ変えず、理解した後も怖い相手を残す。匂い追跡の専用メーターを必須にせず、対象の行動や攪乱・探査の描写に使える。

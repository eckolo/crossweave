# 錆眠りの巨人

眠った街区を肩に載せ、必要な熱が来るまで動かない保守機構。

## 具体像

目覚めた直後は人を住人と認識できず、侵入した虫を払う手順を適用する。全てが故障ではなく保護の順序が違う。

## 活かし方・接続案

高い身構と大きい突破を持つ相手。起こす前に周辺の熱源をどう扱うかを、イベントと環境に分ける。

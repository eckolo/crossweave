# 硝子角の獣

角に周囲の景色を映し、実際の体より大きく見える草原の獣。

## 具体像

群れの幼獣が人の足跡を道として覚えてしまい、通行人を追う。人を食べる習性はない。

## 活かし方・接続案

攪乱が高いが、必ず高い突破を持つ必要はない。親を刺激せず群れを別の経路へ誘導する案件が作れる。

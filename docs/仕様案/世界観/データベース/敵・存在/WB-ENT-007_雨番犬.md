# 雨番犬

濡れた外套のような毛を持ち、預かった雨の匂いを守る犬。

## 具体像

晴天の日ほど落ち着かない。雨を盗む者を追うが、持ち主へ返す人には道を開く。普通の犬のように寝床を選ぶ。

## 活かし方・接続案

必ず敵として出さず、依頼で敵対理由が変わる存在。雨栓を先に開けると場の働きと敵対の理由が両方変わる。

# じゃんけんの王様

負けた遊びの記憶を継ぎ足した王冠をかぶり、誰より勝負をしたがる大きな手。

## 具体像

指の数や身振りは一定せず、自分の知らない遊びには堂々と説明を求める。負ければ悔しがり、強い相手にはまた挑む。通り道を競技場にしてしまうことがあり、旅人にとっては厄介な強敵でもある。

## 活かし方・接続案

勝負そのものを楽しむ相手として置ける。救うべき過去や勘違いを必ず用意せず、正面から挑んで押し通る場面もよい。対象別の行動名を「挑む」等とし、動きの見極めと突破を現行の共通処理で表せる。名称だけで三すくみ・手選択の別ゲームを必須にしない。

# 空腹の皿

料理が載るまで食卓を滑り回り、建物でも料理と見なす大皿。

## 具体像

皿自身には味覚がなく、配膳の印を手掛かりに動く。小皿を載せると世話を始める個体もいる。

## 活かし方・接続案

戦う相手にも移動の足場にもなる。撃退する案と、集落から離れる配膳経路を用意する案を分けて検討する。

# 他所の理屈

同じ働きに見えても、別の土地では理由が違うと知る心得。

## 具体像

測量蜂と人は同じ長さを別の仕方で揃える。初めての札を既知の道具へ無理に当てはめず、手触りの違いから使い分ける。

## 活かし方・接続案

直前と異なる由来の札を続けて使うと探査を補う案。属性の切替を条件とする既存案とは区別する。由来は属性や世界の起源と同義にせず、既存の札の由来情報を基に判定を詰める。

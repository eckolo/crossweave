# 足元の記録

一度見た足跡を、次の一歩の物差しにする心得。

## 具体像

草原の案内人は遠い景色より、直前に踏んだ草の倒れ方を記録する。同じ対象を見続けることで小さな違いを拾えるという、辿り屋の日々の技術。

## 活かし方・接続案

同じ対象への連続した行動で探査を補う新効果案。対象を変えると補助が切れる方向で、危険な対象へ固執するか切り替えるかの判断を作る。未知の情報を自動開示する効果にはしない。

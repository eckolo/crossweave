# 手繰り直し

道具の巡りが一周したとき、持ち方も息も整え直す心得。

## 具体像

使った札を捨て場から集め直す時間は、失敗を数える時間でもある。札の向きを揃える手順に、旅の途中で身についた小さな休み方がある。

## 活かし方・接続案

山札の再構築時に小さく回復する案。回収と不足分の生成は区別し、どの完了時点を契機にするかを詰める。探索内の回数制限など有限性が必要で、永久回復を前提にしない。

# 借り物の作法

初めて握る道具ほど、元の持ち方を確かめてから使う心得。

## 具体像

鑑札商の店には、柄の擦れ方だけを集めた見本帳がある。道具の来歴を全部知らなくても、どこを持てば働きを邪魔しないかは観察できる。

## 活かし方・接続案

他の由来の札を一致して使ったときの間隔を助ける案。既存の借り札に関する守りの候補と役割を分ける。由来を自分へ変更したり消滅条件を消したりはしない。

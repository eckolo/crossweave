# 当てにしない勇気

大きく進めた直後ほど、次も同じように通ると思わない心得。

## 具体像

先輩の辿り屋が、一度の鮮やかな突破の後に足元を崩した話から伝わる。勢いを否定せず、進めた分だけ周囲を確かめる習慣。

## 活かし方・接続案

一閃が発動した次の行動で身構を補う案。会心率という確率能力へ戻さず、現在の機転と一閃の処理を用いる。守りを適用する行動と終了条件は要検討。

# 半歩の重さ

大きく跳ぶより、確かな半歩へ力を集める心得。

## 具体像

歩く巡礼路では、道の動きに逆らう長い踏み込みほど足を取られる。手数の速さとは別に、必要な場所へ重さを置く技術として教わる。

## 活かし方・接続案

探査の低い札の突破を補う候補。隠蔽を掴む別の手段を必要とし、探査の弱さを無条件で消さない。対象や場に合わせて役割を組む心得にする。

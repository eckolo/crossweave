# 期限の読み

消える間際の不思議を、慌てず使い切る心得。

## 具体像

手札の端の冷たさや、開くときの抵抗から働きの薄れを察する。長く抱えた札ほど惜しむのでなく、最後に向く使い方を探す技術として語れる。

## 活かし方・接続案

手札の期限が近い札を使うと機転を補う案。期限を延長したり、消滅後に札を復活させたりする効果ではない。期限の判定幅と表示方法は設計検討が必要。

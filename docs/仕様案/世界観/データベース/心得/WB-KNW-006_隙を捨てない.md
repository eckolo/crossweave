# 隙を捨てない

## 具体像

見つからなかった場所や通らなかった力の向きも記録する。失敗を成功扱いにするのでなく、同じ見落としを減らす習慣。

## 活かし方・接続案

隠蔽を越えなかった一致行動で機転を少し補う案。隠蔽未達時に既存の機転を持ち越す処理とは区別する。追加量と一閃の発動時点は現行の共通処理に整合させる。

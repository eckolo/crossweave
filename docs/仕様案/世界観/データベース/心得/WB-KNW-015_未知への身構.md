# 未知への身構

入口で見た景色だけを、その土地の全てだと思わない心得。

## 具体像

辿り屋は初めての場所ほど、戻れる印を一つ置いてから進む。怖がり方を決めておくことで、知らないものへ近づけるという考え。

## 活かし方・接続案

初訪問区間の序盤に身構を助ける案。未見の敵や報酬を予告する効果にはしない。初訪問の単位と補助の終了時点は進行管理側の追加検討が必要。

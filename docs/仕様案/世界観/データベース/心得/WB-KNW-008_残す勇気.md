# 残す勇気

立ち塞がるものを、すぐ取り除かず利用する心得。

## 具体像

雨栓や上り水は障害でもあり、そこに暮らすものの支えでもある。役目を知るまで残すという仕事の姿勢を、場の扱いへ落とし込む。

## 活かし方・接続案

場の供給源となる環境が残っている間に探査を補う案。供給源を残す危険も引き受ける。環境の役割を判定する情報が新たに必要で、現在の対象分類だけで実装済みとはしない。

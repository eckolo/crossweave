# 引き際の勘

まだ進めるという感覚を、一度疑って足を止める心得。

## 具体像

乾海の師匠は帰り道を見失った経験から、疲れたときほど守る手順を省かない。臆病と呼ばれても、次の旅へ戻れることを仕事の一部と考える。

## 活かし方・接続案

余力が少ない間の身構を補う候補。自動撤退や回復の無限循環にはしない。低い余力を維持し続けることが必須の最適解にならない強さを検討する。

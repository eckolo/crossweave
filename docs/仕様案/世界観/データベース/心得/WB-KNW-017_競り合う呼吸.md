# 競り合う呼吸

相手の勢いに呑まれず、競り合う中で自分の踏み込む拍を掴む心得。

## 具体像

競技でも危険な対峙でも、相手より速く動くことだけが手段ではない。動きを見てから決める間に、自分の呼吸を置く。専用のライバルイベントを経なくても、探索での経験から習得する背景にできる。

## 活かし方・接続案

直前に他の主体が主行動を成立させた後の自分の主行動で、機転を補う条件案。誰の何の行動を参照するか、条件の保持期間、環境を含む適用範囲は設計側で要検討。相手の次の非公開行動を先読みする条件にはしない。新しい条件判定が必要なため、新効果案として分ける。

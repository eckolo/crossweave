# 道具を貸す手

自分の道具が別の手で働くところから、使い方を学ぶ心得。

## 具体像

巡礼路の修繕では道具が人から人へ渡る。辿り屋も場へ残した札の働き方を見て、次の一手を組み直す。相手が敵でも観察はできる。

## 活かし方・接続案

自分の由来の場札を他の主体が利用した際、機転を補う候補。相手に作用を渡す危険と対になる。由来の追跡や発動回数の制御が必要な新効果案。

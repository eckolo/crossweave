# 雨待ちの支度

雨が来てから慌てないよう、先に道具を置く心得。

## 具体像

雨番の仕事では栓を回す前に退避場所を作る。辿り屋も場を整える一手を、次の働きに備える時間として使える。

## 活かし方・接続案

場に出した後の最初の一致行動が守りに向く場合、身構を補う候補。置くだけで永久に守れる効果にはせず、適用回数や終了条件を必要とする新効果案。

# 二つの国の迷子

門の両側で住民扱いされるのに、どちらにも帰宅を認められない子がいる。

## 具体像

仮住民会は家族を知っているが、通行記録だけが本人を別の場所へ送ろうとする。国境の継ぎ目にある旧記録所へ辿ると、住所の書換えが人名と結び付いていたと分かる。

## 活かし方・接続案

本人の望む帰る場所を先に聞き、記録を調べる。正式な国籍の選択を強制せず、仮住所の維持や同行者の登録も後続案にする。奥へ進むのは制度の由来を知るため。

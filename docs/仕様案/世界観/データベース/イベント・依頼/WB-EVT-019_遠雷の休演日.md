# 遠雷の休演日

鋳造所の職人が盆地へ招かれた日は、誰も声を使わない声の休耕日だった。

## 具体像

顔なじみの聞き耳工が完成した鐘を見せに来る。一方、招いた住人は静かな市のごちそうを用意している。日付の間違いというより、片方は「仕事の音を聞いてもらう日」、片方は「仕事を休んでもらう日」と思っていた。主人公は以前双方と話した客として居合わせる。

## 活かし方・接続案

鐘を鳴らさず鋳肌に触れる、身振りで作業を教わる、休耕の終わった別の畑で音を確かめるなど、仕事をしている時とは違う職人に会える。短い立ち寄りだけでも成立する。深部探索へ広げるなら、音を試せる場所の現地調査を別の目的として置く。必ず危機や文化対立に発展させず、本人たちが笑って予定を変える結びも残す。

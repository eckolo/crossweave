# 村の色を取り返す

顔料を売っていた村で、家と橋から色が抜け始めた。

## 具体像

村は外からの盗掘を疑うが、ラルは採取量と白い季節の関係を気にしている。雨林の底に溜まる色を調べると、盗まれた色と自然に休んでいる色が混ざっている。全部を持ち帰れば森の回復が遅れる。

## 活かし方・接続案

橋を支える色の確保と、採取の仕方の調査を分ける。応急復旧、盗掘経路の遮断、次の季節までの代替生業を成果にできる。

# 優勝旗のその先

新しい競走路の終点を確かめる仕事に、先着を狙う走者が同じ方向から挑んでくる。

## 具体像

旗は入口から見えるが、近づく道が丘の裏へ続き、別の白線と重なっている。主催者もまだ完成した道を知らない。主人公の役目は勝者になることだけでなく、何が終点へ通じる道なのかを現地で確かめること。

## 活かし方・接続案

危険を冒す理由を、新しい経路の踏査と到達そのものに置く。走者とは利害が一部重なり、一部は競合する。勝負の結果と仕事の達成を分けてもよい。専用の順位計算や競争AIなしでも、先行者の痕跡・対象別の「挑む」・進む道の表現から内容案を作れる。予め必要な道具の所在を知る調達仕事にはしない。

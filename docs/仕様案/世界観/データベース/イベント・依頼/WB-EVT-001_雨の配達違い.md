# 雨の配達違い

畑へ届くはずの雨が、閉鎖した駅舎に降り続けている。

## 具体像

雨番組合から荷札の照合を頼まれる。奥の配水室に進むと、古い避難所への供給指示が今も生きていると分かる。避難所が無人なのか、誰かが使っているのかは現地で確かめる必要がある。

## 活かし方・接続案

荷札の追跡、避難者との接触、雨栓の切替が段階目標。配送の正常化だけでなく、分配の組み直しを報告案にできる。帰還後には町へ届く雨の匂いが変わる。

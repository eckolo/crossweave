# 根を向けた収穫祭

収穫前の実が一斉に空へ引かれ、果樹園ごと浮きかけている。

## 具体像

祭りの準備をする住人は、実を落とす仕事を辿り屋へ頼む。奥の古木へ進むと、上り水の流れが隣の園まで変わっている。接ぎ木が捕まえるのは侵入者だけでなく、逃げる土そのものでもある。

## 活かし方・接続案

果実を壊すだけでなく、水路と根の働きを調べる。収穫、支柱の確保、祭りの場所変更を組み合わせ、修繕後には食事や音楽の場面を置く。

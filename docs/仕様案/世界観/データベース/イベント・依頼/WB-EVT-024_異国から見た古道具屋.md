# 異国から見た古道具屋

異界の顔なじみが店を訪れ、主人公にはありふれた暮らしを珍しがる。

## 具体像

顔料採りが古道具屋へ来て、服を着替えても肌の色が移らないことや、看板の赤が毎朝収穫されないことに驚く。主人公は初めて「現地を知っている案内役」になる。見慣れた湯沸かし器や窓の外を、相手の問いから見直す。

## 活かし方・接続案

配達や別の旅のついでの短い来訪にできる。店先と茶の席だけで、主人公の日常も誰かにとっての異世界だと描ける。普通の品を全て強い道具へ写せるという性能保証にはしない。学校や町中の人間関係を一斉に増やさず、来客のために湯呑みを一つ選ぶ小さな行為で締めてもよい。

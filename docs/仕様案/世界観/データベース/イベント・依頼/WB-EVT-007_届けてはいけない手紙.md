# 届けてはいけない手紙

配達期限を過ぎた手紙が、受取人の家だけを探し続けている。

## 具体像

差出人は届けてほしいが、受取人は受領を拒んでいる。未着便局の記録から、灯台が古い宛名を増幅している疑いが出る。奥の保管庫には、別人へ書き直された封筒が何重にも重なっている。

## 活かし方・接続案

奥へ進む目的は強制配達ではなく、追跡が止まらない理由の特定。返送、保管、宛先の失効を相談し、手紙の本文を覗かずに済む手順も考えられる。

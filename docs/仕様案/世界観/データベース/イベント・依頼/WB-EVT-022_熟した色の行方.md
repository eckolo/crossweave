# 熟した色の行方

熟した果実を選ぶために借りた色見本が、雨林ではまだ育ちきっていない色だった。

## 具体像

逆さの果樹園の収穫人と顔料採りが、果皮の色を記録する試みを始めた。ところが雨林で育つ色は変わり続け、運んだ見本と果樹園に残した印が合わなくなる。果実は色だけでなく軽さでも熟れを示すため、どちらかの観察が全面的に間違っているわけではない。

## 活かし方・接続案

樹冠側の収穫枝と雨林の古い色層へ進み、色が採られた場所と時期、果実が軽くなった経過を確かめる。土地をまたぐ技術の試作と調査を案件にし、危険な輸入品を排除する話一辺倒にしない。返すものは完成した万能の規格ではなく、両方の観察を添えた見本帳でもよい。色と熟度の厳密な共通換算は定めない。

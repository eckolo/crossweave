# 消える一尺

橋の両端から測ると、真ん中の一尺だけが足りなくなる。

## 具体像

職人と測量蜂は互いの間違いを疑う。巣の奥の基準室には、成長した女王の歩幅と昔の目盛りが並存している。橋の継ぎ足しだけでは翌日にまた寸法が変わる。

## 活かし方・接続案

女王を傷つけず基準室へ辿り、どの単位がどこへ伝わるかを記録する。共通の基準点を置く、季節ごとに換算するなどの解決を考えられる。

# 雨の受取人

雨の駅から届いた礼状は、雨を頼んだ人ではなく、その雨で芽吹いた畑からのものだった。

## 具体像

雨の誤配を解決した後、駅を通じて食卓大陸から礼状が届く。配膳人は贈り主を知りたいと言うが、雨番の帳簿にあるのは町の客の名で、客は畑を知らない。自宅へ贈った天気の余りが別の土地へ回ったらしい。雨が役立ったことは確かで、以前の解決が失敗だったわけではない。

## 活かし方・接続案

雨の受け渡しを辿り、食卓の端から奥の発芽床へ進むと、誰がどんな意図で余りを分けたのかが分かる。現地を見るまで単なる親切か無断の転用かは決めない。帰還後は礼状だけを返す、次から余りを受け取る相手を決めるなどの結びがある。全世界共通の天気売買制度にせず、二つの土地にある個別の取り決めとして使う。

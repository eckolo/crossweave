# 値段の付いた帰り道

使っていた裏道の通行権が、本人の知らない間に競売へ出された。

## 具体像

鑑札商の燈子は買い戻す前に出品票を見たいと言う。市場の奥の原簿には、通行者本人ではなく古い目印の所有者を売主とする記載がある。代金を払っても別の権利が残れば再出品される。

## 活かし方・接続案

原簿へ辿り、目印と道の関係を確かめる。権利の訂正、共同保有、別路の開拓を候補とし、特定の通貨を必須にしない。

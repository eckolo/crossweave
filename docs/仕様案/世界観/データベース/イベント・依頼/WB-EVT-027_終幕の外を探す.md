# 終幕の外を探す

終わるたび次の見せ場が始まる物語で、演じる場所の外にある出口を探す。

## 具体像

英雄役の客の中には舞台を楽しむ者も、もう日常へ帰りたい者もいる。客席と舞台の境目は物語の進行で移り、見せ場を完璧に演じるだけでは出口へ近づけない。主人公は筋書きに書かれていない場所を辿り、演じる仕組みの奥へ進む。

## 活かし方・接続案

主役を待つ鎧との対決、拍手をやり過ごす観察、舞台裏へ進む突破を同じ探索に重ねられる。帰りたい相手を連れて出るなら通常帰還まで含める。すべての物語を侵略者とせず、残りたい者の遊びや表現が続く結びもある。専用の演技点や会話選択の正解を取得条件にしない。

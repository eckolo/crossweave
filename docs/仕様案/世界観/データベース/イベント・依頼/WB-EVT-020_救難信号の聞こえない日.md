# 救難信号の聞こえない日

かつて救出した潜り手が、今度は救難ではない調査への案内を申し出る。

## 具体像

乾いた深海で信号を辿って連れ帰った相手から、今日は事故がないと便りが届く。以前は通り過ぎるだけだった浮標の休み場で、相手は自分の仕事を見せてくれる。助けられた人がずっと保護される立場に留まらず、現地の知識を持つ人物として再登場する。

## 活かし方・接続案

深く潜る案件にするなら、以前の救出で気づいた分岐の先に、古い航路が今も続くか確かめる仕事を置く。案内人も深部の現状までは知らないので、既知の品を取りに行くだけにはならない。探索の同行が必要でなければ、入口までの見送りや地図への書込みだけで役割を表せる。救出済みの相手を再び遭難させる必要はない。

# 脱皮の内側を歩く

剥がれかけた山の殻の内側へ入り、まだ誰も歩いていない谷のつながりを調べる。

## 具体像

外からは谷の一部しか見えず、奥の出口候補は脈打つ膜の向こうに隠れている。危険な生き物も入り込み、古い岩と新しい地面では足の掛け方が違う。同行者や依頼人を必ず置かず、踏査記録の仕事や主人公の関心から始められる。

## 活かし方・接続案

深部へ到達して初めて得られる地形の知識を成果にする。脱皮を止める、山を治す、住人を助ける、という結末を必須にしない。未知の場所を見て戻ること自体に達成を置く。周期は物語上の条件で、実時間の締切・一度逃すと永久に入れない制限は未採用。

# 音を失った製造法

道具を打つ手順は残っているのに、完成品だけが働かなくなった。

## 具体像

聞き耳工は、手順に含まれていた音の返事が消えたと考える。閉じた冷却坑の先では、昔の作業音を食べて育った鉱層が振動を抱え込んでいる。盗難か故障かという最初の見立ては途中で変わる。

## 活かし方・接続案

製造記録、音の通り道、鉱層の順に踏破する。鉱層を砕くほか、新しい返事を作る実験も案件の出口になる。製法の再現と改善を別の成果として残す。

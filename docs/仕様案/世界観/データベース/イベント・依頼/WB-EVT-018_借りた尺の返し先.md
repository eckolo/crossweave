# 借りた尺の返し先

借りた板を元の長さにして返したのに、貸し手と借り手のどちらも「これでは足りない」と言う。

## 具体像

測量圏から国境の仮住民会へ、橋板とそれを測る尺が貸し出されていた。巣の一歩と国境で数える歩幅が違い、双方は丁寧に約束を守ったつもりでいる。主人公は返却の立会いを頼まれるが、通訳だけでは、最初にどの地点からどの地点までを約束したのか分からない。

## 活かし方・接続案

渡り場の奥に残る橋の受け口、巣の踊り、二つの借用記録を辿る。必要なのは正しい単位を世界へ押しつけることではなく、この貸借が何を支える約束だったかを確かめること。既に直した橋を再び壊して始めず、別の貸借や新しい区画の仕事にできる。返却後、店の預かり証へ小さな寸法図が添う程度の変化も使える。

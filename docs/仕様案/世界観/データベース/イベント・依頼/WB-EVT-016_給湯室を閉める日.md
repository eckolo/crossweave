# 給湯室を閉める日

建物の改装が決まり、庭へ水を運ぶ給湯室が使えなくなる。

## 具体像

世話人は庭ごとの移動を望むが、窓越しの同僚は外へ出たことがない。戸棚の奥から庭の水源へ辿り、蛇口、差し入れ、建物の記憶のどれが春を支えるかを調べる。

## 活かし方・接続案

奥まで確かめる仕事を、世界全体の危機に頼らず作る。別の入口、世話の交代、庭の縮小を相談できる。帰還茶の場所が移るだけでも長く残る変化になる。

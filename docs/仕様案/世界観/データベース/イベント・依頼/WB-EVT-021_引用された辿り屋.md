# 引用された辿り屋

主人公が言った覚えのない約束が、旅先で「辿り屋の言葉」として待たれている。

## 具体像

未着の港で引用の群れが運ぶ短い言葉に、主人公の以前の返答と、別の誰かの約束がつながってしまった。「また見てくる」という一言が、誰かの帰還を請け合った言葉として届いている。便局は誤りらしいと分かっていても、元の受取人を特定できない。

## 活かし方・接続案

港の奥の保留便と、引用を聞いた者の記憶を辿り、何を誰に伝え直すべきかを探す。噂を全部消すことや、その場で不可能な約束を引き受けることを解決にしない。必要な一言を本人から届ける場面で、無口な主人公にも主体性を出せる。噂が自動的に実体の偽主人公を生む等の追加法則は、この案の前提に含めない。

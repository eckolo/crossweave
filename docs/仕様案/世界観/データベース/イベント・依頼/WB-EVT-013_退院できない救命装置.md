# 退院できない救命装置

回復した患者が、退院口を通るたび病室へ戻される。

## 具体像

担架係は患者が装置の一部として登録されていると疑う。診療区の奥の制御室に進むと、退院判定と重力の支えが同じ系統にまとめられている。装置を切れば出られても、帰路に耐えられない人がいる。

## 活かし方・接続案

支えの代替、患者の移送、判定の切替を順に準備する。途中までの安全な足場も成果とし、一度の訪問で全員を救い切る条件にはしない。

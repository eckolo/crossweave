# まだ渡さない預かり物

先代から長く預かっていた品を、受取人は「まだここで預かっていてほしい」と言う。

## 具体像

店の棚の古い包みに返事が届き、主人公は巡礼路の修繕団へ受取りの意思を確かめに行く。受取人は生きて仕事を続けているが、道の移動でかつての作業小屋へ戻れていない。包みは新しい住まいの祝いに渡す予定の、ごく普通の道具だった。

## 活かし方・接続案

必要なら巡礼路の深部へ進み、移った小屋が今どこへつながるかを調べる。先代の記憶は手掛かりになるが、今の希望は本人に聞く。保管継続、別の場所へ渡す、約束を改めるなどを残し、預かり物を消すことだけを成功にしない。先代の仕事の全てを未解決の負債にせず、果たし続けてきた約束の一つとして扱う。

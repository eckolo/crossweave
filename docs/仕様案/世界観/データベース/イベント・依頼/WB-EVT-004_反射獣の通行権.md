# 反射獣の通行権

安全とされた隊商路が、硝子角の獣の出産地と重なった。

## 具体像

隊商と獣のどちらが先に道を使っていたかは、現在の地図では分からない。草原の奥の古い道標には、以前の群れと人の足跡が別々の高さで残っている。獣を追い払っても幼獣が道へ戻ってくる。

## 活かし方・接続案

巣の奥と古道の接点を調べ、季節ごとの通行案を作る仕事。共存の準備として危険な探索を要する。再訪では荷車の時間帯や草の踏まれ方で結果を見せる。

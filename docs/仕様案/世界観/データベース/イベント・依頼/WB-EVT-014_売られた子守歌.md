# 売られた子守歌

盆地の子守歌が売り出され、歌った家では誰も眠れなくなった。

## 具体像

歌い手は販売を認めたが、声の休耕まで買い取られた覚えはない。集音小屋の奥で、同じ息継ぎが休みなく複製されている。買った側も安眠を求めただけで、元の家の不眠は知らない。

## 活かし方・接続案

記録、採音場所、増幅元を追う。販売の全面禁止以外に利用時間や別の歌の育成を提案できる。手掛かりとして拍手の偏りや歌の切れ目を使う。

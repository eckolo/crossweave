# 食べられる集落

次の配膳で、皿の縁の集落が料理として運ばれてしまう。

## 具体像

住人は昔から食卓で暮らすが、今回の盛り付けは知らない。配膳人への抗議だけでは献立の出所が分からず、食卓中央の献立台まで辿る必要がある。皿を止めると食事を待つ別の地域も困る。

## 活かし方・接続案

献立の調査、避難路の確保、集落の移転先探しを並行する。食卓全体の停止だけを正解にせず、皿の交換や配膳順の変更も後続案にする。

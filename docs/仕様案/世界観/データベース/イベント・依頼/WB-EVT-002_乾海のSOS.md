# 乾海のSOS

海のない深海から、今も潜水船の救難信号が届く。

## 具体像

潜りの師弟は信号の年代が合わないと気付く。海溝の奥には、乗員を降ろした後も救命袋を抱える作業機がいる。信号は録音ではなく、袋の内側から更新されている。中身は調査するまで決めつけられない。

## 活かし方・接続案

圧力の段差を越えて信号源へ到達する動機。記録回収、作業機の退避、袋の安全確認を別々に評価できる。全てを運べない場合も次回の足場を残す。

# 一晩だけ止まる巡礼路

止まらない巡礼路を、一晩だけ休ませてほしいという依頼。

## 具体像

修繕団には道を進めたい仕事があり、宿には歩き続けられない客がいる。里程骨の折れ目を塞ぐだけでは休止場所も消える。道の足元へ潜り、骨の継ぎ目と歩調の変わる場所を確かめる。

## 活かし方・接続案

踏破して得るのは停止させる位置の知識。休止と再開の両方を試す案件にする。副目的として行方不明の荷車や、古い宿帳の所在も追える。

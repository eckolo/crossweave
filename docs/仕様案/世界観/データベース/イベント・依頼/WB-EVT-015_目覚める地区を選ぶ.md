# 目覚める地区を選ぶ

予定外の寒波で、都市の全地区を同時に起こす熱が足りない。

## 具体像

住人は優先順の決定だけでなく、古い配熱路の調査を頼む。巨人の眠る下層へ進むと、未使用区画へ熱が逃げている可能性が出る。調査前には節約で足りるかも分からない。

## 活かし方・接続案

配熱路の踏破で判断材料を増やす。段階的な起床、移住、漏れの修繕を比較し、犠牲者の二者択一に固定しない。次の訪問では開いた店や眠る窓で結果を見せる。

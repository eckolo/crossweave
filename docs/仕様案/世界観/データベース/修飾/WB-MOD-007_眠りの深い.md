# 眠りの深い

起こすには時間が掛かるが、一度働くと力を逃しにくい修飾。

## 具体像

冬眠都市では眠りの長さを故障と区別して扱う。心得の個体へ付く場合も、旅の序盤から調子が出るとは限らない癖として表現できる。

## 活かし方・接続案

機転を助ける心得の発動開始を遅くし、開始後の補助を増やす候補。区間・探索のどちらで開始を数えるかは未決定。現行の装備制限方式をここで選ばない。

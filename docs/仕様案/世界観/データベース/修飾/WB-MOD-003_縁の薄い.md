# 縁の薄い

触れているのに、輪郭が周囲へほどける修飾。

## 具体像

道具の端を見続けるほど背景と区別しづらくなる。持ち主を消すのでなく、相手が輪郭を捉える手間を増す。

## 活かし方・接続案

攪乱を増やす代わりに身構を減らす候補。両方の数量に意味がある札や心得の個体へ限定し、失う身構が元からない対象への無償強化を避ける設計が必要。

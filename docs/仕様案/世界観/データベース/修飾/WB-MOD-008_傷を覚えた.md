# 傷を覚えた

一度受けた負荷を、働き方の偏りとして残す修飾。

## 具体像

傷跡そのものを集める思想ではなく、道具や経験が苦手な状況を覚えるという表現。手入れで見た目の傷が消えても癖は残り得る。

## 活かし方・接続案

守りを助ける心得に対し、余力が少ない時は強く、十分ある時は弱く働く候補。回復を避ける遊びだけが有利にならない調整を要する。同種心得の同時使用可否は装備設計側で扱う。

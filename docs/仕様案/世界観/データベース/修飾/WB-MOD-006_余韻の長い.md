# 余韻の長い

使い終わった後の働きが、その場へ長く残る修飾。

## 具体像

鈴なら鳴り止んだ後の耳、布なら外した後の温もりに癖が現れる。長いという語はまず印象であり、独自の持続時間を自動追加しない。

## 活かし方・接続案

主行動の機転補助を減らし、場での機転補助を増やす候補。双方の数量を持つ札が対象。持続時間の延長へ発展させる場合は新効果として切り分ける。

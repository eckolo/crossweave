# 腰の重い

動き始めるまでが遅く、始まると重く働く修飾。

## 具体像

札を開く感触は固いが、具体的な道具になった瞬間に重さが落ち着く。遠雷や底抜けなら由来との対応を描きやすい。

## 活かし方・接続案

札の突破を増やす代わりに間隔を長くする候補。単に上位品を作らず、隠蔽を捉える手段や相手の手数との兼ね合いを残す。数値と併用制限は未決定。

# 片道の

一度の仕事へ力を集め、戻る道筋を持たない修飾。

## 具体像

開くと札の折り目が伸び切り、役目を終えると道具の形がほどける。永久に残る強化品とは違う収集上の位置づけを検討できる。

## 活かし方・接続案

主行動を強める代わりに捨てる時に消滅する札候補。札実体の消滅と収集済み原本の削除を混同しない。有限品の獲得・再生成・所持扱いは既存分類と照合して決める。

# せっかちな

開く前から働き始めたがる修飾。

## 具体像

手の中で端が動き、道具を広げる動作も急かされる。短い仕事を何度も任された不思議に現れるという解釈ができる。

## 活かし方・接続案

札向けに、間隔を短くする代わりに手札の期限も短くする候補。期限のない対象へそのまま適用しない。通常の消滅時点を守り、心得への付与は別の代償設計が必要。

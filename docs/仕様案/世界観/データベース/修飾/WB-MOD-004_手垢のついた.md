# 手垢のついた

多くの手を渡り、置かれた場所に馴染みやすくなった修飾。

## 具体像

汚れていること自体が魔力になるのでなく、異なる持ち方に応じて働いてきた癖が残る。鑑定帳には手入れの跡と使い方が記される。

## 活かし方・接続案

場での補助を増やす代わりに主行動の作用を弱める候補。相手にも強い場を渡す。由来によって利益を変える追加案は別途検討し、所有者だけが使える札にはしない。

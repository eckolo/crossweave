## 1. 今回の共通前提と、前案からの変更

ユーザーは前案F/R06のプレイヤー側の方向を気に入り、「道具に宿す」から「取り込んだ不思議を具体的なツールにする」へ発展させる案を提示した。取り込む対象は怪異だけに絞らず、夢の具現化、現実を侵食する物語、世界の裏で培われた魔法、かつて存在したらしい文明の遺構等を広く含める。これを共通の土台として、舞台を再び広く比較する。

**不思議の出所はさまざまでも、主人公はその働きを具体的な道具にして扱う。** 元から持っている傘や手袋へ力を付けることを基本にせず、不思議そのものから錠前・針・ふいご・灯具等の形と機能が生まれるという方向で考える。

この提案の利点は、探索先が変わってもプレイヤーの行為に一貫性があること。「次はどんな不思議があり、どんな道具になるのか」という期待を、札の選択肢が増える楽しさへつなげられる。敵を倒して武器を拾う以外にも、場所の法則、夢の出来事、物語の展開、魔法の働きを成果の題材にできる。

全ての不思議が一つの魔力・同じ文明・単一の異界に由来する必要はない。共通化するのは、ひとまず主人公がそれらを道具として扱えるという能力。由来の異なるものが共存する理由は、舞台ごとに比較する。

人間という種族、調査員という職業、現代という時代、専門組織への所属まで一括選択されたとは扱わない。今回の案では、道具を使う探索者として見せる方向を共通にし、機械・人形・生体外殻・身体変形を再び中心候補として並べない。

初回8案は[0.1](https://github.com/eckolo/crossweave/blob/b83c63e7fc4570198742818d3d4baecc2da65f86/docs/仕様案/世界観/世界観候補.md)、前回6案は[0.2](https://github.com/eckolo/crossweave/blob/1ae9f448f5491c01e49f64ce884a2cb0f976ae38/docs/仕様案/世界観/世界観候補.md)に履歴を保持する。W07/W08の小人・音楽方向は今回の中心へ戻さない。

## 2. 不思議が道具になる感覚

道具化の例は、元の不思議が持つ働きを具体的な形で使えるようにする。単に「怪異から攻撃札」「夢から防御札」と分類するよりも、由来と使い方が結び付いた方が収集の魅力を作りやすい。

| 出会う不思議の仮例 | 引き出す働き | 道具になる姿の仮例 |
|---|---|---|
| 内側からは誰も出られない部屋 | 閉じ留める | 閉鎖の錠前 |
| いつまでも落ち続ける夢 | 下へ引かれる力が尽きない | 落下の錘 |
| 物語から漏れ出た、家を吹き飛ばす息吹 | 空気を押し出す | 大息のふいご |
| 影を地面へ縫い留める秘術 | 影を固定する | 影縫いの針 |
| 遺構の中で何千年も熱を逃がさない炉 | 熱を保つ | 蓄熱の灯具 |

いずれも表現の仮例。実際の効果・性能・適用対象・入手条件はまだ採用しない。道具には武器、防具、測る物、切る物、結ぶ物、照らす物などを含められる。現行の探索と戦闘を共通の札で扱う方向にも接続できるが、道具ごとの別操作や自由物理シミュレーションを必要条件にはしない。

### 魅力を保つための検討方針

- **元の不思議の性質を残す。** 「閉じ込める部屋」から理由なく万能鍵を作るより、閉じ留める錠前にすると意味が伝わりやすい。反転・応用を扱うなら、変換の根拠を見せる。
- **道具として使う姿を想像できる。** 強い概念名だけで終えず、手に取る形と使う動作を伴わせる。全てを剣や銃へ変える必要はない。
- **未知の由来と、操作の分かりやすさを両立する。** 不思議の正体が未解明でも、今その道具で何ができるかはプレイヤーに分かるようにする。
- **収集するたびに使用規則を増やし過ぎない。** 豊かな由来と見た目は共通の札操作へ載せる。個別の儀式・別ゲーム・新たな資源管理を全道具へ付けない。

これらは今回の設計提案であり、道具の製作手順や変換の唯一解を確定するものではない。どこまでを自動的な能力とするか、複数の道具形態を選べるか、同じ道具をどの頻度で現せるかは後の検討対象。

## 3. プレイヤーを共通にした舞台8案

全案で、怪異・夢・物語・魔法・文明遺構等の複数の出所を扱える。いずれか一種類の不思議に世界を閉じない。そのうえで、不思議が日常・社会・地理とどう関わるか、出かける動機、帰る場所を変えて比べる。

| ID | 舞台 | 不思議と世界の関係 | 探索の主な気分 |
|---|---|---|---|
| S01 | 日常の裏側に広がる世界 | 普段は隠れているが、身近な場所から入れる | 見慣れた景色に別の奥行きを発見する |
| S02 | あらゆる境界が交わる街 | 様々な不思議と人の暮らしが接している | 街のつながりを知り、自分の居場所を持つ |
| S03 | 世界の継ぎ目を巡る旅 | 土地ごとに現実の性質や歴史が違う | 道具箱に旅の足跡を増やしていく |
| S04 | 不思議に書き換えられた後の世界 | 元の現実と侵入したものが新しい土地を作った | 失われた世界を探り、今の暮らしへつなげる |
| S05 | 内部に世界が続く巨大遺構 | 出所の違う不思議が、一つの構造物に積層する | 未知の構造と、その存在理由を知る |
| S06 | 巨獣の背と内側にある世界 | 生体・呑み込んだ歴史・巨獣の夢が接する | 大きな生き物の中でしかできない冒険 |
| S07 | 失われたものの漂着地 | 現実から失われたものが別の場所で続いている | 忘れられたものに出会い、その働きを持ち帰る |
| S08 | 不思議を使って暮らす文明 | 道具化された不思議が社会を支えている | 未知の不思議から新しい使い方を見いだす |

### S01 日常の裏側に広がる世界

見た目は現代に近い日常。地下街の閉鎖区画では昔話の夜が明けず、病院の一室から患者の夢が広がり、山中のトンネルの奥には建造年代の分からない設備が動いている。

主人公は、自分の暮らす場所から不思議へ足を踏み入れる探索者。依頼の調査、巻き込まれた人のための探索、個人的な好奇心等を動機にできる。帰る場所は小さな工房や住まいが似合う。

**魅力：** 現実の物との比較が効き、不思議な道具を手にした感覚が強い。探索から戻って日常へ帰る緩急も作りやすい。

**検討点と対応：** 単なる現代怪異集へ寄らないよう、夢・物語・秘匿された魔法・文明遺構等に異なる探索の手触りを持たせる。外に知られにくい理由は必要だが、最初から万能の隠蔽組織を置いて全てを説明しない。現代・秘密主義・調査業務はこの舞台案の要素であり、プレイヤー能力自体の必須条件ではない。

### S02 あらゆる境界が交わる街

街の地下鉄が古代遺構の通路を走り、夜だけ夢の住人が店を開き、ある通りでは上演された物語が実際に起きる。異なる場所や時代の境界が接する街で、人々が折り合いをつけて暮らしている。

主人公はこの街を拠点に、周縁や閉鎖された区画へ出かける。暮らしの困り事、由来不明の道具、街の成り立ちが探索の動機になる。同じ工房へ帰り、探索先や顔見知りを増やす体験に向く。

**魅力：** 場所・住人・手に入れた道具が結び付きやすい。怪異だけでなく、奇妙だが平穏な暮らしやユーモアも描ける。

**検討点と対応：** 何でもある街にすると意外性を失いやすい。日常的に知られた区画と、まだ人の理解・利用が及ばない領域を分け、地区ごとの性質と歴史を保つ。商売や住民交流を厚くするかは後で決め、経営ゲームを自動追加しない。

### S03 世界の継ぎ目を巡る旅

世界には、隣接していても成り立ちの違う土地がある。夢が地形になる盆地、物語の出来事が繰り返される王国、魔法を密かに育ててきた森、誰も起源を知らない機械の高原を、旅人が渡っていく。

主人公は道具化の能力を頼りに各地を訪れ、足りない手段を増やしながら旅を続ける。滞在先の工房や旅の拠点から個々の探索へ出る構成にできる。旅の最終目的は未定とし、地図作りや特定の不思議の追跡等を候補にできる。

**魅力：** 道具箱が旅の記録になる。大きな舞台の変化と、別の土地で得た手段を今回の土地へ持ち込む面白さを強く出せる。

**検討点と対応：** 地方ごとに切れた短編集にならないよう、道具の出自、人の往来、遠くへ続く疑問等で旅をつなぐ。各土地で一から能力を失う方式にはしない。旅行の描写を、移動費管理・常時移動拠点・オープンワールド実装の採用へ広げない。

### S04 不思議に書き換えられた後の世界

過去の大きな変化によって、夢、物語、隠れていた魔法、失われた文明の痕跡が現実に重なった。元の街路の先に童話の森があり、ビルの中に昔の海が残り、線路は起源不明の都市へ続いている。

現在は変化後の暮らしが始まっており、主人公は安全な生活圏から外へ探索する。道具は、危険な不思議を今の暮らしでも扱える手段にする成果となる。記録の回収、新しい道の調査、まだ見ぬ土地への到達などを動機にできる。

**魅力：** 現実と幻想が混ざる景観に強い個性がある。持ち帰った不思議が役立つ理由も分かりやすい。荒廃だけでなく、変化後の美しさや新しい文化を描ける。

**検討点と対応：** 世界崩壊の阻止や時間制限を主人公へ常に背負わせると、反復探索と好奇心の余地が減る。変化から時間が経ち、人が暮らせる段階を候補の基本像とする。集落の建築・物資経済・恒久的な地域復旧は別途の追加案として扱う。

### S05 内部に世界が続く巨大遺構

建造者も全体像も分からない構造物の中に、都市、庭園、海、機械区画が続く。眠っている区域では夢が実体化し、記録庫の物語が廊下へ広がり、深部では現代の魔法と似て非なる仕組みが動く。

主人公は比較的安全な居住区を足場に、未知の区域へ向かう。より深い場所への到達、遺構の目的の解明、道具の出所に関する手掛かり等を目的にできる。巨大でも無限とは決めない。

**魅力：** 一つの巨大な謎を追いながら、景観と不思議を幅広く変えられる。探索の先が気になる構成と、持ち帰った道具で未知の場所へ挑む構成が噛み合う。

**検討点と対応：** 全てを「遺構のシミュレーション」と説明すると、異なる由来の魅力が薄れ得る。遺構が生んだもの、外から持ち込まれたもの、後の住人が育てたものが共存する余地を残す。区域の違いは気まぐれな切替ではなく、配置・歴史・用途の手掛かりでつなぐ。

### S06 巨獣の背と内側にある世界

巨大な生き物の背に街があり、内部には呑み込まれた文明や土地が残る。巨獣の眠りから夢が染み出し、昔飲み込んだ本の物語が一つの谷を作り、生体の奥では古い魔法や設備が作用している。

主人公は道具を携えた探索者のまま、その背や内側へ出かける。身体を生体部品へ変える設定は必要ない。脈動する通路、記憶に触れた区画、人工物のある空洞から、それぞれの不思議を道具にできる。

**魅力：** 生きた世界の規模と動きそのものが冒険になる。巨獣の生態、呑み込んだものの来歴、現在の住人という違う時間の層を重ねられる。

**検討点と対応：** 何でも飲み込んだとするだけでは舞台が雑多になる。体内の流れ、器官、呑み込まれた時期などを区域のつながりに使う。夢・物語を巨獣の体内に置けるが、全てを巨獣一体の創造物へ統一しない。臓器の生々しさ、巨獣を救う使命、周期変動の追加ルールは未決定。

### S07 失われたものの漂着地

誰も覚えていない夢、読まれなくなった物語、継承が途絶えた魔法、地図から消えた文明が、どこかに漂着している。忘れられたものは単なる記録でなく、その場所では今も働き、生きている。

主人公は漂着地を巡り、そこにある不思議を持ち運べる道具にする。住人の頼み、道具の来歴探し、まだ訪れたことのない場所への好奇心が動機になる。「全てを救わなければ消える」という使命に限定しない。

**魅力：** 道具を得ることに「失われかけた働きを、新しい形で持ち帰る」という意味が加わる。静かな街、終演後も残る舞台、使い手のいない魔法設備等、情緒と収集の魅力を結び付けられる。

**検討点と対応：** 忘却を便利な説明にし過ぎると、知識保持や再挑戦の一貫性が崩れる。来歴として失われていても、探索先として存在した後の性質は把握・再利用できるようにする。全てを悲しい話にせず、新しい住人の生活や奇妙な明るさも含める。

### S08 不思議を使って暮らす文明

瓶に入れた夢が照明になり、約束に従う橋が川を渡り、古い物語の暖炉が街を暖めている。道具化された不思議が社会を支え、その外側には未解明の現象・古代設備・新しく現れる怪異がある。

主人公は、新たな不思議を見つけて具体的な道具にできる探索者。未知の素材や使い方を求める依頼、自分の道具を増やす関心、街の道具では到達できない領域への挑戦が動機になる。職人・独立した採集者等の立場を比較できる。

**魅力：** 道具化する能力が世界の暮らしと直結する。既存の使い方を知ったうえで、その先の新しい発見へ向かう楽しさがある。魔法だけでなく、夢・物語・遺構の異なる仕組みが生活の中へ入り込める。

**検討点と対応：** 不思議を全て分類・工業化すると、発見が製品の部品集めに寄り過ぎる。扱えるものは一部であり、社会の理解の外にある働きを探索の中心へ残す。誰もが主人公と同じ能力を持つか、製法が職人に限られるかも未決定。製作・販売シミュレーションを自動追加しない。

## 4. 今回の比較で見たい違い

| 好みに関わる問い | 比較する候補 | 違い |
|---|---|---|
| 不思議は身近な日常から遠い方がよいか、暮らしの中にある方がよいか | S01／S02・S08 | 日常との落差／不思議と暮らす親しみ |
| 一つの場所を深く知りたいか、場所を渡っていきたいか | S02・S05／S03 | 拠点や構造への愛着／旅と景観の変化 |
| 探索の大きな背景に何が欲しいか | S04／S05／S06 | 変わった世界の来歴／巨大な人工物の謎／生き物の生態と歴史 |
| 道具を持ち帰ることにどんな気分が欲しいか | S07／S08 | 忘れられた働きを残す／新しい使い方を増やす |

現段階で全案を一つへ混ぜる必要はない。「主な舞台」と「そこに存在する探索先」を分ければ、魅力を保ちながら複数案を使える。例えばS02の街を拠点にS05の遺構へ入る、S03の旅の途中にS06の巨獣を訪れる構成が可能。

ただし、その混合を今回の既定案にはしない。S05やS06の内側だけで世界全体を構成するからこそ生まれる魅力もある。全舞台を短いエピソードとして消費する方式が、常に最も幅広く楽しめるとは限らない。

能力と舞台の接続を分かりやすく見る候補はS01/S02、旅の拡がりはS03、規模や景観の強さはS05/S06、収集の情緒はS07等。それぞれの魅力は作者側の仮説であり、ユーザーの選好順位を取得した記録ではない。

## 5. 札・共有循環との接続案

プレイヤー能力の魅力を、現在の共通ルールへ接続する際の整理。以下の対応は提案であり、今回の舞台比較のために新しい採用仕様へ昇格させない。

| 論点 | 接続の候補 | 区別しておくこと |
|---|---|---|
| 札が何を表すか | 不思議の働きと、その利用手段を札で扱う。主人公は具体的な道具として現す | 札が世界内で紙の現物か、道具の設計・再現の表現かは未決定 |
| 同じ札の他者利用 | 元の不思議と主人公の道具は、同じ働きの異なる現れ方。使われた働きが循環し、敵・環境にも渡る | 敵に主人公と同じ道具化能力を必須にせず、通常の札性能は同じ。主人公しか使えない札を追加しない |
| 現地での取り込み | 共有循環で手元に来た札を、一時的に道具として使う描写に接続できる | 対象選択による任意吸収・確定取得や、敵を倒すと即座に恒久取得する規則は未採用 |
| 帰還後の成長 | 持帰り成果から、次回自分で準備・再現できる手段を増やす | 現地の借り札の現物をそのまま恒久在庫にしない |
| 成長ポイントと用途限定報酬 | 道具化を支える成長と、特定の働きの再現に必要な成果等を比較できる | 成長の作用先・素材名・用途・費用は設計側と検討。D43だけでレシピ必須にしない |
| 一致と場作用 | 同系統の働きを接続したときに道具の作用が成立する等の表現が考えられる | 一致必須・不一致設置・場補正と主効果の区別を維持。道具だから常時使えるとはしない |
| 失われる札 | 現地の働きを支えていた出現元が去れば、その由来札は既存の退場規則で消える | 回収山内は退場時、他者領域・場の分は次回収時まで残る。全道具が永久所有物という説明を避ける |

主体ごとの見た目を変える場合でも、使用者が変わっただけで札性能を変えない。道具と元の現象の対応を画面で追える必要があり、具体的な表示はUI担当へ別途提案する。現段階で既存UIを更新しない。

## 6. 今回の到達点と次の比較

- プレイヤーの方向は、ユーザー提案「不思議を道具化する」を今回の共通前提として扱った。前案Fを怪異・既存道具への付与・調査員という職業ごと継承していない。
- 取り込む対象を複数の出所へ広げた。共通の起源・資源体系へすぐ還元せず、各出所の違いを残す。
- 舞台はS01〜S08の8案を比較材料として用意した。正式な選択、能力名、主人公設定、具体的な札・数値、道具化操作は未決定。
- D44に従い、各探索先の攻略傾向と狙う成果の系統を維持しつつ、遭遇の組合せ等の変化を許容する。夢や物語の自由さは、攻略上の法則が無制限に変化する根拠としない。
- D45の、敵・環境の強さをプレイヤー成長へ自動追随させない基本方針も維持する。世界観上「不思議は常に使い手と同じ強さになる」等の逆の前提は置かない。
- 次は気になる舞台について、暮らし・探索先・現地の不思議・得る道具・帰還後の期待を同じ粒度の短い一周で比較する。舞台が決まる前に個別の材料・価格・レシピを詰める工程には進まない。

## 1. 今回の反応と、案の組み直し方

ユーザーは、探査機のようにパーツやアクションを札に割り当てる方向を面白いと評価した。同時に、夢・物語を環境として利用し、取り込んでアクションにする発想も残したい。初回W07（小人）・W08（音）はイメージからずれる。W03（巨獣）は舞台としてよいが、取り込んで利用するループには追加の要素が必要との評価。

この反応から、今回の比較軸を「何を探索するか」に加え、**何を取り込み、それが自分の何になるのか**へ移す。パーツの具体性と、夢・物語の自由さは両立できるため、両方を持つ案を含める。機械やSFに一本化する判断、全候補を混ぜる判断は得ていない。

| 軸 | 今回比べる幅 |
|---|---|
| 主体 | 自律探査機／夢に入る機械／物語の人形／魔法生命／生体外殻の探索者／人間の調査員 |
| 取り込む対象 | 機構と動作／夢の現象／物語の役割／魔法現象／生体と文明の機能／怪異の振る舞い |
| 取り込んだ先 | 機能部品／夢を再現する装置／衣装と所作／自分の身体／変形する外殻／携行道具 |
| 主な楽しさ | 組み替えて使う／不思議なものを具体的に動かす／役割を借りる／自分が変わる／異質なものを共存させる／危険を手なずける |

札を出すたびにパーツが永久装着される等の規則は、この比較から追加しない。「取り込む」には、探索中の共有循環で一時利用することと、成果を持ち帰り次回から準備できることの二つがある。両者を分けると、現地での変化と帰還後の構築の両方を描ける。

初回8案は[0.1の保存版](https://github.com/eckolo/crossweave/blob/b83c63e7fc4570198742818d3d4baecc2da65f86/docs/仕様案/世界観/世界観候補.md)に保持する。W07/W08とそれらを含む混合案は今回の提示候補から外す。過去案を削除して存在しなかったことにはしない。

## 2. 今回の6案

| ID | 案 | 何を自分の手段にするか | 初回案との関係 |
|---|---|---|---|
| R01 | 組み替わる探査機と巨大遺構 | 敵や設備の動作を、機体の機能として再現する | W01を具体化。機械だけでも成立する比較の基準 |
| R02 | 夢を実装する機械 | 夢の現象を、機械の部品・動作に変える | W01＋W04。ただし夢の中身まで機械に統一しない |
| R03 | 物語をまとう人形 | 登場人物・道具・舞台の役割を、自分の衣装や所作にする | W06＋パーツの具体性 |
| R04 | 現象から身体を作る旅人 | 土地の魔法現象を、自分の身体や技として借りる | W02を、術を覚える人から取り込みで変わる主体へ発展 |
| R05 | 文明を呑み込む巨獣 | 巨獣の生体機能と呑み込まれた文明の機能を、外殻に再現する | W03へ異質な機能の源と取り込む器を追加 |
| R06 | 怪異を道具に宿す調査員 | 怪異の振る舞いを、人間の持つ道具で扱う | W05＋手段を身近な物に結び付ける具体性 |

以下は世界観・表現の案である。札名・能力・入手方法・属性系統・成長対象の正式採用ではない。例は変換のイメージであり、環境を選んで即座に任意の札へ変換できる能力や、その札を必ず入手できる規則を示さない。

### R01 組み替わる探査機と巨大遺構

主人公は、失われた機能を補いながら進む自律探査機。巨大遺構の深部へ到達するため、出会った機械や設備の働きを自分の一部として再現する。札は「持ち歩く武器の一覧」より、機体がその時に実行できる機能と動作を表す。

| 遭遇したもの | 自分の手段になる姿の例 |
|---|---|
| 圧搾機の動作 | 圧縮腕による打撃 |
| 通路を塞ぐ隔壁 | 展開装甲による防御 |
| 防衛機械の加速動作 | 突進や姿勢変更 |

取り込む前から用途を想像しやすく、機体が現地の機構に染まっていくのが魅力。出発時の構築は機能の準備、現地の借り札は一時的な機能の再現、帰還後の解放は安定して準備できる設計の取得と読める。

共通の作動基盤を遺構・機体・敵が使うため、自分の動作も相手へ渡る。属性一致は対応する動力・制御系統への接続として表せる。札の主効果と場に残した際の補助作用は区別する。

配分型ポイントは機体の成長へ、用途限定報酬は部材・設計の取得へ接続できる。具体的に何の能力を伸ばすかは設計側と決める。

**この案の強みは、札と動作の関係が明快なこと。** 課題は、機械部品だけで探索先の驚きをどこまで作れるか。取り込んだ機能が一時的に失われる表現には、「現物を永久装着した」との誤解を避ける整理が必要。

### R02 夢を実装する機械

人や巨大な存在の夢に入るために作られた機械。夢の中で見た現象を、自機が使える装置や動きとして再現する。金属の機体が、夢から得た不可能な機構を備えていく。

| 夢の中で出会うもの | 自分の手段になる姿の例 |
|---|---|
| どこまでも落ち続ける夢 | 落下を打撃に使う動作 |
| 一面の鏡でできた部屋 | 鏡面の装甲を展開する防御 |
| 誰かに追われる夢 | 追跡の勢いを帯びた突進 |

舞台は水没した駅、机の下に広がる街、空へ続く寝室など、機械である必要がない。探索の目的は、持ち主を目覚めさせる手掛かりや、失われた記憶の核の回収等を比較できる。自機の出自を探す旅も候補だが、主人公の個別物語はまだ固定しない。

機械も夢の中では夢を構成する一要素となり、敵と環境も同じ現象を取り込む。自分の機械的な動作が夢の住人の手段になる逆流も描ける。属性は現象の系統を主にするか、機械側の機能へ翻訳した系統にするかを次段階で比較する。

持参構築は再現可能な機能、借り札は現地の夢から一時的に得た働き。配分型ポイントは機体や再現能力の成長、用途限定報酬は夢の核・再現用の型に当たる。

**具体的な機体と、抽象的で自由な探索先を両立する案。** ただし夢から部品への翻訳が恣意的だと札が読めなくなる。「夢の元の性質が動きにも残る」ことを重視したい。機械設定と夢設定の用語を増やし過ぎる負担もある。

### R03 物語をまとう人形

特定の役を持たない人形が、壊れた物語の中を渡る。登場人物の役割、道具の働き、舞台の性質を借り、自分の衣装や動きにする。物語を読むだけでなく、その一部を演じられるようになる。

| 物語の中で出会うもの | 自分の手段になる姿の例 |
|---|---|
| 城門を守る騎士 | 鎧と、受け止める所作 |
| 旅人を阻む茨の森 | 茨の腕と、打ち払う動作 |
| 獲物を追う狼 | 脚や仮面と、飛びかかる動作 |

人形を使う理由は、身体や衣装を取り替えることと、別の役を演じることがどちらも自然だから。自分の顔や姿を得る、物語を修復する、失われた登場者を探すなど、探索動機を選べる。

同じ物語の登場者と舞台は共通の役割から成る。人形が持ち込んだ「守る」役を敵が借りるなど、役割の移動は双方向。属性は対立・庇護・潜伏等の役割の系統という案があるが、分類は具体札との読みやすさから検討する。

持参構築は自分で演じられる役の準備。現地で一度役を借りることと、帰還後に次回も選べる役が増えることを分けられる。配分型ポイントは人形の器としての成長、用途限定報酬は衣装の型・物語の断片へ接続できる。

**札を選ぶことが「どんな存在として振る舞うか」に見える案。** 物語の抽象性を、人形の見た目と所作が支える。課題は、同じ役を敵・環境が使った場合も分かる表現と、物語の読み終わり後にも再探索したくなる内容。結末分岐や自由な文章入力は本案の必須条件にしない。

### R04 現象から身体を作る旅人

主人公は、決まった身体を持たない魔法生命。嵐、石、影、炎などを借りて姿と行動を形作り、世界を旅する。探索で学ぶのは技だけでなく、自分がなれる姿でもある。

| 土地で出会うもの | 自分の手段になる姿の例 |
|---|---|
| 崩れない石壁 | 石の皮膚による防御 |
| 荒れ狂う雷雲 | 雷を帯びた腕による打撃 |
| 地表を滑る影 | 影に沿って身を運ぶ動作 |

術師が魔法を唱える方向から、世界の現象を自分の身体として動かす方向へ寄せる。原始的な自然だけでなく、夢の現象や遺構の働きも土地の候補にできるが、最初から全部入りにはしない。

敵や土地も同じ魔法現象から成り、使った力は周囲へ戻る。一致は同系統の現象との接続。敵から借りるだけでなく、自分の作った動作も環境に使われる。共有循環が世界の法則として説明しやすい。

持参構築は自分で安定して作れる身体・技の準備、現地の借り札は一時的な変化。配分型ポイントは器の成長、用途限定報酬は姿や現象の型を定着させる核等にできる。

**探索した場所が、自分の姿や動きに残る感覚が中心。** 明確な機械部品がなくても「自分の手段が増える」具体性を作れる。反面、何にでもなれる設定が効果や属性を曖昧にしやすい。変身の演出と、持続する性能変更の規則を区別する。

### R05 文明を呑み込む巨獣

巨大な生き物の体内に、呑み込まれた街や機械文明が残っている。主人公は、周囲の機能を写し取る生体外殻をまとった探索者。生体組織と人工物が混ざった場所を進み、それぞれの働きを自分の外殻で使う。

| 体内で出会うもの | 自分の手段になる姿の例 |
|---|---|
| 脈打つ筋肉の壁 | 収縮を打撃に使う腕 |
| 巨獣に取り込まれた防壁 | 骨質と装甲が混ざった盾 |
| まだ動いている古い掘削機 | 角状の掘削器官による突進 |

初回W03の舞台に、**生体と文明という二種類の取り込む対象**と、**それらを機能に変える外殻**を足す。体内を歩いて治すだけの探索から、自分が異質な機能を組み合わせて進む探索へ変わる。目的は埋もれた文明の記録・機能の回収、内部集落の維持、巨獣の正体の解明等を比較できる。

巨獣自身が呑み込んだものを自分の一部へ作り替えるため、土地・敵・探索者が同じ機能を巡らせられる。機械だけが生体機能を使えないといった制限は追加しない。属性は形が違っても共通する作用の系統として考えられる。

持参構築は外殻の機能の準備、現地では借りた機能を短期的に再現する。配分型ポイントは外殻の成長、用途限定報酬は組織の型・文明の機構の再現に使う成果へ接続できる。

**生きた世界を舞台に、機械と生体の機能を組み合わせる案。** 肉体と機械の混ざる美術が合うかは重要な好みの分岐。「生々しい臓器」から「珊瑚・樹木のような生体」まで表現の幅を残す。別変形システムや自由工作を追加しなくても、札の動作として具体化できる。

### R06 怪異を道具に宿す調査員

主人公は人間の調査員。異常領域に入ると、怪異の性質がコート、手袋、傘、ランタン等へ宿り、道具の働きが変わる。人間の身体は保ちながら、危険なものを手元で扱う。

| 異常領域で出会うもの | 自分の手段になる姿の例 |
|---|---|
| 開かなくなる扉 | 衝撃を受け止めるコート |
| 何度も繰り返す足音 | 追いすがる踏み込み |
| 人を押し戻す路地 | 打ち払う手袋 |

探索の動機は異常の調査・証拠回収・対処法の確立。R03の「自分が役を演じる」と比べ、人間の自分と異質な道具の距離が残る。日常的な道具を使うため、抽象的な怪異も画面では具体物に結び付けやすい。

道具が怪異を永久封印する規則ではなく、異常領域の作用を一時的に形にする表現とする。その振る舞いは相手へも戻り、場・回収山を共有する。属性は怪異の法則の系統として整理できる。

持参構築は再現できる対処道具、借り札は現地での一時的な宿り。配分型ポイントは探索準備の成長、用途限定報酬は再現に必要な証拠品や媒体へ接続できる。

**人間の探索者を中心に、異常を使いこなす案。** 怪異の性質と道具の動作の対応が薄いと、単なる魔法装備になる。今回の評価対象は身体より道具を変えたいかどうかであり、怪異ごとの複雑な儀式や罰則を足すことではない。

## 3. 選び分けるための比較

| 比較点 | 主に見比べる案 | 大きく変わる体験 |
|---|---|---|
| 取り込む対象が具体的か、意味・現象まで含むか | R01とR02 | 機能を理解して使う楽しさ／不思議なものが機能になる驚き |
| 主人公は機械か、演じる存在か | R02とR03 | 装置として実装する／役割を身にまとう |
| パーツと身体のどちらが変わるか | R01とR04 | 機体を組み替える／自分自身の姿と技が増える |
| 巨獣の舞台に何を加えるか | 初回W03とR05 | 生体環境への対処／異質な文明の機能も取り込む探索 |
| 自分そのものか、持つ道具が変わるか | R03・R04とR06 | 別の存在になる／人間として異質な力を扱う |

今回の反応を両立させる比較の中心にはR02・R03を置ける。ただしこれは作者側の提案であり、ユーザーが二案を有力と評価済みという意味ではない。R01は具体性、R04は身体変化、R05は舞台の魅力、R06は人間らしさを確かめる候補として残す。

舞台の採用と、主体の採用は別にできる。例えばR03の人形を夢の舞台へ置く、R01の探査機をR05の巨獣内へ入れることも可能。混ぜるほど良いとは限らず、何がどう自分の手段になるかの説明が伝わる組合せを選びたい。

## 4. 仕組みへの接続と、まだ決めないこと

- **現地で使うことと、次回から準備できることを分ける。** 循環中の札が手元に来ることを世界観上の取り込みとして表現できる。恒久的な札解放は既存の報酬・精算に従う。敵や環境を見た瞬間に専用ボタンで吸収する、任意の札を確定取得する仕組みは別案となる。
- **取り込みは双方に起きる。** 敵・環境も他者由来の札を使う。主人公だけのコピー能力に置き換えない。所有者が変わっても通常の札性能は共通であり、器の強化が借り札の威力を自動変更するとはしない。
- **札が部品を表しても、常時装備の規則を自動追加しない。** 攻撃・防御等の動作を示すパーツ表現と、装備枠・永続性能・装着条件は別。構築時に部品札と動作札の二種類を必ずセット要求する方式も未採用。
- **一致と場作用を区別する。** 場へ出しただけでは主効果は発動しない。一致時の場補正は、部品そのものの主効果をもう一度発動することではない。属性の名前も、この操作が読みやすくなるかで検討する。
- **共有循環の喪失も表現に含める。** 出現元退場時、共通回収山内の由来札は消滅。他者領域・場に残った分は次回収時まで使える。再現を支える現地の源が失われると読めるが、詳細な説明で初回の理解を重くしない。
- **D43の報酬と既存精算を維持。** 配分型ポイントと用途限定報酬は併用する。今回は役割の候補までとし、能力種・価格・レシピ・全強化への素材必須を決めない。知識は失敗後も残るが、今回の報酬は死亡なら保護分も失う。
- **D44を反映。** 同じ探索先の攻略傾向と成果の系統を保ち、敵・環境の組合せ等は変化し得る。夢や物語だから毎回法則が変わってよいとはしない。各案の景色の自由さと、知識を生かせる一貫性を両立させる。

次は、好感を得た方向について「出発時に持つ姿・手段」「現地で借りた札を使う一場面」「帰還後に次回へ残すもの」を比較する。今回の再提案は世界観方向の正式採用を求める段階ではなく、取り込みをどんな体験として描きたいかを明確にするためのもの。

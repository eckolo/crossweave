# crossweave — 世界観候補

版：0.6／2026-09-10。
状態：**日常と異世界の旅、不思議を道具化するプレイヤーの方向を継承。生業を道具化能力へ必ず結び付ける制約を外し、未知の場所を探索すること自体に価値がある仕事を5案で比較する。職業・所属・具体設定は未採用。共通仕様への正式統合は未実施。**

入口：[Work設定](../../作業資料/Work/20260910-worldbuilding.md)／[反応の原記録](../../作業資料/世界観/検討記録.md)。

## 1. 今回の修正：探索できること自体を、生業の根拠にできる

0.5では、不思議を道具化する能力と仕事の直結を優先し、「不思議を仕立てる道具屋」を推薦した。ユーザーから次の修正があった。

- 道具化自体を仕事へ無理に結び付ける必要はない。旅に出られること、探索できること自体が主人公の特性でもよい。
- 道具化を仕事の土台にする案が悪いわけではないが、案出しをそこへ制限しない。
- 必要な道具の調達は個別目標として使える。一方、「そこへ行けば求める不思議に遭遇できる」と事前に見込む構成を全体の基盤にすると、未知の探索との相性が悪い。

そこで今回は、**まだ分からないことを調べに行き、発見・接触・回収等の成果を仕事へつなぐ**方向へ広げる。道具化は、未知に対応し、旅で使える手段を増やす能力として残せる。

「道具化能力を削除する」「調達依頼を禁止する」「全ての探索先を事前情報ゼロにする」という指示ではない。仕事のために道具が必要になる場面も、探索で所在を知った不思議へ再訪する目的も残す。

## 2. 継承する世界とプレイヤー

骨格はS01「日常の裏側に広がる世界」＋S03「世界の継ぎ目を巡る旅」。不思議が一見見えない日常に帰る場所があり、その裏側の道から数多の世界へ出かける。

現代に近い町、商店街、古い駅、住まいの作業机等は引き続き仮の具体像。主人公が道具店を営むことは既定にせず、生業に応じて自宅兼事務所、記録をまとめる部屋、取引先への窓口等を考える。

旅先には境界の市場、物語に覆われた旧市街、内部に空がある巨大遺構、巨獣の背と内側、忘れものの漂着地、不思議を使う文明等を置ける。住人の暮らしや歴史を持つ世界として、それぞれの成り立ちを保つ。

主人公の強みには「境界を越え、普通なら踏み込めない場所で探索を続けられること」も含められる。その理由を、体質、経験、知識、道具化を含む複数の技術のどれに置くかは未決定。唯一の越境者や、必ず無事に帰れる能力とは定めない。

不思議を取り込み具体的な道具にする方向は継承する。怪異・夢・物語・魔法・文明遺構等を広く対象にできる。探索中に初めて知った働きが、自分の手段になることを重視し、出発前からその道具の完成形を知る必要はない。

## 3. 出発時に何を知っていればよいか

探索へ出る理由と、何が見つかるかの確定を分ける。

| 時点・情報 | 仮例 | 扱い |
|---|---|---|
| 出発する手掛かり | 未記録の分岐、知らない地名の手紙、町で起きた異変、由来不明の漂着物 | 調べる場所や問いの足場になる |
| 事前に見込める範囲 | 水の多い場所らしい、古い設備がある、往来の記録が途絶えている | 根拠のある概略情報として準備に使える |
| 現地で初めて分かること | 向こうの世界の暮らし、現象の原因、どんな不思議が働くか、別の道の行き先 | 探索の発見と判断の中心 |
| 帰って仕事へつながること | 実地の記録、危険や通行条件、確認した事実、回収物、相手からの返事 | 依頼者や取引相手に価値がある成果 |
| 後の探索に使うこと | 発見した現象の所在、住人との接点、未調査区域、準備できるようになった道具 | 再訪・追加調査・個別の調達目的へつながる |

出発時に「何を知りたいか」はあってよい。「どの不思議を獲得して、どの道具にするか」は未知のまま仕事が成立するようにする。

既存のD40では初訪問でも攻略傾向の概略を示す。世界設定の未知と、遊ぶための見通しは両立させる。手掛かりの不確かさを使って、提示済みの攻略情報が理由なく裏切られることを前提にしない。

## 4. 未知を探索する生業5案

K01〜K05は今回の新しい比較ID。旧J01〜J04とは区別する。どの案も道具化を使えるが、それを仕事の成果にすることは必須にしない。

| ID・生業 | 誰が成果を必要とするか | 未知のまま出発できる理由 | 仕事として持ち帰る価値 |
|---|---|---|---|
| K01 **異界の踏査員・地図作り** | 裏道を利用する商人、旅人、離れた集落、案内所 | 道や入口は見つかったが、その先と通行条件が分からない | 経路、危険、地形、人の暮らす場所、未確認範囲の記録 |
| K02 **異界の記者・紀行作家** | 世界を渡る人々向けの出版社、記録を求める研究者、読者 | まだ伝えられていない土地や出来事そのものが取材対象 | 実見した話、土地の記録、住人の声、新しい発見を伝える記事 |
| K03 **漂着物・遺物の回収屋** | 収集家、資料館、商店、研究者、持ち主を探す仲介人 | 新しい漂着地や未調査区域があり、何が残るかは入ってみないと分からない | 価値を見極めて持ち帰った品、その来歴と発見場所の情報 |
| K04 **境界の異変を調べる調査屋** | 異変に遭った住人、店、建物や地域の管理者 | 現象の兆候はあるが、原因・向こう側・対処の要否が分からない | 原因や影響範囲の確認、状況の説明、対応を選ぶ材料 |
| K05 **途絶えた世界との連絡屋** | 連絡を失った家族・商人・集落、世界間の郵便や交易を担う人 | 古い宛先や往来の痕跡はあるが、今の道・相手・土地の状態が分からない | 相手の消息、届けた連絡、返事、往来が可能かという確認 |

### K01 異界の踏査員・地図作り

裏道の案内所や商人から、「この分岐はどこへ出るのか」「人が通れる場所か」を調べる仕事を受ける。未知の先へ入れることと、観察して判断できることが専門性になる。

例えば、駅の使われていない通路の先で未記録の分岐が見つかる。階段を上がると、海が空にも広がる港だった。港の暮らし、潮の動き、古い桟橋の危険、さらに先へ行く船を知る。その過程で出会った夢の働きを道具にできる。

仕事の成果は、確認した範囲を他の人が利用できる情報にすること。先に進めない理由が分かった、古い記録が誤っていた、という確認にも価値がある。主人公から未記録の道を選んで調べ、記録を取引する形も考えられる。

**魅力：** 新しい土地へ入ることが毎回仕事になる。地図の空白が埋まり、その先に新たな空白が見える。

**検討点：** 地図埋めの作業だけに見えないよう、出会う人や土地の営みを記録へ含める。踏査の職業設定から自由移動マップや測量ミニゲームを要求しない。

### K02 異界の記者・紀行作家

日常の部屋で旅の記録をまとめ、異界を行き来する人々に読まれる小さな出版物へ寄稿する。専門の出版元と契約する形なら、まだ成果の内容が分からない取材にも出発できる。

「眠ると町の位置が変わるという噂が本当か」「巨獣の背では人がどんな暮らしをしているか」。何が起きているかを現地で確かめ、そこで知った事実を伝えることが仕事になる。主人公自身が面白い題材を選び、取材を提案する余地も大きい。

**魅力：** 旅先の文化・風景・人との出会いが成果になる。日常へ帰って記録を形にする時間も自然に置ける。

**検討点：** 危険な奥地へ踏み込む必要は、具体的な取材対象や問いで支える。毎回の戦闘を取材の必須儀式にしない。不思議が表の日常で広く知られている設定へ変えず、読者・流通範囲は別に決める。

### K03 漂着物・遺物の回収屋

新しい漂着地や、開いたばかりの遺構から、残っているものを探して持ち帰る。対象は文明の品だけでなく、物語から流れ出た品、夢の残骸、失われた生活の記録等にも広げられる。

出発前に分かるのは「何かが流れ着いた」「未調査の区画へ入れる」といった範囲。現地で品を見つけ、何に価値があるか、持ち帰れるか、さらに奥を見るかを判断する。買い手との継続的な取引や回収調査の契約が、生業を支える候補になる。

**魅力：** 未知の収穫と帰還の判断が近い。依頼品の決め打ちがなくても、自分の目利きで旅へ出られる。

**検討点：** 発見を全て換金品として描くと、人や世界そのものへの関心が薄れ得る。来歴や持ち主を知ること、資料としての価値も題材にする。道具化は回収方法の一つにもできるが、全品に必須とはしない。

### K04 境界の異変を調べる調査屋

日常の町で、説明の付かない出来事を調べる小さな仕事を請け負う。「空き家の窓に知らない町が映る」「井戸から潮の匂いがする」「古い階段を通ると知らない人の夢を見る」。依頼者は困っている現象を知るが、その原因は知らない。

主人公が境界を越えて調べると、窓の向こうは別世界の市場だったり、井戸が巨獣の眠る海へ通じていたりする。原因を確認した結果、見守ればよい場合、往来を調整する場合、さらに調べる必要がある場合に分かれる。

**魅力：** 日常から異界へ向かう理由が強い。向こう側の事情を知ることで、最初の依頼の見え方が変わる。

**検討点：** 全てを退治すべき怪異にしない。初回の調査後にも訪ねられる住人や未調査の土地が残れば、案件の解決と世界の消滅が直結せず、旅が広がる。主人公から気になる兆候を調べ、次の調査を提案する形も取れる。

### K05 途絶えた世界との連絡屋

古い宛先、返事の来なくなった集落、失われた交易相手等をたどる仕事。出発前にあるのは不完全な記録や最後の消息で、道が今も通じるか、相手がどこにいるか、その先がどう変わったかは調べる必要がある。

例えば、届かなくなった手紙の宛先を追うと、地図にあった町が巨獣に呑み込まれ、今も内側で暮らしていると分かる。住人に会って返事を預かることで、二つの世界の関係が再び動き始める。

**魅力：** 旅の目的に人との関係があり、訪問先が次の仕事相手にもなる。行くこと・会うこと・帰って伝えることに価値がある。

**検討点：** 既知の場所へ運ぶだけの配達は、未知探索の主軸としては弱い。今回比較するのは途絶えた経路や消息の調査を含む仕事。緊急救助ばかりにせず、反復探索や寄り道と両立する時間幅を持たせる。

## 5. どの方向を比較の中心にするか

現時点で職業を一つへ決定しない。今回のユーザーの関心に対しては、K01とK04が異なる強みを持つ。

| 重視する体験 | 有力な方向 | 理由 |
|---|---|---|
| まだ見たことのない世界へ自分から踏み込む | K01 踏査員 | 未知の場所を調べること自体が仕事の目的になる |
| 日常の違和感から、予想しなかった世界へ入る | K04 調査屋 | 身近な出発理由と現地で初めて分かる事情がつながる |
| 世界や人を知り、その経験を持ち帰る | K02 記者 | 発見を伝えることが継続的な活動になる |
| 何が見つかるか分からない収穫と帰還判断 | K03 回収屋 | 現地で価値を見極めることが中心になる |
| 人や土地の関係をたどって旅を続ける | K05 連絡屋 | 不確かな消息や経路が、旅の問いになる |

主人公を個人事業者にするか、小さな事務所や組織の現地担当にするかは、職業とは別の選択。例えば踏査員は案内所と仕事ごとに契約でき、記者は出版元に活動を支えられ、調査屋は町に自分の窓口を持てる。全てを巨大な秘密機関へ集約する必要はない。

道具屋・出張修繕師の旧案は、仕事の一形態や副次的な依頼として引き続き使える。道具を他人に譲渡できるかは、その案を具体化する際の論点へ戻し、今回の全候補に先行する必須判断にはしない。

## 6. 一件の仕事の具体例：未記録の分岐を調べる

以下はK01の体験例。地名・契約・報酬・経路を正式採用するものではない。

### 出発前：問いはあるが、発見物は分からない

裏道を利用する運送人から、「古い案内図に載っていない分岐を見つけた。どこへ出るのか、人や荷が通れる場所かを知りたい」と話が来る。

入口付近には水の流れた跡と、使われなくなった標識がある。主人公は、この手掛かりと既存の概略情報を基に準備する。未知の場所へ行き、確認できた範囲を記録して帰ることが今回の仕事になる。

### 現地：知ることで次の目的が生まれる

分岐の先は、海が空にも広がる港だった。人が暮らす区域はあるが、奥の桟橋では潮に混じった夢が現実へ作用している。

港の住人から通行条件を聞き、実際に調べるうちに、落ち続ける夢や由来不明の設備に出会う。道具化の機会があれば、初めて知った働きを現地の手段として扱える。

さらに先には別の世界へ向かう船があると分かる。港への道を確認して帰るか、今の状態で奥まで調べるかを考える。出発前に決めた道具を探し当てることは、この仕事の成功条件ではない。

### 帰還：知ったことが仕事になり、知らないことが次に残る

探索を既存ルールに沿って終え、帰還後に持帰り成果を整理する。運送人には、確認した経路、通行上の注意、住人と話せたこと、まだ見ていない区域を報告する。

その情報は、相手が往来を始めるか、別の手段を探すか、追加調査を頼むかの判断材料になる。次の仕事は奥の桟橋の調査かもしれず、主人公自身が先の船に関心を持って調査を提案してもよい。

今回出会った不思議の所在を知ったことで、後に道具の調達や別の客の相談が具体的になる。未知の探索で得た知識を、再訪の目的へ使える。

対照的にK04なら、同じ港への入口を「町の井戸から潮の匂いがする」という相談から発見できる。最初に知りたいのは井戸の異変の原因で、港の存在は調査を通じて分かる。同じ舞台でも、踏査は地理の未知、調査屋は現象の理由を追う体験になる。

## 7. 仕事の成果とゲーム上の報酬を区別する

生業として説明できることと、具体的なゲーム機能を採用することは別に扱う。

- 仕事上の依頼、プレイヤーが今回狙う成果、環境踏破、一回の探索全体クリア、次の探索先の解放は別に扱う。途中で関心や目的を変える余地を持たせ、依頼の完了だけで全体クリアや行先解放が成立する設定にはしない。同期元の[全体進行・探索構成案](../カード探索ゲーム_探索全体の設計.md#expedition-composition)は未採用案として参照する。
- 探索の結果を誰が必要とするかを示したが、報告ごとの料金、前金・成功報酬、雇用形態、依頼選択画面、評判値、納期、生活費等は未決定。
- 調査で否定的な結果が分かることにも物語上の価値を持たせられる。探索失敗や死亡でも毎回満額の報酬を得る、同じ既知の報告を繰り返し換金できる等の規則は追加しない。
- D41の保持される知識と、D43の今回探索で得る成長報酬は区別する。知識が残ることを理由に、今回失った報酬を報告で無条件に取り戻す形へは変更しない。具体的な調査記録・回収品と報酬の対応は設計担当へ渡す。
- 共有札は敵・環境・プレイヤーの間で循環し、同じ札の通常性能は使用者だけで変わらない。道具化を主人公だけの共有札利用権とはしない。
- 現地で一時的に使う札と、帰還後に初期構築へ準備できる手段の解放を区別する。任意の不思議の確定吸収・自動恒久取得は採用しない。
- 属性一致、場への設置、主効果と場作用、出現元退場時の由来札の消滅は既存設計を維持する。
- 帰還後の成長、HP全回復と探索入口からの再出発、保護済み成果のみを持ち帰る任意撤退、探索全体クリアでの全成果持帰り、死亡時の今回成果喪失を維持する。
- D44の探索先の攻略傾向・成果系統の一貫性と、D45の成長への難度非追随を維持する。未知探索を、既知の土地まで毎回根本から変わる根拠にはしない。

## 8. 今回の到達点

道具化を生業に結び付ける必須条件を外し、未知の場所へ旅・探索できる能力を仕事の価値にできる5案を用意した。道具化は維持しつつ、出会った後で利用法を見いだす余地を広げた。

比較の主要点は、旅で「土地を知る」「経験を伝える」「品を持ち帰る」「原因を明らかにする」「人と再びつながる」のどれを仕事の中心に置くか。特定職業の選択はまだ取得していない。

必要な道具の調達は、発見後の再訪や個別依頼の目的として位置付けられる。探索全体の出発理由を、特定の不思議の所在を事前に知っていることへ依存させない。

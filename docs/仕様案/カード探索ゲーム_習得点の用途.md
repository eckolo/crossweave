# カード探索ゲーム — 全習得後の習得点と取得候補

2026-09-11（UTC）。候補選択型の補助取得の大枠はD53・基本設計0.53で採用。候補数を三つに固定せず、踏破難易度等に応じた選択肢の変動を許容する。価格・候補数範囲・内容配分・更新条件・実装詳細は具体案。ASの予算比較は当時の固定条件を保持する。

## 1. 採用した大枠：基礎習得に加えて取得候補の選択にも使う

習得点の主用途は基礎の心得の習得として維持する。全習得した後も使える補助用途として、**内容の見える候補から、欲しい札・心得を選んで取得する**方式を採用した。呼び名や世界観上の供給者は未定。

探索で見つかる品を収集の主軸に置き、余った習得点で別の組合せも試せるようにする。買わずに次の基礎習得へ貯めてもよい。不要品の変換はその足しになり、容量内で何を装備するかという選択はそのまま残る。購入しても追加の装備枠・同時効果・未取得修飾の編集権は得ない。

全習得後に習得点が余ること自体は不具合ではない。新しい候補が増える節目へ貯める意味もあり、消費し切ることを設計目標にしない。ただし、長く取得が続くのに習得点だけが使えない期間には補助用途を用意する。

## 2. 七つの方向の比較

| 用途 | 収集・装備への働き | 主な懸念 | 今回の位置付け |
|---|---|---|---|
| 新しい基礎の心得を習得 | 手段が増え、取得品の使い方も広がる | 有限の基礎を揃えた時点で用途は一度尽きる | 主用途を維持。全習得を否定するほど増やし続けない |
| 見えている少数候補から個体を選んで取得 | 接頭辞の得意不得意を見て支出を決められ、完全重複も選べる | 配布量が多いと探索報酬を圧迫し、候補更新だけの反復にもなり得る | **補助用途の第一候補** |
| 系統だけ指定して中身を伏せた品を取得 | 探索先と同様の振れ幅が生まれ、短い操作で済む | 不要品が続く時の負担が大きく、性能比較をして選ぶ機会が少ない | 候補選択方式との代案 |
| 所持品の接頭辞を再抽選・付替え | お気に入りの基礎を育てやすく、繰返し用途になる | 欠点だけを外す最適化、理想品までの作業、価格と保存の処理が増える | 今回は追加しない。再検討するなら品全体と代価を一組で設計 |
| 既存品の固定段階強化 | 育成の目標が明快 | 個性より強化段階が重要になり、未強化の新取得品を試しづらい | 後回し。接頭辞収集の代わりにしない |
| 装備容量・基礎能力を繰返し購入 | 習得点の使い道を長く保ちやすい | 長く遊ぶほど装備制限を消すか、強さの数値だけが伸びる | 無制限方式は推さない。有限の節目拡張は別案 |
| 出発・付替え・取り直しの恒常費用 | 消費先が常に存在する | 試したい構成へ変える負担になり、無料取り直し方針にも抵触する | 今回は使わない |

材料、見た目、記録の収集等へ回す用途も作れるが、それだけでは札・心得を試す循環と遠くなる。新しい通貨を増やすだけでも用途不足は解消しない。まず既存の習得点のまま比較する。

## 3. 採用した大枠の具体例

帰還後に複数の札・心得の候補を提示する。前回の三候補は固定数にせず、踏破した内容の設定難易度に応じて候補数や修飾の傾向を変える具体案へ進める。一組から一個だけ任意に購入する点は当面の試行。内容を見てから支出を決め、見送る場合は消費しない。購入で得るのは選んだ取得個体だけで、未選択品や選択権自体を所持品へ加算しない。

候補は到達済みの探索範囲や成果系統に対応させ、未知の後半の固有品を序盤の習得点だけで買えるようにはしない。同種重複や欠点付きの修飾も候補にできるが、取得品の性能は固定された組合せのまま。追加の数値乱数や、購入時に欠点を切り離す編集は入れない。

例えば「通常の探査補助」「借り札では強いが時間が重い探査補助」「速い身構補助」が並べば、同種を重ねる、条件付きの個体へ置き換える、別の役割を足す、全て見送るという判断になる。表示には習得条件と装備コストを含める。習得点が足りても、現在の装備へ無理なく入るとは限らない。

更新の最初の案は、成果を実際に持ち帰った探索の帰還ごとに一組。無成果撤退・死亡・出発直後の戻り・画面の開閉だけでは候補を更新しない。購入した場合も同じ帰還の追加候補をすぐ作らず、次の成果持帰りまで待つ。具体的にどの成果を更新対象とするか、未購入候補の保持、探索先別の候補割合は試行前に固定する。

探索へ出れば必ず欲しい品が得られる方式にはしない。基礎や修飾の系統を少し狙いやすくする補助とし、直接探索で得る固有品や複数修飾に価値を残す。未購入候補の更新を逃さないために毎回買うことが義務にならないよう、購入量と更新頻度を併せて評価する。

## 4. 既存の取得経過から見た予算【AS1】

[AR1](../検証/装備制限/ar/検討結果.md)の32経過・各8探索を固定して再集計した。全4基礎の8ptは既に支出済みで、残りは平均10.67pt。変換から得た分は平均0.73ptだった。次の表は、この残額だけで支払える回数であり、候補在庫・更新間隔・購入後の攻略は含まない。

| 一個の取得価格（仮） | 支払える回数の平均 | 最小〜最大 | 一度も支払えない経過 |
|---|---:|---:|---:|
| 2pt | 4.94回 | 0〜7回 | 1/32 |
| 4pt | 2.22回 | 0〜3回 | 2/32 |
| 6pt | 1.41回 | 0〜2回 | 3/32 |

第一比較値は4ptとする。基礎一種2ptという現行の試行に対して追加個体一個が二種分の支出になり、序盤に基礎習得と競合し得る。全習得後の余りでは8探索当たり約二回分という目安で、適正価格を実証したものではない。2ptは取得が頻繁になる対照、6ptは貯蓄が重くなる対照として残す。

途中で購入すれば、装備、勝敗、直接報酬、変換対象、次の探索先も変わる。固定ARの余りから「購入しても同じ回数でクリアできる」とは言えない。また、以後の基礎追加に備える貯蓄をゼロとした支払能力であり、毎回この上限まで購入する方策を推奨するものではない。

## 5. 無料の取り直しと、個体購入・変換を分ける

| 処理 | 第一案で維持・追加する条件 |
|---|---|
| 基礎の取り直し | 実際に支払った基礎習得費を全額返す。売却できる個体を新しく作らない |
| 取得候補の購入 | 候補・価格・購入IDを確定し、習得点の減算と一個の所持加算を同じ確定処理にする |
| 同じ購入を再実行 | 同じ購入IDは同じ結果を返し、支出や個数を再加算しない |
| 候補表示・保存再開 | 抽選結果を先に保存し、画面の再表示・復元・無料取り直しで引き直さない |
| 買った品の変換 | 普通の取得品として低効率で変換できる。購入費の全額返還とは扱わない |
| 買った品を装備 | 基礎の習得条件、所持個数、装備容量を通常と同様に満たす |
| 無料の探索用札・習得通常版 | 変換できる取得個体として増やさない |

現行の通常品は価値基準2ptの25％、すなわち一個0.5ptへ変換する試行である。4ptで購入した品を同じ0.5ptへ変換するなら、購入費に対する実回収率は12.5％、差引支出は3.5pt。「購入額の25％が戻る」とは違う。取得価格と変換価値は別に表示・定義する。

今回の2／4／6ptという価格例はいずれも即変換で習得点が減る。将来の高価な品、割引、まとめ買い等にもこの条件が自動で成り立つとは限らない。最小の支出に対して全成果を変換した総額が上回らないことを、その価格・報酬組ごとに確認する。

この表は必要な処理条件の設計であり、新しい購入機能の検査を完了した記録ではない。ARで確認した無料取り直し・所持・変換・保存は引き継ぎ、購入の実装時には候補表示前、支払直後、所持加算直後からの復元を確認する。

## 7. 踏破難易度に応じて候補を揺らす具体案【AT1】

難易度は、実際に踏破・撃破して成果を持ち帰った対象や案件の設定値を使う。高難度の探索へ入っただけでは、その未達成部分の候補を得ない。苦戦した時間、残り余力の少なさ、装備の弱さで候補を増やす方式も第一案にはしない。自ら弱い構成へ変えたり、安全な場所で待ったりする誘因を作らないためで、ユーザーが難度算出式まで指定したわけではない。

| 仮の難度区分 | 候補数の抽選範囲 | 修飾の組合せを選ぶ傾向 |
|---|---:|---|
| I | 2〜4 | 通常版・一修飾を中心にする |
| II | 3〜5 | 一修飾を中心に、二修飾も混ぜる |
| III | 4〜6 | 二修飾が増え、三修飾も出る。通常版・一修飾も残す |

これは検証用の三段階で、正式な最小・最大候補数でも、全探索の格付けでもない。候補数と修飾傾向を変えた際の作用を分けて読むため、最初は各品4ptを共通にする。修飾が多いほど強いとはせず、マイナス効果を含む組合せと装備コストをそのまま表示する。

一つの提示内では同じ性能だけが重なって選択肢を埋めないようにし、別の帰還では同じ性能を再入手できる。基礎の種類を分散する補助枠を一つ置く仮案とし、同種重複の所持・購入を禁止するものではない。低難度の通常版や使いやすい一修飾も、少ない装備コストや発動条件の少なさで選ぶ意味を残す。

支払能力と候補の価値は別に扱う。高難度で候補を増やしても同じ所持金で何個も買えるわけではなく、提示量の増加が比較負担になる可能性もある。実際の購入・無料取り直し・低効率変換・保存再開へ接続し、候補を増やす利点と整理の負担を評価する。

## 8. 取り直しで購入資金を作るときの準備比較【BA1・検討案】

AYは現未使用額だけで買える帰還を比較した。別に、既習得を取り消せば購入できる帰還もある。無料取り直しの全額返還は維持するが、購入費を作るためにどの基礎を外すかは、現在の構成を変える選択として扱う。購入ボタンの不足分を、本人の選択なしに基礎の取消で埋めない。

### 金額と使えなくなる手段を一緒に見る

[BA1の結果](../検証/構築と探索/ba/検討結果.md)では、現未使用3pt・C攻略後の4帰還から、基礎優先／最小限の基礎返還後に取得優先の8枝を比較。実際の返還購入は3件で、いずれも2ptを返して4ptの札を買い、未使用1ptが残った。もう1件は現在の方策の構成へ入る候補がなく、返還も購入も行わず元状態を保った。

購入した3枚は全て持込構成へ入り、本人11回・他主体5回の使用を得た。次Cでは1対で手数・消耗が改善、2対で負担が増えた。基礎の取消で失う手段と購入札の作用が同時に変わるため、購入札だけの強弱とはしない。買わなかった候補が人の構成でも不要であるという判定にも使わない。

| 比較する情報 | 表示・説明の案 |
|---|---|
| 現在使える額 | 未使用習得点と端数。既習得へ払った額は合算しない |
| 取り直しで戻る額 | 選んだ基礎の実支出額。任意の額だけ返す処理とは区別する |
| 外れるもの | 取り消す基礎と、その基礎を必要とする装備中の通常版・取得心得。取得個体の所持は残る |
| 購入後に残る額 | 現未使用額＋返還額−購入額。残額で再習得できる基礎と、足りない額を区別する |
| 次の構成 | 実際の札組・心得・容量の前後差。買えることと、その後装備できることを別に示す |

例えば未使用3ptで4ptの品を買いたい場合、2ptの基礎を取り消すと5ptになり、購入後は1pt残る。取り消した基礎を2ptで習得し直すには足りない。返還が無料でも、購入後に元の構成を直ちに戻せるわけではない。一方で、買った取得個体は取り直しによって失われず、再び基礎を習得すれば通常の条件で利用候補へ戻る。

### 比較と適用を分ける

候補を見たり比較案を変えたりする間は、習得・所持・候補組を変更しない。購入後の構成へ入らない場合も、それを製品の購入禁止条件にしない。将来用の保持、別の探索先用の準備、本人が別の札組を作る選択を残す。

取り直しを適用する際は外れる基礎と返還額、購入する際は購入品と支出を識別できる形にする。価格4pt・基礎2ptや、自動方策が返還対象を選ぶ順位は試行条件であり、正式価格・強制操作順・自動取消の採用ではない。具体的な画面はUI担当へ渡す案として扱い、既存の予算確認と準備変更に必要な情報を優先する。

## 9. 初攻略前の購入で、準備の変化と利用時点を区別する【BB1・BC1・検討案】

[初攻略前の経路と結果](カード探索ゲーム_探索全体の設計.md#first-c-acquisition-bb-bc)を追加した。初帰還では未使用A3pt／B2pt・返還0で買えず、反対側A/Bの踏破後は未使用3ptと既払PS02 2ptから返還購入を選べる。初回帰還から買えると案内せず、基礎の既払額を現未使用額へ合算しない。

BCの実購入2例は基礎を外して初Cを踏破したが、片方は手数・消耗が増え、片方は手数と残余力の交換になった。購入札の本人4回の使用は全て初回山札再構築後であり、出発構成へ入れたことを初巡の利用保証へしない。8章の比較案には「購入後の実構成」と「失う装備」を優先して示し、未公開の次札・未来の成績を購入前の保証として表示しない。

候補が現在の自動構成に入らない2例は、取消・購入で元帰還を変更せず、その後は基礎優先と同じ準備へ進んだ。将来用の保持や別構成を本人が選ぶ余地は残す。購入品への交換だけで攻略が短くなる説明、余力だけで有利とする説明、購入のためのA/B再訪を必須とする誘導にはしない。価格・候補数・操作画面の正式採用と、人の購入意欲・理解は今回評価していない。

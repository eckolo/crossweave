# カード探索ゲーム — 修飾と収集

2026-09-10（UTC）。基礎全習得と修飾収集D50、複数入手と低効率変換D51、制限を伴う同種の同時利用D52・基本設計0.52を反映。具体方式・呼称・効果値・個数・価格は案。AO・APの固定検証を保持し、最新の装備比較は[パッシブ装備](カード探索ゲーム_パッシブ装備.md)・AQ1、変換案は本書11章を参照する。

## 1. 今回の意図と、前の成長案から変える点

基礎パッシブは全習得可能とする。その先の収集は、札・パッシブの基礎種類を増やし続けることだけに依存させず、取得物に付く接頭辞的な修飾による性能・使い方の違いを軸にする。後には複数の修飾、マイナス効果も含む組合せを扱い、用途に合う品を探し続けられることを目指す。

ユーザーが挙げた「ローグライク的な振れ幅」は取得物の個性を指す。数値を細かく乱数で上下させることや、死亡で過去の恒久成果まで失う方式へ読み替えない。修飾の抽選と、その修飾が持つ定義済みの効果を分ける。個々の数値が決まっていても、得られる組合せによって準備と行動が変わり得る。

前の探索全体26章は「基礎候補を増やすことで習得の選択を更新する」ことに寄っていた。基礎候補の追加は許容するが、基礎全習得後も派生の取得・選択が続く構造へ改める。D50時点では全体の装備容量を必須としなかった。その後D52で制限を伴う同種の同時利用の方向が示されたため、全習得と今回の装備を分け、総装備コスト等を比較する。

## 2. 基礎・取得した派生・探索中の現物を区別する

| 対象 | 何を表すか | 第一案での扱い |
|---|---|---|
| 基礎の札・パッシブ | 同じ働きを持つ種類。例：踏み込み、PS02 | 基礎の識別子でまとめる。パッシブの基礎習得は成長ポイントを使い、全習得可能 |
| 取得した派生の性能 | その基礎に、ある修飾の組合せが付いた性能 | 同じ作用の組合せは同じ性能として比較する |
| 所持する取得物 | ある性能の品を、何個持ち帰って残しているか | 同じ性能も複数所持。個数と取得元を保ち、変換した分だけ手放す |
| 探索中の一枚 | 出現元、現在位置、手札期限、消滅予定などを持つ現物 | 同じ派生から作られた一枚でも別の現物。共有循環へ出した後も、その一枚の修飾と出現元を保持 |

例えば「重い・精密な踏み込み」を得たことは、「重い」と「精密な」を全ての札へ自由に付けられることではない。接頭辞の並び順だけが違い、作用も同じなら同じ派生として扱う案。基礎名・修飾名・見た目の違いだけで同名上限を回避しないよう、投入上限は基礎単位で数えることを第一案とする。具体的な上限値は現行どおり別扱い。

## 3. 複数所持と、同時に働くパッシブを分ける

D51で同じ種類の複数入手、D52である程度の同時利用と制限を認めた。AOで試した「同じ基礎ごとに一つの派生を選ぶ」案は、現在の第一案から外す。旧AOの入力・実装・結果は当時の固定比較として保持する。

現在の第一候補は、[総装備コストの範囲で、所持する個数分を選ぶ方式](カード探索ゲーム_パッシブ装備.md#recommendation)。習得済み基礎は選択可能な範囲を表し、装備していないものは効果を出さない。複数の同種を働かせるなら、それぞれの個数と容量を使う。

| 状態 | 第一候補で働く効果 |
|---|---|
| 全基礎を習得、装備なし | 装備パッシブの効果は0。習得済みという事実は保持 |
| 通常PS02を2個選択 | 条件成立時の削り補助を2個分加算。通常版の追加1個が必要 |
| PS02の通常版と借り札限定版を選択 | 各個体が条件を満たした分だけ発動し、両方の容量を使用 |
| 基礎を取り直す | 対応する装備を外して実支出を全額返還。取得品の個数・修飾は不変 |

具体方式・容量・個々の重複定義は未採用。総コスト、固定枠、併用、追加負荷、役割別枠、逓減まで[AQの比較](カード探索ゲーム_パッシブ装備.md#comparison)に整理した。同種を多少使えるかという意図の再確認は不要。

## 4. 接頭辞が使い方を変える例

名称・数値は試行例。A〜Dの属性に世界観上の意味を新しく与えない。

| 対象・修飾例 | 変化の例 | 選ぶ理由・負担 |
|---|---|---|
| 攻撃札「重い」 | 威力＋2、行動時間＋1 | 低い体勢を崩した後の進行量を増やす。場へ置く行動も遅くなる |
| 攻撃札「精密な」 | 体勢削り＋20、威力−1 | 高めの体勢を削り切る手を早める。毎回崩せる相手には威力低下が目立つ |
| 攻撃札「響く」 | 使用時の体勢削り−10、場の体勢削り補助＋20 | 自分で使う性能と、場の材料として他者も利用する性能が変わる |
| 防御札「堅い」 | 防御値＋2、回避−10 | 崩される頻度と、崩された後の軽減量が入れ替わる |
| 回復札「濃い」 | 回復量＋4、行動時間＋2 | 一枚で大きく回復できるが次の行動が遅い。消費型という性質は維持 |
| 札「短命な」 | 手札期限−1 | 使える順番が狭まる。期限が0以下になる組合せは生成しない |
| PS02「借り技の」 | 体勢削り補助を20→30にし、使う札が他者由来の場合だけ発動 | 借り札を活かす構築・現地判断へ寄せる。自前の札では基礎効果も発動しない |
| PS02「速効の」 | 補助を20→10にし、発動した行動の時間−1 | 体勢の削りと手番の早さを交換する |
| PS02「借り技の・強引な」 | 借り札で条件を満たす場合は補助40、行動時間＋1 | 強い補助と、借り札条件・遅さを一組で持つ |

単純な数値比較で優劣がつく取得物が一切あってはならないとはしない。明確な強化品も収集の喜びになり得る。ただし、ほぼ全てが上位品待ちになったり、マイナス修飾を大量の不要品を作るためだけに使ったりはしない。強い作用と不利な条件を組にする、行動のタイミング・対象・札の由来で適性が変わる、といった方向を優先する。

また、共有札では自分へのマイナスが敵にも及ぶことがある。使用性能と場へ残す性能を分け、単一の総合点だけで劣る品を自動処分しない。修飾が多いほど常に有利、という格付けにはしない。

## 5. 修飾を重ねる際の規則案

- 修飾は、それぞれの固定した効果と適用条件を持つ。付く修飾や離散的な種類を抽選し、同じ修飾の中で威力を細かく再抽選する方式を中心にしない。
- 単純な値の補正は基礎へ加算してから一度だけ確定する。条件は併せて満たす必要がある。毎回付与順に丸めて別性能になる処理や、無制限な乗算を最初のモデルへ入れない。
- 同じ修飾の重複、同じ系統の相反する修飾、期限0など成立しない値、現在の対象では発動不能な条件を生成前に除く。効果が完全に相殺されるだけの見掛けの派生も点検する。
- 単独では使いにくい条件でも、構築・借り札・別の修飾で活かせるなら残す。単に今の手札で発動しないことと、対象となる札が存在せず発動できないことを分ける。
- 不利な部分だけを取り直しで外さず、取得した修飾の組合せを一つの性能として選ぶ。付与・合成・抽出・再抽選を追加するなら別の規則として扱う。

AOでは0〜3個と少数の系統制限を置いた。これは組成と処理を確かめるための仮条件であり、最終上限3の採用ではない。実際に付く数を増やすときは、比較と読解に必要な負担も測る。

## 6. 無料取り直しと、取得物の保持

AO・APの試行では、成長ポイントは基礎習得に使い、所持している派生を選ぶ追加料金は設けない。取り直すと基礎習得に実際に使ったポイントを全額返し、発動する効果を外す。所持品の個数・修飾は不変で、再び基礎を習得すれば残している品を選べる。売却で手放した品は取り直しで復活しない。取得物を売る際の低率変換は、この全額返還とは別処理である。

この価格の扱いは具体案。派生にも追加習得費を設定する代案では、その費用も実際の支出に基づき無料で取り直す必要がある。取得・抽選・修飾の削除を返金処理へ混ぜない。

基礎を全習得し、派生選択も無料とするなら、成長ポイントの使い道は一度尽き得る。取得物の収集が続くことだけで、ポイントにも無限の使い道が生じるとはしない。後半は札・パッシブの派生や固有の成果を中心に報酬を構成できるが、余剰ポイントの自動交換や、新しい強化費を今回追加した扱いにはしない。D43は毎回必ず同じ種類・割合の報酬を渡す規則ではない。

## 7. 札の派生と共有循環

札の取得物を保持している間は、次の初期山札へその性能を組み込める第一案とする。D35との整合を優先し、探索中に消費型札を使い切っても、所持する取得物の数を減らしたり、次回の補充費を課したりしない。所持している同じ組合せから探索用の現物を作り、その現物は売却可能な所持品に数えない。取得物の最後の一個を売却すると、その派生を持ち込めなくなる具体案は11章。初期から無料の通常札は別途利用可能とする。

一度場へ出た現物は、その修飾を持ったまま回収・再配布される。敵が使うと接頭辞が消える、使用者ごとに都合のよい効果へ再抽選される、といった処理はしない。札自体の性能と、現在の使用主体が持つパッシブの修飾効果を別々に適用する。プレイヤー側のパッシブを札へ焼き付けて敵に渡さない。

場の材料になったときは場作用に属する補正が働き、材料札の攻撃威力・使用時間・パッシブ発動をそのまま重ねない。出現元の退場による消滅予定、消費型の回収時消滅、手札期限の扱いは同じ現物へ適用する。敵がどんな修飾付き札を初期に持つか、補填・基本札にも付くか、敵パッシブの派生をどう用意するかは、今回の独立モデルでは未実装。

## 8. 報酬の抽選・保護・精算

報酬が発生したときに、基礎と修飾の組合せを一度決め、その報酬の記録へ保存する第一案。戦闘用の乱数とは別に扱い、報酬を確認した回数や読み込みによって次の札が変わらないようにする。

| 場面 | 第一案の扱い |
|---|---|
| 同じ報酬の再表示・保存復元 | 保存した同じ組合せを表示する。再抽選しない |
| 環境踏破で保護 | 今回得た派生にも既存の保護を付ける。保護自体で上位品へ変化しない |
| 撤退 | 保護済みだけを所持品へ追加し、同じ性能でも数量を残す。未保護分は失う |
| クリア | 今回得た派生を全て持ち帰り、所持数へ加える |
| 死亡 | 保護済みを含め今回分を失う。以前の取得済み派生は保持 |
| 精算後の再読込み | 同じ取得物やポイントを重複追加しない |
| 見た派生を死亡で失った | 知識としての観測と、準備に使える取得物を分ける。知っているだけでは装備・構築へ使えない |

一つの敵で見た修飾を、同種の全個体へ一般化しない。未観測の次の敵・報酬の具体的な修飾も先に明かさない。観測知識と既存の初期カタログの版管理へ派生をどう記録するかは、共通実装へ接続する際の検査対象。

## 9. 重複品・情報量・収集の広がり

D51により、完全重複も個数を保持し、選んだ数量を資源へ変換できる。AOの数量を持たない集約案は修正する。準備画面では同じ性能を一行へまとめられるが、「所持3、使用中1、変換可能2」のように数量を読み取れる案とする。性能が違う品を同名というだけでまとめて売ったり、重複品を取得時に自動売却したりはしない。合成・修飾の付替えへの転用は別途検討する。

準備では基礎ごとにまとめ、現在選択中の派生と取得した候補の差を比べる。常設表示には行動を判断する数値・発動条件・主な利点と欠点を絞り、全接頭辞の長い説明を毎回の盤面に展開しない。複数修飾の名前を全て一行に押し込む必要もない。正式な用語・見た目と、UIの専用実装は各担当と接続する。

進行の例は「基礎と少数修飾の扱いを知る→複数修飾の組合せを比べる→相性のよい特殊な品を探す」。基礎を何種類追加したかだけで次の地域の報酬を評価しない。初期の使いやすい一修飾が、後に得た三修飾より自分の構築に合う場合も残す。D/Eの案件ごとの取得傾向を作る際も、片方の固有品を他方の唯一の攻略手段にしない。

## 11. 重複品を低効率で習得リソースへ変換する具体案

### 11.1 複数入手を、選択と成長へつなぐ

使いたい性能を残し、不要な札・パッシブを習得の足しにする。同じ基礎でも役割の違う派生は保管でき、完全重複にも変換先がある。売却相当の操作で手放すのは所持品であり、習得したという事実や、探索中に何度でも供給される札そのものではない。

同じ種類を複数持てることはD51、その同時利用をある程度認めつつ制限する方向はD52で採用済み。売却できること自体は重複効果を抑えないため、[総コスト等の装備制限](カード探索ゲーム_パッシブ装備.md)を別に用意する。AQではPS02を2個分加算した＋40と、容量・所有個数・取り直し・売却の接続を確認した。

### 11.2 変換対象と保持するもの

| 対象 | 第一案の扱い |
|---|---|
| 持帰り済みの札・パッシブ | 個数を保持し、本人が選んだ品と数量を変換 |
| 使用対象にしている品・保護した品 | 先に選択・保護を外す。売却のために勝手に構築を変更しない |
| 同じ性能が複数ある | 使用中の一個を残し、別の一個だけを変換できる |
| 最後の一個 | 手放すと、その取得品の性能を選べなくなる。性能を知っている記録は残る |
| ポイントで習得した基礎 | 取消しは従来どおり実支出を全額返還。売却用の所持品を発生させない |
| 探索用に作る札・借り札・補填札 | 共有循環用の現物。所持品として持ち帰る報酬になっていなければ変換対象外 |
| 初期から無料で使える札 | 無限に売れる在庫とは扱わない。別に報酬として同じ性能を得た一個は変換できる |
| 素材M・既知情報 | 今回の変換対象へ広げない |

APは帰還精算後に変換する案を検証した。探索中の変換を加える代案なら、資源化した後も元の保護状態と死亡時の喪失を引き継ぐ必要がある。変換だけで未保護報酬を恒久成果へ移せる方式にはしない。

最後の一個を売っても性能が永久に残る方式では、所持品の他の用途がなければ、初入手品も直ちに売るのが常に有利になる。このためAPでは、最後の一個を売るとその取得品の利用も手放す案を選んだ。通常使用による消費型札の消滅とは区別し、使うたびの補充費を追加しない。

### 11.3 交換率と成長量

第一候補は基準価値の25％。仮に通常品の基準価値を2pt、基礎パッシブの習得を2ptとすれば、通常品1個で0.5pt、4個で1種類を習得できる。比較値は10％・25％・40％。価格基準や最終率は未採用であり、接頭辞が多いだけで高価になる計算にはしない。

端数も同じ成長リソースへ累積する案とする。一個ずつ変換すると全て0になる、まとめた時だけ得をする、といった差は作らない。表示単位はUI側で整理でき、新しい交換専用通貨を必須にしない。

既存AM・ANの報酬を固定して再計算した。Aの序盤反復272探索は札・パッシブの持帰り0個のため今回の対象では成長速度不変。初回C帰還で札2個を全て売った場合、25％の例ならA経由の累計6pt→7pt、B経由5pt→6pt。それぞれの札を残すなら増加は0。攻略中に先に売っても同じ結果になるという比較ではなく、帰還後の資源上限である。

今後の報酬は、直接ポイントと実際に売却する品の合計で成長速度を点検する。基礎全習得が早まること自体を不具合とせず、成長する喜び、使うか手放すかの判断、再訪の目的を確認する。

### 11.4 残る論点

変換先を成長ポイントとすることは具体化の第一案で、別の用途を持つリソースも比較可能。ただし、別通貨を加えるだけで余剰資源の使い道が解決するわけではない。基礎習得後の用途が有限なら、売却後のポイントも余り得る。新しい基礎・派生の習得費や他用途は、実際の同時発動・習得方式と合わせて判断する。

売却額だけで劣る品を自動処分せず、残す・使う・変換する判断を分かりやすくする。買戻し、合成、再抽選、所持容量、売却の確認画面は未実装・未採用。今回のAPは経済と所持の接続検証であり、人の収集・整理の楽しさを実証したものではない。

## 12. 全習得後の習得点を、取得品を選ぶ補助にも使う案【AS1】

[習得点の用途案](カード探索ゲーム_習得点の用途.md)で、基礎追加、見えている候補からの取得、伏せた取得、再抽選、段階強化、容量購入、恒常費用の七方向を比較した。第一候補は、基礎習得の主用途を残し、余剰習得点で少数の見える候補から取得個体を一個選べる方式。既存品の修飾を自由に編集する方式は追加しない。

ARの32経過の残額は平均10.67pt。仮の4ptなら平均2.22回分を支払えるが、候補の在庫・更新頻度や購入後の攻略は未実装。通常品を0.5ptへ変換する試行では即変換の差引支出3.5ptとなり、購入費の全額返還や購入費の25％回収と混同しない。正式な取得経路と具体価格は未採用。

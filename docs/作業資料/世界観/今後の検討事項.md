## 0.9で進めたことと現在の焦点

- ユーザーの「良い」「判断することが無ければ継続」を受け、普通の窓口と不思議な相談、既存のつながりを辿る主人公、帰路の任意描写の方向を世界観設定1.13へ記録した。個別の入口・使い・能力名は未採用。
- WB-NEXT-006・007・003を進め、[再訪・往来と日常の変化0.1](../../仕様案/世界観/再訪・往来と日常の変化.md)を新設。再訪6型、日常の任意描写8例、旅に通せる三つの線を整理した。
- DBへイベント8件（WB-EVT-017〜024）・文化4件（WB-CUL-009〜012）を追加。既存132案のID・本文・採用状態を保ち、現行144件と索引を整合する。全追加案は未採用の描写案。
- 解決済みの案件を反復のために巻き戻さず、別区域・仕事の周期・立場の変わる再会等で再訪の幅を作る案。平穏な立ち寄りも残し、本格探索には個別の深部目標を置く。帰還後の全専用場面や新しい取得条件は必須にしない。

先にユーザー判断が必要な事項はない。次は異界ごとのテーマ・暮らし・立ち塞がる理由・解決後の魅力を、対照的な組合せで点検する。修復・救助・伝言だけに偏らず、遊び・競争・生態・信仰・観測・遺構の側から内容を増やす。個別名、全編を貫く謎、最終的な案件採用順は必要になった段階で扱える。以下0.8以前は経緯として保持し、現在の到達点と順序は本節を優先する。

## 0.8で進めたこと

- 関わりの深まりは、探索中に札・道具として複数回使い、帰還後に着想で札を得る流れの背景として定める。専用の会話・手伝い・取得イベントは任意とし、必要使用回数の新設もしない。
- WB-NEXT-002・004について、[相談経路と異界への往来0.1](../../仕様案/世界観/相談経路と異界への往来.md)を新設。普通の窓口・旧知・不思議な伝言の6経路、主人公の渡り方3案、道の5型、通常帰還と救出、既存DBからの一往復3例を用意した。
- 第一案は、古道具屋への普通の相談を土台に、先代のつながりと不思議な伝言が混じる形。主人公は既にある不思議のつながりを道として辿れる案を軸とする。これらの新しい共通原則は比較段階で、今回の継続指示だけで採用しない。
- 帰路は背景として省略でき、救出等で意味を持つ場合に必要な分を描く。全探索の帰り道や全救出の護衛フェーズを必須化しない。

次の焦点は、この相談と渡り方の組合せの方向を定め、WB-NEXT-006・007・003の再訪・再会・旅が日常に残る変化へ接続すること。道具の全専用場面や渡航の細則を完成させるまで待つ必要はない。以下0.7以前の到達点は経緯として保持する。

## 1. 現在の到達点

主人公の人物像、先代が経営する古道具屋と暮らし、通学、先代自身の不思議への対処能力、相棒との分担と渡航の負担は、探索を支える背景として方向が定まった。[先代の具体化資料0.3](../../仕様案/世界観/先代の辿り方と主人公の単独探索.md)の具体的な台詞・小道具・能力名・相棒の正体までは一括採用しない。

0.6では主人公の行為に戻り、**何をどう写すか → 札としてどう扱うか → 何を持ち帰って自分の手段にするか**を先行するとした。今回の到達点は上の0.7節に記す。既に決まった元への無影響、札と道具の基本形、貸与条件、人物像や店を未選択へ戻さず、残る境目を具体例で比較する。

3は本筋の取得・構築の検討とも関係が深いため、1・2の全細部の確定を待たずに必要な箇所を進められる。4の主人公の渡航・帰還条件が写しの説明に影響する場合も、関係する点を先に取り上げる。

## 4. 他Workとの分担

| 担当 | 主に定めるもの | こちらから接続するもの |
|---|---|---|
| 世界観Work | 複数案件に共通する世界の原則、主人公・日常・不思議の関係、正式用語、世界観DB | 原則案、採用区分、代表例、変更IDと参照版 |
| ビジュアル・演出Work | 画風・空間・材質・動き、札と道具の表現見本 | 何が実体か、何を写しているか、札と道具の関係。見た目や所作の比較は担当側で進める |
| シナリオ・探索内容Work | 代表案件を一往復の場面・対象・本文・素材へ落とす | 写し・帰還・相談の共通原則と、再訪の型。具体案件の順序や台詞は担当側で進める |
| 設計本筋・UI・試遊 | 進行・演算・数値・統合、情報と操作、実際の試遊 | 世界内説明と用語。説明だけで新しい取得規則・渡航費・表示操作を採用しない |

今の残課題は既存の分担で扱えるため、新しいWorkの新設を前提にしない。共通の世界法則と個別案件の都合を分け、全論点の決着を他Workの進行条件にはしない。

## 5. 後へ回せる詳細

先代の能力名や厳密な準備日数、相棒の正体、人物の固有名、学校の全名簿、世界全体の起源、全異界の地図・年表は、必要な場面から詰める。旅が深まるほど主人公の関係が広がる軸は検討するが、生業の動機を必須の宿命へ置換しない。

言語や時間差は往来の具体例で不都合が出る範囲から検討し、万能通訳・一律の時間差・全世界共通の通貨を先に導入しない。不思議の多様性を保ち、全案件を同じ修理・退治・悲劇へ寄せない。

## 3. 各論点で最初に比較する範囲

### WB-NEXT-001：道具化

まず、元の不思議から性質を写す・分けてもらう・取り除くなどの違いと、どこまで共通にするかを比較する。由来を夢等へ絞り直さない。札を他人が使えるか、共有の場で借りることと恒久的な譲渡をどう区別するかも対象にする。

能力の万能化や制約の増加を目的にしない。現行の札循環・出現元・消滅・恒久解放を読める基本形を先に作り、必要な例外を残す。材質・所作の見本はビジュアルWork、共通の存在上の扱いは世界観Workが担う。

### WB-NEXT-002：日常と社会

既に採用した「知識は人や地域によって偏る」を具体化する。一般住民、顔なじみ、入口を知る専門家など、何を知る人が何を頼むかを短い場面で比較する。往来の痕跡、地域の宿や仕事を足場に、世界間の接点を作る。

主人公の仕事を道具調達へ固定せず、未知を調べられる専門性を維持する。統一組合・全世界共通通貨・万能通訳・一律の時間差などは必要性を比較してから扱う。

### WB-NEXT-003：主人公と拠点

主人公がどこまで固定された人物かを先に考える。見た目・一人称・台詞の主体性への影響を比較し、その後に名前や詳しい経歴を詰める。仕事場の一角、顔なじみ数人の役割、帰還で変わる小さな生活を最初の材料にする。

### WB-NEXT-004：失敗と再訪

本筋の各結果で何が保持・喪失されるかを先に確認し、作中の描写を対応させる。死亡を自動的に救出へ言い換えるなど、処理に関わる変更は提案として本筋へ渡す。解決後も住人や土地が続き、別の用事・区域・往来が生まれる型を複数持つ。対象の残量0、区間の突破、探索クリア、案件解決を分ける。

### WB-NEXT-005：成長と取得

帰還後の振り返り・他者との持寄り・試作・教えや譲り受けなどから、各処理に合う営みを比較する。札を現地で使うこと、利用の解放、所持個体の取得、基礎の心得の習得、今回の装備を一つに混ぜない。

[成長・取得・心得準備の用語0.3](../../仕様案/世界観/成長・取得・心得準備の用語.md)では着想を正式名候補として仮置きした。心得容量・負荷等は未採用案。従来の習得点と同じ資源として対応を保持する。用語の最重要軸を世界観との適合、次点を分かりやすさとし、維持案も比較する。資源の支出を記憶の消失にしたり、名称だけで装備方式を決めたりしない。

同資料0.1は基本設計0.52時点の記録であり、候補取得方式の採用状態は更新された。最新0.53・D53で帰還後の候補選択型取得の大枠が採用済み。三候補固定ではなく踏破難易度等で選択肢を揺らせる。価格・候補数範囲・更新条件・総装備コスト方式等の未決定部分とは区別して、次の比較へ反映する。

### WB-NEXT-006〜008：作品の幅と継続管理

一つの案件の都合を、全異界共通の真相や唯一の遊び方へ広げない。恐怖、驚き、可笑しさ、土地の生活、解決しきれない余韻などを、短い具体例で比較する。長い旅の関心も候補にできるが、決定済みの生業動機を置換する必須の宿命にはしない。

DBは景観・由来に加え、危険の理由、現地判断、奥へ行く目的、帰還後の変化で点検する。全案件を同じ設備修理や退治へ寄せない。新Workからの素材は安定IDと出典を保ち、個別採用と本文反映を分ける。属性は働きの軸、道具名は具体的な形と必ずしも同じでない原則を維持する。

## 4. 着手順と、後へ回せること

第一のまとまりは **道具化の基本形（001）・日常との距離（002）・帰還後の営みと成長用語（005）**。それぞれ少数案と場面例を用意し、共通原則としてどこまで採るかを比較する。

次に主人公と拠点（003）、失敗・再訪（004）、語り口と長い旅の軸（006）を、新Workの場面案・表現見本から得た問いと合わせて詰める。DBと用語（007・008）は必要箇所を継続更新する。

創世の全貌、全異界の地図や年表、全人物の詳細な経歴、全素材の大量制作は、今の開始条件にしない。代表案件の手掛かりに真相が必要な箇所は局所的に定め、作り手が定めることと作中で明かすことを区別する。

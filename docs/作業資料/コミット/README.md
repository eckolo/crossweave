## 確認方法

元リポジトリのルートで、現在の作業状態を変えずに確認できる。

```sh
git log --oneline dev_design_tmp_assembly..dev_design_docs_organized
git diff --stat dev_design_tmp_assembly..dev_design_docs_organized
git show --stat dev_design_docs_organized
```

現在の作業ツリーには整理済みの未追跡・変更中資料があるため、ブランチ切り替えや現在のブランチへの取り込みは、`git status` で状態を確認したうえで行う。作業内容を捨てるresetや強制更新は不要。

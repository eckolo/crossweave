カード探索ゲームの「一手の選択を面白くする、最小限の戦闘設計」を検証したWorkからの報告です。戦闘・探索・札循環・行動コストの設計と照合し、確認済み事項、採用候補、統合後の検証を整理してください。

最重要の評価軸は「これで面白いかどうか」です。勝率・合法な選択肢の数・計算上の最大ダメージだけで判断せず、状況によって選ぶ札・対象・温存する札・許容する危険が変わるかを重視してください。

まず上記の現在の入口から採用仕様・未採用案・作業状態を確認し、次の資料を読んでください。読めない場合は推測で補完せず確認してください。

- [カード探索ゲーム_戦闘検証報告.md](../../検証/戦闘/カード探索ゲーム_戦闘検証報告.md)：判断・比較結果・前提・到達手順。8章は準備への介入、9章は防御反復、10章は敵の防御会心への牽制、11章は統合後の課題。
- [カード探索ゲーム_戦闘検証.js](../../検証/戦闘/カード探索ゲーム_戦闘検証.js)：再現コード。外部パッケージ不要。通常実行で防御持続等13枝、`--gain` で会心加算時点6枝、`--extra` で今回追加32枝。各コマンドへ `--full` を加えると初期状態からの履歴を出力します。

本Workの最新参照版は基本設計0.8です。正本は直接更新していません。報告の付録Bは旧防御期限での前段検証であり、現行仕様や最新の未確定事項と混同しないでください。

このWorkでの確認・判断は以下です。

- 命中度100未満の攻撃はダメージ0で蓄積し、100以上になった攻撃で命中・リセットします。
- 会心倍率は `1+floor(会心度/100)`。100未満でも通常1倍で攻防が働きます。未命中で100以上へ到達した会心度は消費せず、後の命中時に発動・リセットします。攻撃・防御の会心度は主体ごとに共用します。
- 能動防御は札の一致で起動し、ノーガードで受ける選択を作る方向で検討しました。防御は自分の次の札が一致するまで規定回数有効、不一致の設置は待機として防御を維持する方向です。
- 防御の有効回数は未命中では消費せず、命中した攻撃へ防御を適用したときに1消費します。0ダメージへ抑えた場合も含みます。
- 防御側の会心度は、防御札の一致時に1回だけ加算し、実際に防ぐ際には加算しない方式をユーザーが選択しました。原案意図は実際の防御ごとの加算でしたが、自分の札選択で制御しやすくすることを理由に変更した判断です。両方式の併用ではありません。
- 基礎防御力はなくてもよく、常時の硬さは持続軽減で表す案が出ています。試作は基礎防御力なし、防御札の効果量で軽減します。持続軽減の演算は未設計です。

防御値3・回数1/2、会心加算25/50、HP、各札の主効果・場補正・期限、敵の選択規則、山札順、待ち時間8/10はすべて仮値です。能力値と札効果の合成、新しい防御への置き換え・重ね掛け、負ダメージ、会心超過の上限、複数対象等の細則は独断で確定しないでください。

主な知見は以下です。

1. 防御を維持して不一致の札を置くか、今使える重撃を一致させて防御を終了するかが、敵HPによって変わる局面がありました。一方、手札の全属性が場に揃うと待機を選べず、防御を維持できない失敗例もあります。自由パスは追加していません。
2. 重撃を既に手札に持つ状態でも、踏み込みを設置して場の攻撃+6を使う準備が成立しました。短い期限の牽制を失って長い期限の設置札を使う理由になります。しかし敵がB札を持つと補正を利用され、環境が先にBを使う場合も準備を失います。大技を場へ置き、その負の命中補正を使う選択が危険を抑える例もありました。
3. 設置後の仮待ち時間を10から8へ変えると、先に動く環境より前に自己再利用できる例がありました。ただし途中の敵には奪われます。総回数や連続行動の有無だけでなく、誰が介在し、どの属性を使えるかを評価する必要があります。具体コストの採用根拠にはしないでください。
4. 防御の一致材料が規則的に供給され、敵の命中が遅く、環境も進行しない診断条件では、17巡まで無傷で防御を繰り返せました。防御回数を2から1に減らしても変わりません。一方、敵の命中や供給属性を変えると同じ手順で被害が出ます。防御で会心を蓄積し、設置→重撃で無傷の撃破へつなぐ手順も成立しました。戦術としての成功と、安全な反復への固定化の危険を両方報告しています。無限継続や通常デッキでの最適性は証明していません。
5. 敵の防御会心を0ダメージの牽制で消費させ、次の重撃を通す手順が成立しました。専用の体勢崩しゲージは追加していません。ただし、牽制で相手の命中度もリセットされるため、重撃を再命中させる場補正等が必要です。敵HPが低ければ重撃を先に出して撃破する方が早く、牽制を毎回挟む必要はありません。

すべて、空の場・命中度0・会心度0から、手札補充・期限・一致強制を適用して到達した局所比較です。追加分は行動時刻も確認しました。ただし指定した山札と行動列を使う診断であり、山札再構築・探索全体・報酬・一般的な手札頻度のシミュレーションではありません。敵の隠れ手札や対象選択の確率を置いていないため、勝率や期待報酬へ読み替えないでください。

統合では、追加状態異常を急いで増やさず、攻撃量・命中の進み方・共有場の補正・期限・能動防御と共用会心で最初の試作を構成する候補を検討してください。そのうえで次を優先してください。

- 実際の札構成と共通循環で、牽制・大技・防御・一致材料の競合が適度に生まれるか。
- 行動コストを具体化した際の回数均衡、自己再利用、敵・環境の介入、防御中の被弾回数。
- 環境進行・イベント・報酬・回復を含めた長居の利益と負担。会心上限などの新制限は自動採用せず、既存の設計範囲から比較すること。
- 命中度・会心度・防御残回数・行動時刻・敵の性格情報をどこまで示せば、読み違いを抑えながら一手を考えられるか。これは試遊で判断負担とともに確認すること。

本Workでの結論は「最小構成でも選び分ける理由と崩れる条件を具体化でき、統合試作へ進める材料が揃った」です。面白さの実証や全数値の確定とは扱わないでください。重要な設計判断が残る場合は、ユーザーへ一つずつ確認してください。

今回の制作対象は代表2点。用途表だけ・1点だけで終了しない。入手や編成の価格・個数・効果計算は描き込まず、D03Rの経済契約を制作開始条件にしない。札絵は札枠・文字・数字から分け、必要な透過を生成時から指定する。札枠の現行248×208等は読取参照として記録し、UI側の最新版との一致を確認して出力条件を決める。

## 担当境界と終了

直接更新は既存のビジュアル専用フォルダ、自Work設定、同期記録。新成果は専用領域の`CO-V02A/`等へまとめ、旧背景原本・制作記録は保全する。UI原本・共通runtime・世界観・シナリオ・計画原本を独立編集しない。UIへの実装は提出素材を受け取ったUI担当が行う。

合成・コードからの寸法確認・実ブラウザーでの描画・ゲーム実操作・ユーザーの個別採用を区別する。正式手順への準拠を、個別画像の正式採用済みという意味にしない。素材納品と候補提示を完了単位とし、既了承の画風を再選定する確認待ちで止めない。

最終応答冒頭は「今回の依頼全体（CO-V02A）は完了／未完了」。V1〜V4、成果commit・ファイル、未保存／未反映、実施した確認と未確認、残件・ユーザー判断、UIに渡す素材と再開点を自Workへ保存して提示する。UI受領・実接続やCO-V02全体完了を先取りしない。

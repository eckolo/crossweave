## 利用者へ最初に案内する範囲

1. Windows11 x64の実機を使えるか、本編ZIPを既存Dropboxから入手済みかを確認する。必要なのは本編ZIP1個。コードや検証資料ZIPの展開、Godot／SDK／Python導入は不要。
2. ZIPの版とSHAを一度照合する。入手先と一致した実ファイルの記録を残す。これは実機確認で使用する版の識別で、P5の2ZIP全量内容検査を利用者へ追加する指示ではない。
3. 全展開して `Crossweave.exe` を起動。最初は画面が出ることと、短い探索を中断して再起動後に続けられることを確認してもらう。問題があればその地点の画像・直前操作・ログだけを求める。
4. 操作可能なら同じ版で一巡と残項目へ進む。確認済みの操作を別票のためだけに繰り返さない。遊びの所感は保全し、P02の評価を実施済みにはしない。

通常セーブは `%APPDATA%\crossweave\saves\local\m1.json`。終了後に保存フォルダーを控え、実行物の更新先と区別する。既存セーブの削除・初期化や検査用slotへの無断切替はしない。同一ZIPの差替えと将来の異なる配布版への移行を区別する。

性能目標や測り方は元の確認票に従う。高性能PC・CIの値を基準機合格に一般化せず、測れない数値は未計測にする。本編は旧proofのmetrics.jsonを生成しないので、その提出を一律要求しない。音だけ旧proofを使う理由を説明する。

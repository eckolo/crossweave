## 1. 最重要の設計方針【採用】

最重要の評価軸は「これで面白いかどうか」。合法な選択肢や分岐の数だけで評価せず、状況によって選ぶ札・対象・許容する危険が変わるかを確かめる。

- ゲーム全体は、ハクスラ的な「探索による自己強化と、その成果を使ったさらなる探索」を基軸とする。
- 共有の場に出した札を、敵や環境にも利用されることが駆け引きの中心となる。
- 属性一致を行動成立の条件とし、有利な一致だけでなく、不利な一致を避けたい状況も作る。
- 札の循環によって、その後の自分・敵・環境の行動材料が変わる。
- 突破を重ねるイベントでは攻撃寄り、敵との戦闘では防御も含む構成が役立つ、といった探索内容に応じた攻防配分の取捨選択を目指す【0.39・ユーザー要望】。具体的な最適比率や、敵戦で防御札を必須にする規則は定めていない。
- 操作の中心は手札から出す札の選択。常設ターゲットの切替は許容し、毎回の対象指定や札の個別整理をできるだけ繰り返させない。
- 途中の判断・展開に乱数が関わることは許容する。乱数だけで最終結果が決まる構造や、完全に次の行動が読める構造への偏りは避けたい。
- 行動主体の違いは、パラメータと行動決定者に集約することを目指す。

## 2. 行動主体と探索【採用仕様・移動済み試験節の案内】



<a id="section-2-1"></a>

### 2.1 共通の行動主体

プレイヤー・敵・環境は、共通の札使用、属性一致、補充、回収、効果適用のルールを使う。

| 項目 | 方針 |
|---|---|
| 行動決定 | プレイヤーが決める主体と、自動で決める主体がある |
| 主体の個性 | 手札規定枚数、初期山札構成、初期属性傾向、再構築量、能力値、性格などで表す |
| 相互作用 | 環境から敵、敵から環境への作用も認める |
| 基本頻度 | 通常の構成・行動選択では各主体がおおむね同じ行動回数になるよう調整する。札コストによる回数差は許容する。従来の1巡1回は比較基準として残す |
| 将来の拡張 | 行動順を補正する手段を検討する |

<a id="section-2-2"></a>

### 2.2 踏破イベントと参加する対象【0.32で一般化】

- 環境は探索・戦闘に参加する行動主体。手札規定枚数は1枚を基本とする。踏破時に旧環境が退場し、新しい環境へ交代する構成を認める。
- 探索を構成する踏破イベントには、敵との遭遇、障害物への対処などを含める。敵との遭遇はその一種として扱い、探索進行の仕組みを敵遭遇専用にしない。
- 大岩を削って破壊し先へ進む／環境を削って迂回する、といった複数の解決経路を設定できる。
- 敵との遭遇では、環境に加えて敵が行動主体として参加する。
- 複数の環境が同時に存在する構成も認める。環境を常に一つに限定しない。
- テンポへの影響は、敵だけでなく環境等を含めた同時行動主体の総数で評価する。多数を標準にするとは決めていない。
- 障害物の具体的な行動方式・札構成、各終了経路の報酬・状態引継ぎは、個別イベントとして具体化する。
- 単一属性に強く偏る環境・敵も、極端な構成として許容する。
- 環境は出す札が1枚に定まっていても、他者単体効果の対象を決める行動判断を持ち得る。

<a id="section-2-3"></a>

### 2.3 HPによる決着

- 通常の敵はHPが0になれば撃破。
- プレイヤーはHPが0になれば敗北。
- 環境にもHPを持たせ、通常はその残HPを探索区間・フェーズの進行条件に用いる。イベントごとに別の値・条件を使ってもよい。
- 環境HPを削り切ることは、その環境の踏破を表す。ボス戦中も環境踏破をイベント終了条件に含め、選ばれた場合に旧環境を退場させ、緩めの新環境が参戦する後続イベントで戦闘を続けられる。
- 踏破後も戦闘に環境が参加し続けることは、HP0の同一環境を残す方式に限定しない。現在は旧環境の退場・新環境の参戦で表す方針へ更新している。
- イベントの終了条件を優先順位で選ぶことによって、通常のダメージやHP0の基本規則を取り消すわけではない。

- 攻撃側の会心について、未命中の攻撃で会心度が100に達した場合はその時点で消費せず、後の命中時に会心を発動・リセットする【ユーザー報告内の確認事項を統合】。

### 2.4 探索の成果と成長【採用方針・探索Work報告を統合】

- 個々の敵や攻略対象から成果を確保でき、環境の削り切りによる踏破にも報酬を持たせる。全滅まで報酬を一括保留する設計にはしない。
- 逃走は、ダンジョン内で遭遇した敵対存在を振り切る行動であり、探索全体の終了を意味しない。それまでに獲得した敵報酬などは保持する。
- 成長報酬に、探索中の循環へ混入した札の現物そのものは含めない。初期山札にセットできる札の選択肢の増加や、パッシブスキルの習得などを想定する。成長ポイントの用途の具体像は2.23・D47に従う。
- 成長報酬は、使い道を選択できる成長ポイントと、素材や札などの用途が限定された報酬を併用する【D43】。ポイントによる成長先の選択と、報酬ごとに定まる用途・札の選択肢の獲得を共存させる。
- 成長ポイント・用途限定報酬とも、今回分の持帰りは2.13の既存の保護・精算に従う【D43】。報酬としての札は初期構築の選択肢へ接続し、共有循環中の札の現物を持ち帰る扱いへ変更しない。
- 環境踏破後もボス戦が続く場合、その環境に設定された踏破報酬は踏破分として確保する。環境交代そのものを追加報酬の根拠にはしない。
- 9.4の、ボス撃破後に追加踏破を要求するかを環境ごとに設定できる方針と両立させる。

能力強化は帰還後に反映する（2.14）。環境1つの長さと途中中断・状況確認の方針は2.11、任意撤退・クリア・死亡時の精算と報酬保護は2.12・2.13へ記録する。死亡時は今回の報酬を保護済みも含めて失うが、過去の探索で確保した札解放・恒久強化は失わない。

個別報酬を全滅まで保留しないことと、報酬の厳密な判定時点は別の設計とする。報酬導入によって9.3の「終了条件を一つ選んで対応処理を行う」規則を変更しない。遭遇中の敵の撃破報酬は、とどめの主体やプレイヤーの直接攻撃の有無によらず得る（2.15）。

### 2.5 回復資源の扱い【採用方針・探索Work報告を統合】

- 回復は、探索中の利用機会や回復量をやり繰りする設計とする。
- 主に回収時消滅などを用い、再利用が難しいか、高コストになる方向で調整する。すべての回復札に同じ仕様を義務付けない。
- ここでの「高コスト」は一般的な負担の意味であり、今回提案された行動時間コストへの一本化を意味しない。

回収時消滅型の回復札は、使用だけでなく期限切れでも失われる。

### 2.6 初期山札の構成を残す目標【採用方針・具体手段は未確定】

- 出発前に組んだ札の組合せを、探索後半でも常に狙える必要はない。
- 一方で、その構成が完全に崩れ、狙っていた組合せや強みとの接点が失われる状態も目標としない。
- 戦い方の工夫によって構成を維持しやすくできることを、望ましい検討方向とする。具体的な維持手段の採用ではない。
- 共有循環で借りた札を使う変化と、初期構成に沿う動きを再び狙える機会の両方を評価する。初期属性比率そのものを一定値へ戻すことを達成条件とはしない。
- 能力値などに得意分野が残ることだけで、この目標を満たしたと決めつけない。実際の札・場・成立機会を含めて検証する。

方針はユーザー確認済み。特定札の供給保証、属性優先受取、主体専用供給、新しい適性・固有能力は、この判断だけで追加しない。

### 2.7 初期山札の同一札投入上限【基本方針を採用・具体値未確定】

- 初期構築時に限り、全札共通の固定枚数上限を設ける方向を基本とする。
- 初期山札が大きくなっても、同じ札を入れられる上限は比例して増えない。山札の一定割合まで入れられる方式とは区別する。
- この構築上限を、探索中の共有循環で同じ札を受け取る場合へ適用しない。超過札の選別・排除などの追加操作は設けない。
- 札ごとに別の上限を持たせる方式を、最初から基本にはしない。
- 制約は必須条件として固定しない。制約なしの方が面白いと判断されれば見直せる、というユーザーの方針を維持する。
- 山札の大小、主力札の反復、使い分ける札、借り札への適応、探索へ持ち込む消費資源によって、構築や行動の選択が変わるかを評価する。

試作で使う数値と札案は2.8で区別する。

### 2.11 区間の長さと中断・継続支援【採用方針・詳細は未確定】

- 環境の踏破にかかる長さは、難度や性質によって変えられるようにする。
- 長めでも30分程度で踏破することを肌感の目安とする。遵守が必要な上限・標準値・時間制限ではなく、全環境を同じ長さへ揃える判断でもない。
- 途中で探索を切り上げる離脱、セーブしての一時中断と再開などを整え、長い連続プレイを強制しない方向とする。
- 体力・山札・手札・獲得済み報酬の状況確認を充実させる。可能なら、ある程度の履歴も確認できるようにする。
- 30分を既存試験の行動数へ固定換算せず、仮HPや行動コストをこの目安だけで自動変更しない。探索全体の時間と、環境1つの踏破時間は区別する。

戦闘中の任意撤退は2.12、踏破による報酬保護と撤退時の未保護分喪失は2.13へ記録する。探索終了時は2.13に従い、クリア・任意撤退・死亡で精算を分ける。状況確認の詳細は6.5、中断・再開の比較は統合検討17章、探索終了時の精算と強化反映時期の比較は18〜23章へ記録する。

### 2.12 任意撤退と代償【採用方針・詳細は未確定】

- 戦闘中でも、任意に探索全体を終了できる。本書では「任意撤退」と呼ぶ。
- 「進むか退くか」をゲーム性に持つため、撤退のデメリット・コストを低すぎないものとし、安易な濫用を抑える。2.13の未保護報酬の喪失を基本とし、追加の負担の要否は今後の検討とする。
- 現在の敵を振り切って探索を続ける「遭遇からの逃走」と、探索全体を終える任意撤退は区別する。前者で既得成果を保持する採用事項から、後者の成果保持を推測しない。
- 同じ探索を後から続ける「セーブしての一時中断・再開」も別の機能であり、今回の撤退負担の検討対象と混同しない。
- 今回の探索で獲得した報酬の一部を、任意撤退の代償として失う方式を許容する【採用した設計の幅】。今回得た初期山札用の札解放や恒久的な能力強化も、喪失対象に含められる【採用した設計の幅】。
- 喪失の範囲は2.13の保護状態で決める。一律の割合減算やランダム選別を基本には使わない。今回の能力強化は帰還後に反映するため、探索中に適用してから撤退時に巻き戻す方式は使わない（2.14）。

帰還用の道具・新しい通貨・待ち時間・追加被弾・支払不能時の撤退禁止は導入していない。探索前から持つ解放・強化の没収へは広げない。環境踏破による保護と任意撤退時の精算は2.13へ記録する。比較と次の判断は統合検討18〜24章、要検討事項Q05・D18〜D24へ接続する。

任意撤退の方針から、成立済みの一手を取り消せるとはしない。

### 2.13 環境踏破による報酬保護と探索終了の精算【採用】

- 個々の敵・攻略対象から報酬を都度獲得する。報酬を得たことと、任意撤退で失わなくなることを区別する。
- 大岩を破壊して進む／環境を削って迂回する、のどちらも報酬獲得へつなげる。各経路の報酬内容・量・獲得条件は具体イベントで定める【0.33で方針を明確化】。
- 環境踏破がイベントの結果として処理されたとき、その踏破報酬を含む、そこまでに獲得した報酬を任意撤退の喪失から保護する。
- 保護の契機は環境踏破に揃え、踏破以外の障害物破壊や個々のイベント終了へ、追加の保護設定を持たせない。報酬獲得は複数の攻略から得られ、保護は踏破でまとめる。細かな保護条件を覚える負担を増やさないことを理由とする【0.33で確認】。
- 探索全体から任意撤退すると、保護済み報酬を保持し、最後の保護以降に得た未保護報酬をすべて失う。探索前から持つ解放・強化の没収は含めない。
- 踏破時点より後に得る報酬は未保護となる。先に環境を踏破したことだけで、後から倒す敵の報酬まで保護されるわけではない。新しい環境へ進んでも既に保護した報酬の状態は維持する。
- 最初の踏破前に任意撤退すれば、今回の成果がすべて未保護で全損する場合がある。踏破直後に未保護報酬がなければ、獲得済み報酬を失わず任意撤退できる。両方を含めて採用する。
- 遭遇からの逃走で探索を続ける場合は、未保護分も保持する。一時中断・再開を、報酬喪失や保護の契機にはしない。
- ボス戦中に環境を踏破して交代する場合も、その時点までの報酬を保護する。後から得るボス報酬は未保護となる。
- 単なる戦闘イベントの終了、敵単独の逃走、増援などを追加の保護契機にはしない。環境踏破と他の終了条件の同時成立には既存の優先処理を使う。
- 探索全体をクリアした場合は、未保護分も含めて今回の獲得報酬をすべて持ち帰る。最後の報酬を保護するためだけの追加踏破は要求しない。途中の戦闘イベント終了や中間ボス撃破を、それだけで探索全体のクリアとは扱わない。
- 死亡によって探索が終了した場合は、今回の探索で獲得した報酬を、保護済み・未保護ともすべて失う。過去の探索で既に確保した札解放・恒久強化は失わない。死亡後の追加ペナルティは、この精算に加えて採用していない。

この「保護」は任意撤退による喪失からの保護であり、死亡時には保護済み分も失う。強化が使えるようになる時点とは区別する。能力強化の反映は帰還後とする（2.14）。探索を継続するイベント移行では、移行だけを理由に未保護分を消さない。9.4の追加踏破を要求しない設定も維持する。

採用理由は、欲しい敵から成果を得る判断と、環境を進めて今の成果を守る判断を、既存の対象選択へ接続できること。

障害物突破等へイベントごとに保護を付ける拡張案は見送り。岩破壊による進行を、それだけで環境踏破と読み替える新しい定義も追加しない。複数環境の踏破・後続・報酬獲得時点の具体的な接続は、[仕様案9.1](../仕様案/カード探索ゲーム_仕様案.md#section-9-1)で継続する。判断記録は[統合検討54章](../作業資料/カード探索ゲーム_統合検討.md)。

### 2.14 能力強化は帰還後に反映する【採用】

- 今回の探索で得た成長報酬としての能力強化は、帰還後に反映する。報酬獲得時や環境踏破による保護時には、今回探索の能力を増やさない。
- 帰還時は2.13の精算を先に適用し、持ち帰れた強化が反映対象となる。クリアは今回分すべて、任意撤退は保護済み分を対象とし、死亡では今回の強化を持ち帰らない。過去の探索で確保した強化は維持する。
- 個別報酬を獲得・確認することは探索中に行える。帰還後反映を、全滅や探索終了まで報酬獲得そのものを保留する意味にしない。
- 探索中の手段や戦い方の変化には、敵・環境由来の札が混じる既存の循環を活かす。混入が常に強化になることや、有用な札が必ず手元に回ることは保証しない。
- 採用理由は、札循環で新しい手段を使う体験を作れることと、序盤に有利な能力強化報酬を得られるかによって、その後の攻略が左右され過ぎる構造を避けたいこと。
- この方針の対象は成長報酬の能力強化であり、札効果などによる探索中の一時的な能力変化を一律に禁止する判断ではない。
- 2.4の併用方針に従い、成長ポイントは帰還後に使い道を選んで成長へ用いる。素材・札などの用途限定報酬は、それぞれに定めた用途を持つ【D43】。用途が限定されることと、自動で消費・適用することは別とし、具体的な使用操作は個別に定める。
- ポイントと用途限定報酬の配分・入手先・個別用途・費用・上限、素材とポイントを同時に要求するか、重複した札や余剰素材の処理は未決定。成長ポイントの主用途とパッシブの取り直しは2.23・D47へ明記する。併用方針だけから、全報酬のポイント換算や全強化への素材必須を導入しない【D43の採用範囲】。

帰還時の全回復と探索の入口からの新しい出発は、0.34の別の採用判断として2.18へ記録した。札解放は初期山札の選択肢を増やす既存方針を維持し、現在の循環へ報酬札を自動投入しない。

序盤の成長報酬による戦力差の増幅を抑える判断であり、借り札の引きや遭遇内容による変動までなくなるとはしない。検討記録は統合検討23・24章。

【別資料へ分離】未採用案・未決定の詳細：[仕様案](../仕様案/カード探索ゲーム_仕様案.md#section-2-14)／試験前提・仮設定・検証メモ：[試験条件・検証メモ](../検証/統合試作/カード探索ゲーム_試験条件.md#section-2-14)。

### 2.15 他主体による敵撃破と個別報酬【基本方針を採用】

- プレイヤーが遭遇中の敵が環境や別の敵に倒された場合も、その敵に設定された個別の撃破報酬を得る。
- プレイヤーがとどめを刺すこと、直接攻撃すること、一定の与ダメージ割合に達することを条件にしない。これらの寄与による報酬減額も基本方式には使わない。
- 報酬を得た後は2.13の保護・精算に従う。他主体に倒させたことを追加の保護契機にはしない。
- 敵の逃走やイベント都合の退場を、それだけで撃破報酬の取得条件とは扱わない。
- 場の材料を残す・奪うことで他主体の攻撃を利用する行為も、成果へつながるようにする。直接攻撃をしない攻略を、報酬条件によって一律に不利にしないことが採用理由。

NPCにプレイヤーと同じ恒久成長報酬を配る決定には広げない。

### 2.18 帰還と新しい探索【0.34で採用】

- 探索を終えて帰還したらHPを全回復し、次の探索はその探索の入口から新しく始める。
- 入口は選んだ探索の開始地点を指し、ゲーム全体の最初からやり直す意味ではない。到達済み区間の初めから再出発する方式を基本にはしない。
- 2.13の精算に従って持ち帰った札解放・能力強化を使い、出発前に初期山札を選び直せる。過去の探索で確保した解放・強化は保持する。
- 新しい探索には、前回の手札・共有の場・借り札・命中/会心蓄積・防御・削りかけの敵HPなど、探索中の状態を持ち越さない。
- 同じ探索内のイベント移行は、既存の継続主体・退場・札循環の規則で状態を引き継ぐ。帰還後の再出発と区別する。
- セーブしての一時中断・再開は同じ探索の継続であり、HP回復や帰還精算を発生させない。
- 任意撤退・クリア・死亡による報酬精算は2.13を維持し、新しい帰還費や死亡への追加罰はこの採用に含めない。

複数区間にわたる消耗、探索中に変化した札構成、途中で帰還して準備し直す判断を一つの探索へ結び付ける基本方針。比較と採用記録は統合検討58〜60章、要検討事項D34。消費型の持参札を次探索で再セットする方針は2.19・D35で採用した。回復札の具体性能と探索内の補給は引き続き具体化する。

<a id="section-2-19"></a>

### 2.19 消費型の持参札と次の探索【0.35で採用】

- 解放済みの消費型札は、前の探索で使い切っても、次の探索の初期山札へ補充費なしで組み込める。
- 消滅による持参資源の制限は、一回の探索内で扱う。探索をまたぐ恒久的な枚数在庫や補充費は基本方式へ設けない。
- 初期構築の枚数・同名札の上限は既存の規則に従う。解放だけで無制限に持ち込める意味ではない。
- 同じ探索内では消費・消滅状態を保持する。区間移行やセーブ中断で札を自動復元しない。帰還後に新しい探索へ出発することと区別する。
- 探索中の有限補給を設ける場合は、具体的な札・イベントの条件として扱う。今回の採用だけで補給イベントや回復の無限生成を追加しない。
- この方針は消費型札の次探索での扱いを定める。全ての札を消費型にする、全ての回復札を同じ消滅条件にする、という採用ではない。

持込配分と探索中の使い所へ判断を集める方針。統合検討63章の案に対するユーザーの「よい」を64章・D35へ記録する。回復量・期限・場効果・探索内の供給量は仮条件による比較を続け、数値ごとの許可待ちは設けない。

### 2.20 探索先の特徴と再挑戦時の変化【0.44・D44で採用】

- 同じ探索先では、出発前の準備と狙う成果の根拠になる攻略傾向・成果の系統を保つ。その範囲で、探索ごとに遭遇する敵・環境の組合せや順番などが変化し得る構成を基本とする。
- 探索先を選んで準備する意味と、現地の相手・場・共有循環に応じて対応する意味を両立させる。
- 毎回すべての内容を変更する義務ではない。固定の場面や、同じ構成へ再び遭遇することも許容する。
- 対象について学んだ知識は6.4に従う。同じ識別対象の基本構成と、別構成の個体・現在の非公開札を区別する。
- 2.18の帰還後の新しい探索と、同じ探索の中断・再開を区別する。中断からの再開は保存した同じ探索の継続として扱う。

具体的な生成方式、変動範囲・率、途中の進路選択、報酬の確率・獲得保証・詳細公開、成長量、探索先の解放条件は未決定。成長に対する敵・環境の難度方針は2.21を参照。この基本方針だけで、マップの全面自動生成、毎回の報酬抽選、特定対策や勝利の保証を追加しない。

採用根拠は、統合検討100章の基本案に対する2026-09-10のユーザー承認「よい」。101章へ採用範囲を記録し、[探索全体の設計](../仕様案/カード探索ゲーム_探索全体の設計.md)に比較経緯と未決定の詳細を保持する。

### 2.21 恒久成長と探索内容の難しさ【0.45・D45で採用】

- 敵・環境の強さは探索内容側の設定を基準にし、プレイヤーの恒久成長に合わせて自動的に引き上げる方式を基本にしない。
- 成長によって以前の探索が楽になることを許容し、新しい挑戦には別途その内容に応じた難しさを設定する。
- 2.20の遭遇構成の変動と、共有循環・現在状態による行動の変化は維持する。同じ敵が常に同じ札を使う、同じ消耗・勝敗になる、という保証ではない。
- 別の強い個体・難しい内容の設定と、同じ内容をプレイヤーの成長だけに連動して強めることを区別する。

個別の成長先・量・上限、難度選択UI、探索先の解放条件、報酬配分はこの採用に含めない。成長ポイントによるパッシブ習得と取り直しは、その後の2.23・D47による別の採用。通常の行動性能を札から取得する4.7の方針も維持する。

採用根拠は、統合検討102章の基本案に対する2026-09-10のユーザー回答「それでよいが、課題への対応策もしっかり策定するように」。採用範囲は統合検討103章、対応策の具体案は[探索全体の設計10章](../仕様案/カード探索ゲーム_探索全体の設計.md#growth-countermeasures)へ記録する。対策の策定指示だけで、新たな成長制限・報酬ルールまで採用した扱いにしない。

<a id="section-2-22"></a>

### 2.22 探索先の選択と全体の進行【0.46・D46で採用】

- ゲーム全体は、攻略傾向や得られる成果の異なる探索先を選びながら進み、要所の攻略によって次の範囲が開く構成を基本にする。
- 各段階の全探索先の攻略を、次へ進むための一律の必須条件にはしない。
- 探索先が新たに選べることと、同じ探索の途中で別の区間へ進むことを区別する。帰還後の新出発は2.18、探索中の状態継承は既存9章に従う。

採用対象はこの基本構造。探索先の数・具体的な解放条件と記録時点、初期の公開範囲、成長量・入場費、世界観上の地理や接続方法、ゲーム全体の終点は未決定。AまたはBを一つクリアするとCが開く等の例を、そのまま全体共通の解放条件へ固定しない。

採用根拠は、統合検討106章・探索全体の設計12.5の基本案への2026-09-10のユーザー承認「良い」。併せて「様々な世界の繋がり」という世界観側の要素との整合が指摘された。採用記録は統合検討107章、世界観と情報・目的の接続案は[探索全体の設計14章](../仕様案/カード探索ゲーム_探索全体の設計.md#unknown-exploration)を参照する。特定の世界・職業・道具化の仕様を同時採用したものではない。

<a id="passive-growth-d47"></a>

### 2.23 成長ポイントによるパッシブ習得と無料の取り直し【0.47・D47で採用】

- 成長ポイントの主な使い道は、パッシブスキルの習得を想定する。最大HP・攻撃力等の基礎ステータスへ直接ポイントを配分し続ける方式を、成長の基本として置かない。
- 成長ポイントで習得したパッシブスキルは、帰還後に追加費用・ポイント損失なく取り直せることを基本にする。取り消す習得とその効果を外し、使ったポイントを戻して、別の習得へ使える。
- 探索中の習得構成の変更は行わない。帰還後の変更を次の出発へ反映し、探索中は習得済みパッシブがそれぞれの効果・条件に従って働く。
- 取り直しは、持帰り済み報酬・札解放・知識や、過去の探索全体を巻き戻す操作ではない。素材取引や札解放の取消し・返還を、この承認から導入しない。

通常の行動性能を札から取得し、主体の特殊な作用を明示パッシブとして扱う4.7・D36、ポイントと用途限定報酬を併用するD43を維持する。具体的なスキル効果・価格・ランク・前提条件・習得候補の解放方法・同時有効数・装備枠・成長上限・素材との接続は別途検討する。基礎値に関係する効果を持つパッシブを全面禁止する、すべてのパッシブを条件付きにする、という追加制約も採用していない。

採用根拠は、112章・探索全体の設計17.5への2026-09-10のユーザー補足。ユーザーは基礎ステータス的な成長をあまり想定せず、パッシブスキル習得のイメージであり、その取り直しが無償ならよいと説明した。旧数値配分案をそのまま承認された扱いにはせず、成長対象を修正して採用する。採用記録は統合検討113章、具体候補は[探索全体の設計19章](../仕様案/カード探索ゲーム_探索全体の設計.md#passive-growth-design)。

## 3. 札・領域・出現元【採用】



<a id="section-3-1"></a>

### 3.1 札が存在する領域

- 各主体の手札。
- 各主体の山札。
- 全主体が共有する場。
- 1つの共通回収山。

消滅した札は、いずれの領域にも存在しない。回収と消滅は異なる処理とする。

<a id="section-3-2"></a>

### 3.2 札の基本情報

現在の設計では、少なくとも次の情報を扱う。

| 情報 | 用途 |
|---|---|
| 属性 | 場札との一致判定 |
| 主効果 | その札を手札から出して成立させた際の効果 |
| 場での効果 | 場札として一致に使われた際の小効果・専用効果・補正 |
| 使用期限の初期値 | 手札に置ける期間を決める |
| 手札での残り使用期限 | 手札の時間経過を管理する |
| 出現元 | どの主体が初期持込・基本札生成によって供給した札か |
| 消滅に関する状態 | 補填専用札、出現元退場による次回収時消滅など |

【別資料へ分離】未採用案・未決定の詳細：[仕様案](../仕様案/カード探索ゲーム_仕様案.md#section-3-2)／試験前提・仮設定・検証メモ：[試験条件・検証メモ](../検証/統合試作/カード探索ゲーム_試験条件.md#section-3-2)。

<a id="section-3-3"></a>

### 3.3 現在の所持者と出現元

- 初期山札として持ち込んだ札は、その主体を出現元とする。
- 共通回収山を経由して他者へ渡っても、出現元は変わらない。
- 不足時に生成する基本札の出現元は、受け取る主体とする。
- 現在所持していることだけを理由に、その札を所持者由来として扱わない。
- 補填専用札は回収時消滅の規則を持つ。

【別資料へ分離】未採用案・未決定の詳細：[仕様案](../仕様案/カード探索ゲーム_仕様案.md#section-3-3)。

<a id="section-4"></a>

## 4. 属性一致と場札【採用】



<a id="section-4-1"></a>

### 4.1 通常の札使用

1. 行動主体が手札から1枚を出す。
2. 同じ属性の場札があれば、一致が必須となり、主効果が成立する。
3. 一致した場札の小効果・専用効果・補正を、今回の成立したアクションへ適用する。
4. 通常は、出した札と一致に使った場札の2枚を共通回収山へ送る。消滅条件がある札は、その規則に従う。
5. 一致先がなければ、主効果は成立せず、出した札が共有の場に残る。

【別資料へ分離】未採用案・未決定の詳細：[仕様案](../仕様案/カード探索ゲーム_仕様案.md#section-4-1)。

<a id="section-4-2"></a>

### 4.2 一致の強制と不利益

- 一致先のある札を出し、意図的に不一致として残すことは認めない。
- 別の属性・別の札を選ぶことはできる。
- 場札に負の補正を持たせることを認める。一致させてしまうこと自体が不利益になる局面を作れる。

<a id="section-4-3"></a>

### 4.3 場は全主体で共有する

- 誰が置いた札でも、全主体が一致先として利用できる。
- 場札は主効果の遅延発動予約としては扱わず、後の一致時に場での効果を働かせる。
- 標準の場札について、設置した瞬間や常時の効果を自動的に追加しない。
- 一致材料となる場札と、成立した効果を受ける行動主体は異なる。対象が敵であっても、環境が置いた札を一致材料にできる。

<a id="section-4-4"></a>

### 4.4 属性の例外

- 基本ステータスとしては単一属性を通常とする。
- 混合属性の札を存在させる場合は、非常に稀な存在として扱う。
- 他属性と一致できるようにする効果は許容する。

【別資料へ分離】未採用案・未決定の詳細：[仕様案](../仕様案/カード探索ゲーム_仕様案.md#section-4-4)。

<a id="section-4-5"></a>

### 4.5 命中と共用会心【既存の確認済み事項を集約】

- 命中度100未満の攻撃は未命中でダメージ0とし、100以上に達した攻撃で命中して命中度をリセットする。
- 会心倍率は `1＋floor（会心度／100）` とする。
- 未命中で100以上になった会心度は保持し、後の命中時に会心を発動・リセットする。
- 攻撃・防御の会心度は主体ごとに共用する。
- 一致時の会心増加量は、使用した札のステータスを参照する。主体側には現在の蓄積値を保持し、通常の加算量を行動主体の固定能力として与える前提にはしない【ユーザー補足・0.36】。

出所：[統合検討](../作業資料/カード探索ゲーム_統合検討.md)3章「確認済みとして統合する事項」。0.30で既存の確認済み事項を基本設計へ集約したものであり、新たなゲーム判断ではない。会心増加量を札から参照することは0.36で明記した。各札の具体的な加算量・上限、命中度の具体式、複数対象への完全な適用仕様は未決定。能力の参照元と場補正の対応は4.7に従う。未決定範囲は[仕様案4.5](../仕様案/カード探索ゲーム_仕様案.md#section-4-5)を参照する。

<a id="section-4-6"></a>

### 4.6 能動防御の内部規則【既存の確認済み事項を集約】

- 能動防御は防御札の一致で起動し、自分の次の札が一致するまで、規定回数だけ有効とする。
- 不一致の設置では、現在の防御を維持する。
- 防御の有効回数は、命中した攻撃へ防御を適用したときに1消費する。防御で0ダメージへ抑えた場合も消費し、未命中では消費しない。
- 防御側の会心度は、防御札が一致したときに1回加算し、実際に防ぐときには加算しない。

出所：[統合検討](../作業資料/カード探索ゲーム_統合検討.md)3章「確認済みとして統合する事項」。この内部規則の確認は、すべての防御札の性能・すべての主体の防御量を同じにする判断ではない。通常の攻防性能を札から参照し、必要な常時作用を明示パッシブとして扱う方針は4.7に従う。防御の置き換え・重ね掛けや持続軽減の演算などは[仕様案4.6](../仕様案/カード探索ゲーム_仕様案.md#section-4-6)を参照する。

<a id="section-4-7"></a>

### 4.7 能力の参照元と、防御時の場補正【ユーザー想定の明確化・0.36】

通常の行動性能は札のステータスから取得する。会心の増加量も命中・回避と同様に札ごとの性能として扱う。札が別主体へ渡った場合も、使用時の性能はその札に従う。

HP、蓄積中の命中度・会心度、現在の防御などは主体の状態として保持する。通常の攻撃力・命中・回避・会心増加量などを、主体固有の恒常能力として常設する前提にしない。大岩の常時軽減や周囲への回避支援のような常時作用は、その主体の特殊パッシブとして明示する。

| 一致材料となる場札の補正 | 攻撃札の一致時 | 防御札の一致時 |
|---|---|---|
| 攻撃に対する補正 | 攻撃への補正 | 防御への補正 |
| 命中に対する補正 | 命中への補正 | 回避への補正 |

正負いずれの補正も、この対応で今回成立する効果へ組み込む。場札の主効果を発動する意味ではなく、4.1〜4.3に従った場効果の適用である。

出所：67章の試遊後、ユーザーから会心増加量の参照元・主体の恒常能力の扱い・防御時の場補正について補足を受け、69章・D36へ記録。具体的な札性能、負の防御/回避の下限、倍率・持続効果の細部は試行として記録し、未決定詳細を仕様案に保持する。

防御札の個性を、防御量の大小だけに偏らせない。回避や会心増加など、札ごとの性能で使い分ける理由を持たせる方向をユーザーが要望した【0.37】。見切りの回避・受け流しの会心は例示であり、各札の具体値や攻防共用という新しい主効果方式の採用ではない。

大岩の遮蔽は、大岩以外のプレイヤー・敵・環境へ共通に及ぶ。支援源である大岩自身には回避支援を適用しない【0.39・ユーザー補足】。大岩自身の硬さは固有の軽減として区別する。対象範囲は効果ごとに明示し、全体作用という表現だけで発生源を含めない。

この回避支援が、残すと場を動かしにくくなる厄介な地形の個性を持つことを許容する【0.39】。自分も支援を受けられることと、攻略上どこかで除去したくなることは両立する。あらゆる環境作用を強い停滞・除去必須へ一般化せず、すべての局面で維持と除去を等価な選択にする目標も置かない。支援量・重複・解除の細部は、仕様案と記録付きの試行条件で具体化する。

<a id="section-5"></a>

## 5. 手札の補充と使用期限【採用】



<a id="section-5-1"></a>

### 5.1 手札補充

- 各主体は、自分のアクション開始前に、手札を規定枚数まで自動補充する。
- 手札規定枚数は、主体の個性を表すパラメータとする。
- 毎回残った手札を一律に捨てる方式にはせず、使用期限に従って保持・回収する。

<a id="section-5-2"></a>

### 5.2 使用期限

- 各札に1以上の整数で使用期限の初期値を設定する。
- 手札に入る際は、その札の初期値から開始する。
- 自分のアクション終了時、残った手札すべての使用期限を1減らす。
- 0以下になった札は共通回収山へ送る。回収時消滅の条件があれば消滅する。
- 他の主体の行動によって、この手札期限を減らさない。
- 主効果が成立せず場に札を置いたアクションでも、残り手札の期限は進む。
- 場に移った札には、手札の期限減算を適用しない。

期限1の強い札、抱えやすいが使いにくい札などの個性を作れる。

【別資料へ分離】未採用案・未決定の詳細：[仕様案](../仕様案/カード探索ゲーム_仕様案.md#section-5-2)。

## 6. ターゲットと情報表示



<a id="section-6-1"></a>

### 6.1 常設ターゲット【採用方針】

- 自分以外の行動主体へターゲットを指定し、その指定を維持する。
- 他者単体へのアクションは、原則として現在のターゲットへ作用する。

【別資料へ分離】未採用案・未決定の詳細：[仕様案](../仕様案/カード探索ゲーム_仕様案.md#section-6-1)。

<a id="section-6-2"></a>

### 6.2 性格と予測【採用方針】

- 敵などの行動は、性格として大まかな傾向が見える程度を目指す。
- 変更され得る現在のターゲットを精密に常時表示するより、「何を狙うことが多いか」を性格の説明に統合する方向を優先する。

- 同程度に有効な候補から乱数で選ぶことは許容する。
- 性格を厳密な公開優先順位表や、次に使う札・対象など行動内容の確定予告にするとは決めていない。行動順の表示は6.7に従う。
- 現在のターゲットを一切見せないという禁止までは決めていない。

【別資料へ分離】未採用案・未決定の詳細：[仕様案](../仕様案/カード探索ゲーム_仕様案.md#section-6-2)。

<a id="section-6-3"></a>

### 6.3 山札メニュー【採用】

- 自分の山札を、RPGのメニューのように確認可能とする。
- 山札に含まれる全種類について、現在の残数・属性・それぞれの効果をいつでも参照できるようにする。カード名と枚数だけで判断させず、札の暗記を前提にしない【ユーザー要望・0.37】。
- 現在の未ドロー分、手札、初期持込の構成を取り違えない表示にする。再構築後も、実際に自分の山札にある札を参照対象とする。
- 含まれる札のうち、どれが消滅予定になったかを把握できるようにする。
- 山札の内容確認と、全ドロー順の公開は区別する。

【別資料へ分離】未採用案・未決定の詳細：[仕様案](../仕様案/カード探索ゲーム_仕様案.md#section-6-3)。

<a id="section-6-4"></a>

### 6.4 報酬・特徴に関する知識【採用方針・0.42】

- 敵や環境の報酬・特徴は、完全把握できなくても見当をつけられるようにする。
- 未訪問の探索先にも、構築判断に使える大まかな攻略傾向を出発前から示す【D40】。突破中心、敵との戦闘が多い、といった程度の情報を手掛かりとし、初見でも目的に応じた準備を考えられるようにする。
- 敵の札構成や報酬の詳細などは、遭遇・戦闘・踏破等の経験によって明らかになる方向とする【D40で初訪問の案内との関係を明確化】。
- 初期構成についての知識と、共有循環後に相手が現在持っている札は区別する。具体的な未来の全遭遇・札順・相手の次行動の確定公開を採用したものではない。
- 実際に公開・開示された敵や環境の特徴、札構成、報酬候補の知識は、その時点で記録し、死亡・任意撤退・クリアのいずれでも保持する。次の探索の準備や攻略時にも参照できるようにする【D41】。
- 知識の保持は報酬の精算と分ける。記録に報酬候補が残っていても、その報酬の持帰り・初期山札用の札解放・能力強化を獲得したことにはしない。実際の成果は2.13・2.14に従う【D41】。
- 保持するのは開示済みの範囲であり、未公開の札・報酬や、未達成の情報解放条件を探索終了・死亡だけで埋めない。中断からの同じ探索の再開と、終了後の次探索への知識の保持を区別する【D41】。
- 公開使用を確認した札はその都度記録する。敵は初回撃破、環境は初回踏破で、その識別対象の基本となる初期山札の種類・性能・枚数をまとめて開示する【D42】。複数回の攻略や一定時間の滞在を条件にせず、遭遇中に他主体が敵を倒した場合も含む。未攻略の生存退場は含めない。
- 初攻略で開示された構成はD41に従って死亡・撤退後も保持する。敵を倒さず環境を踏破した場合、敵については観測済みの情報を残し、その敵の未開示構成は補完しない【D42】。
- 基本構成の識別を前提とし、可変構成・未識別の特殊個体へ同じ構成を保証しない。初攻略を、未確認の報酬候補・確率の全面開示、札解放や能力強化の獲得へ拡張しない【D42】。
- 具体的な案内文・分類、可変構成の識別、報酬等の残る情報解放条件、表示方式は未決定。
- 6.2の性格による大まかな予測を、次に使う札・対象など行動内容の確定予告へ変更する意図はない。

【別資料へ分離】未採用案・未決定の詳細：[仕様案](../仕様案/カード探索ゲーム_仕様案.md#section-6-4)。

<a id="section-6-5"></a>

### 6.5 状況確認と再開の支援【採用方針・表示案は未確定】

体力・山札・手札・獲得済み報酬を確認しやすくし、長い区間でも途中で休み、状況を把握して続けられる方向とする。履歴の確認は「可能ならある程度」の要望として記録し、全履歴の保存・常時表示を必須仕様にしない。

「ここまでの経過」は新しい順を基本にし、直近の出来事を長くスクロールせず確認できるようにする【0.38・ユーザー要望】。表示順などを設定で調整できることを目標とする。設定の保存範囲・履歴の件数・具体レイアウトは未決定。

履歴表示を理由に、敵の非公開手札・未来の山札順・内部の行動候補まで公開する判断は含めない。

【別資料へ分離】未採用案・未決定の詳細：[仕様案](../仕様案/カード探索ゲーム_仕様案.md#section-6-5)／試験前提・仮設定・検証メモ：[試験条件・検証メモ](../検証/統合試作/カード探索ゲーム_試験条件.md#section-6-5)。

<a id="section-6-6"></a>

### 6.6 自分の今回の行動の事前表示【採用方針・0.30】

- 札を選択した時点で、公開情報から確定する「自分の今回の行動」の結果を事前表示する方針を基本とする。
- 命中・与ダメージ・今回の一致による防御終了など、現在の場・選択札・対象・公開済み状態から確定できる結果を対象とする。
- 未来の他主体が使う札・対象選択や、未知の能力を明らかにする方針ではない。設置した札が後で残ること、準備後の追撃が同じ結果になることを、今回の確定結果として示さない。
- 採用理由は、計算を繰り返す負担を減らし、札の使いどころ・対象・許容する危険を考える時間を残すこと。

具体的な画面配置、常時表示と詳細表示の分担、条件付きの将来見通しの示し方は、[仕様案6.6](../仕様案/カード探索ゲーム_仕様案.md#section-6-6)に区分する。

<a id="section-6-7"></a>

### 6.7 行動順の見通しと逐次更新【採用方針・0.31】

- 現在の予約と、既知の条件から確定できる行動順の見通しを、常時確認できるよう一通り表示する。次に行動する主体だけでなく、それ以外の主体の順序も含める。
- 表示を「一主体につき次回1回分」に一律固定しない。さらに先まで順序が確定できる場合は、その見通しも表示対象とする。
- 各行動の処理結果に応じ、今行動した主体の待機列への挿入と、行動順の変化を逐次反映する。
- 表示された順序は、現在の予約・既知の条件に基づく見通しであり、以後の行動によって変更され得る。未選択の札に依存する将来の待ち時間など、まだ確定できない部分を確定済みとして扱わない。
- 採用理由は、設置／一致コストを「自分がどこへ戻るか」「場札を使う前に誰が介在するか」という判断へ結び付けること。札・対象など行動内容の予測方針は6.2、山札の公開範囲は6.3と区別する。

表示量、時刻数値の有無、未確定部分の見せ方、選択中の仮挿入表示、更新演出等の詳細は[仕様案6.7](../仕様案/カード探索ゲーム_仕様案.md#section-6-7)で検討する。同時刻の順やコストの具体値を、この表示方針から決定しない。

## 7. 共通回収山と山札の再構築【採用】



<a id="section-7-1"></a>

### 7.1 通常の循環

- 使用済みの札、期限切れの手札などを1つの共通回収山へ送る。
- 各主体の山札が尽きた際は、この共通回収山から山札を再構築する。
- 再構築では、その主体の規定の受取上限まで受け取る。余った札は共通回収山に残る。
- 受取上限は、手札規定枚数と同様に個性を表すパラメータとする。
- 共通回収山に札が少なく、通常より小さい山札になること自体は許容する。
- 極端な補充不能や、十分に行動できないほど小さな再構築を防ぐため、補充用の札を生成できるようにする。

通常のプレイヤー構築では「再構築の受取上限＝初期山札枚数」を基本とする【採用】。初期枚数を選ぶことで、持参札の量と通常の受取上限も決まる。これは上限の関係であり、回収山が少ない場合にも毎回その枚数を保証する意味ではない。

敵・環境や特殊な設定まで一律にこの関係へ縛る決定は含めない。

【別資料へ分離】未採用案・未決定の詳細：[仕様案](../仕様案/カード探索ゲーム_仕様案.md#section-7-1)／試験前提・仮設定・検証メモ：[試験条件・検証メモ](../検証/統合試作/カード探索ゲーム_試験条件.md#section-7-1)。

<a id="section-7-2"></a>

### 7.2 新しく登場する敵

- 初登場時は、その敵専用の初期山札を持ち込む。
- その後、山札を再構築するときから共通回収山を利用する。
- 同一主体が次イベントへ持ち越される場合は、既存の手札・山札を引き継ぐ。イベント切替だけを理由に初期山札を再支給しない。

## 8. 札不足への補充【採用・最新仕様】



<a id="section-8-1"></a>

### 8.1 補填専用札と基本札

| 種類 | 役割 | 回収時の扱い |
|---|---|---|
| 補填専用札 | 再構築時の極端な枚数不足を補う、非常に弱い補充用の札 | 回収へ送られる際に消滅する |
| 基本札 | 全体の札数が下限を割った際、必要な補充の一部として生成する札 | 通常は再循環する。出現元が退場した後は次回収時に消滅する |

- 生成する補填専用札・基本札には、受取主体の初期属性傾向を反映する。
- 基本札は受取主体を出現元とする。
- 補填専用札も、属性一致で使用したときは使用主体の会心値を加算する【採用・ユーザー補足】。主効果がないことを理由に会心加算の対象外にしない。

【別資料へ分離】未採用案・未決定の詳細：[仕様案](../仕様案/カード探索ゲーム_仕様案.md#section-8-1)。

<a id="section-8-2"></a>

### 8.2 下限判定に使う総量

**全主体の手札・山札、共有の場、共通回収山に実在する全札を合計する。補填専用札も、消滅予定札も含める。**

総量 N は、概念上、次の合計で表す。

`N = 全主体の手札枚数 + 全主体の山札枚数 + 場札枚数 + 共通回収山枚数`

- 現在存在する札だけを数える。
- 補填専用かどうかで除外しない。
- 再循環可能かどうか、消滅予定かどうかで除外しない。
- 消滅予定フラグが付いただけでは、総量を減らさない。
- 領域間を移動しただけでは、総量は変わらない。
- 実際に消滅した時点で総量が減る。生成・新規持込によって実在札が増えた時点で総量が増える。
- 将来消える札を差し引いて、基本札を先回り生成しない。

この方針は、プレイヤーに再循環可否別の枚数管理を要求しないことを重視した、最新の明示決定である。

<a id="section-8-3"></a>

### 8.3 生成の基本方針

- 実際の総量が下限未満で、山札再構築に補充が必要な際は、その補充分の一部を基本札として生成する。
- 残る必要補充分を、補填専用札で補う。
- 下限割れを理由として、退場直後などに一括で札を生成する方式にはしていない。
- 補充のために削除済みの特定の札を復活させることはしない。

総量下限と、各主体の再構築枚数は別の基準である。全体に札があっても他主体の私有領域へ偏っていれば、共通回収山は不足し得る。

【別資料へ分離】未採用案・未決定の詳細：[仕様案](../仕様案/カード探索ゲーム_仕様案.md#section-8-3)。

<a id="section-8-4"></a>

### 8.4 最新方針で検証する点

【別資料へ分離】試験前提・仮設定・検証メモ：[試験条件・検証メモ](../検証/統合試作/カード探索ゲーム_試験条件.md#section-8-4)。

## 9. イベントの終了条件・後続分岐・状態の引継ぎ



<a id="section-9-1"></a>

### 9.1 終了条件の一般化【採用・最新仕様】

探索中の敵との遭遇、障害物への対処、複数環境のある状況を、踏破イベントとして同じ終了条件・後続分岐の仕組みで扱う【0.32で明確化】。踏破イベントという名称だけで、すべての終了を環境踏破・探索区間終了・報酬保護と同一にする判断は含まない。報酬獲得と環境踏破による保護は2.13に従い区別する【0.33】。具体的な接続は[仕様案9.1](../仕様案/カード探索ゲーム_仕様案.md#section-9-1)へ区分する。

- 各イベントに、そのイベントを終了させる条件を定義する。
- 終了条件が参照する値は環境残HPに限定しない。敵の全滅、特定敵の撃破、障害物の破壊など、イベントに応じて異なる状態を参照できる。複数環境がいる場合も、どの対象・状態を参照する条件かを定義する。
- イベントは複数の終了条件を持てる。いずれかを満たせば終了する形式を取れる。
- 終了条件ごとに優先順位と後続イベントを設定する。後続イベントなしも認める。
- 同時に複数条件を満たした場合は、イベントごとの優先順位が最も高い条件を達成した扱いとして、その条件に対応する後続を選ぶ。
- 低い優先順位の条件にも、後続イベントをすべて重ねて起動する方式ではない。
- 通常の探索進行も同じ考え方で扱える。環境残HPは普段の進行条件だが、常に必須となる唯一の条件ではない。

データ上の最小単位は「終了条件・優先順位・後続イベント（なしを含む）」という関係で整理できる。

【別資料へ分離】未採用案・未決定の詳細：[仕様案](../仕様案/カード探索ゲーム_仕様案.md#section-9-1)。

<a id="section-9-2"></a>

### 9.2 許容する終了条件の構成例【採用した設計の幅】

| イベント例 | 終了条件の例 | 結果 |
|---|---|---|
| 通常の進行 | 環境残HPが所定の条件を満たす | 次への進行。環境残HP以外の条件も設定可能 |
| 大岩による通行の阻害 | 大岩の破壊、または環境への進捗が迂回条件に達する | 破壊して進む／迂回して進む、という異なる後続を設定できる |
| 複数環境への対処 | 個別の環境や複数の状態を参照する、イベントに設定した条件 | 一部への対処後に残りを継続する場合や、別経路へ進む場合などを個別に設定する |
| 通常戦闘 | 環境以外の敵全滅、または環境残HPが一定以下 | 全滅・逃走のどちらで終えたかに応じて後続を変えられる |
| 特定敵の撃破で終わる戦闘 | 指定された敵・ボス格の撃破 | 他の敵が生存していても戦闘イベント自体が終了する |
| 逃走不能のボス戦 | ボス撃破等の戦闘決着条件、または現在の環境の踏破 | 環境踏破が選ばれた場合は、緩めの新環境と同じボスとの戦闘へ移る。逃走成功へ接続しない形で逃走不能を表せる |

これらは作れるイベントの種類を示す。具体的な敵、閾値、後続イベント、報酬や発生頻度を採用したものではない。大岩破壊と迂回の両方に報酬獲得の見返りを持たせる方針は2.13へ明記した。進行条件として岩を破壊できることと、環境踏破の保護条件を満たしたことは別に扱う。

ここでの「逃走不能」は、戦闘を離れて探索を続ける逃走経路がないことを指す。探索全体を終える任意撤退は2.12の別の扱いであり、この表によって禁止するものではない。

<a id="section-9-3"></a>

### 9.3 同時達成とイベント更新【採用・最新仕様】

- 成立した一手の効果は、途中でHP0やイベント終了条件を満たしても最後まで解決する。その効果を解決し終えるまで、撃破に伴う退場やイベント切替を行わない【採用】。
- 行動者が効果途中でHP0になっても、その一手で成立済みの相手への攻撃などを取り消さない。敵撃破や環境踏破を理由に、同じ一手の場効果による負担を途中で免除しない。
- 主効果と場の補正を今回の効果へ組み込む方針を維持する。「主効果を先、場効果を後」のような固定した逐次処理順を、この判断によって追加しない。
- 同じアクションで満たした終了条件を、イベントを変更する前にまとめて判定する。
- 次のイベントによる条件再設定を、元のイベントにおける達成判定へ遡って適用しない。
- 同一イベントの終了条件が複数成立した場合は、9.1のイベント別優先順位に従って一つを選び、その条件に対応する終了処理・後続イベントを実行する。
- 敵単独の逃走も、対応する終了条件が選ばれた場合に実行する。条件を満たしていても、より高い優先順位の条件が選ばれた場合、その敵の逃走を別途成立させない。
- 条件をまとめて判定することと、各条件に対応する出来事をすべて発生させることを区別する。従来の「同時に条件を満たした各主体の離脱をすべて確定する」案は、この選択方式に更新する。

HP変化やHP0に関する従来の基本規則は維持する。未選択の逃走条件だけを理由にその敵を退場させたり、出現元退場による札処理を行ったりはしない。選ばれた終了処理・後続イベントで別途指定される退場は、その指定に従う。

通常の敵撃破報酬の帰属は2.15に従う。死亡による探索終了が確定した場合の報酬精算は2.13に従う。

【別資料へ分離】未採用案・未決定の詳細：[仕様案](../仕様案/カード探索ゲーム_仕様案.md#section-9-3)。

<a id="section-9-4"></a>

### 9.4 環境の踏破・交代と戦闘継続【採用方針・最新仕様】

- プレイヤーの逃走成功を戦闘イベントの終了条件として扱い、その条件が選ばれた場合に戦闘を終了させる構成にできる。
- イベントが終了しても、その後続イベントで同じボスとの戦闘を続けてよい。イベントの終了と、戦闘全体の決着を区別する。
- ボス戦でも、現在の環境のHPを削り切ることをイベント終了条件に含める。
- 環境踏破の条件が選ばれた場合は、現在の環境が離脱し、新しい緩めの環境が参戦する後続イベントへ移る。
- プレイヤー・ボスなど継続する主体の状態は、9.6の通常の引継ぎ規則に従う。
- 「環境が動き続ける」意図は、HP0の同一主体を残すことではなく、交代後も環境が行動主体として参加する形で実現する。
- この環境交代により、環境の削り切りを「今いる環境の踏破」として扱い、既存の終了条件・後続イベント・退場処理へ統合する。
- 交代後の緩めの環境には、ボス戦中に削り切れない性質を持たせる方向で検討する。

旧環境踏破・環境交代後の、ボス撃破による進行は環境ごとに設定できる【採用】。全環境で一律に固定せず、終了条件に対応する後続イベントとして次の両方を表現できるようにする。

| 環境ごとの設定 | ボス撃破に対応する終了条件が選ばれた場合 |
|---|---|
| 追加踏破を要求しない | 交代後の環境の残HPによらず、次のフェーズへ進む |
| 追加踏破を要求する | 交代後の環境の攻略を続け、その踏破を次の進行に必要とする |

追加踏破を要求する場合も、継続する環境の残HPなどは9.6に従って引き継ぎ、イベントに明記された変化だけを適用する。

旧環境が実際に退場するため、10章の出現元退場による札の扱いを適用する。他主体の手札・山札や共有の場に残る旧環境由来札は、次の回収まで使える。環境交代だけで流通中の札がすべて新環境の札へ置き換わるわけではない。

<a id="section-9-5"></a>

### 9.5 敵の単独離脱・イベント再設定【採用・最新仕様】

- 同一の環境のHPは共有であり、誰が削った分でも、その残HPを参照する各主体の離脱条件に寄与する。複数環境のHPを一つの値へ合算する意味ではない。
- プレイヤーの離脱条件を他主体の行動が満たすことも認める。そのためにプレイヤー自身が最後の環境ダメージを与える必要はない。
- 敵単独の逃走をイベント終了条件の一つとして表す。その条件が優先順位に従って選ばれた場合に、その敵を離脱させ、残る敵との戦闘へ移る構成にできる。
- 離脱などを契機に、別のイベントを開始して戦闘を継続してよい。
- 残る主体の離脱条件を「引き継ぐ／再設定する」はイベントごとに定義する。
- 再設定によって、離脱までに必要な環境HPの削減量が増えてもよい。
- 単に敵1体が逃げる場合は進捗を引き継ぎ、増援を呼んで逃げる場合は再設定する、という使い分けを許容する。

プレイヤーの逃走、特定敵の撃破、敵単独の逃走に対応する終了条件が同時に満たされた場合も、イベントごとの優先順位で一つを選ぶ。敵単独の逃走が選ばれなければ、その条件に対応する離脱・増援・条件再設定は実行しない。

### 9.6 状態の引継ぎ【採用】

イベント切替でも、残る主体のHP・手札・山札、共有の場札・共通回収山はそのまま引き継ぐ。イベントに明記された変化だけを適用する。

同一主体が追撃などで次イベントへ持ち越される場合と、継続中のプレイから退場する場合を区別する。特定敵撃破でイベントが終了する際に、生存している他の敵を持ち越すか退場させるかは、個別の後続設計で決める必要がある。

### 9.8 イベントの発生と探索を進める圧力【採用方針・許容する手段】

- 固定の時間制限や遭遇周期を採用したわけではない。
- 環境自身が札の効果で自傷し、環境HPの減少によって進行する仕組みを、進行を促す手段として認める。全環境への必須搭載は未決定。

実装上の留意点：自傷が主効果だけにある札を、プレイヤーが場から一致材料として取っても、その主効果は発動しない。取る主体へ負担を生じさせるには「場で一致に使われたとき、今回の行動主体へ自傷を与える」場効果が必要となる。不一致で置くだけでも自傷する、常時自傷する、といった例外は追加していない。

## 10. 退場した主体の札【採用】



<a id="section-10-1"></a>

### 10.1 退場時の返却

- 継続中のプレイから退場する主体の手札・山札は、撃破・逃走のどちらでも共通回収山へ送る。
- その主体が以前置いた場札は、共有の場に残す。
- 次イベントにも持ち越す主体は手札・山札を保持する。

<a id="section-10-2"></a>

### 10.2 出現元の退場による消滅予定

出現元が退場した札には「次の回収時に消滅」の状態を付ける。

| その出現元に由来する札の所在 | 出現元退場時と、その後の扱い |
|---|---|
| 退場する本人の手札・山札 | 退場時の回収処理で消滅する |
| 他主体の手札・山札 | その場では残り、次に回収へ移る際に消滅する |
| 共有の場 | 一致材料・補正として残り、回収へ移る際に消滅する |
| 共通回収山 | 出現元の退場時、その場で消滅する |

- 手札の期限切れや、別効果による回収でも、回収時消滅を適用する。
- 不一致で場に置くこと自体は回収ではない。その時点では消滅しない。
- 消滅予定になっても、主効果・場での効果・使用期限の通常ルールは維持する。
- 退場者が持っている他者由来の札を、所持者の退場だけで消滅予定にしない。ただし、その札自身が既に消滅条件を持つ場合は適用する。
- 追撃などで同一主体を継続して扱う場合は、イベントが変わったことだけで出現元退場の状態を付けない。

<a id="section-10-3"></a>

### 10.3 ねらいと限界

敵の影響は、退場と同時に全領域から消えるのではなく、手元や場に残った札が使われて回収されるにつれて薄れていく。これは探索ゲームの雰囲気と、残存札を利用する判断を両立させるための方針である。

回収山内の退場者由来札が長期に蓄積することは防げる。一方、手札・山札・場へ残る期間や、同時に登場する主体数によって、実在札の総量は変わる。固定の総量上限を採用したわけではない。

<a id="section-11"></a>

## 11. 許容した効果の方向【採用した設計の幅】

以下の効果の存在を許容する方針は採用済み。具体的なカードとしての採用枚数・数値・頻度は別途判断する。

- 一致に使った札を、今回の効果処理後に回収へ戻さず消滅させる。
- 一致に使った札以外の場札も、条件に従って回収山へ送る。
- 手札全体の使用期限を一定量減らし、結果として期限切れ札を入れ替える。
- 山札先頭など、自動で特定される札を回収・消滅させる。
- 手札全体の回収・消滅など、個別選別を要求しない整理効果。
- 一致先として認める属性を広げる。
- 行動順を補正する。

場札をそのまま完全消滅させる効果は、大技として扱う。日常的な整理手段として気軽に使える設計にはしない。

<a id="section-11-1"></a>

### 11.1 札ごとの行動コスト【採用した調整方針】

今回の札の効果は現在の行動内で処理し、コストを次の自分の行動までの待ち時間へ反映する【採用】。ここでの時間はゲーム内の行動時刻を表す。コストにより今回の効果の発動を待機させる方式ではない。

行動頻度に関する方針【採用】：

- 低コスト札を使う主体が、他主体より多く行動できることは許容する。
- ただし通常のバランスでは、各主体の行動回数がおおむね同じになることを目指す。低コスト札を使うだけで恒常的に大きな手数差を得ることは目標にしない。
- 主な理由は、不一致で置いた札を他主体に使われる前に自己再利用する動きが、このゲームでは強くなりやすいため。
- 回数差や自己再利用を全面禁止したわけではない。

## 1. 日常と、数多の世界を行き来する

不思議が一見見えない日常の町に、帰る場所がある。その裏側に通じる道から、数多の世界へ旅に出る。現代に近い暮らし、店、古い建物、仕事の相談が届く小さな窓口を、未知の場所への出発点にする。

旅先は、それぞれに住人の暮らしや来歴を持つ。夢が具現化した場所、物語が現実へ入り込む街、世界の裏で続いていた魔法、かつての文明の遺構、巨獣の背と内部などを広く含められる。不思議の由来を一種類へ統一しない。

日常と異界は行き来する場所であり、探索を終えるたびに訪問先そのものが消える前提にはしない。出会った人、残る疑問、未調査の区域が、再訪や次の旅につながる。

## 2. 主人公の仕事と、奥へ進む理由

主人公は異変を調べる仕事を行う探索者。日常や旅先から相談を受け、現地に入り、原因と影響を確かめ、必要な対応へ進む。危険な場所に入って調査を続けられること自体が専門性になる。

主な案件には、深部でしか確認できない事実や、その場に行かなければ行えない対応がある。水の流れ、住人の証言、記録、現象の変化などをたどることで、奥へ進む理由が現地で明らかになる。

道中の副目的には、経路や土地を調べる踏査、住人や出来事の取材・記録、価値ある品や資料の回収を置く。全てを毎回の必須課題にはしない。途中の成果を持って帰る判断と、さらに奥を目指す動機を両立させる。

出発時に分かるのは、相談された症状や場所、大まかな見通し。真相、解決方法、得られる不思議まで事前に知る必要はない。特定の道具の調達は、発見後に生まれる個別目的にもなる。

## 3. 不思議を具体的な道具にする

主人公は、出会った不思議の概念や働きを取り込み、具体的な道具にできる。既存の道具へ何かを宿すことを中心には据えず、不思議そのものを使える一つのツールへ形にする。

道具を**札の形で持ち運べる**方向で具体化する。札は道具と世界観をつなぐ携行形態でもある。「道具を札の姿に畳み、開いて使う」という具体的な見せ方、場札との対応、材質や所作は[用語検討](../../仕様案/世界観/用語検討.md)3章の案として詰める。

対象は怪異、夢、物語、魔法、遺構などにまたがる。これらは例示であり、対象の閉じた分類ではない。未知の働きを知ることが、探索中に使える手段の広がりにつながる。

生業を道具制作や注文品の調達へ限定しない。能力の由来、全ての不思議を必ず取り込めるか、他者への道具の譲渡、道具化に伴う対象の変化は、別に定める。札の共有利用・出現元・消滅・恒久解放のゲーム規則は[基本設計](../カード探索ゲーム_基本設計.md)に従う。

## 4. 知られ方と、往来の痕跡

不思議や入口の知識は、人や地域によって偏っている。日常の問題として見過ごす人も、一つの裏口や言い伝えを知る人もいる。相談は店や建物の管理者などを介して調査の窓口へ届く。

世界の境目には、それを利用してきた往来の痕跡がある。道標、宿、渡り場、倉庫などが残り、使われる道も途絶えた道もある。中継地は地域の往来を支える施設として扱い、全世界を生んだ唯一の装置へ集約しない。

主人公が関わる範囲は、身近な異変から、世界間の往来、旅先の住人が抱える問題へ広がる。日常に帰る窓口は残り、知り合いと仕事の範囲が増えていく。

## 5. 異変と探索の扱い

ゲームの意味的な中心を**探索と突破**に置く。足場や筋道を探り当て、有効に働きかけて先へ進む。敵対者との戦闘も、動きや輪郭を見極め、通れる状況へ近づける一つの表現として扱う。威力は進展の大きさ、命中に相当する働きは手早く確かに捉える力として具体化する。新しい戦闘専用の世界法則や数値規則はこの意味付けだけで加えない。

向こうでは自然な働きがこちらへ入り込んだ場合、設備の故障、制御を離れた存在、誰かの意図した行為など、異変の原因には幅がある。調査は、その世界で何が普通で、誰がどう困っているのかを知る行為でもある。

全案件を即時の人命危機にはせず、帰還して準備し、複数回の探索で進められる案件も含める。事件の解決後も土地や関係は残る。初回の解決と反復探索の具体的な接続は、内容設計で詰める。

一つの世界、一つの探索先、一回の探索、一件の案件は、必ずしも同じ範囲ではない。一回の探索で世界の境目を越えてもよい。境目を越えることだけを回復・帰還・報酬確定の契機にはしない。

## 6. 個別化を続ける範囲

大枠の採用と、次の詳細を区別する。

- A〜Eの案件・探索名・敵・道具は、[具体化の資料](../../仕様案/世界観/世界観候補.md)10章にある内容案。五探索という総量や解放の閾値を、世界観の承認だけで固定しない。
- 主人公の名前・年齢・種族・所属、事務所の固有名、世界全体の起源、言語や時間差、死亡後の物語上の扱いは未確定。
- 追加の背景は[背景断片](../../仕様案/世界観/背景断片.md)、正式名称の検討は[用語検討](../../仕様案/世界観/用語検討.md)へ分ける。今回新しく出した名称まで承認済みとはしない。

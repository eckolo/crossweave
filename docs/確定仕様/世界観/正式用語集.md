# crossweave — 正式用語集

版：1.3／2026-09-12。状態：現行の正式用語と、明示的に区別した正式名の仮置き。担当：`20260910-worldbuilding`。

ユーザーの「いったん今の用語を正式版として保存しておいて」に基づき、用語検討0.4から現行の呼び方を採用した。採用の原記録は[検討記録19章](../../作業資料/世界観/検討記録.md)。今後の世界観案では本書を参照する。

1.1では、後続のユーザー指定によりHP相当の残量表示名を行動主体ごとの設定へ変更した。未設定時は余力、道の例は道のり、障害物の例は耐久。原記録は検討記録20章。成長・取得・心得準備の追加語は[専用の用語検討](../../仕様案/世界観/成長・取得・心得準備の用語.md)で比較し、現行正式名と分ける。

**一閃は現行の正式名として使う。** よりよい呼称が見つかった場合の改称余地は残すが、未命名や選択待ちには戻さない。旧名・比較案は[用語検討](../../仕様案/世界観/用語検討.md)とGit履歴で追える。

**1.2では「着想」を正式名候補として仮置きする。まだ本決まりではない。** ユーザーの「他に良い案が出なければ着想を正式名として採用していく」に従い、今後の世界観検討では着想を用いる。従来名の習得点との対応を残す。一閃の「現行正式名・将来改称可」とは確度が異なる。原記録は[検討記録23章](../../作業資料/世界観/検討記録.md)。

名称の採用と、札・心得・探索先の内容採用は別。既存の内容案に付けた名称も現行名として扱うが、効果・価格・配置・取得条件まで今回一括確定しない。方式自体が未定のものは、その状態を保持する。

## 1. 世界と主人公

主人公の職業は**辿り屋**。異変の筋道を辿り、原因のある場所まで辿り着いて調べる。主業は異変調査、踏査・取材・記録・現地回収が副目的になる。

日常の町から裏道を通り、異界や渡り場を訪ねる。出会った不思議の働きを道具化し、札の形で携える。道具の名前は形を必ず含めず、「ひと息の休息」という水筒や「綻び縫い」という針があってよい。詳しい大枠は[世界観設定](世界観設定.md)。

### 2.1 残量表示名は行動主体が持つ

各行動主体に、HP相当の数量へ使う**残量表示名**を設定できるようにする。個別指定がない場合の共通既定値は**余力**。主人公だけの既定値ではなく、敵・環境も同じ規則で表示する。文字のない未設定状態も余力へ戻す。

| 行動主体の例 | 個別の残量表示名 | 表示例 | 攻撃相当の行動名の例 |
|---|---|---|---|
| 主人公 | 未設定 | 余力 18 / 30 | 対象が持つ行動名を使う |
| 敵対する獣 | 未設定 | 余力 18 / 30 | 攻撃 |
| 道 | 道のり | 道のり 18 / 30 | 進む |
| 岩などの障害物 | 耐久 | 耐久 18 / 30 | 壊す |

数値は表示の仮例。道のり・耐久は内容に応じて選ぶ例であり、環境や障害物という分類に固定する規則ではない。同じ分類でも主体ごとに別の名を設定できる。

道のりは**残っている道のり**を指し、進むと減る。同じHP相当の現在値・最大値を表示し、移動済み距離や実距離の単位へ変換しない。詳細では「現在値」「最大値」と組み合わせ、当該対象の残量0を探索全体・案件全体の完了と同一視しない。

旧版の対象共通表示「踏破まで」は、現行の一律表示から外す。行動名、残量表示名、数量の増減・退場条件は別に扱う。表示名を道のりや耐久へ変えても、HP相当の演算は共通のまま。同じ主体を示すゲージ・詳細・履歴等は、その主体の表示名を参照する方針とする。

### 2.2 隠蔽と一閃

隠蔽は残量M−L、攪乱は今回の探査を通りにくくする作用として区別する。隠蔽には自然に見えない状態も含む。敵の動き、道筋、岩の亀裂などを捉え、一度解決した後は次の有効な箇所を捉え直す。恒久的な調査記録を消す意味にはしない。

D48の閾値、初回1倍、超過100ごとの加算、共有累積、進展0を含む解決後のリセット、一閃の保持・消費、同一主体の状態継承は[基本設計](../カード探索ゲーム_基本設計.md)に従う。名称の採用だけで演算を変更しない。

## 3. 行動名と循環

攻撃相当の行動名は対象側の設定で決まる。敵なら攻撃、道なら進む、岩なら壊す、迷路なら探す等。同じ種類でも動かす・解くなどを設定できる。数量名は共通。回復・身構・不一致の設置はその処理に合う表示を使う。

| 処理・場所 | 正式な呼び方 |
|---|---|
| 今使える札／次に巡る札 | 手札／山札 |
| 一致に使える共有の働き | 場／場札 |
| 使用後などの札を置く共有領域 | 捨て場 |
| 手札・場などから捨て場へ送る | 捨てる |
| 捨て場から山札へ戻す | 回収 |
| 不足時の生成を含む再構築全体 | 山札の補充（設計上は再構築） |
| 旧「回収時消滅」 | 捨てる時に消滅 |
| 不一致の場への配置 | 設置／場に出す |

1.3で存在上の説明を更新：場札と捨て札は、世界内では主人公の実体札そのものではなく、放たれた不思議を札として表したもの。場へ出す／一致させることは道具の不思議を放つ行為に対応する。画面上で厳密な描き分けは不要。借り札も共有循環上の由来を示す語で、展開道具の貸与を受けた証明ではない。名称・全184用語IDと処理区分は維持する。原記録は[検討記録27章](../../作業資料/世界観/検討記録.md)。

捨てる時の消滅を、新語の回収時まで遅らせない。出現元が退場した際、既に捨て場にある由来札の即時消滅も保持する。手動の捨てる・回収操作を新設する指定ではない。

## 4. 属性の名称と追加基準

現行の属性語は**流動・重圧・変容・境界**。不思議の出所ではなく、何にどう働くかを表す短い抽象名詞として使う。試作用A〜Dへの割当と全体の属性数は、この用語採用だけでは固定しない。

| 属性 | 主に表す働き |
|---|---|
| 流動 | 流す、運ぶ、向きを逸らす |
| 重圧 | 重みや圧を掛ける、押す、押し留める |
| 変容 | 形・性質・状態を変える、戻す、繕う |
| 境界 | 隔てを作る・保つ・緩める、通す、閉じる |

新属性は働きを一文で定義し、複数の由来・複数の役割に適用できるか、既存属性との違いを複数の道具と場の例で示せるかを確認する。夢・怪異・文明は由来、突破・回復は役割であり、属性とは別。属性語から固有ボーナスを自動追加しない。

## 5. 成長・成果の呼び方

主人公が習得する特性は**心得**。習得点と呼んでいた資源には、**着想**を正式名候補として仮置きする。別資源を増やす変更ではない。帰還後の取り直しは**心得の組み直し**。既知情報は**調査記録**、今回の持帰り対象は**成果**として分ける。

| 対応 | 今回の扱い |
|---|---|
| 習得点・成長ポイント | 着想を仮置き。よりよい案がなければ正式採用へ進める方向で、本決まり前 |
| 資源の用途・支出・返還・変換 | 同じ既存資源として維持。名称から数値や資源取得の規則を変更しない |
| これから作る世界観案・表示検討 | 着想を使い、資料の採用区分で仮置き中と明示する |
| 既存の設計資料・UI・コード | 習得点を同じ資源の従来名として読めるよう対応を保持。全置換・実装完了とはしない |

説明の基盤は、ユーザーの「探索で得た着想から今後の探索の心得を習得する」という営みをゲームのシステムで表すこと。支出・返還の各点へ細密な実体設定を与えることは必須にしない。従来の蓄積という比喩も使えるが、知った事実そのものを消費する定義にはしない。「必要着想」「戻る着想」等の文言は[専用資料](../../仕様案/世界観/成長・取得・心得準備の用語.md)で検討する。

取得物を手放して資源にする現行の呼び方は**変換**。心得の習得を外した際の習得点の全額返還とは別。修飾、複数所持、限定的な同時利用の基本方向はD50〜D52に従い、装備枠・装備可能コスト等の具体方式は引き続き設計側の検討対象。

装備容量・個別コスト・取得候補・個体入手の呼び方は、[成長・取得・心得準備の用語](../../仕様案/世界観/成長・取得・心得準備の用語.md)へ集約した。心得容量、負荷、備える等は引き続き名称案。知見は以前の資源名候補であり、現在の仮置き名は着想とする。

## 7. 運用

新しい世界観案は本書の呼称を使い、案そのものの採用状態は個別に記録する。検討資料の旧語は履歴として残す。共通設計・UI・ゲームコードへの実際の受入れは各担当の作業として行い、本書の保存を実装完了とはしない。

一閃を将来改称する場合も同じ意味・演算との対応と旧名を残す。呼称の確定を、発動条件や演出方式の固定と同義にしない。

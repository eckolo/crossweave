# 実行フォルダーの入替とセーブ

1. crossweaveを終了し、ウィンドウが閉じるまで待ちます。
2. 必要なら `%APPDATA%\crossweave\saves\local` をエクスプローラーで開き、フォルダーごと控えを取ります。
3. 新しい版の実行フォルダーを、旧版とは別の場所へフォルダーごと配置します。中のサブフォルダーもすべて必要です。旧版へ上書きして混在させないでください。
4. 新しいフォルダーの `Crossweave.exe` を開き、「続きから」を選びます。途中の進行・所持・編成が保持されているか確認します。

セーブは実行フォルダーの外にあります。セーブの削除・初期化は不要です。新旧アプリを同時に起動しないでください。

今回のW8は、同じ実行一式を別フォルダーへコピーして同じ保存から再開する確認です。将来の異なる版・保存形式への移行保証とは区別します。問題が出たら終了し、表示内容と直前の操作をこのWorkへ返してください。

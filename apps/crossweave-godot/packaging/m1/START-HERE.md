# crossweave 本編 — はじめに

1. 受け取った実行フォルダーを、サブフォルダーごとWindowsのPCへ揃えます。Dropbox同期を使う場合はフォルダー全体をオフラインでも利用できる状態にし、同期完了を待ちます。既に同じ一式が揃っていれば再取得は不要です。
2. 実行フォルダーの **Crossweave.exe** を開きます。ほかのファイル・フォルダーも一緒に置いておきます。Python、.NET SDK、Godotエディターの導入や追加ダウンロードは不要です。
3. 初回は「新しく始める」、再開は「続きから」。準備を整え、夜潮の排水路へ出発します。札のクリックは詳細、短く保持してから中央へドラッグすると使用です。右クリック／Escでドラッグを取り消せます。本文を読んだら「続きを読む」で進みます。
4. 確定操作ごとに自動保存します。探索の「中断して終了」は撤退ではなく、続きから再開できます。終了操作の後、保存処理が終わりアプリが閉じるまで待ってください。準備の未確定変更は確認して破棄するか、戻って確定します。

## セーブと更新

保存先は `%APPDATA%\crossweave\saves\local\m1.json` です。エクスプローラーのアドレス欄へ `%APPDATA%\crossweave\saves\local` を貼り付けると開けます。バックアップ等もこのフォルダーにあります。アプリ終了後にフォルダーごと控えを取れます。

更新時は旧版を終了し、新しい実行一式を**別の新規フォルダーへフォルダーごと配置**して、そのCrossweave.exeから「続きから」を選びます。保存フォルダーは消さず、新旧アプリを同時に起動しないでください。旧版の実行物へ上書きしてファイルを混在させないでください。今回確認するのは保存形式v1の同一配布物の入替で、将来の全版への互換保証ではありません。

「保存失敗」は画面の案内に従って同じ要求を再試行します。成否不明で操作が止まった場合は「読直し」の確認を行い、確定状態を読んでから進みます。破損時の復旧は確認付きです。保存ファイルを消して初期化することを通常の対処にしないでください。

## 起動できないとき・実機の確認

Windows 11 x64を実機確認対象にしています。未署名の限定配布版です。ブロックされた場合は、表示された文面・スクリーンショット・Windows版を返してください。セキュリティ設定の無効化を通常手順にしません。

エラーや表示崩れは、実行フォルダー名、PC／GPU、画面倍率、直前の操作、画像を添えて報告してください。ログは `%APPDATA%\crossweave\logs\godot.log` です。個人情報を含むPCパスは必要に応じて伏せてください。

実機の確認依頼を受けた際は、同梱の「Windows11確認票.md」を使います。CIの合成操作と実描画は、実マウス・DPI・音・GPU性能の合格を意味しません。今回の初回確認は「起動→短い探索→中断して終了→再起動して続きから」です。一巡・倍率・性能などは、その結果を返してから同じ確認票で進めます。

詳しい入替手順は同梱の `更新案内.md`。初回は使ったフォルダー名、Windows 11か、画面倍率、マウス／タッチ、起動と再開の結果をこのWorkへ返してください。開発用の起動スクリプトやファイルごとのhash計算は不要です。

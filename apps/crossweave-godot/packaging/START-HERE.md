# crossweave — Godot代表試作 RD-PROOF-02

Windows 11 x64向け。これは基盤と操作の検査用で、本編・M1完成版ではありません。

1. ZIPを**すべて展開**し、`start-proof.cmd`または`Crossweave.Proof.exe`を開きます。exeだけを移動しないでください。Godot・.NET SDK・Node.jsの導入は不要です。
2. 読込み画面の後、札が3枚ある場面が開きます。既存の札名・属性を使い、一致／設置と共通回収だけを検査します。戦闘ダメージ・経済・期限・本編進行は未実装です。
3. 札をクリックすると詳細窓。同じ札の再クリック、外クリック、Escで閉じます。札を220ms保持してから場へドラッグすると出札します。保持より前の横移動は横送りです。今回の3枚は収まるため移動量を小さく制限しています。
4. 「牽制」を出した直後、移動演出中に「踏み込み」を選んで「出す」。確定2回・回収4枚になります。連打で追加確定しないこと、取消後に札が出ないことを確認してください。
5. 専用保存は右下のカウンターです。「＋1」→「保存」→ウィンドウを閉じる→再起動→同じ数値になることを確認します。盤面はメモリー保持のため毎起動初期化します。
6. F11で全画面、F12で検査用スクリーンショット。「音を確認」で短い検査音を鳴らします。
7. `Windows確認票.md`に結果を記入します。確認票と、下記フォルダーの`metrics.json`・必要なら`screen.png`を返してください。普段のゲーム保存や端末内の他ファイルは不要です。

保存・検査記録：`%APPDATA%\crossweave\proofs\rd-proof-02\manual\`

- `probe.json`：版付きの専用小状態。本編`m1.json`は使いません。
- `metrics.json`：閉じた時の起動・フレーム・メモリー等。イベント処理時間は物理入力から表示までの遅延ではありません。
- `screen.png`：F12で保存した場面。

`verify-restart.cmd`は別スロットでプロセス再起動を自動確認します。画面・マウス・音・GPU・倍率の確認は代行しません。

署名・SmartScreen等で起動を止められたら、警告文とファイル版・hashを記録してください。セキュリティ設定の無効化は標準手順に含めません。

更新試験・正式セーブ互換・複数起動の所有権は今回の合格範囲に含めません。本試作を二重起動して同じ専用保存を同時編集しないでください。
